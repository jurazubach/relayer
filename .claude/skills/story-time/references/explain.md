# Объясни: почему время устроено так

Для автора — коротко «почему», откуда правило и упражнение, чтобы сделать самому. Правило целиком — `npm run -s
story:rule R-NN`; источник — `алиас:ID` из [sources.md](sources.md); сила урока — [lessons.md](lessons.md).

## Почему персонаж не говорит, когда вернётся

Игрок в реальном времени живёт своей жизнью, а «напишу через час» превращает персонажа в будильник: игрок
начинает сверять часы, и любое опоздание читается как поломка. По клику обещание вообще ложное: следующее
сообщение приходит через секунду. Причина ухода («иду к щитку») при этом нужна — без неё тишина выглядит как
сбой. Откуда: R-63, решение A-01; база спорила — `contradictions.md`, спор 1.

**Упражнение.** Возьми три паузы своей главы. Для каждой напиши реплику-дело без единого слова о времени
возвращения и первую строку после — результат этого дела. Проверь: `promise-scan.mjs --story <id>`.

## Почему напоминаний не больше двух

Одно-два напоминания возвращают того, кто смахнул уведомление; третье — уже давление. После них персонаж
решает сам: история не стоит, и игрок, вернувшись, видит последствие, а не упрёк. «Не ответил» стоит ровно
столько, сколько «Промолчать», — иначе мы наказываем за то, что человек был занят. Откуда: R-120, A-03.

**Упражнение.** Выбери развилку, где собеседник ждёт решения. Напиши два напоминания: второе с новой деталью
мира. Реши, хватит ли `#silent` или нужна своя ветка `#noanswer`. Прогони `npm run -s story:trace -- --story <id>
--compare silent`.

## Почему обижаться можно только на «Промолчать»

Нажатый `#silent` — ход игрока, на него честно ответить, даже обидой. Пауза, которую поставила история, или
молчание игрока у кнопки — не ход: упрекнуть за них — значит наказать за правила формата или за жизнь вне игры.
Откуда: R-74; решение королевы T-08 о границе; `attention-today:P-10`.

**Упражнение.** Найди строки-упрёки: `guilt-scan.mjs --story <id>`. Для каждой с ✗ перепиши реакцию без
обвинения: что персонаж сделал сам, пока игрока не было.

## Почему «доброе утро» — время мира, а не игрока

Мы не знаем, где и когда игрок: у одного четыре утра, у другого обед. Угаданное время ошибается у каждого
второго, а время мира, рассказанное событием («у нас светает»), правдиво в любой час. Откуда: R-121, A-02.

**Упражнение.** Пройди `clock-scan.mjs --story <id>`: каждая метка времени мира — сверь с хронологией
`facts.md`, каждая пара «сплю → утро» — с ночью мира.

## Почему текст один на оба режима

Режимы равноценны: тот, кто не хочет ждать, получает ту же историю. Поэтому ничто не держится на прожитом
ожидании — после скачка приходит событие, которое само объясняет время. Откуда: R-122, A-04; риск — урок
`messenger-genre:LESSON-10`.

**Упражнение.** Прочитай главу через `click-transcript.mjs --story <id>`. Отметь места, где по клику что-то
звучит странно; каждое — событие вместо ожидания.

## Почему история не дольше трёх дней

Каждая пауза — шанс, что игрок не вернётся; интерес живёт дни, а не недели. Ночь — на стыке глав, внутри главы —
паузы короче, к развязке ещё короче. Откуда: R-67, A-05; уроки inkle и веб-романов в `lessons.md`.

**Упражнение.** `npm run -s story:sessions -- --story <id>`: найди три самые длинные паузы внутри глав и реши для
каждой — сократить или перенести на стык.
