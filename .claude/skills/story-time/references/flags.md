# Признаки: что видно и чем ловить

Красные — дефект, зелёные — как выглядит хорошо. В колонке «чем ловить» — команда или ключ; «глазами» — где
замера нет и судит модель (помечай «модель» в находке).

## Красные

| признак | чем ловить | как чинить |
|---|---|---|
| перед паузой персонаж называет срок («утром напишу», «через час») | `C-27.deadline`; `promise-scan.mjs` | причина без срока (ST-60); срок события мира оставить с `// намеренно:` |
| пауза посреди разговора без причины | `C-27.long_h`, `C-27.unexplained`; `promise-scan.mjs` | реплика-дело + «не в сети»; или событие в другом чате |
| пауза посреди перечисления («код — 4, 7…») | `C-27.midlist` | паузу после выбора или данные целиком после паузы |
| после напоминаний история стоит | C-32 п. 6 (`story.reminders.max`, «стоит») | `#noanswer` или `#silent` у развилки |
| напоминаний больше предела, второе повторяет первое | C-32 п. 6; `guilt-scan.mjs` | два разных, второе с деталью |
| «не ответил» теряет вариант или финал, которые есть у `#silent` | `C-32.no_answer`; `story:trace --compare silent` | ветка «не ответил» туда же, куда `#silent` |
| упрёк после паузы истории, напоминания, в «не ответил» | `C-32.no_answer_reproach`, `C-47.absence`; `guilt-scan.mjs` | реакция без обвинения (SG-40) |
| «ты, наверное, спишь», «у тебя же вечер» | `C-47.player_time`; `clock-scan.mjs` | время мира у персонажа (ST-64) |
| «доброе утро» вскоре после «сплю» | `story.sleep_morning.min_h` (C-32 п. 5); `clock-scan.mjs` | ночь мира или убрать «утро» |
| «наконец-то», «ты долго» после паузы | `C-47.lived_wait`; `click-transcript.mjs` | событие вместо ожидания (ST-63) |
| свой `#sys` «прошло 3 часа» у паузы | `clock-scan.mjs`, `click-transcript.mjs` | убрать: метку ставит движок (ST-65) |
| «у тебя 5 минут», от которого ничего не зависит | `C-37.false_deadline` | событие мира, решаемое выбором |
| больше `C-37.per_chapter` «срочно / ответь / ты где» за главу | `C-37.per_chapter`; `guilt-scan.mjs` | одно, обеспеченное событием |
| узел из одних «!!» и «помоги» | `C-37.shout_share` | одна реплика с другим чувством |
| история дольше потолка | `story.length.max_h` (C-31); `story:sessions` | сначала паузы внутри глав (LOCAL-01) |
| одна пауза дольше суток | `story.pause.max_h` (C-31) | событие посередине или сжать |
| карточка расходится с замером | `story.card.mismatch_ratio`, `C-31.card_missing` | числа из `story:sessions` (`story-release`) |
| больше `C-32.returns_per_day` возвращений за сутки от старта | `C-32.returns_per_day`; `clock-scan.mjs` | склеить мелкие паузы (F-03 у `story-pauses`) |
| первая длинная пауза до выбора или слишком длинная | `C-32.first_pause_choices`, `C-32.first_pause_h` | выбор и крючок раньше, пауза короче |
| пауза перед главой 2 длиннее остальных межглавных | `C-32.ch2_pause_h` | самая короткая из межглавных |
| пауза выровнена под ночь игрока условием | глазами (условие, внутри только `#delay`) | убрать: время мира (A-02) |
| эмоция сцены держится на прожитом ожидании | глазами в `click-transcript.mjs` | событие или «Прочитано» вместо тишины |

## Зелёные

| признак | чем видно |
|---|---|
| перед каждой паузой от `story.pause.notice_min` — дело персонажа и «не в сети» | `promise-scan.mjs`: «объяснено: причина» |
| первая строка после паузы — результат дела | `promise-scan.mjs`, строка «→ через …» |
| второе напоминание приносит деталь, после — ход персонажа | `guilt-scan.mjs`, раздел «напоминания» |
| «не ответил» идёт веткой `#silent` или своей с переменной и откликом позже | `story:trace --compare silent`: финалы совпадают |
| ночь мира между «сплю» и «утро» не короче `story.sleep_morning.min_h` | `clock-scan.mjs`: ✓ у пары |
| игрок сам выбирает ждать до утра или действовать сейчас | глазами; у «сейчас» своя короткая пауза |
| срок — событие мира, решаемое выбором | C-37 молчит; в `promise-scan.mjs` срок «без паузы рядом» — сюжетный |
| медиана в пределах `story.length.target_h`, карточка совпадает с замером | `story:sessions`, C-31 молчит |
| эпилог «через месяц» — свой `#sys`, хвост в минутах | `clock-scan.mjs`: «скачок дальше паузы», C-42 молчит |
