# Повтор и быстрый режим

Семь уроков базы советуют открывать прохождение без пауз только после первого финала. Решение автора (A-04)
отменило эту часть: «по клику» доступен с начала и наравне. В силе другая половина уроков: ускорение не
продаётся, повтор должен быть дешёвым, и игрок должен знать, что повтор что-то даст. Здесь — то, что из этого
следует для текста и для движка.

**Что уже есть.** Режим выбирают в начале; «Начать заново» стирает прогресс и даёт выбрать режим снова (A-04).
Пропуска прочитанного и старта с главы для игрока нет — это фича движка, кандидат в `docs/capabilities.json`
со статусом `planned` (решает автор, реестр этот скилл не правит).

## messenger-genre:LESSON-04 · Сделай повтор дешёвым

Lifeline после гибели героя откатывала к выбору, а найденный финал открывал режим без пауз. В Bury Me, My
Love на Switch не было ни контрольных точек, ни пропуска, и рецензенты называли повтор ради девятнадцати
финалов утомительным. Вывод: второе прохождение идёт без пауз (у нас — «по клику» после «Начать заново») и,
когда появится, с пропуском прочитанного; чем больше финалов, тем нужнее пропуск. Класс C: рецензии.

## sheldon-character-storytelling:LESSON-11 · Дай переиграть с середины, не заставляя ждать заново

Дай переиграть с середины, не заставляя ждать заново. Игроки Bury Me, My Love жалели, что нельзя перезапуститься с выбранной точки. Для нас: реальное время — для
первого прохождения, на повторе паузы предлагаются ускоренными; старт с главы — фича движка (`planned`), а не
правка сценария. Для теста автора она уже есть: отладка прыгает к любой главе или узлу, `story:trace --start
<узел>`. Класс C.

## skolnick-video-game-storytelling:LESSON-06 · Ускорение — не за деньги

Рецензент Lifeline отдельно отметил, что игра не продаёт ускорение по модели freemium. Часть «ускорение как
награда за повторное прохождение» отменена A-04: «по клику» — не награда. В силе — граница: платного
ускорения нет и не будет (R-115, `story-release/ethics.md`). Класс C.

## narrative-postmortems:LESSON-15 · Если история рассчитана на повтор, скажи об этом

Если история рассчитана на повтор, скажи об этом. По словам Инголда (inkle), многие не перепрошли Heaven's Vault: студия плохо объяснила, что каждое
прохождение будет другим. Для нас: если у истории несколько финалов, карточка и последняя реплика говорят,
что путь мог пойти иначе, — без ярлыка «плохая концовка». Текст карточки — `story-release`, финал —
`story-endings`. Класс C: признание без цифр.

## Как проверить повтор

- `npm run -s story:endings -- --story <id>` — сколько финалов и как часто; повтор нужен, если их несколько.
- `npm run -s story:trace -- --story <id> --mode click --persona last` — второй путь глазами игрока за минуты.
- `npm run -s story:sessions -- --story <id>` — минуты по клику: столько стоит повтор.
