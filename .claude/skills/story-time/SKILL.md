# story-time — время истории в двух режимах

История идёт настоящими часами, но **не знает часов игрока**. Решения автора выше базы: перед паузой —
причина без срока (A-01); время суток — время мира (A-02); если игрок молчит — 1–2 напоминания, потом история
идёт дальше, отсутствие не дороже `#silent`, упрёков нет (A-03); режимы «реальное время» и «по клику»
равноценны, текст один (A-04); длина — до `story.length.target_h`, потолок `story.length.max_h` (A-05). Скилл
меряет это командами, сверяет каждую находку с ink и правилом и предлагает правку с вариантами. Текст не правит
сам: применяет `story-fix` после одобрения. Числа — только из команд, пороги — ключами `thresholds.json`.

**Команды — по одной на вызов, ровно как написаны:** без `cd`, пайпов, `;`, `&&`, `>`, `$?`, `| head`. Длинный
вывод — `--summary` или `--json`. Упала команда — «нет данных: <команда>», не угадывай.

## Границы

- **Вход:** история `src/stories/<id>/` (или папка / `.json`), фраза автора («а по клику?», «что ночью?»,
  «сколько дней?», «так можно — «буду через час»?») или вызов `story-review`.
- **Выход:** находки строкой формата, варианты правки на ink, отчёт для `story-desk`, «объясни».
- **Не здесь:** крючок перед паузой и первая реплика после неё, пачка непрочитанного, сессии — `story-pauses`
  (C-26, C-28…C-30, C-33, C-39); нажатый `#silent` как ход и его след — `story-choices` (C-11); хвост после
  последней кнопки — `story-endings` (C-42); число на карточке, платная граница, этика — `story-release`;
  календарь мира и сюжетные дни — `story-core/time-model.md`; хронология `facts.md` — `story-continuity`;
  голос реплики и маркеры C-47 — `story-voice`; применить правку — `story-fix`; записать — `story-desk`.

## Алгоритм

1. **Состояние.** Прочитай `docs/stories/<id>/STATUS.md`. Не знаешь, о какой истории речь, — спроси. Шаг не тот
   (идея, ядро без скелета) — скажи. Нет `STATUS.md` (мутант, история вне цикла) — работай и отметь это.
2. **Замер.** `npm run -s story:lint -- --story <id> --only C-27,C-31,C-32,C-37` (папка вне каталога — путь
   вместо id; длинно — тот же вызов с `--summary`). Развилка «симптом → что делать» —
   [references/decisions-time.md](references/decisions-time.md).
3. **Длина.** `npm run -s story:sessions -- --story <id>` — медиана в обоих режимах, пауза, хвост против карточки.
   Длиннее потолка — [references/length.md](references/length.md) (начни с пауз внутри глав, LOCAL-01).
4. **Паузы и сроки.** `node ${CLAUDE_SKILL_DIR}/scripts/promise-scan.mjs --story <id>` — окно до каждой паузы,
   первая строка после, сроки возвращения во всём тексте. Как решать — [references/clock.md](references/clock.md).
5. **Молчание игрока.** `node ${CLAUDE_SKILL_DIR}/scripts/guilt-scan.mjs --story <id>` — напоминания, упрёки с
   контекстом, давление; затем `npm run -s story:trace -- --story <id> --compare silent`. Читай
   [references/reminders.md](references/reminders.md) и [references/no-guilt.md](references/no-guilt.md).
   **Ждёт без напоминаний** — блок «⚠» того же вывода (`--missing`; в `--json` — `reminders.missing`). Где собеседник
   не ждёт (банк, рассылка, факт) — сними. Где ждёт — с вопросов «?» и концов глав: 1–2 `#remind` перед `- (ask)`
   по `docs/style.md` ST-66 и `reminders.md` «Как написать» (второе — с деталью, без срока и упрёка), плюс
   `#noanswer` или `#silent`, ink до/после. Одна P2 на главу со списком узлов (R-120 в `decisions-time.md`).
6. **Часы и режимы.** `node ${CLAUDE_SKILL_DIR}/scripts/clock-scan.mjs --story <id>` — время игрока, «сплю →
   утро», нагрузка по суткам от старта (не часы игрока). Затем `node ${CLAUDE_SKILL_DIR}/scripts/click-transcript.mjs
   --story <id> --flags` — что ломается по клику. Читай [references/modes.md](references/modes.md).
7. **Сверка с ink — обязательно, до отчёта.** Каждую находку открой в узле ink и сверь с текстом правила:
   `npm run -s story:rule R-NN` (или `C-NN`). Особенно: C-27 — причина есть другими словами? пауза-угроза или
   «Прочитано»?; C-32 п. 7 — упрёк или ответ на нажатую кнопку («наконец-то, закрыли»)?; C-37 — погоня?; «сплю»
   — уход ко сну или воспоминание? Не подтвердилась — «ложное: почему» или `// намеренно: C-NN причина`.
8. **Правка.** Прочитай `docs/style.md` §8 (ST-60…ST-68) и образцы §12.5 прямо перед тем, как писать реплику,
   напоминание или пример ink. Приём — [references/patterns-time.md](references/patterns-time.md); два-три
   варианта, до/после на ink, теги только `ready`. Повтор и быстрый режим — [references/replay.md](references/replay.md).
9. **Отчёт и состояние.** Сначала находки строками формата, потом разговор и правки. В конце предложи записать
   находки через `story-desk` (раздел «Состояние»); применяется только одобренное.

## Главные правила

- **R-63** перед паузой — причина без срока; время события мира — можно (C-27).
- **R-120** молчит игрок — напоминаний не больше `story.reminders.max`, потом «не ответил», не дороже `#silent` (C-32 п. 6–7).
- **R-74** упрёк — только ответ на нажатый `#silent`; после паузы истории, напоминания, в «не ответил» — нет (C-32, C-47).
- **R-114** без сроков во времени игрока; давления — не больше `C-37.per_chapter`, напоминания не в счёт (C-37).
- **R-121** время суток — время мира; от «сплю» до утра — не меньше `story.sleep_morning.min_h` (C-32 п. 5, C-47).
- **R-122** текст читается в обоих режимах: событие после скачка, метку ставит движок (C-27, C-47).
- **R-67** длина до `story.length.target_h`, пауза до `story.pause.max_h`, хвост — минуты (C-31, C-42).

## Формат находки

```
P1 · непонятно · <узел> · симптом · правка (F-NN) · [C-NN · замер|модель|человек · уверенность]
```

Строго этот порядок: узел третьим полем. Своих ремонтных приёмов у скилла нет: в поле правки — приём владельца
(F-03 «склейка сессий» у `story-pauses`) или «—» и ссылка на `patterns-time.md`. Тип: непонятно / скучно / не
верю / нестыковка / баг. **P1** — история стоит после напоминаний, «не ответил» дороже `#silent`, упрёк за
отсутствие, история дольше `story.length.max_h`; **P2** — срок возвращения, пауза без причины, утро через минуты,
собеседник ждёт без напоминаний (история не стоит — кнопка ждёт, но A-03 не исполнено);
**P3** — шлифовка. Отклонённая находка не всплывает, пока не изменится узел. JSON — поля `node`, `check`,
`summary`, `fix`.

## Состояние

Сам не пишет — отдаёт `story-desk` (после одобрения автора, в конвейере — королевы): отчёт
`docs/stories/<id>/reviews/<дата>-story-time.md` (находки, сверка с ложными и причинами, правки) и строку для
`STATUS.md`: «время <дата>: P1 — N, P2 — M, длина — X ч / карточка Y дн, главное — …, отчёт — reviews/…».

## Готово, когда

Все находки замера сверены с ink и правилом: правка с вариантами, `// намеренно:` или «ложное» с причиной; у
правки — до/после на ink и перезапуск замера; запись в состояние предложена.

## Объясни

По запросу «объясни»: **почему** (что почувствует игрок в каждом режиме), **откуда** (`npm run -s story:rule

упражнение из [references/explain.md](references/explain.md).
