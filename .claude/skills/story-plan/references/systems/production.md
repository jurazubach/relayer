# Конвейеры производства у студий

Как студии доводят историю от замысла до текста — опора нашего порядка «скелет → главы 1–2 → тест → главы 3–N»
(`process.md`, R-09). Общее у всех трёх: каркас целиком раньше текста, проверка каркаса, потом слои.

### failbetter-qbn:SYS-4 · Производственный процесс студии сторилетов

| шаг | вход | выход | если пропустить |
|---|---|---|---|
| заявка | идея | одна страница: о чём, какие качества, ресурс, сколько контента | качества заводятся по ходу, каждая линия тащит свои |
| играбельный каркас (midflight) | заявка | все сторилеты, условия и эффекты, по строке на бит; проверка на темп и гринд | структурные ошибки находят, когда на узлах уже проза |
| проза | проверенный каркас | текст в лимитах длины | — |
| QA | готовый текст | около трети времени написания | баланс делают по отзывам ветеранов, начало остаётся сырым |

**Ошибка понимания.** QA — не вычитка, а прогон на темп, достижимость и баланс: у нас `check:story`, карта и одна игра
новичком. **Короткая форма:** заявка — несколько строк, каркас — час, QA — один прогон бота и одна живая игра; не
пропускается ни один шаг, сжимается только время. У нас заявка — ядро (`story-core`), каркас — скелет, проверка
каркаса — `plan-check.mjs`.

### inkle-ingold:SYS-5 · Конвейер производства студии ink

**Элементы.** Текстовая сборка целиком (без графики) → слои деталей → автоигрок с проверками → тест на людях → кнопка
отчёта с журналом. **Шаги:** полный сценарий от начала до конца как играбельный текст, пусть грубый (у студии — на
третьей неделе из примерно четырнадцати); показать людям — если ядро нравится, дальше только контент и полировка, без
пересмотра основы; наращивать слоями (сценарист даёт текст, дизайнер добавляет логику); автоигрок плюс проверки
невозможных состояний; кнопка отзыва с журналом (у нас — журнал выборов в отладке).
**Если пропустить.** Без полного грубого прохода механики проверяются на кусках, и что-то вырезают за недели до
выхода; без автоигрока — сотни нестыковок, которые находят игроки.
**Ошибка понимания.** «Сначала одна глава идеально»: студия делает наоборот — вся история грубо, потом слои.
**Короткая форма.** Для истории на пять минут полный проход — два десятка строк ink за вечер, показ — один человек с
`?fast=1`.

### bateman-game-writing:SYS-3 · Процесс сценаристки большой игры о нелинейности

Процесс сценаристки DeMarle на крупном кибер-триллере — система её практики о нелинейности и неизбежных моментах сюжета (своего названия у процесса нет): 1) сюжет целиком на уровне
замысла — без деления на уровни, иначе точки выбора появляются случайно; 2) проверка темы против механики — тема,
которую механика выражает, иначе тема — декорация; 3) точки выбора и места их отзвука — список «где выбор → где
последствие», иначе переменные без чтения; 4) раскладка деталей по слоям — минимальный сюжет и необязательное; 5) канал
подачи для каждого пункта — у нас основной чат, побочный, `#sys`, заметки; 6) критический путь линейно, развилки — все
версии сразу; 7) учёт ветвлений инструментом — у нас карта и `story:vars`.
**Короткая форма.** Шаги 1, 3, 6: слои и каналы схлопываются в один чат. Шаг 3 на плане — колонка «пишет / читает».
