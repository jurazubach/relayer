# Сторилеты и качества (QBN): из чего собирать хабы

Нарратив на качествах: сцены с предусловиями и эффектами, отбор доступных. У нас — хаб внутри главы и колода
«иногда», а не основа истории (`hubs.md`, `ashwell-standard-patterns:contra-3` в `contradictions.md`).

### emshort-structures:SYS-2 · Нарратив на качествах (QBN)

**Элементы.** *Качество* (quality) — число: предмет, навык, отношение, шаг сюжета. *Сторилет* — короткий кусок
текста с выбором, у него есть предусловия (prerequisites) и эффекты (effects). *Отбор* — какие сторилеты сейчас
доступны; выбирает игрок. *Хребет* — качество-прогресс, которое ведёт главную линию; ручной учёт хребта многими
значениями практик называет слабостью системы.

**Шаги.** Завести качества (вход — оси истории, выход — список `VAR`) → написать сторилеты (текст + условие + эффект)
→ отбор по состоянию → выбор игрока → эффект меняет состояние → снова отбор.

**Если пропустить шаг.** Без хребта история распадается на эпизоды без кульминации. Без эффектов сторилеты не
открывают друг друга, меню не меняется. Без колбэков к раннему контенту теряется сильная сторона системы.

**Ошибки понимания.** «QBN — это гринд»: гринд был чертой ранней игры студии, а не системы, и студия его урезала.
«QBN — значит без структуры»: классические структуры собираются из сторилетов через прогресс и угрозу (ниже). «Чем
больше сторилетов, тем лучше»: мало — пресно, много — перегружает.

**Короткая форма.** Хаб внутри одной главы на 3–4 сторилета, 1–2 из них открываются по состоянию.

### emshort-structures:SYS-5 · Классические структуры из сторилетов: прогресс и угроза

**Элементы.** Счётчик прогресса (как далеко продвинулся игрок) и счётчик угрозы (насколько он в беде). Из них
собираются коридор (gauntlet, ошибка меняет путь), ветвление с горлышком, шляпа, петля с ростом, пещера времени.

**Шаги.** Выбрать классическую структуру → выразить её порогами прогресса и угрозы → написать сторилеты с этими
предусловиями → прототипировать на карточках: одна карточка на сторилет, на ней текст и правила качеств (у нас
карточка — строка скелета).

**Если пропустить шаг.** Без карточек сторилеты пишут сразу в тексте и не видят, какие никогда не откроются (у нас —
недостижимое, C-15). Без угрозы коридор не наказывает за ошибку, и её перестают бояться.

**Ошибки понимания.** «Пещера времени на сторилетах — то же самое»: нет, каждый кусок зависит от точного маршрута,
нужны уникальные метки, и преимущества сторилетов теряются.

**Короткая форма.** Прогресс — номер главы или шага, угроза — один счётчик с низким порогом
(`emshort-structures:PAT-10` в `patterns-structures.md`); петля с ростом — дни реального времени.

### procedural-storytelling:SYS-4 · Сторилет: содержание, предусловие, эффект, отбор

**Элементы.** Содержание (сцена), предусловие (когда доступна), эффект (что меняется после), отбор (какие из
доступных показать: все, лучшую по специфичности или по счётчику). **Шаги:** записать мир → вычислить доступные →
выбрать → сыграть → применить эффект → повторить. **Если пропустить эффект** — сцена бесконечно доступна, её проходят
дважды; предусловие — сцена ломает связность. **Ошибки понимания:** сторилеты — не обязательно хаб со свободным
порядком; в ink это может быть одна условная кнопка `* {x}` в линейной главе. Предусловие с верхней границей на
растущей переменной прячет сцену так, что игрок считает это багом. **Короткая форма:** на пяти минутах — один
необязательный сторилет (кнопка по условию), а не пул.

### failbetter-qbn:SYS-3 · Что показать: всегда, иногда, ярус

| элемент | функция | ошибка, если пропустить |
|---|---|---|
| always — постоянные сторилеты | ключевые шаги к цели, всегда на виду | игрок не находит, как продвинуться |
| sometimes — колода возможностей | случайные, но уместные эпизоды, отбор по состоянию | мир без сюрпризов или важное в случайном |
| ярус прогресса | внутри яруса открыто всё, переход — по завершению историй | контент «исчезает» при росте навыка |
| релевантность | случайный эпизод — только когда уместен (лечение — при ранах) | пул засоряется бесполезным |

**Порядок:** сначала always (цель видна), потом sometimes (разнообразие), переход по ярусу — когда пройдены шаги
always. **Ошибка понимания:** случайный пул — не способ сэкономить на важном; если через случайное идёт главный путь,
игроки превращают его в гринд. **Короткая форма:** глава — это ярус, `#chapter` и есть переход, в его первой реплике
— награда и показ следующего яруса; sometimes — один случайный эпизод на 2–3 главы.

### emshort-structures:PAT-07 · Пул улик в любом порядке

Игрок собирает несколько фактов, порядок не важен, часть фактов открывается только после других (storylets /
quality-based narrative): каждый вариант — сторилет с условием, текстом и эффектом `~`. Цена линейная по числу фактов,
порядок прохождения — бесплатно.
- **Когда не работает.** Важна последовательность откровений, каждое меняет смысл предыдущего (порядок раскрытий — у
  `story-mystery`). Обвинение доступно при одной комбинации — бот покажет, что до неё доходят редко; игрок не понимает,
  почему кнопки обвинения нет — пусть персонаж намекнёт, чего не хватает.
- basis: secondary · `emshort-structures:PAT-07`.

#### emshort-structures:PAT-07#нюанс · пул, пройденный без поиска

Нюанс: обвинение открывает одна комбинация — плохо, до неё почти не доходят; улик хватает с первого шага — тоже
плохо: пул пройден без поиска.
На 5 сообщениях — две улики, обвинение по любой; на 50 — четыре-пять улик, по варианту обвинения на каждую.
