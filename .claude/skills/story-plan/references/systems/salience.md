# Значимость: самая подходящая реплика

Каскад «от узкого условия к широкому» выбирает реплику под состояние. У нас — только для реплик (приветствие главы,
первая строка после паузы, эпилог), не для выбора сцен и финалов (`emshort-structures:P-12` в `endings-plan.md`).

### emshort-structures:SYS-3 · Нарратив на значимости (salience)

**Элементы.** Пул реплик или сцен с условиями; мера значимости (сколько условий совпало или их вес); правило ничьей;
общая запасная реплика; для сцен — переменные дуги, которые не дают развязке выпасть рано.
**Шаги.** Написать общую реплику (`else`) → играть и замечать момент, который стоит отметить → написать частную реплику
с условием → поставить её выше общей → прогнать случайными прохождениями: что не выпадает, что выпадает слишком часто.
**Если шаг пропустить.** Без общей реплики при неожиданном состоянии — тишина. Без прогона широкое условие перекрывает
узкое навсегда. Без переменных дуги — развязка не вовремя. Без правила ничьей поведение недетерминировано.
**Ошибки понимания.** «Значимость решает, какая будет сцена» — для реплик безопасно, для сцен рискованно. «Веса надо
вычислить» — их угадывают и правят пробами. «Это то же, что QBN» — там выбирает игрок, здесь система.
**Короткая форма.** Только реплики; порядок веток вместо весов.

### procedural-storytelling:SYS-3 · Правила реплик: факты, правила, самое специфичное

**Элементы.** Факты о мире (кто где, кто что сказал, сколько раз); правила — условия на факты плюс реплика; отбор —
выигрывает самое специфичное подходящее правило, запасные правила с малым числом условий есть всегда; сказанная
реплика сама становится фактом, поэтому её не повторят (последнее — знание модели). **Вход → выход:** состояние → одна
реплика и обновлённые факты. **Если пропустить запись** — персонаж повторяет ту же реплику; в ink запись — число
посещений узла или флаг. **Ошибка понимания:** система не ведёт сюжет, персонажи в ней ни к чему не стремятся — это
слой реакций поверх сюжета. **Короткая форма:** на пяти минутах каскад из двух веток (`факт` / `else`), три ветки —
предел (`C-51.cascade_branches` у `story-continuity`).

### emshort-structures:PAT-08 · Самая подходящая реплика

Приветствие в начале главы, реакция на возвращение в чат, эпилог — когда состояний много, а реплика одна
(salience-based): условия от узкого к широкому, первое совпадение, `else` — общая реплика. Цена — строка на правило.
- **Когда не работает.** Выбор основной сцены или финала без контроля дуги. Ловушки: широкое условие стоит выше узкого и
  перекрывает его навсегда; нет `else` — при неожиданном состоянии реплика пустая.
- basis: secondary · `emshort-structures:PAT-08`.

```ink
# contact: tim, Тимур, amber
VAR trust = 0
VAR lied = false
-> ch3
=== ch3 ===
Глава 3 · Гараж #sys:tim #chapter
{
- lied && trust >= 2: [3.1] Тимур: Ладе ты врёшь, мне — нет. ладно #from:tim
- lied: [3.1] Тимур: вчерашнее «я дома» — неправда. я видел #from:tim
- trust >= 2: [3.1] Тимур: хорошо, что ты здесь #from:tim
- else: [3.1] Тимур: гараж открыт #from:tim
}
-> END
```
