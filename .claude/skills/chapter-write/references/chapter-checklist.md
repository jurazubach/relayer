# Чек-лист «написать главу» (сводный)

Сведён из разделов «Как написать главу или сцену» в `checklists.md` всех 30 разборов: дубли склеены, отменённое
решениями автора выброшено (внизу — что и почему), числа заменены ключами `thresholds.json`. Владелец —
`chapter-write` (TH-27); `story-review` берёт отсюда пункты для ревью главы. Пункт: **действие** → результат,
которым проверить; в скобках — откуда.

## До текста

1. **Пакет главы.** `chapter-context.mjs --story <id> --chapter N` → facts.md, план главы, карточки, концы прошлой
   главы по путям у тебя перед глазами ([facts-anchor.md](facts-anchor.md); `procedural:LESSON-08`).
2. **Вопрос и событие главы из плана.** → одной строкой: что случится, какой вопрос глава оставит перед паузой, кто
   давит на героя (`snyder`, `truby:P-07`, `yorke:P-16`). Нет плана — к `story-plan`, каркас не придумывать
   (`procedural:LESSON-01`, `LESSON-03`).
3. **Цель каждого участника сцены, включая собеседников.** → у каждого есть, чего он добивается в главе
   (`sheldon:P-03`, `maass`, `skolnick:P-01`); в рабочих заметках, не в ink (A-06).
4. **Линии A/B/C, если чатов три и больше.** → главная линия, контрастная в другом чате, одна-три мелочи, одна
   отзовётся позже (`nicklin:P-08`, `yorke:PAT-09`).
5. **Сначала скелет главы.** Узлы, кнопки, `~`, переходы с одной строкой на узел → `ink-compile.mjs --story <id>`
   без ошибок, `check:story` без тупиков; только потом реплики (`failbetter:P-01`, `choiceofgames` проходы 1–2).
6. **Каждый новый факт: где он выстрелит.** → факт → переменная → условие в этой или следующей главе
   (`cron:P-10`, `narrative-testing:PAT-06`, `mobile:P-06`); без чтения — не заводить переменную.

## Вход в главу

7. **Узел с `#chapter`, первые строки — следствие прошлой главы.** → первые две реплики называют имя или предмет из
   крючка прошлой главы и стоят под условием на её переменные (R-27; `cron:PAT-03`, `chat-fiction:PAT-05`,
   `serial:PAT-03`, `mobile:P-15`, `choiceofgames:PAT-09`).
8. **Первое сообщение — событие, не приветствие.** → C-28 молчит; первая строка понятна с экрана блокировки
   (ST-62; `messenger:P-02`, `schell:PAT-03`, `truby` «начни как можно позже»).
9. **Событие главы — в первых входящих.** → C-39 молчит: новый отправитель, вложение, `#unlock` или вопрос в первых
   `C-39.start_lines` входящих главы (`yorke:RED-02`, `chat-fiction:RED-03`).
10. **Хотя бы один отклик на прошлые главы от другого контакта.** → условный блок на переменную прошлой главы
    (`meaningful:PAT-01`, `messenger:RED-11`, `narrative-postmortems:PAT-03`).

## Сцены

11. **Сцена — сначала переписка, потом кнопки.** → weave по [systems/weave.md](systems/weave.md) (`inkle:P-10`).
12. **У каждого узла есть перемена.** → `~`, факт, новый контакт или смена тона; узел без перемены слит или дописан
    ([decisions-scene.md](decisions-scene.md); `yorke:PAT-03`, `maass:P-07`, `mckee:P-01`).
13. **Шансы и помехи чередуются, помехи разного рода.** → хотя бы одна помеха из другого чата или `#sys`
    (`maass:P-08`, `mckee:LESSON-04`).
14. **Нет трёх тяжёлых узлов подряд.** → передышка с полезной деталью (`schell:P-15`, `PAT-04`).
15. **Серии без кнопки разрезаны.** → C-35 молчит: не больше `C-35.series` входящих подряд, один `#from` — не больше
    `C-35.monologue` (`inkle:P-01`, `sheldon:P-13`, `skolnick`, `maass`, `attention:PAT-04`).
16. **Конкретика.** → в каждой цепочке из `C-36.vague` входящих есть цифра, имя, предмет или фото (`cron:P-11`).
17. **Новые имена и термины поясняются в той же или следующей реплике.** → C-22 молчит: за сцену не больше
    `C-22.scene`, в реплике не больше `C-22.line` (`edgerton:P-07`, `attention:P-04`, `video:P-08`).
18. **Предыстория — через конфликт, вопрос или кнопку, не справкой.** → нет серии реплик о прошлом без вопроса
    (`mckee:P-12`, `edgerton:PAT-02`; ST-14).
19. **Одно событие подано интерфейсом.** → `#sys` «прочитано», `#rename`, `#unlock` — один такой приём на главу
    (`schell:P-07`, ST-71).
20. **Повторяемые реплики варьируются, повороты — руками.** → шафл только в проходных ([patterns-ink.md](patterns-ink.md);
    `inkle:P-11`, `procedural:P-11`).

## Кнопки

21. **Последняя реплика перед кнопками — вопрос или факт, на который они отвечают.** → кнопки понятны без
    прошлых сообщений, непонятные — с `#label` (ST-36; `inkle:P-08`).
22. **У каждой кнопки свой ответ и что-то меняется.** → ветка, переменная или ответ, который запомнят; косметика не
    подряд (`cron:P-04`, `bateman:P-02`, `emshort` RED-11, `narrative-postmortems:P-04`).
23. **Кнопки по форме.** → `docs/style.md` §6: обычно две, до `C-13.words` слов, без рода игрока, все разумны
    (ST-30…ST-35; `failbetter:P-16`, `messenger:P-13`, `choiceofgames:RED-10`).
24. **У ключевого выбора названа цена каждой кнопки.** → цена видна до нажатия (`maass:P-05`, `meaningful:P-02`,
    `schell:P-12`).
25. **`#silent` имеет своё последствие.** → реакция или `~`, переспрос с новым (ST-43; `inkle:P-07`, `nicklin:P-11`).
26. **Хотя бы одна условная кнопка со второй главы.** → `* {var}`, которую видит только часть игроков
    (`inkle:P-09`, `messenger:PAT-05`).
27. **Сшитые реплики прочитаны во всех вариантах.** → нет несогласованных родов (`bateman:P-17`).

## Паузы и молчание

28. **У каждой паузы от `story.pause.notice_min` — причина без срока.** → C-27 молчит (ST-60, A-01;
    [pause-lines.md](pause-lines.md)).
29. **Пауза — после события, не перед ним и не посреди перечисления.** → нет анонсов перед паузой
    (`serial:P-03`, `attention:P-13`).
30. **Нет пустых пингов «ещё жду».** → между двумя паузами есть новое (ST-68; `attention:PAT-07`, `messenger:LESSON-05`).
31. **Развилки, где собеседник ждёт ответа, — с напоминаниями.** → `chapter-lint.mjs`: нет «кнопка ждёт вечно»;
    1–`story.reminders.max` `#remind` без упрёка и `#noanswer` или `#silent` (A-03, R-120, ST-66).

## Конец главы

32. **Глава кончается крючком.** → последние `C-39.end_window` строк перед `#chapter` следующей или долгой паузой —
    вопрос, угроза, новый контакт или находка; прощание стоит раньше (C-39, C-26; `chat-fiction`, `dille:P-13`,
    `snyder`, `yorke:PAT-05`, `skolnick`, `vogler`).
33. **Самая длинная пауза — после самой весомой кнопки.** → после неё условный текст (`serial:PAT-06`).
34. **Если глава кончается выбором с последствием — сводка в заметки.** → строки состояния голосом героя
    (`narrative-postmortems:PAT-06`, `mobile:PAT-06`).

## После текста

35. **Прочитать главу вслух и с `?fast=1`.** → реплики, на которых споткнулся или пролистал, переписаны
    (`nicklin` [S6], `inkle:LESSON-10`).
36. **Проверки.** → `chapter-lint.mjs --story <id> --chapter N`, затем `node scripts/hooks/full.mjs <id>`; ошибок нет
    (`snyder`, `choiceofgames` «тестировать по ходу»).
37. **Факты.** → новые времена, числа, имена и VAR предложены строками для facts.md ([facts-anchor.md](facts-anchor.md);
    `dille:P-04`, `narrative-testing:GREEN-05`).
