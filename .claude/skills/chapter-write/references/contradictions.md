# Споры источников и наши решения

Спор → наше решение → на чём стоит. Решения автора (`INTENT.md`, `docs/playbook/superseded.md`) выше любой книги:
если источник советует отменённое, берём только часть «в силе».

| спор | наше решение | на чём стоит |
|---|---|---|
| Перед паузой назвать срок возвращения («напишу через час», `#delay` = срок) — `chat-fiction-apps:P-04`, `PAT-03`, `serial-hooks:P-13`, `failbetter-qbn:P-08` — против «ожидание без известного конца тяжелее, но честнее для двух режимов» | причина ухода без срока; время **события мира** назвать можно | A-01, R-63 (у `story-time`); риск «ожидание без конца» (`messenger-genre:LESSON-10`) проверяется персоной «неотвечающий» и холодными читателями |
| «Кнопка ждёт вечно, время стоит, пока игрок молчит» (`attention-today:P-10`, `messenger-genre` attention §3, Lifeline) — против «история идёт дальше» | в реальном времени 1–`story.reminders.max` напоминаний, потом ветка «не ответил», не дороже `#silent`; по клику кнопка ждёт | A-03, R-120; `inkle-ingold:PAT-07` (опора) |
| Разметка сцены комментариями в ink (`// ценность:`, `// + → −`, `// хочет / мешает`, `// truth:`, `// verb:`) — у Макки, Снайдера, Крон, Скольника, Dille, Nicklin — против «в ink только то, что кто-то читает» | заметки сцены — в плане главы и рабочих заметках, правда — в facts.md; в ink только шапка и `reveal` / `намеренно` / `финал` | A-06, C-53; `build-plan.md` §9 |
| Только нужное (Крон: каждая деталь need-to-know, `cron-wired-for-story:P-10`) — против фактуры мира в дозе (`messenger-genre:P-11`) | «ясность мира» и «голос персонажа» — законные функции детали; детали без функции режем; фон — вне главного пути и коротко | `cron-wired-for-story:contra-7`, `SYS-3` ([scene.md](scene.md)) |
| Вырезать сцену без поворота (Маасс, `maass-fire-in-fiction:P-07`) — против «живого фона» и награды необязательному (`messenger-genre:P-11`, `dille-ultimate-guide:P-09`) | на главном пути правило Маасса строгое; фон допустим вне главного пути, коротко, с трением или голосом | `maass-fire-in-fiction:contra-2` ([decisions-scene.md](decisions-scene.md)) |
| Шафл и генерация реплик экономят текст (Kazemi, Compton) — против «промах случайной реплики рушит сцену» (Short) | шафл только в проходных репликах; повороты, крючки, раскрытия, финалы — руками; в комедии шире | `procedural-storytelling:P-11` и нюанс ([patterns-ink.md](patterns-ink.md)) |
| Сшивать реплики из кусков (Adams у Бейтман) — против русского согласования | подстановка только имён, чисел и целых фраз; род и падеж — фразой целиком под условием; род игрока — никогда | `bateman-game-writing:P-17`, R-119 (у `story-voice`), ST-35 |
| Каркас главы генерировать моделью (процедурные системы) — против «сюжет из случайного не ведёт к одной точке» (Wildermyth) | каркас, порядок, повороты — план автора (`story-plan`); модель пишет реплики и реакции | `procedural-storytelling:LESSON-01`, `LESSON-03` |
| «Ты» в каждой реплике — близость (Шелл, психологическая близость) — против «давление и знание без источника» | «ты» растёт к финалу и только с источником знания; персонаж знает только своё | `schell-art-of-game-design:P-08`, `RED-13`; `skolnick-video-game-storytelling:P-12` ([facts-anchor.md](facts-anchor.md)) |
| Быстрый режим — награда после первого финала (`nicklin-writing-for-games:LESSON-08`, `chat-fiction-apps:LESSON-01`) — против «по клику с начала» | режим выбирается в начале, равноценный; текст пишется для обоих режимов | A-04, R-122 |
