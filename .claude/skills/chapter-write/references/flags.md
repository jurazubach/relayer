# Флаги главы: что видно сразу после письма

Красные и зелёные признаки написанной главы: чем поймать и как чинить. Числа — только из команд; если команда
упала — «нет данных: <команда>». Перед тем как чинить находку, сверь её с ink и с правилом: узел, контекст,
исключение (нюансы в references) — команда ищет признак, а не смысл.

## Красные

| признак | чем поймать | правка |
|---|---|---|
| глава не собирается или тупик | `node ${CLAUDE_SKILL_DIR}/scripts/ink-compile.mjs --story <id>`; `chapter-lint.mjs` (сборка) | ошибка с файлом и строкой; тупик — ветка без `->` |
| тег не из реестра, сцена держится на фото | `ink-compile.mjs --file <черновик>` | словами персонажа или `#sys` (R-118, [ink-idioms.md](ink-idioms.md)) |
| первая строка главы не помнит прошлое | `chapter-lint.mjs` → C-39 (стык), C-04/C-05 | условная первая строка по VAR на стыке (R-27) |
| первая строка после паузы — «привет», «ок», «ты тут?» | C-28 | событие первым, вежливость вторым (ST-62, [pause-lines.md](pause-lines.md)) |
| пауза без причины или со сроком «через час» | C-27 | причина без срока, затем «не в сети» (A-01, ST-60) |
| последняя строка перед паузой — прощание | C-26, C-39 | крючок последним, прощание раньше (ST-61) |
| кнопка ждёт вечно в реальном времени | `chapter-lint.mjs` → «молчание» | `- (ask)`, `#remind`, `#noanswer` или `#silent` (A-03) |
| напоминание с упрёком, повтором или сроком | C-32 (п. 6–7) | своими словами, новая деталь, без «где ты пропадал» (ST-66) |
| «наконец-то», «ты долго», «я всю ночь ждала» | C-47 | время объясняет событие, не ожидание (ST-63, R-122) |
| длинная серия без кнопки, монолог одного `#from` | C-35 (`C-35.series`, `C-35.monologue`) | вставка выбора в монолог (`inkle:PAT-02`) |
| узел без перемены | C-36 (`C-36.static_share`) | слить или дописать поворот ([decisions-scene.md](decisions-scene.md)) |
| кнопки одинаково отвечают, пустые кнопки | C-10, C-11 (у `story-choices`) | свой ответ на каждую (ST-34) |
| кнопка длинная, с родом игрока, с чувством за игрока | C-13, C-14 | `#label`, безличная форма (ST-31, ST-35) |
| сообщение длиннее порога | C-34 (`C-34.line_warning`) | разрезать на пузыри (ST-01) |
| новые имена без пояснения, два имени одного лица | C-22, C-48 | пояснить в той же или следующей реплике; одна форма (ST-10) |
| время в реплике не совпадает с facts.md | C-49 (г), `facts.mjs` (у `story-continuity`) | взять из facts.md или записать ложь ([facts-anchor.md](facts-anchor.md)) |
| персонаж знает то, чего ему не писали | C-51 (у `story-continuity`) | сцена утечки или условие «узнал» (`schell:RED-13`) |
| `{~…}` в узле с поворотом или финалом | глазами по главе | авторский текст (`procedural:RED-09`) |
| сшитая реплика с несогласованным родом | `story:trace` разными персонами, чтение вслух | фраза целиком под условием (`bateman:RED-09`) |
| метка `// слово:`, которую никто не читает | C-53 | заметку — в план, в ink только шапка и `reveal` / `намеренно` / `финал` |

## Зелёные

- Первые строки главы различаются по путям и называют предмет крючка прошлой главы.
- У каждой развилки, где собеседник ждёт, есть одно-два напоминания и ветка «не ответил», которая не хуже `#silent`.
- В главе есть помеха из другого чата или `#sys`, и хотя бы одно событие подано интерфейсом (ST-71).
- Последняя строка главы — вопрос, угроза или находка, которую можно пересказать.
- Новые факты главы предложены строками для facts.md; имена — одной формой.
- `chapter-lint.mjs` и `node scripts/hooks/full.mjs <id>` — без ошибок; предупреждения сверены с ink и либо
  исправлены, либо объяснены (`// намеренно: C-NN причина`).
