# Шкала ценности Макки

### mckee-story:SYS-4 · Шкала ценности: позитив → противоположное → противоречащее → отрицание отрицания

Вход — ценность-пара ядра (`тема`); выход — ступень для каждого финала и для конца предпоследней главы. Четыре
ступени: позитив («Зоя верит брату»), противоположное («сомневается»), противоречащее («верит, что он вор»),
отрицание отрицания — хуже простой противоположности: зло выдаёт себя за добро или герой сам его выбрал («Зоя сама
сдаёт брата, уверенная, что спасает его»).

- **Без шага.** Плохие финалы равны по силе: «семь финалов» ощущаются как один плохой и один хороший.
- **Ошибка понимания.** Четвёртая ступень — не «очень плохо». Для нас это финал, где плохой исход вызван «хорошим»
  выбором игрока. Шаг «− → −−» у Coyne — усиление, а не смена знака: засчитывается как поворот, если ступень
  сменилась по шкале ядра; цепочки в одну сторону — монотонность.
- **У нас.** Шкала пишется в поле `тема` ядра, не в шапке ink (A-06).
- **Короткая форма.** Две ступени.
