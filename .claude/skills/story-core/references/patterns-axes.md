# Приёмы осей с ink

Как ось ядра выглядит в ink. Примеры выдуманные, компилируются, теги — только `ready`. Перед письмом реплик по
приёму — `docs/style.md`. Числа шкал в примерах — данные примера, пороги проверок — ключи C-09.

### cron-wired-for-story:PAT-04 · Переменная-ось внутренней проблемы

Строка ядра «герой верит, что…» становится осью: в каждой главе одна сцена, где убеждение под ударом; кнопка
«толкнуть к правде» +1, «поддержать убеждение» −1; финал читает ось. Внутренняя проблема героя видна игроку
через то, что он сам толкнул.

```ink
# contact: zoya, Зоя, amber
VAR zoya_truth = 0
если я спрошу Глеба прямо, он перестанет со мной говорить #from:zoya
* [Он уже не говорит. Спроси #to:zoya]
    ~ zoya_truth += 1
* [Тогда не спрашивай пока #to:zoya]
    ~ zoya_truth -= 1
- {zoya_truth > 0: я написала ему. прочитал #from:zoya #delay:2h | я удалила черновик #from:zoya #delay:2h}
-> END
```

- **Когда не работает.** Короткая зарисовка на 3–5 минут: удар по убеждению один, ось лишняя. Знак у оси —
  только у скрытой оси отношения (R-41).
- **Масштаб.** 5: одна развилка и одно условие. 50: сцена-удар в каждой главе.
- basis: secondary.

### failbetter-qbn:PAT-05 · Часы: минутная стрелка двигает часовую

Grandfather Clock: мелкие эпизоды прибавляют `pressure`; при пороге приходит следующий бит главной линии, и
счётчик сбрасывается. Главы — часовая стрелка, `pressure` — минутная. Ядро решает, нужен ли такой ход вообще:
он для историй, где сюжет двигают не отдельные выборы, а накопление.

```ink
VAR pressure = 0
-> rounds
=== rounds ===
* [Ещё одна смена, без вопросов]
    ~ pressure += 1
* [Спросить про склад]
    ~ pressure += 1
- {pressure >= 2: -> next_beat}
-> rounds
=== next_beat ===
Склад опечатали раньше #sys
-> END
```

- **Когда не работает.** В короткой истории каждая глава и так один шаг. Игрок не понимает, что двигает главную
  линию, — нужен намёк репликой.
- **Масштаб.** 5: не нужен. 50+: одна такая петля на хаб, с выходом по числу кругов.
- basis: secondary.

### failbetter-qbn:PAT-08 · Угроза с видимым потолком

Menace: ошибка → `suspicion` +1 → персонаж называет уровень словами → на пороге яркая сцена, история идёт
другим путём, а не обрывается. Угроза видна игроку, и её можно уменьшить поступком.

```ink
# contact: ostap, Остап, slate
VAR suspicion = 0
* [Сказать, что ночью никого не было #to:ostap]
    ~ suspicion += 1
    странно. камера говорит иначе #from:ostap
* [Промолчать #to:ostap #silent]
- {suspicion >= 1: я за тобой посмотрю #from:ostap #delay:1m}
-> END
```

- **Когда не работает.** На пороге нет сцены — тогда это просто штраф. Угроза, которую нельзя уменьшить ничем,
  учит не выбирать.
- **Масштаб.** 5: одна ступень. 50: 2–3 уровня словами и сцена провала.
- basis: secondary.

#### failbetter-qbn:PAT-08#нюанс · В первой главе угроза только предупреждает

Нюанс: в первой главе угроза только предупреждает, но не обрывает линию: первый провал мягче поздних (смерть
сильнее всего била по новичкам, и студия облегчила первый визит). В ядре порог угрозы для главы 1 выше, чем
может набрать бот за одну главу.

### sheldon-character-storytelling:PAT-01 · Две оси отношения

По мотивам attitude system — системы отношений из The Gryphon Tapestry: выбор двигает `trust` и `respect`
независимо, а условная реплика после паузы смотрит на их сочетание.

```ink
# contact: platon, Платон, teal
VAR platon_trust = 0
VAR platon_respect = 0
Вы обещали ответить до девяти. #from:platon
* [Простите, я соврал про работу #to:platon]
    ~ platon_trust -= 1
    ~ platon_respect += 1
* [Был занят #to:platon]
    ~ platon_trust -= 1
- {platon_respect > 0: Я вам не верю. Но вы хотя бы не выкручиваетесь. #from:platon #delay:2h | Ясно. #from:platon #delay:2h}
-> END
```

- **Когда не работает.** У эпизодических контактов хватит одного флага.
- **Масштаб.** 5: одна ось. 50: две оси у одного-двух главных.
- basis: secondary.

#### sheldon-character-storytelling:PAT-01#нюанс · Одна ось с двумя именами

Нюанс: если варианты двигают оси одинаково, получается одна ось с двумя именами — не применять. Нужны одна-две
развилки, где оси расходятся, и 2–3 чтения сочетания; иначе вторая ось — лишний долг для `story:vars`.
В ядре это проверяется до плана: назови развилку, где оси расходятся, или оставь одну.

### skolnick-video-game-storytelling:PAT-07 · Механика = характер

Ludonarrative harmony: у игрока роль или легенда → каждая ложь копит счётчик → другие персонажи сверяют
показания → ложь всплывает, цена видна действием (удалил из контактов, не ответил). Механика и характер роли
работают вместе: ось ядра — это и есть моральная слабость роли игрока (`player-role.md`).

```ink
# contact: zoya, Зоя, amber
VAR lies = 0
ты был в копировальне в ту ночь? #from:zoya
* [Нет, я ушёл в десять #to:zoya]
    ~ lies += 1
* [Был. Глеб просил не говорить #to:zoya]
- {lies > 0: Остап говорит, ты закрывал смену в два #from:zoya #delay:1h}
-> END
```

- **Когда не работает.** Игрок — нейтральный свидетель без маски: сверять нечего. Обвинять игрока в том, чего у
  него не было кнопки сделать, нельзя (R-85, `story-continuity`).
- **Масштаб.** 5: одна сверка в конце. 50: сверка на главу.
- basis: secondary.

#### skolnick-video-game-storytelling:PAT-07#нюанс · Ложь не выгоднее правды

Нюанс: для нейтрального свидетеля хватит одной сверки в конце. На длинной истории — сверка на каждую главу и
проверка, что ложь не выгоднее правды, если сюжет хвалит правду: иначе механика учит обратному тому, что
говорит история. В ядре это строка темы: какую сторону хвалит история и чем платит игрок за другую.
