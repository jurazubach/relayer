# Вопросы автору: всегда с вариантами

Автор не умеет строить сюжеты (INTENT): открытый вопрос «какая ставка?» его останавливает. Поэтому каждое поле ядра
скилл решает сам в 2–3 вариантах, которые **различаются по сути**, а не формулировкой, называет цену каждого и
рекомендует один. Автор выбирает, правит или отвергает. В конвейере выбирает королева в пределах `INTENT.md` и
записывает почему. Отвергнутые варианты не пропадают: `story-desk` кладёт их в `ideas.md` с причиной.

## Формат вопроса

```
<поле> · что решаем одной строкой
  А — <вариант> · цена: <что теряем> · даёт: <что получаем>
  Б — …
  В — …
  рекомендую: <буква>, потому что <правило / связь с уже решённым> [R-NN · модель · уверенность]
```

Не больше трёх полей за один заход: автору легче выбрать три раза по три, чем один раз из двенадцати. Порядок —
`systems/core-pass.md`; каждый следующий вопрос опирается на ответ на предыдущий.

## По полям: чем должны различаться варианты

| поле | оси различия вариантов | правило |
|---|---|---|
| роль | кто «ты» (свидетель / участник / чужой номер); маленькое желание (деньги / долг / любопытство); риск (имя / номер / правда) | R-06 |
| ставка | лицо (герой / третий / игрок); что теряет (человек / свобода / правда); срок мира (часы / дни) | R-08, R-17 |
| вопрос | о ком (кто сделал / что выберет герой / успеет ли); на что отвечают финалы | R-03 |
| противник | кто (близкий / власть / незнакомец); видимый или скрытый; чем бьёт в слабость игрока | R-84 |
| тема | пара полюсов (верность / правда, свобода / безопасность …); куда тянет вера героя | `mckee-story:P-02`, R-07 |
| оси | типы (отношение / угроза / прогресс / ресурс); что их двигает | R-39, R-41 |
| время мира | одна ночь / два-три дня / неделя со скачками; где ночи мира | A-02, TH-13 |
| состав | сколько главных; у кого какая функция и позиция по вопросу | R-90 |

## Пример (выдуманный: копировальня, Зоя ищет брата)

```
противник · кто хочет тех же накладных
  А — Остап, управляющий: хочет сжечь накладные, чтобы его махинацию не увидели · цена: видимый с главы 1,
      тайны меньше · даёт: прямое давление, сделка, срок — опечатка склада
  Б — сам Глеб: прячет накладные от сестры, чтобы шантажировать Остапа · цена: нужна карта улик (story-mystery),
      герой и противник — семья · даёт: сильнейшее раскрытие, дилемма «верность / правда» на финал
  В — Остап видимый, Глеб скрытый · цена: дороже всего, нужна история от пяти глав · даёт: смену противника
  рекомендую: А для истории на 25 минут, В — если глав пять и больше: правило «противник — соперник за ту же
  вещь» держат все три, но В требует улик против Глеба на стволе с главы 1 [R-84 · модель · средняя]
```

## Если автор отверг все варианты

Не давать четвёртый «средний». Спросить, что не так, по осям из таблицы («слишком близко к прошлой истории?
противник слишком злой? срок слишком короткий?»), исключить отвергнутое, дать два далёких варианта — по другой оси.
Отвергнутое — в `ideas.md` через `story-desk`. Если отвергнуто ядро целиком — это вопрос направления
(`story-brainstorm`), а не ядра.

## Когда вопрос не задают

- Поле уже решено в D-NN направления — показать и спросить «оставляем?», без вариантов.
- Поле вытекает из решённого однозначно (срок мира из ставки «к утру понедельника» → время мира «одна ночь и
  утро») — записать как следствие и назвать, откуда оно.
- Вопрос о тексте реплик — это не ядро: `chapter-write`, `story-voice`.
