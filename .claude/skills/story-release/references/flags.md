# Признаки: красные и зелёные перед выпуском

Каждый признак — с командой, которой его видно, и правкой. Команда упала — «нет данных: <команда>», не на
глаз. Уровень находки — по `.claude/skills/story-review/references/priority.md`.

## Красные

| признак | команда | правка |
|---|---|---|
| выпускаются не все главы (главы в `meta.json` ≠ строки `#chapter`, есть `beta_stop`) | `release-gate.mjs` «главы» | дописать главы или выпускать как набор для теста (`story-playtest`) |
| ошибки `story:lint` | `release-gate.mjs` «линт»; `npm run -s story:lint -- --story <id>` | владелец по `owners.md` §3 через `story-fix` |
| второй волны нет или она до последней правки | `release-gate.mjs` «тест» | `story-playtest`: панель на полной истории |
| `days` на карточке расходится с медианой больше `story.card.mismatch_ratio` | `durations.mjs` | вписать предложенное число; длинную историю сжать (`story-time`) |
| история длиннее `story.length.max_h` или пауза длиннее `story.pause.max_h` | `durations.mjs` | `story-time`, потом карточка |
| карточка называет позднего героя, обещает финалов больше, чем есть | `card-check.mjs` (б), (з) | роль вместо имени; честная карточка или `story-endings` |
| затравка — поворот поздней главы, имя или число, которого игрок не слышал в главе 1 | `card-check.mjs` (ж) | факт главы 1 ([teasers.md](teasers.md)) |
| на платной границе нет крючка или она стоит на «ок» | `boundary-check.mjs`; C-26, C-39 | сдвинуть `--free N` или крючок через `story-pauses` |
| после открытия платной главы долго ждать выплату | `boundary-check.mjs` (`skill.release.boundary.pause_max_min`) | пауза строки `#chapter` короче |
| пауза или выбор продаётся, бесплатный путь наказан | шаг 6, [ethics.md](ethics.md) | ✗ — переделать |
| правка ломает сохранения, а `revision` прежняя | `revision-check.mjs` | `revision` +1 и журнал |
| `story:pack --check` с потерями | `pack.mjs` | раскладка по `CLAUDE.md` |

## Зелёные

| признак | команда | держать |
|---|---|---|
| каждый пункт `features` звучит в тексте, хотя бы один — в главе 1 | `card-check.mjs` (е) без находок | при правке главы 1 перемерить |
| `tagline` — ядро одной строкой, не больше одного имени и числа | `card-check.mjs` (поле целиком), глазами | шаблон «X, который Y» |
| две-три затравки, все из главы 1 и по стилю | `card-check.mjs` (ж) | править вместе с главой 1 |
| два времени совпадают с медианой | `durations.mjs` «совпадает» | перемерить после любой правки пауз |
| граница на развилке, выплата в первых входящих платной главы | `boundary-check.mjs` ✓ | — |
| строка «этика» гейта без предупреждений | `release-gate.mjs` | — |
| сохранения не ломаются или revision поднята | `revision-check.mjs` ✓ | тег `<id>-r<revision>` после выпуска |
