# Система: гейт выпуска по шагам

Вход: история в `src/stories/<id>/`, состояние `docs/stories/<id>/`. Выход: вердикт «можно / после решений /
нельзя», отчёт с находками, строка для `STATUS.md` и (после одобрения) тег `<id>-r<revision>` и файл выпуска.
Команда целиком — `node ${CLAUDE_SKILL_DIR}/scripts/release-gate.mjs <id>`; ниже — что делает каждый пункт и что
будет, если его пропустить.

| шаг | вход → выход | без шага | ошибка понимания |
|---|---|---|---|
| 1. Шаг цикла | `STATUS.md` → `playtest:wave2` или `release` | выпуск главы 1–2 из пяти как «готовой истории» | «тест был» ≠ тест полной истории |
| 2. Все главы | `meta.json` + ink → главы совпадают, `beta_stop` нет, бот доходит до последней | карточка обещает 5 глав, играется 2 | набор для теста (`--partial`) — не выпуск |
| 3. Линт | `story:lint` → 0 ошибок (`skill.release.lint_errors`) | тупик, недостижимый финал, сломанная разметка у игрока | предупреждения — не ошибки: решить, а не обязательно чинить |
| 4. Тест | волна 2 → свежая, после последней правки | правка после теста не проверена никем | симуляция — законная волна в этом проходе (INTENT) |
| 5. Карточка | `card-check.mjs` → C-49 без находок, два времени | обещание расходится с текстом до первой реплики | «карточку поправим потом» — первое, что видит игрок |
| 6. Граница | `boundary-check.mjs` → крючок и выплата | граница на «ок, спокойной ночи», заплатил — и ждёт | граница ≠ пауза |
| 7. Этика | строка «этика» + семь вопросов [ethics.md](../ethics.md) | давление и вина вместо вопроса истории | «у нас нет денег — нет и тёмных паттернов» |
| 8. Ревизия | `revision-check.mjs` → revision поднята, если ломаются сохранения | игроки продолжают на чужом состоянии ink | поднять «на всякий случай» — стереть прогресс зря |
| 9. Файл | `pack.mjs` → `--check` без потерь; `--write` после одобрения | загруженный файл играется иначе, чем папка | «собралось» ≠ «склейка играется так же» |

- **Порядок важен:** шаги 1–4 — история готова, 5–9 — выпуск честный. Нет смысла править карточку истории,
  которую ещё перепишут.
- **Решения, а не правки:** гейт ничего не меняет. Он даёт отчёт и варианты; правит `story-fix` по одобренному,
  записывает `story-desk`.

Короткая форма: «готово ли (главы, линт, тест) → честно ли (карточка, граница, этика) → не ломает ли (ревизия,
файл)».
