# Признаки: красные и зелёные

Что видно в тексте или замере, какой командой ловить и как чинить. Команды — по одной на вызов, ровно
как написаны. Числа — ключами `thresholds.json`.

## Красные

| признак | чем поймать | правка |
|---|---|---|
| кнопка называет имя или время, которого игрок на этом пути не слышал | `npm run -s story:lint -- --story <id> --only C-51` (`C-51.unknown_fact`) | условие `* {knows_x}` или кнопка без факта (`patterns-continuity.md` P1) |
| персонаж в общем узле представляется заново | C-51 (`C-51.met_twice`), `merges.mjs` «опора» | [F-13](fixes/F-13-merge-guard.md), вход по счётчику посещения |
| персонаж называет факт из чужого чата | `node ${CLAUDE_SKILL_DIR}/scripts/knowledge.mjs --story <id>` «знает лишнее» | условие на перенос или кнопка переноса раньше (P4); свидетель — запиши в facts.md «кто знает» |
| закрытый контакт пишет дальше как ни в чём не бывало | глазами по `#sys` «заблокировал» / «ушёл»; поздние реплики без условия | P5 — реплики под `{not blocked}` |
| одно событие — разное время в двух узлах | `node ${CLAUDE_SKILL_DIR}/scripts/facts.mjs --story <id>` «кандидаты»; с facts.md — «реестр» | правка «меньшинства» по хронологии; ложь — `// намеренно: C-49 ложь` |
| время в реплике, которого нет в хронологии | C-49 (`C-49.facts`), `timeline.mjs` «✗ нет в facts.md» | внести в хронологию или исправить реплику |
| две реплики «сейчас ЧЧ:ММ» расходятся с паузами между ними | `node ${CLAUDE_SKILL_DIR}/scripts/timeline.mjs --story <id>` (`C-51.clock_drift_min`) | поправить время в реплике или длину `#delay` (длину — с `story-time`) |
| каскад на входе шире порога | `merges.mjs` «каскад» (`C-51.cascade_branches`) | разделить сцену или свести состояния (`canon.md`, PAT-04) |
| ветка каскада ни разу не выпадает, блок без `else` | C-15 (`C-15.never`, `C-15.no_else`) у `story-choices` | узкое выше, `else` последним |
| текст повторяется после второго входа в узел | `merges.mjs` «повторы» (C-46 `C-46.path_repeat`) | F-13 шаг «лишнее»; копия в нескольких узлах — туннель (`story-voice`) |
| в главе два чата со своим знанием, но они не пересекаются | `knowledge.mjs` «! нет переноса» | кнопка `#to` с фактом из другого чата и эхо (P4, R-55) |
| нет facts.md, а в тексте точное время | `facts.mjs` «facts.md: нет» | черновик `facts.mjs --draft` → автор → `story-desk` |
| новый контакт дописан в готовую историю | `git diff` по `meta.json`, `merges.mjs --all` | проход по узлам, где упомянуты остальные |
| больше трёх состояний мира на главу | `npm run graph`, `merges.mjs` «разное на входах» | свести в одно сводное (`mobile-interactive-stories:RED-07`) |

## Зелёные

| признак | как увидеть | зачем держать |
|---|---|---|
| в общем узле `{флаг: …|…}` на контакт | `merges.mjs` не помечает «опору» | персонаж знает, писал ли ему игрок (`inkle-ingold:GREEN-03`) |
| каскад от узкого к общему, `else` есть, каждая ветка выпадала | C-15 молчит | реплика попадает в ситуацию (`procedural-storytelling:GREEN-03`, `emshort-structures:GREEN-08`) |
| одно событие доставляется разными путями | блок по исходу прошлой главы в начале главы | связность при любой предыстории (`procedural-storytelling:GREEN-06`) |
| факт из чата A открывает кнопку в чате B | `knowledge.mjs` «кнопок-переносов» > 0 | ощущение расследования (`messenger-genre:GREEN-03`) |
| игрок знает больше собеседника и решает, сказать ли | кнопки в два `#to` и «промолчать» | драматическая ирония (`mckee-story:GREEN-06`) |
| время одного события повторяется символ в символ | `facts.mjs` — нет кандидатов, реестр без расхождений | нестыковка не станет ложной уликой (`narrative-testing:GREEN-05`) |
