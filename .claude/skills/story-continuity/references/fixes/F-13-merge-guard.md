# F-13 · Защитить слияние

Ремонтный приём `story-continuity`. Применяет `story-fix` — только одобренное. Ссылаются `story-review`
(находки C-51 и повторы C-46 после слияния) и `story-choices` (каскад на входе в хаб).

### F-13 · Защитить слияние

**Когда.** Узел с двумя и более входами, а факт или знакомство с контактом есть не на всех путях: C-51
(`C-51.unknown_fact`, `C-51.met_twice`), «! опора» у `merges.mjs`; или на другом пути то же уже сказано —
повтор на пути C-46 (`C-46.path_repeat`) из-за второго входа в общий узел.

**Шаги.**
1. Входящие рёбра узла и что приходит по каждому: `node ${CLAUDE_SKILL_DIR}/scripts/merges.mjs --story <id> --node <узел>`
   (входы, «разное на входах», «опора»). Карта — `npm run graph` при необходимости.
2. Множества «кому игрок писал / что слышал» на каждом входе — оттуда же; если факт не имя и не время,
   сначала заведи его слово в реестр `facts.md` ([facts-format.md](../facts-format.md)).
3. **Нужное.** Каждую реплику и кнопку узла, которая опирается на разное, оберни условием: флаг знания,
   счётчик посещения узла (`{gleb_first}`), метка варианта. Факт, который игрок мог пропустить, — повторное
   введение одной фразой, а не пересказ (ST-03).
4. **Лишнее.** Реплика, которая на другом пути уже прозвучала, — под `not`: персонаж не спрашивает то, на что
   игрок уже ответил (`inkle-ingold:LESSON-07`).
5. Упорядочи каскад: самое узкое и свежее выше, `else` последним; веток не больше `C-51.cascade_branches`,
   иначе раздели сцену (R-35).
6. Прочитай `docs/style.md` (ST-03, ST-10, ST-15) прямо перед тем, как писать реплики веток: голос тот же,
   имя то же.
7. Перезапусти: `npm run -s story:lint -- --story <id> --only C-51,C-15,C-46` и `merges.mjs --node <узел>`.

**Готово, когда.** Нет реплик и кнопок про незнакомый факт (C-51 молчит по узлу); у каждой ветки условия
хотя бы одно выполнение за прогоны бота (C-15 `C-15.never` молчит); повтор на пути ушёл.

**Что нельзя сломать.** Хвост сцены общий — каскад меняет строку, а не сцену (иначе ветвление растёт
сочетаниями); выбор игрока и его последствия — переменные не трогаем; число кнопок и адресаты — как были;
голос персонажа в каждой ветке один (`story-voice`).

**До** (Глеб представляется заново тому, кто уже с ним говорил):

```ink
# contact: tamara, Тамара, teal
# contact: gleb, Глеб, amber
-> start
=== start ===
к кому сначала? #from:tamara
* [К сторожу #to:tamara] -> gleb_first
* [Сразу к боксу #to:tamara] -> box
=== gleb_first ===
я Глеб, сторож. ключи у меня #from:gleb
-> box
=== box ===
здравствуйте. я Глеб, сторож этого склада #from:gleb #delay:1m
третий бокс открыт. замок целый #delay:20s
-> END
```

**После** (вход по счётчику посещения, хвост общий):

```ink
# contact: tamara, Тамара, teal
# contact: gleb, Глеб, amber
-> start
=== start ===
к кому сначала? #from:tamara
* [К сторожу #to:tamara] -> gleb_first
* [Сразу к боксу #to:tamara] -> box
=== gleb_first ===
я Глеб, сторож. ключи у меня #from:gleb
-> box
=== box ===
{gleb_first:
    это опять Глеб. я у бокса #from:gleb #delay:1m
- else:
    здравствуйте. я Глеб, сторож этого склада #from:gleb #delay:1m
}
третий бокс открыт. замок целый #from:gleb #delay:20s
-> END
```
