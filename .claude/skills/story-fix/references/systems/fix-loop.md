# Система: цикл одной правки

Цикл, по которому `story-fix` проводит каждый одобренный пункт. Собран из практики регрессионных маршрутов
(`narrative-testing:P-16`), шага 7 разбора цикла (`flow-review.md`) и решения автора об одобрении. Своими словами.

## Шаги

| шаг | вход → выход | что будет без шага |
|---|---|---|
| 1. Пункт | находка + выбранный вариант (или приём F-NN) → одобренный пункт с именем одобрившего | правка без одобрения — нарушение `INTENT.md` |
| 2. Свежесть | ink «до» варианта → «найдено в файле:строке» или «устарело» (`pick.mjs --story`) | вариант ляжет не туда или затрёт чужую правку |
| 3. Маршрут (баг) | путь, где баг виден → маршрут `--route` и его нынешний финал | после правки нечем доказать, что баг ушёл и не вернётся |
| 4. Правка | вариант → текст в файле главы, каркас (переходы, сборки, метки) на месте | — |
| 5. Страховка | «до» и «после» → `fix-guard.mjs`: цело / проверь / сломано | сломанная переменная или улика всплывёт у игрока |
| 6. До и после | обе ревизии → `text-diff.mjs` (реплики) и `diff-report.mjs` (полный lint, метрики) | автор видит цифры, но не реплики; регрессия в чужой ветке не видна |
| 7. Повтор линзы | изменённые узлы → та же линза или читатель на тех же узлах | правка закрыла цифру, а не симптом |
| 8. Отчёт и состояние | всё выше → `reviews/<дата>-story-fix.md`, строка `STATUS.md`, D-NN — через `story-desk` | находки и решения теряются в разговоре (LOCAL-10) |

## Ошибки понимания

- **«Lint зелёный — значит, правка хорошая».** Lint ловит форму; «скучно» и «не верю» закрывает повтор линзы
  и, позже, человек.
- **«Маршрут нужен только для тупиков».** Маршрут ловит и смену финала на пути, который правка не собиралась
  трогать.
- **«Повтор линзы — вся линза заново».** Только изменённые узлы: иначе отчёт утонет в старых находках, уже
  разобранных автором.

## Короткая форма

Одобрено → «до» на месте → (баг: маршрут) → правка → `fix-guard` → `text-diff` + `diff-report` → линза на
узлах → отчёт через `story-desk`.

- **Когда не работает.** `--compress` — не одна правка, а серия: цикл идёт по каждому сокращению, а шаг 6 —
  ещё раз в конце по всей истории с `compress-plan.mjs`.
- **Масштаб.** Правка одной реплики проходит цикл за минуты; правка главы — шаги 5–7 по каждому узлу и раз
  на всю главу.
- basis: secondary (`narrative-testing:P-16`; `flow-review.md` §A шаг 7).
