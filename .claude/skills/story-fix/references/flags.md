# Признаки хорошей и плохой правки

Каждый признак — чем его поймать (команда) и что делать. Числа — из команд, не на глаз.

## Красные

| признак | почему плохо | как поймать | что делать |
|---|---|---|---|
| правка без одобрения пункта | нарушает `INTENT.md`: скилл предлагает, применяет только одобренное | в отчёте нет строки «одобрено: кем» | откатить, показать пункт ([approval.md](approval.md)) |
| вариант переписан «чуть лучше» | автор одобрял другой текст | `pick.mjs --take … --story <id>` против `text-diff.mjs` | вернуть дословный вариант или показать новый пунктом |
| вариант применён к устаревшему узлу | «до» не совпало — правка легла не туда | `pick.mjs --story <id>`: «устарело» | повтор линзы на узле |
| правка вышла за одобренные узлы | автор видит сюрприз в дифе | `text-diff.mjs --nodes …`: «изменены и другие узлы» | объяснить или откатить лишнее |
| из узла раскрытия ушли реплики | улика пропала (RED-10) | `fix-guard.mjs`: «улики ⚠/✗» | вернуть, раздробить подачу ([patterns-fix.md](patterns-fix.md)) |
| пропала запись или видимое чтение переменной | кнопка опустела, финал ничего не помнит | `fix-guard.mjs`: «переменные ✗» | вернуть запись, дать эхо (F-08) |
| новая находка в чужом узле | регрессия в другой ветке | `diff-report.mjs`: «появились в других местах» | разобрать по ink: регрессия → новый пункт, сдвиг замера → ложное |
| ошибок `story:lint` стало больше | правку нельзя сдавать | `diff-report.mjs`, код выхода 1 | чинить до сдачи |
| метка `// намеренно:` без решения | проверка погашена навсегда без следа | `fix-guard.mjs`: «метки ⚠/✗» | D-NN через `story-desk` или снять метку |
| реплика правки называет срок паузы или упрекает за отсутствие | A-01, A-03 | `npm run -s story:lint -- --story <id> --only C-27,C-47` | причина без срока, без упрёка (`docs/style.md` ST-60, ST-66) |
| в правке тег не `ready` | движок его не покажет | `npm run -s story:lint -- --story <id> --only C-53` | тег из `docs/capabilities.json` |
| баг закрыт без маршрута | следующая правка вернёт его незаметно (`narrative-testing:P-16`) | `fix-guard.mjs` без маршрутов, в отчёте нет `--route` | записать маршрут, повторить |
| «сжать» отрезало финал или развязку | короткая история без ответа на вопрос начала | `fix-guard.mjs`: «финалы ✗»; `diff-report.mjs`: доли финалов | вернуть развязку, сжать её (F-12) |
| реплики написаны без `docs/style.md` | голос и формат плывут (LOCAL-09) | `npm run -s story:lint -- --story <id> --only C-34,C-14,C-13` | открыть style.md перед репликой |

## Зелёные

| признак | почему хорошо | как увидеть |
|---|---|---|
| у каждой правки — строка находки, вариант и кто одобрил | автор видит, что и почему поменялось | отчёт `reviews/<дата>-story-fix.md` |
| `fix-guard.mjs` — «цело» или каждое «⚠» разобрано | ничего не сломано рядом | вывод скрипта в отчёте |
| «ушли» в `diff-report.mjs` совпадают с одобренными находками, «появились в других местах» пусто | правка точная | раздел «До и после» |
| дифф реплик короткий и про то, что почувствует игрок | автор учится, а не читает код | `text-diff.mjs --md` |
| линза на изменённых узлах находку больше не видит | правка закрыла симптом, а не цифру | повтор линзы |
| маршрут бага сохранён и проходит | регрессия поймается в следующий раз | `fix-guard.mjs`, раздел «маршруты» |

- **Когда не работает.** История вне git: `fix-guard` и `diff-report` без ревизии «до» видят только «после» —
  признаки «пропало» не ловятся. Сохрани копию до правки коммитом.
- basis: our_estimate.
