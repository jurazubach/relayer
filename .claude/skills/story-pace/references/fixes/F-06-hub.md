# F-06 · Хаб вместо коридора

Приём владельца `story-pace`: лечит скуку длинного обязательного коридора. Правила хабов (выход, число спиц,
анкета, тонкие спицы — R-34, R-36, C-19) держит `story-choices` (`choice-types.md`, `hubs.md`); здесь — только
перестройка коридора. Применяет `story-fix` после одобрения. Перед письмом — `docs/style.md` (ST-30…ST-34).

### F-06 · хаб вместо коридора
**Когда:** в главе почти нет узлов с несколькими выходами, или экспозиция дольше `C-35.series` входящих подряд
(C-35), а биты коридора не зависят друг от друга по порядку (обойти места, опросить нескольких, разобрать вещи).
**Шаги:**
1. Выдели биты без порядковой зависимости; бит, который нужен для следующего, остаётся в стволе.
2. Заведи одну переменную-счётчик пройденных бит.
3. По сторилету на бит: короткая сцена со своим ответом и записью счётчика; один сторилет — условный по прошлому
   ответу игрока (память, а не только порядок).
4. Выход — по счётчику, без полного обхода, и реплика-прогресс («ладно, двух хватит»).
5. Проверь: `npm run -s story:lint -- --story <id> --only C-19,C-35` (C-19 — у `story-choices`) и `npm run check:story`.

**Готово, когда:** хаб из трёх-четырёх веток (границы спиц — `C-19.spokes_min`, `C-19.spokes_max`), выход виден и
доступен без полного обхода, серия коридора ниже `C-35.series`. **Нельзя сломать:** факты, которые нужны дальше
по стволу (они либо в каждой спице, либо в стволе после хаба); выход хаба (без него тупик — `check:story`).
**Когда не работает:** биты зависят друг от друга по порядку; первая глава (хаб в начале — меню, а не переписка,
`#attn-cut`); хаб на много адресатов, где игрок не помнит, кому писал. basis: secondary
(`failbetter-qbn:/storylet-hub`, PAT-01; `emshort-structures:PAT-04`).

До — коридор: смотритель по очереди рассказывает про три места.

```ink
# contact: vit, Вит, indigo
-> walk
=== walk ===
у пирса пусто. лодка на месте #from:vit
у склада замок цел #delay:30s
сторожка открыта. чайник тёплый #delay:30s
значит он был тут недавно #delay:20s
* [Где он сейчас? #to:vit]
- -> END
```

После — хаб: игрок выбирает, куда Виту идти, выход после двух мест.

```ink
# contact: vit, Вит, indigo
VAR seen = 0
VAR asked_boat = false
-> hub
=== hub ===
{seen == 0: я у пирса. куда сначала? #from:vit}
{seen == 1: дальше куда? #from:vit}
* [Проверь лодку #to:vit]
    ~ asked_boat = true
    лодка на месте. вёсла мокрые #from:vit #delay:30s
    ~ seen += 1
    -> hub
* [Загляни на склад #to:vit]
    замок цел. но следы у двери свежие #from:vit #delay:30s
    ~ seen += 1
    -> hub
* [Сторожка #to:vit]
    открыта. чайник тёплый #from:vit #delay:30s
    {asked_boat: и вёсла мокрые. он вернулся с воды}
    ~ seen += 1
    -> hub
+ {seen >= 2} [Хватит. Где он сейчас? #to:vit]
    ладно, двух хватит. думаю, он на маяке #from:vit #delay:20s
    -> END
```
