# F-02 · Рекап после паузы

### F-02 · Возврат непонятен или пуст → первая строка с событием и якорем

**Когда.** C-28: первая строка после паузы — приветствие, пустая или закрывающая (`C-28.greeting`); нет связки с
крючком (`C-28.link`); пачка до кнопки длиннее `C-28.pack` (после `C-28.pack_long_pause_s` — `C-28.pack_long`);
C-29 `C-29.opening_repeat` — одна формула открытия; холодный читатель после паузы не понимает, о чём речь.
Сверь с ink: первое сообщение нового контакта и «доброе» с переменой после тяжёлой ночи — не дефект.

**Шаги.**
1. Собрать петли, открытые на момент паузы, и узел ближайшей развилки после неё.
2. Выбрать петлю, которая платится в этой развилке: о ней и напоминаем (`serial-hooks:P-10`).
3. Выбрать ступень по длине паузы (`attn.recap.hook_h`, `attn.recap.stake_h`, `attn.recap.deed_h`, [../return.md](../return.md)):
   предмет крючка → плюс ставка или срок мира → плюс эхо поступка игрока.
4. Первая строка — событие («эмоция + имя или предмет», новость, ход противника), вежливость — вторым пузырём.
   Без «напомню», «итак», «как ты помнишь», «в прошлый раз»; без «наконец-то» и «ты долго» (R-122, `story-time`).
5. Если до паузы была развилка — строка под условием `{var: … | …}`, узкое условие первым; невыбранное не
   напоминать (R-71).
6. Кнопка — не дальше `C-28.pack` входящих; длинную пачку разрезать кнопкой-реакцией.
7. Перезапустить `npm run -s story:lint -- --story <id> --only C-28,C-29,C-47` и `hook-pairs.mjs`.

**До:**

```ink
# contact: asya, Ася, teal
VAR took_key = false
-> gate
=== gate ===
ключ от подсобки у меня. брать с собой? #from:asya
* [Бери #to:asya]
    ~ took_key = true
* [Оставь на вахте #to:asya]
- ок. мне на смену #from:asya
Ася не в сети #sys:asya
#delay:9h
привет #from:asya
ну что, продолжим? #delay:4s
-> END
```

**После:**

```ink
# contact: asya, Ася, teal
VAR took_key = false
-> gate
=== gate ===
ключ от подсобки у меня. брать с собой? #from:asya
* [Бери #to:asya]
    ~ took_key = true
* [Оставь на вахте #to:asya]
- ок. мне на смену #from:asya
Ася не в сети #sys:asya
#delay:9h
{took_key:ключ так и лежит у меня в кармане. а подсобку ночью вскрыли|ключ с вахты пропал. а подсобку ночью вскрыли} #from:asya
до проверки склада три часа #delay:5s
* [Что пропало? #to:asya]
* [Кто был на вахте? #to:asya]
- -> END
```

**Что нельзя сломать.** Не менять переменные и переходы; не напоминать невыбранное; не вводить новичка первой
строкой (R-72); если перед паузой был крючок — первая строка его подхватывает, а не отменяет (R-69). Реплика по
`docs/style.md` ST-62, ST-63.

- **Когда не работает.** Паузы короче `story.pause.notice_min` — напоминание звучит как повтор; рекап по ветке, которую
  никто уже не читает, — общий для всех.
