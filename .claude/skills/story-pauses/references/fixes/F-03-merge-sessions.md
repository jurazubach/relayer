# F-03 · Склейка сессий

### F-03 · Микросессии и паузы подряд без кнопки → одна пауза, одна полная сессия

**Когда.** C-30: доля микросессий выше `C-30.micro_share` (возврат из `C-30.micro_lines` строк без кнопки), паузы
подряд без кнопки (`C-30.streak_warning`, `C-30.streak_error`); C-33 `C-33.return_min_msgs` — возврат не окупается.
Хроника последствий из нескольких реплик с часовыми паузами — та же капельница. Сверь с ink: пауза с сюжетной
причиной (событие мира в назначенный час) и серия коротких возвратов, которая сама сюжет, — не дефект.

**Шаги.**
1. Выписать цепочку: паузы от `story.pause.session_s` между двумя кнопками и что приходит после каждой
   (`npm run story:sessions -- --story <id> --schedule`).
2. Оставить одну длинную паузу — ту, у которой есть причина в мире; остальные сжать до секунд-минут «печатает…»
   внутри одной сессии.
3. Внутри склеенной сессии дать кнопку: реакцию с содержанием, а не «дальше» (`bateman-game-writing:contra-2`).
4. Перед оставшейся паузой — крючок (F-01).
5. Пересчитать реальное время: склейка его сокращает — `days` на карточке сверяет `story-time` (C-31).
6. Перезапустить `npm run -s story:lint -- --story <id> --only C-30,C-33` и `story:sessions`.

**До:**

```ink
# contact: ostap, Остап, grey
-> after
=== after ===
он подписал #from:ostap
* [И что теперь? #to:ostap]
* [Ты уверен? #to:ostap]
- юрист уехал #from:ostap #delay:1h
склад опечатали #delay:1h
ключи забрали #delay:1h
* [Это конец? #to:ostap]
* [А мы? #to:ostap]
- -> END
```

**После:**

```ink
# contact: ostap, Остап, grey
-> after
=== after ===
он подписал #from:ostap
* [И что теперь? #to:ostap]
* [Ты уверен? #to:ostap]
- еду на склад, посмотрю своими глазами #from:ostap
Остап не в сети #sys:ostap
#delay:2h
юрист уже уехал. склад опечатали #from:ostap
* [А ключи? #to:ostap]
    забрали. все три связки #from:ostap #delay:30s
* [Ты внутрь попал? #to:ostap]
    нет. печать на моей двери тоже #from:ostap #delay:30s
- на печати чужая фамилия #delay:20s
* [Это конец? #to:ostap]
* [А мы? #to:ostap]
- -> END
```

**Что нельзя сломать.** Паузу с сюжетной причиной не склеивать; переменные и ветки не трогать; не превращать склейку
в стену — внутри одна-две кнопки; «живое» ожидание, если оно важно, оставить одной короткой паузой.

- **Когда не работает.** Серия коротких возвратов — сам сюжет («пиши, пока я внутри»): тогда паузы внутри короче
  `story.pause.session_s`, и это не микросессии.
