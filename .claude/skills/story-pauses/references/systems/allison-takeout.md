# Система: развязки клиффхэнгера (по Эллисон)

### serial-hooks:SYS-1 · Три вида выхода из обрыва и порядок выбора

Киновед Дебора Эллисон делит развязки клиффхэнгера («выход из ситуации») на три вида: последовательная —
продолжение с той же секунды; дополненная — деталь, которой зритель не видел, но увиденное остаётся верным;
несовместимая — развязка противоречит увиденному. Третья — обман. Это виды *развязок*, а не крючков; шаги — порядок,
в котором автор выбирает развязку для первой сессии после жёсткого крючка (R-69).

| шаг | вход → выход | если пропустить |
|---|---|---|
| 1. Зафиксировать, что игрок видел | строки крючка в окне `C-26.window_lines` → список фактов F, поданных как факт (не как подозрение) | автор «забудет», что подал как факт, и отменит его |
| 2. Выбрать последовательную | F и ситуация сразу после → продолжение с той же секунды | — самый безопасный вариант |
| 3. Или дополненную | F плюс деталь D, которой не было на экране → F верно, D меняет смысл | без D развязка выродится в последовательную — это не ошибка |
| 4. Проверить на несовместимость | развязка → ни один факт F не отменён | игрок узнаёт, что крючки врут, следующие паузы не держат |

- **Где понимают неверно.** (а) Путают дополненную развязку с «поворотом»: новая деталь делает увиденное неполным,
  а не ложным. (б) Считают обманом любое снижение угрозы — снижение допустимо, если угроза меняет форму (курьер
  вместо преследователя, но конверт с именем игрока). (в) Переносят правило на подозрения: крючок «мне кажется, за
  мной идут» честно разрешается «показалось». Правило касается только фактов.
- **Короткая форма.** На 5 сообщениях шаг 1 — один вопрос «что утверждает последняя строка?», шаги 2–4 — «не
  отменяй». На 50 с десятком пауз ревьюер выписывает F для каждой жёсткой паузы; словарь C-29 (`C-29.retract`,
  `dict.false_alarm`) ловит только явные слова отмены, а не тонкие противоречия.
- **Когда не работает.** Мягкий крючок (срок события, отношения): возврат может начать новую сцену, фактов для
  сверки нет.
- basis: secondary (классификация по энциклопедии) · разбивка на шаги — наша.

## Источники

- `serial-hooks:SYS-1`, `P-02`, `PAT-02`; свод R-69, C-29.
