# Нужна ли картинка и какая

Картинка в мессенджерной истории — это то, что персонаж **показывает**, а не то, что автор **иллюстрирует**.
Её прислал кто-то из героев: скрин, фото с телефона, кадр видео, пост. Игрок получает её как улику — и смотрит
дольше, чем читает строку.

## Когда картинка сильнее строки

| случай | пример | вид |
|---|---|---|
| доказательство, которое игрок проверяет сам | скрин переписки с обрезанным временем, детализация звонков | `screen` |
| улика, которую надо заметить | карта памяти на ладони, синяк на запястье, мокрые кроссовки | `photo` |
| место, куда сюжет вернётся | уступ карьера ночью, старая лестница | `photo` |
| человек, которого игрок ещё не видел | фото с вечеринки, где кто-то лишний на заднем плане | `photo` + `refs` |
| документ, почерк | страница дневника, записка | `photo` + `overlay` |
| публичный шум | пост в местной группе, заголовок новости | `screen` (`post`) |

## Когда не нужна

- `shows` пересказывает строку рядом и не даёт ни детали, ни ощущения.
- Деталь, ради которой картинка, не читается в пузыре ≈ 280 точек (мелкий текст на фото, лицо в толпе).
- Картинка отвечает на вопрос, который сюжет ещё держит: лицо виновного, время, имя.
- Три картинки подряд от одного персонажа: каждая следующая весит меньше. Серия кадров видео — исключение,
  если кадры спорят друг с другом.

## Линза ревью (вызов из story-review)

Пройди `npm run -s story:images -- <id>` и сцены с глаголами «скинул», «вот», «смотри», «скрин», «фото».
Находки — строкой общего формата, источник `модель`:

```
P2 · скучно · ch1_ellie_lie · алиби Элли — строкой «Скрин переписки…» без картинки: игрок не видит, что время обрезано · бриф ch01-mom (screen/chat, hideTimes) · [модель]
P1 · непонятно · ch9_receipt · детализация на 9 номеров одной строкой 230 знаков · скрин list по строке на звонок · [модель]
P1 · спойлер · ch05 · бриф ch05-frame1: лицо Джесс на кадре, а строка говорит «чей-то шёпот» · убрать лицо из промпта · [модель]
```

Приоритет: спойлер и противоречие `facts.md` — P1; нечитаемая улика — P1; заглушка там, где игрок должен что-то
заметить, — P2; заглушка «для настроения» — P3.
