# Скрины: шаблоны templates/screen.html

`render.mjs` подставляет `data` брифа в шаблон и снимает chromium'ом из Playwright: ширина 390 точек, плотность 2,
высота по содержимому (минимум — `data.height`). Мессенджер без марки и логотипов — похож на «телефон вообще»,
не на конкретное приложение. Тема — `theme` брифа или `look.screen`.

Общее для всех шаблонов: `status: "00:52"` — строка состояния телефона с часами сверху (нет поля — скрин обрезан
под ней); `height: 360` — минимальная высота в точках, чтобы короткий скрин не был полоской.

## chat — переписка

```json
{ "title": "мама", "subtitle": "был(а) недавно", "hideTimes": true, "height": 360,
  "messages": [
    { "day": "22 июня" },
    { "text": "ты где?", "time": "00:47" },
    { "text": "иду", "time": "00:49", "out": true },
    { "from": "Бет", "text": "в группе — имя отправителя", "time": "00:50" },
    { "text": "элли", "time": "00:41", "out": true, "fail": "Не доставлено" }
  ] }
```

`hideTimes` — время у сообщений не показано (скрин «подрезан»); `out` — сообщение владельца телефона справа;
`fail` — подпись под сообщением (`true` — «Не доставлено»). Сообщения прижаты к низу, как в настоящем чате.

## note — заметка

```json
{ "app": "Заметки", "edited": "Изменено: сегодня, 05:38", "title": "", "text": "это Оуэн Брайт!! он держал меня за руку", "height": 300 }
```

## list — список: участники, звонки, детализация

```json
{ "header": "Shortest Night 🔥", "headerSub": "6 участников", "title": "", "subtitle": "",
  "rows": [
    { "name": "Коннор", "sub": "был(а) вчера" },
    { "name": "Lily 💧", "sub": "был(а) 22 июня", "dim": true },
    { "name": "SMS → …188", "sub": "22 июня", "right": "00:24" }
  ],
  "noAvatars": false, "footer": "Элли вышла из чата" }
```

`header` — шапка с «назад» и кружком; `title` — крупный заголовок без шапки (детализация, журнал вызовов);
`dim` — серая строка; `right` — правая колонка (время, длительность); `noAvatars` — без кружков.

## post — пост в группе, новость

```json
{ "source": "Wexcombe Community Noticeboard", "author": "Wexcombe Watch", "time": "01:12",
  "text": "Кто-то пишет нашим детям под видом опроса…", "audio": { "duration": "0:14" },
  "image": "ch05-ledge", "stats": "48 комментариев" }
```

`title` — заголовок крупно (новость); `audio` — дорожка с волной («дорожка с уступа»), `{ "duration": "0:14" }` — длительность, если строка её называет; `image` — другая картинка
истории внутри поста (сначала её); `quote` — вложенный скрин сообщения:
`{ "title": "скрин переписки", "text": "Здравствуйте", "blurred": "! Я …", "out": true }`. В `blurred` — то, что у
игроков разное (имя `{alias}`, легенда по ветке): картинка одна на все прохождения, поэтому это размыто.

## overlay — текст поверх фото (kind photo)

Почерк, записка, надпись на стене: фото делает FLUX с **пустым** местом под текст («a blank lined notebook page,
no writing»), текст кладёт шаблон шрифтом — буквы точные, кириллица на месте.

```json
"overlay": [
  { "text": "если что-то случится,\nне дайте им обвинить элли", "bbox": [0.32, 0.18, 0.62, 0.84],
    "font": "hand", "color": "#1d2a5a", "size": 0.05, "rotate": -3, "align": "left", "opacity": 0.88 }
]
```

`font`: `hand` (Caveat, быстрый почерк), `neat` (Neucha, аккуратный), `script` (Marck Script, с наклоном),
`print` (печатный). `size` — доля высоты кадра; `bbox` — как у рамок FLUX, y первым. Шрифты берутся из Google Fonts
при сборке; без сети будет запасной рукописный. Сверь `bbox` с рамкой листа в `boxes` — текст должен лечь на бумагу.
