# Объясни: зачем база, ссылки и споры

Для автора, который спрашивает «почему ты отвечаешь так» и «как пользоваться базой самому».

## Почему у каждого ответа ID

База — 30 разборов книг, статей и постмортемов, пересказанных под переписку на ink. Свод (`rules.md`,
`checks.md`) собран из неё. Ответ с ID можно проверить: открыть строку, увидеть, на чём она стоит и насколько
уверен автор разбора. Ответ без ID — мнение модели, его нельзя ни проверить, ни оспорить. Поэтому ID — не
формальность, а то, что отличает знание от правдоподобного текста.

## Почему у нас иногда не так, как в книге

Решения автора выше любой книги: два равноценных режима, никаких сроков возвращения, никакой привязки к
часам игрока, напоминания вместо вечного ожидания. Книги писались для других форматов — сериал, роман,
визуальная новелла. Что из них отменено и что осталось — `docs/playbook/superseded.md`, коротко —
[superseded.md](superseded.md).

## Почему источники спорят и кто прав

Чаще всего спор мнимый: один источник говорит о секундах, другой о часах; один о сцене на 5 сообщений,
другой о главе на 50. Настоящие споры решены в своде одним принципом: на телефоне в начале — строже, дальше —
мягче, число — в `thresholds.json`. Как это устроено — [contradictions.md](contradictions.md).

## Как пользоваться базой самому

1. Есть вопрос — `node .claude/skills/story-kb/scripts/kb-search.mjs <слова>`: строки, их владелец и статус.
2. Есть номер правила — `npm run story:rule R-NN`: текст и опоры.
3. Хочешь понять книгу — `kb-index.mjs --alias <алиас>`, потом README разбора: «Главная мысль» и «Уверенность».
4. Два совета расходятся — `kb-contradictions.mjs <слова>`.

## Упражнение

Возьми одно правило свода, которое тебе кажется странным (например, сколько входящих до первой кнопки).
1. `npm run story:rule R-NN` — прочитай опоры.
2. `kb-search.mjs <алиас:ID>` для двух опор — какого они класса (данные, постмортем, мнение)?
3. `kb-contradictions.mjs <слово из правила>` — был ли спор и как решён.
4. Запиши одной фразой, при каком масштабе истории правило перестаёт работать. Сверь с полем «Когда не
   работает» у владельца. Совпало — ты читаешь базу так же, как скиллы.
