# Уроки: как взвешивать доводы базы

Карточки на 3–5 строк о том, насколько можно доверять разным видам знания в базе. Класс доказательства:
**A** — эксперимент или данные; **B** — постмортем с цифрами; **C** — мнение, отзыв, риторика. Сами уроки
держат владельцы тем (ID в скобках) — здесь только то, что нужно, чтобы ответить автору «насколько это
правда». Реальные компании и игры в уроках — факты о чужих продуктах, не материал для сюжетов.

## Цифра без замера — не правило · C

«Внимание короче, чем у золотой рыбки» разошлось по презентациям, хотя за цифрой нет исследования: источник
сослался на сайт, у которого источника нет. Измеряемое другое — как часто человека прерывают.
**Урок для ответа:** число из базы называть с опорой и `basis`; число без опоры — «наша оценка», ключом
`thresholds.json`. (`attention-today:LESSON-01`, владелец `story-pauses`.)

## Долгий эксперимент сильнее первой недели · A

Большая соцсеть в годовом эксперименте срезала слабые уведомления: первые недели заходов было меньше, к концу
года — больше. **Урок для ответа:** данные платформ — класс A, но о своей платформе; перенос на переписку в
игре — с оговоркой «другой продукт». (`attention-today:LESSON-05`, владелец `story-pauses`.)

## Активное внимание меряют, а не предполагают · A

Аналитика по миллиардам визитов показала, что заметная доля читателей уходит со страницы в первые секунды,
хотя издатели считали визит чтением. **Урок для ответа:** «первый экран решает» — данные о вебе, для нашего
начала они дают направление, а порог ставит свод (C-20). (`edgerton-hooked:LESSON-10`, владелец `story-opening`.)

## Отзыв одного рецензента — сигнал, не закон · C

Порт игры-переписки без реального времени рецензент назвал рваным: прыжки между беседами вместо ожидания.
**Урок для ответа:** это одно мнение, но оно совпадает с риском, который решения автора оставили открытым
(ожидание без известного конца) — поэтому риск проверяется, а не принимается на веру.
(`messenger-genre:LESSON-10`, владелец `story-time`; опора A-04 — `schell-art-of-game-design:LESSON-06`.)

## Нейронаука — только поведением · A против C

Поведенческое наблюдение (люди читают даже сухие новости через намерения героев) проверено; «химия истории»
спорна; знание исхода по данным о спойлерах удовольствию не мешает. **Урок для ответа:** довод «так устроен
мозг» переводить в «что игрок делает и замечает». (`cron-wired-for-story:SYS-5`, [index.md](index.md).)

## Данные тестера сильнее его рецепта · B

Тестер точно говорит, где не понял или заскучал, и часто ошибается, предлагая, как чинить. **Урок для
ответа:** в разборе сцены автора отделять «что почувствовал читатель» от «как исправить»; советы — последними.
(`narrative-testing:P-05`, владелец `story-review`; [systems/scene-review.md](systems/scene-review.md).)

## Модель повторяет ложный замер, если не сверила его с ink · A (наш эксперимент)

В мини-эксперименте с ревью все ложные находки были повтором замера без сверки с текстом и правилом.
**Урок для ответа:** наставник, опираясь на замер в разборе сцены, сначала открывает узел и правило
(`npm run -s story:rule C-NN`). (LOCAL-04, `docs/playbook/local-lessons.md`.)

## Бери инструмент, а не книгу · C

Методы целиком перегружают: шесть теорий подряд дают противоречивые правки к одному тексту.
**Урок для ответа:** на «как по Снайдеру / Труби / Воглеру» отвечать одним инструментом метода, подходящим к
вопросу, со ссылкой на владельца. (`snyder-save-the-cat:LESSON-12`, владелец `story-review`.)
