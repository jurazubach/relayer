# Признаки хорошего и плохого ответа по базе

Красные — ответ нельзя отдавать автору, пока не исправлен; зелёные — так и должно быть. У каждого — чем
поймать и как исправить. Команды — по одной на вызов.

## Красные

| признак | чем поймать | как исправить |
|---|---|---|
| утверждение без ID («база говорит, что…») | перечитать ответ: у каждого порога, запрета и совета есть `алиас:ID`, `R-NN`, `C-NN` или `A-NN` | найти строку `kb-search.mjs <слова>`; не нашлась — пометка «модель, в базе нет» |
| число в тексте без ключа | число в ответе, которого нет в выводе команды | ключ `thresholds.json` (`kb-contradictions.mjs --attn` печатает ключи споров) |
| отменённое как действующее | `kb-search.mjs <ID>`: статус `superseded:A-NN` или «в силе частично» | решение автора первым, книга — с пометкой «отменено: A-NN» ([superseded.md](superseded.md)) |
| спор решён молча одной стороной | `kb-contradictions.mjs <слова>` находит спор, а в ответе одна сторона | спор → решение → на чём стоит ([contradictions.md](contradictions.md)) |
| решение спора из разбора выше решения автора | в индексе «⚠ сверить с A-NN» | в силе только часть, совместимая с решением автора |
| пересказ чужой темы вместо ссылки на владельца | ответ длиннее экрана о теме, у которой есть владелец (`kb-search.mjs TH-NN`) | 3–5 строк и ссылка на reference владельца |
| цитата длиннее 15 слов или текст книги | сравнить с разбором | пересказ своими словами, одна короткая цитата на ответ |
| пример из историй каталога | имена героев и узлы `src/stories/` в ответе | придуманный пример |
| «объясни» посреди правки ушло в `story-kb` | просьба относится к находке, которую чинит владелец | ответ из `explain.md` владельца находки |
| наставник правит текст сам | в ответе готовая глава вместо отклика | отклик по стадиям, правка — через `story-fix` после одобрения |
| довод «химией мозга» | слова «дофамин», «окситоцин», «кортизол» как довод | поведенческая формулировка (`cron-wired-for-story:SYS-5`) |
| оценка на глаз того, что считает команда | «примерно 12 сообщений без кнопки» без вывода `story:lint` | запустить команду; упала — «нет данных: <команда>» |

## Зелёные

- У каждого утверждения — ID и класс доказательства, где он важен (A / B / C, [lessons.md](lessons.md)).
- Спор показан обеими сторонами, решение — со ссылкой на того, кто его держит.
- Отменённое названо отменённым, рядом — что в силе и чем проверяется оставшийся риск.
- Ответ короче, чем тема у владельца: указатель, а не копия.
- В разборе сцены сначала названо, что работает, советов не больше `skill.kb.mentor.advice_max`, у каждого не меньше `skill.kb.mentor.advice_options` вариантов.
- Упражнение заканчивается проверкой командой или холодным читателем.
