# Система: финал из пяти шагов

Авторская система школы сценария для кино, переложенная на переписку. Пересказ своими словами.

### snyder-save-the-cat:SYS-5 · Финал из пяти шагов

Элементы: **план**; **исполнение**, которое идёт хорошо; **ловушка** — цели на месте нет; герой **копает
глубже и меняет план**; **новая попытка** и итог. Вход — синтез двух линий (улики и доверие) из перехода в
третий акт; выход — последовательность шагов, где ранние решения становятся ресурсами.

| шаг | что делает игрок | что будет без шага | в ink |
|---|---|---|---|
| 1–2. План и исполнение | одна развилка «как действуем» | финал — прямая линия, накопленное не нужно | `*` с двумя кнопками, `~ plan = …` |
| 3. Ловушка | ничего: входящие без развилки | без ловушки нет перемены | строки события, ресурсы игрока не трогаем |
| 4. Смена плана | главная развилка, варианты по условиям из ранних глав | перемена героя не видна | `* {kept_key} [...]` и вариант для всех |
| 5. Новая попытка и итог | последняя кнопка | конец не его поступок | текст читает план шага 1 и выбор шага 4 |

**Ошибки понимания.**
- Пять шагов — не пять сцен боя: нужен план, который ломается, а не «замок».
- Нужен не «герой», а тот, кто меняет план; смену плана делает игрок своей кнопкой (R-106).
- Ловушка не отнимает добытое игроком: она меняет обстоятельства (`snyder-save-the-cat:P-14#нюанс`).
- Победа — только один из исходов шага 5: проигрышные финалы проходят те же шаги (R-112).

**Короткая форма.** У нас шаги 1–2 сжимаются в одну развилку, шаги 3–4 — главная развилка с условиями, шаг 5 —
итог и следы; в короткой истории — только ловушка и смена плана. Прямая линия без ловушки — главный признак,
что шаги не сработали: финал решён одной кнопкой (`snyder-save-the-cat:RED-09`, C-06).

**Проверка.** C-06 (ранние переменные в распределителе), `threshold-visibility.mjs` (последний выбор есть),
`npm run story:trace` по последней главе — развилок несколько.
