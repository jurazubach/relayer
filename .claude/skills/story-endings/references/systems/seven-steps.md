# Система: семь шагов — что каждый получает и отдаёт

Авторская система построения сюжета вокруг развития героя, в части, которая касается финала. Пересказ
своими словами; разметка шагов в ink не заводится (A-06), шаги живут в плане (`story-plan`).

### truby-anatomy-of-story:SYS-2 · Семь шагов: что каждый получает и отдаёт

Шаги — точки развития героя, а не главы: слабость и нужда → желание → противник → план → битва →
самораскрытие → новое равновесие. Каждый шаг получает что-то от предыдущего и отдаёт следующему; финалу
принадлежат три последних.

| шаг | получает | отдаёт | в переписке |
|---|---|---|---|
| битва | план и противника | решение «что правильно», а не только «кто победил» | кнопка-ценность (R-102) |
| самораскрытие | цену битвы | перемену героя — поступком, не фразой | поступок NPC; без «я понял(а), что» (R-107, C-43 `C-43.moral`) |
| новое равновесие | перемену | мир выше или ниже исходной точки, видный по сравнению | рамка: последняя строка против первой (R-109) |

**Что будет без шага.** Без битвы-ценности финал — подсчёт улик; без самораскрытия поступком — нотация в
последней реплике; без нового равновесия — «Конец» без перемены (`vogler-writers-journey:RED-12`).

**Ошибки понимания.** Считать шаги главами; ставить самораскрытие в реплику героя, а не в поступок; путать
новое равновесие с хэппи-эндом — равновесие может быть ниже начального.

**Короткая форма.** В пятиминутке: битва — последняя кнопка, самораскрытие — один поступок в ответе,
равновесие — последняя строка, зеркалящая первую.
