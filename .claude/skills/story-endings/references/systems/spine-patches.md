# Система: хребет и заплатки

Авторская система студии интерактивной прозы, разобранная как механизм. Пересказ своими словами; пороги —
ключами `thresholds.json`.

### inkle-ingold:SYS-3 · Хребет и заплатки (core spine and patches)

Элементы: **хребет** — версия сцены, когда игрок ничего не сделал; **шаг хребта** с проверкой «подходит ли он
состоянию» (если нет — пропуск); **заплатка** — самостоятельный кусок, который сам решает, уместен ли он, и не
срабатывает дважды; **место вставки** — точка в хребте, где заплатка может сработать.

| шаг | вход → выход | что будет без шага | у нас |
|---|---|---|---|
| 1. Хребет | начальные значения всех переменных → сцена от начала до конца без единой заплатки | финал без игрока не дочитывается | узел финала, проходимый при всех `false` |
| 2. Условия пропуска | шаг хребта → скрыт, если врёт при каком-то состоянии | финал говорит неправду игроку, который сделал иначе | `{not x: …}` на строке хребта |
| 3. Заплатки | последствие игрока → туннель `-> p_x ->` с условием и проверкой `not p_x` | последствия переписывают хребет, ветки множатся | по туннелю на последствие |
| 4. Места вставки | заплатки → точки в хребте, где они уместны | заплатка срабатывает невпопад | одна-две точки на шаг хребта |

**Ошибки понимания.**
- Принять заплатки за варианты финала: финалы, которые различаются событием, — разные узлы под меткой
  `// финал:` (R-103), а заплатки — вставки в один финал.
- Писать заплатку, которая зависит от другой заплатки: каждая уместна сама по себе.
- Лечить провисание темпа переписыванием хребта: добавляют заплатку, хребет скрыт от игрока и так.

**Короткая форма.** Хребет из трёх строк и одна-две заплатки-туннеля; проверка — бот с начальными значениями
и молчанием доходит до конца, каждая заплатка встречается у бота хотя бы раз.

### inkle-ingold:PAT-11 · inkle-ingold:SYS-6 · Финал-хребет с заплатками-туннелями

- **Когда применять.** Финал или кульминация, которые должны реагировать на несколько переменных: хребет
  «игрок ничего не сделал», заплатки-туннели за поступки.
- **Когда не работает.** Финалов несколько и они действительно разные по событию — тогда это разные узлы, а
  не заплатки. Заплаток так много, что хребет тонет: финал длиннее `C-42.msgs` — режь заплатки до главных.
- **Масштаб.** 5 сообщений: хребет и одна заплатка. 50: по заплатке на ключевую переменную.
- basis: checked · опора: `inkle-ingold:PAT-11`, `inkle-ingold:P-17`, `inkle-ingold:LESSON-02`.

```ink
# contact: savva, Савва, amber
VAR heard_bell = false
VAR has_key = false
-> door
=== door ===
// хребет: версия «игрок ничего не сделал»
я у ворот маяка #from:savva
{ heard_bell && not p_bell:
    -> p_bell ->
}
стучу. никто не открывает #delay:20s
{ has_key && not p_key:
    -> p_key ->
}
ухожу к причалу #delay:20s
-> END
=== p_bell ===
помнишь колокол? он молчит #from:savva #delay:10s
->->
=== p_key ===
ключ подошёл. я внутри #from:savva #delay:10s
->->
```

При всех `false` проходит хребет; при `heard_bell` и `has_key` — обе заплатки, каждая один раз. Ловушка: в
хребте есть строка «ухожу к причалу», которая врёт, если игрок дал ключ и Савва уже внутри, — ей нужно условие
пропуска (шаг 2 системы).
