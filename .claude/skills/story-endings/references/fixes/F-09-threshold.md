# F-09 · Показать скрытый порог

Ремонтный приём `story-endings`. Применяет `story-fix` — только одобренное. Ссылается `story-choices`: эхо
переменной до финала — его F-08, а показ порога, от которого зависит финал, — этот приём.

### F-09 · Показать скрытый порог

**Когда.** Переменная условия финала не звучит: `node ${CLAUDE_SKILL_DIR}/scripts/threshold-visibility.mjs
--story <id>` ставит ✗ «не звучит» (то же, что C-03 `C-03.invisible` на распределителе), или порог счётчика
не назван ни разу до финала (R-104).

**Шаги.**
1. Возьми ✗-переменные из замера; для суммы (Σ) — её составляющие.
2. Для каждой найди, кто в истории естественно следит за этой величиной: тот, кому игрок помогал или врал, а
   не рассказчик (`failbetter-qbn:P-07`).
3. Прочитай `docs/style.md` (ST-13, ST-40, §11 «Что запрещено») — порог звучит голосом персонажа, без цифр
   и игровых слов («уровень», «очки»).
4. Напиши две-три условные реплики по уровням (`{ x: - 1: … - 2: … }`) в конце предпоследней главы или в
   общем узле, куда приходят все пути; для флага — одну реплику с `else`.
5. Проверь, что реплика называет прогресс («двух вещей не хватает»), но не раскрывает финал и не говорит,
   какой исход лучше (R-111).
6. Перезапусти замер: `threshold-visibility.mjs --story <id>` и `npm run story:lint -- --story <id> --only C-03,C-06`.

**Готово, когда.** У каждой переменной условия финала есть реплика до развилки (✓ или · «нет в сводке» в
замере); C-03 молчит по переменным распределителя.

**Что нельзя сломать.** Знание персонажа: он говорит только о том, что мог видеть (`story-continuity`). Тайну:
в загадке называй недостающее, а не счёт улик (`failbetter-qbn:P-07#нюанс`). Режимы: реплика не опирается на
прожитое ожидание (ST-63).

**До:**

```ink
# contact: vera, Вера, amber
VAR helped = 0
-> ch3
=== ch3 ===
Глава 3 #sys:vera #chapter
снова зовут на причал #from:vera
* [Помогу #to:vera]
    ~ helped += 1
* [Не сегодня #to:vera]
- -> ch4
=== ch4 ===
Глава 4 #sys:vera #chapter
{helped >= 2: -> fin_trust | -> fin_alone}
=== fin_trust ===
она открыла мне дверь #from:vera
-> END
=== fin_alone ===
дверь закрыта #sys:vera
-> END
```

**После** (порог звучит голосом Веры в конце главы 3):

```ink
# contact: vera, Вера, amber
VAR helped = 0
-> ch3
=== ch3 ===
Глава 3 #sys:vera #chapter
снова зовут на причал #from:vera
* [Помогу #to:vera]
    ~ helped += 1
* [Не сегодня #to:vera]
-
{ helped:
- 0: я одна таскаю эти ящики. привыкла #from:vera #delay:30s
- 1: один раз было легче. с тобой. я запомнила #from:vera #delay:30s
- else: ты приходишь, когда зову. это редкость #from:vera #delay:30s
}
-> ch4
=== ch4 ===
Глава 4 #sys:vera #chapter
{helped >= 2: -> fin_trust | -> fin_alone}
=== fin_trust ===
она открыла мне дверь #from:vera
-> END
=== fin_alone ===
дверь закрыта #sys:vera
-> END
```

Финала реплика не раскрывает: Вера говорит, что помнит, а не что откроет дверь. Распределитель при этом
по-прежнему без кнопки — следующая правка по R-102 (кнопка-ценность) или F-10 (сводка).
