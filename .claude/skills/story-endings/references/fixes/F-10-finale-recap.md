# F-10 · Сводка перед финалом

Ремонтный приём `story-endings`. Применяет `story-fix` — только одобренное.

### F-10 · Сводка перед финалом

**Когда.** Финал выбирает скрытая проверка по нескольким переменным, а перед распределителем нет перечня:
`node ${CLAUDE_SKILL_DIR}/scripts/threshold-visibility.mjs --story <id>` пишет «сводка перед ним: нет» или
«частичная», у переменных стоит · «нет в сводке» (R-105).

**Шаги.**
1. Выпиши из замера переменные распределителя без ◆ и Σ (последний выбор и итог в сводку не входят; итог
   называется словами по составляющим).
2. Выбери голос: герой, который сейчас решает, или «Заметки» (служебный контакт), — не системная строка.
3. Прочитай `docs/style.md` (ST-01, ST-40, ST-41) прямо перед тем, как писать: сводка — короткие пузыри,
   герой спрашивает конкретно и сомневается своим голосом, а не перечисляет списком.
4. Узел-сводка перед последней кнопкой: «что у нас есть?» → по условной строке на переменную (есть / нет) →
   строка «хватит / не хватит для шага, который ты хочешь сделать».
5. Не называй, какой финал лучше, и не сравнивай финалы (R-111, `meaningful-choice:contra-6`).
6. Перезапусти замер: `threshold-visibility.mjs --story <id>` — сводка «полная».

**Готово, когда.** Игрок до кнопки знает, на что опирается выбор: каждая переменная распределителя названа в
последней главе до него.

**Что нельзя сломать.** Тайну: сводка перечисляет собранное, но не вывод (`story-mystery`). Ритм: сводка —
не больше нескольких сообщений, иначе отчёт (`narrative-postmortems:PAT-06`). Кнопку: после сводки решает
игрок; если распределитель без кнопки, сводка не заменяет R-102.

**До:**

```ink
# contact: ada, Ада, teal
VAR has_log = true
VAR has_witness = false
-> verdict
=== verdict ===
пора идти к смотрителю #from:ada
* [Идём #to:ada]
- {has_log && has_witness: -> fin_believed | -> fin_doubted}
=== fin_believed ===
он поверил #from:ada
-> END
=== fin_doubted ===
он не поверил #from:ada
-> END
```

**После** (сводка голосом Ады до кнопки, «хватит ли» — для шага):

```ink
# contact: ada, Ада, teal
VAR has_log = true
VAR has_witness = false
-> verdict
=== verdict ===
пора идти к смотрителю. что у нас есть? #from:ada
{has_log: журнал вахты — у меня #delay:20s|журнала нет #delay:20s}
{has_witness: Савва подтвердит #delay:20s|Савва молчит #delay:20s}
{has_log && has_witness: с этим он не отмахнётся #delay:20s|этого мало, чтобы он поверил с порога #delay:20s}
* [Идём сейчас #to:ada]
* [Сначала уговорим Савву #to:ada]
    ~ has_witness = true
- {has_log && has_witness: -> fin_believed | -> fin_doubted}
=== fin_believed ===
он поверил #from:ada
-> END
=== fin_doubted ===
он не поверил #from:ada
-> END
```
