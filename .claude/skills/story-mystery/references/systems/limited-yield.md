# База с лимитом выдачи: вывод из половин

Система игры-допроса с поисковой строкой (блок с ID — `clue-map.md`, `narrative-postmortems:SYS-4`). Элементы:
поиск по слову, лимит на число фрагментов в ответ, фрагменты с несколькими смыслами, ручная подгонка частот слов.

Шаги:
1. **Запрос.** Вход — слово, которое игрок вынес из прошлого фрагмента. Выход — первые несколько фрагментов.
2. **Просмотр.** Вход — фрагмент. Выход — новые слова для запроса. Без лимита игрок увидит всё сразу и не будет
   выводить.
3. **Подгонка автором.** Вход — частоты слов. Выход — правка базы, чтобы ключевое не находилось ни слишком
   легко, ни никогда.

- **Ошибка понимания.** Будто порядок случаен. Им управляют частоты и лимит.
- **Короткая форма у нас.** Ввода нет. Переносятся две вещи: собеседник отвечает на один вопрос, а не на все
  (лимит выдачи), и факт из двух половин у двух людей (`patterns-mystery.md`, «Две половины»).
- **Как проверить.** У откровения две улики от разных контактов — `C-54.channels`; условие `{a && b}` — ink.

## Источники

`narrative-postmortems` (SYS-4, P-08, PAT-04, GREEN-03).
