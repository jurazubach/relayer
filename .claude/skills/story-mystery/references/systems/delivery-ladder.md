# Лестница подачи: play → show → say → cutscene

### dille-ultimate-guide:SYS-3 · Лестница подачи (play → show → say → cutscene)

Устройство подачи истории по убыванию участия игрока; формула разработчика из интервью, не термин книги. Каждая
ступень — запасная для предыдущей. Для загадки это выбор, как подать улику.

| ступень | у нас | вход → выход |
|---|---|---|
| 1. play — игрок проживает действием | кнопка добывает факт: вопрос, `#to:notes`, пересылка в другой чат | намёк NPC → флаг `clue_*` / `note_*` → условная кнопка (`clue-by-action.md`) |
| 2. show — событие показано в мире | артефакт в чате: `#photo`, скрин, пересланное | факт без слов персонажа → вывод делает игрок |
| 3. say — о событии говорят | персонаж пишет словами | реплика → игрок верит или не верит |
| 4. cutscene — управление отнято | `#sys`, длинный монолог без кнопок, пересказ | — |

- **Без шага.** Сразу прыгнуть на ступени 3–4 для ключевого факта — отнять открытие (`dille-ultimate-guide:RED-03`).
  Ставить всё на ступень 1 тоже плохо: фон не стоит кнопки, игрок устаёт от «сохранить» на каждой мелочи.
- **Ошибка понимания.** «Покажи» в чате — не описание («она плакала»), а артефакт. Описание — всё ещё ступень 3.
- **Короткая форма.** На 5 сообщениях главная улика — на ступени 1 или 2, иначе игрок ничего не сделал. На 50
  половина фактов может идти ступенью 3. Ступень 4 — не больше раза за главу и никогда в кульминации.
- **Как проверить.** Запись `clue_*` под кнопкой или у артефакта — `npm run story:vars`; серия без выбора — C-35
  у `story-pace`; монолог с выводом — модель.
