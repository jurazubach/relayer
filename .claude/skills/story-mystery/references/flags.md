# Признаки: как поймать и как чинить

Красные и зелёные признаки честной загадки. Колонка «как поймать» — команда, если считает она, или «модель»,
если судит модель (тогда находка помечается «модель» и уверенностью). Числа — ключами `thresholds.json`.

## Красные

| признак | как поймать | как чинить |
|---|---|---|
| улика только в одной ветке, ни одной видимой всем | `npm run story:lint -- --story <id> --only C-54` → `C-54.sure_clue`; `clues.mjs` («по уликам») | улику после схождения или в каждой ветке своими словами (R-93) |
| к раскрытию приходят с одной уликой или без | C-54 `C-54.min_clues` (доля — `C-54.clue_share`) | вторая улика другим голосом раньше раскрытия; мутант m13 — улика после раскрытия |
| ключевой факт в той же реплике, что ответ; выбора между уликой и раскрытием нет | C-54 `C-54.gap_choice` | улику минимум на выбор раньше; ворота перед раскрытием |
| разгадку объявляет NPC, кнопки с выводом нет | C-54 `C-54.gap_choice`; модель (`#me` с выводом, монолог) | ворота дедукции (`deduction-gates.md`) |
| все улики от одного контакта | C-54 `C-54.channels`; `clues.mjs` («ставят») | улика из другого чата, в другой форме (`#sys`, заметка, фото) |
| виновник впервые в последней трети | C-54 `C-54.culprit_error` (между порогами — `C-54.culprit_late`) | след в главе 1–2, `~ culprit_seen = true` (R-95) |
| верная версия в воротах длиннее остальных | C-54 `C-54.long_answer`; `clues.mjs` («ворота», длины) | все версии одной длины и уверенности |
| разгадку угадывают все холодные читатели | `node ${CLAUDE_SKILL_DIR}/scripts/guess.mjs --story <id> --ask` выше полосы `C-54.guess_share` | спрятать одну улику из трёх (`patterns-mystery.md`), убрать подсказку-клише |
| никто не угадывает | `guess.mjs --ask` ниже полосы `C-54.guess_share` | третья улика, механизм — бытовой аналогией заранее (R-98) |
| разгадка ссылается на улику, которой в ветке не было | модель: ссылки без `{clue_x: …}`; соседняя проверка `C-51.unknown_fact` у `story-continuity` | обернуть ссылку в условие |
| приманка без опровержения | модель: таблица «приманка → опровержение»; холодный читатель называет её среди подозрений | опровержение-событие на стволе (R-96) |
| неверная версия ничего не стоит | `npm run story:vars` — неверная кнопка ничего не пишет | цена: доверие, время мира, позиция (GREEN-05) |
| «не знаю» выгоднее догадки | модель: после «не знаю» NPC объясняет всё, `solved` не читается | `solved = false` читается в финале или реплике |
| честный помощник соврал без опровержения | модель: ложь по контактам против `facts.md` | ложь — противнику или контакту с мотивом, `// намеренно: C-49 ложь` |
| двойник без предупреждения | модель: двойник в `meta.json` без ранней реплики о том, что противник знает имена | предупреждение заранее (PAT-08) |
| в разгадке новый механизм | модель: термины разгадки без раннего объяснения | бытовая аналогия за главу (R-98) |
| длинный разбор после последней кнопки | C-42 (`C-42.msgs_short`, `C-42.msgs`) у `story-endings` | главный вывод и одна-две приманки, остальное раньше |
| тайна раскрыта в сцене намёка; призрак — в первой главе | модель по `npm run story:trace` (где слово тайны звучит впервые) | раскрытие на главу позже, после условия доверия (R-97) |
| ворота сразу после долгой паузы | `npm run story:sessions` + узел ворот после паузы от `story.pause.long_s` | напоминание вопроса и улики, ход противника, потом ворота |
| загадка не названа в начале | модель + `npm run story:cold-read -- --story <id> --until <узел> --mode opening` | аномалия с цифрой и нормой рядом в первых сообщениях (R-95) |

## Зелёные

| признак | как увидеть | как поддерживать |
|---|---|---|
| улики к выводу в разных чатах, одна на стволе | `clues.mjs`: «ставят» — разные контакты; C-54 молчит | новую улику — в чат, где улик вывода ещё нет |
| перед разгадкой кнопка с версией игрока | `clues.mjs` («ворота»), нет `C-54.gap_choice` | ворота на каждое структурное откровение |
| виновник виден в первой трети | C-54 без `C-54.culprit_late` | след противника в главе 1–2 |
| разгадка цитирует улику там, где игрок её видел | ink: `{clue_x: …}` в узле раскрытия | ссылка с чатом и временем мира |
| ошибочная версия стоит ресурса | `npm run story:vars` | цена видна в ответе сразу |
| механизм объяснён заранее | модель | знаток объясняет одной-двумя бытовыми аналогиями |
| доля угадавших в полосе | `guess.mjs --ask` в полосе `C-54.guess_share` | одна улика спрятана, одна заметна, одна посередине |

## Где игроку станет скучно

- Помощник раскрывает всё сам: длинные цепочки, где кнопки меняют только ответную реплику (C-35 у `story-pace`,
  `C-54.gap_choice`).
- Глава без улики и без нового вопроса читается как отчёт: `clues.mjs --json` (переменные по главам) — кандидат.
- Ложные версии ничего не стоят — игрок жмёт наугад.
