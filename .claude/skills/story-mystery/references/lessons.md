# Уроки практиков: карточки

Класс доказательства: **A** — эксперимент или данные; **B** — постмортем с цифрами; **C** — мнение, практика
без цифр. Почти все уроки о честной загадке — класс C: опубликованных цифр удержания по этим решениям нет. Полные
блоки с ID — в тематических файлах (ссылка в конце карточки). Наши собственные уроки появятся после Э2 и Э5
(`docs/playbook/local-lessons.md`).

- **Улика — четыре точки отказа (C).** Ведущий расследований: игрок не обыскал, не заметил, провалил проверку,
  понял неверно. У нас: не открыл чат, пролистал, не понял, понял неверно. Считать «выставлена в прогоне», а не
  «есть в тексте». → `clue-map.md`, LESSON-01.
- **Автоматическая улика, вывод — игроку (C).** Школа, где ключевая улика находится сама, теряет ощущение
  расследования. Улика на стволе — наш автомат; ворота возвращают работу ума. → `clue-by-action.md`, LESSON-02.
- **Опровержение — на чужих глазах (C).** Железное для автора опровержение игроков не убеждает; приманка — только
  с опровержением-событием. → `red-herrings.md`, LESSON-03.
- **Список, а не схема (C).** Схемы узлов средней сложности нечитаемы; обратный список «что ведёт сюда»
  диагностирует. Наша метка `// reveal:` — этот список. → `clue-map.md`, LESSON-04.
- **Проверка по частям (C).** Свиток «верно / неверно» целиком злил и поощрял перебор; промежуточные задачи
  подняли удовлетворение. → `deduction-gates.md`, LESSON-05.
- **Вырежи живописное (C).** «Обжитые» сцены с посторонними сведениями мешали; прямая улика делала дело
  тривиальным. В чате каждая строка — кандидат в улики. → `clue-by-action.md`, LESSON-06.
- **Контекст теряется между сессиями (C).** Тестеры, игравшие по делу за раз, забывали прошлое; подпорку не
  добавили. Нам она обязательна: напоминание после паузы. → `patterns-mystery.md`, «Возвращение с уликой».
- **Одно дело — один тест (C).** Сначала прототип одного дела и его тест, потом следующее; дело тестировали
  несколько человек по интервью. Наша единица теста — глава. → `story-playtest`.
- **Подтверждение пачкой (C).** Подтверждение по три защищает от перебора, но в чате тяжело; наш аналог — цена
  ошибки. → `deduction-gates.md`, LESSON-09.
- **Главы событиями (C).** Демо с большим составом запутало игроков; смерти привязали к событиям, игру — к главам,
  журнал стал хронологией. → `reveals.md`, LESSON-10.
- **Кнопка — то, что сделает герой (B).** Ярлыки допроса «правда / сомнение / ложь» расходились с тоном реплик;
  переименование в ремастере помогло, но не до конца (рецензии, без цифр удержания). Текст версии предсказывает
  ответ. → `deduction-gates.md`, нюанс к PAT-02.
- **Неверный финал — только с различающей уликой (B).** Игра с обвинением не того получила средние оценки
  критики за паутину косвенных улик. → `red-herrings.md`, LESSON-12.
- **Вызов читателю — в главах-головоломках (C).** Автор головоломок отказался от вызова, когда романы ушли в
  драму. → `deduction-gates.md`, LESSON-13.
- **Не прятать улики голосом игрока (C).** Спор о рассказчике-убийце идёт век; у нас «рассказчик» — игрок и его
  заметки, им умалчивать нельзя. → `red-herrings.md`, LESSON-14.
- **Финал по охвату (B).** Игра-допрос без проверки ответа заканчивается, когда открыто достаточно; продажи — успех
  игры целиком, а не механики. → `deduction-gates.md`, LESSON-15.
- **Минимальная загадка слишком трудна (C).** Один путь оправдаться оказался угадайкой; реализовали длинный
  список путей. → `clue-map.md`, `inkle-ingold` LESSON-03.
