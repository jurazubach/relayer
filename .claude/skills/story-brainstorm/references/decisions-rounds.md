# Раунд: что делать на каждой развилке разговора с автором

Автор не умеет строить сюжеты: он накидывает идею, смотрит, выбирает. Здесь — развилки раунда «если автор
сказал A → делай X», колонка «что трудно» словами автора и совет по сочетанию направлений с критериями, а не
мнением. Числа — ключами `thresholds.json`.

## Развилки раунда

| автор говорит | режим | что делать | чем проверить |
|---|---|---|---|
| «вот идея», «что из этого может выйти» | первый | банк → таблица осей → текст → трейлеры | `ideas-bank.mjs`, `directions.mjs`, `premise-check.mjs` |
| «ещё», «давай другие» | ещё | исключить показанное: `directions.mjs --exclude`; новый раунд не повторяет прошлые | `directions.mjs` (повторы раундов) |
| «всё не то», «ни одно не нравится» | далеко (Б-4) | спросить по осям, что не так; записать «не то»; дать `skill.brainstorm.directions.far_count` далёких | `directions.mjs` (режим «далеко») |
| «возьмём B, но с героем из D» | сочетание | собрать новое направление, прогнать критерии ниже, показать, что выполнено | `premise-check.mjs`, `directions.mjs` |
| «беру C» | выбор | записать выбранное и отвергнутое, передать ядро | `story-desk`, `story-core` |
| «доведи вот это» (готовое направление) | — | это не раунд, а ядро | `story-core` |
| «хочу как в такой-то книге» | первый | механизм, не сюжет | `fiction.md` |

- **Когда не работает:** автор отвечает «не знаю» на вопрос по осям — покажи два направления на противоположных
  полюсах одной оси (свидетель против подозреваемого) и спроси, какое ближе; ответ — ось.
- **Масштаб:** раунд для пятиминутки — три направления и четыре оси; для сезона — до верхней границы
  `skill.brainstorm.directions.count` и все семь осей.
- basis: source · `build-plan.md` §2 (шаг 1, Б-4); `flow-review.md` §A шаг 1, §B Б-4.

## Б-4: автор отверг всё

Четвёртый набор тем же способом не генерировать: модель повторит себя. Порядок:
1. Вопрос с вариантами ответа по осям: «Что мимо: кто ты в истории / кто рискует / правило мира / что на кону /
   кто против / как устроена / какой жанр?» Можно несколько.
2. Записать в шапку нового раунда «- режим: далеко» и «- не то: <оси>».
3. `directions.mjs --exclude --story <id>` — что было по этим осям; новые метки берутся вне этого списка.
4. Дать `skill.brainstorm.directions.far_count` направления, каждое далеко от всех прошлых по каждой оси «не то».
- **Когда не работает:** автор отвергает и далёкие — вероятно, мимо сама идея; предложи вернуться к сырой идее и
  спросить, что в ней для автора главное (это ось, которую нельзя трогать).
- **Масштаб:** любой.
- basis: source · `build-plan.md` §2 Б-4.

## «Что трудно» — цена направления словами автора

Колонка объясняет, что направление значит для того, кто будет его писать. Не «сложно», а что придётся сделать:

| если в направлении | что трудно (для автора) | кто потом поможет |
|---|---|---|
| скрытая правда, виновник | честные улики на общем пути с первой главы; игрок должен мочь догадаться раньше раскрытия | `story-mystery` |
| ложный союзник, маска | улики против него — раньше предательства; раскрытие во второй половине | `story-mystery`, `story-branch` |
| смена противника | второго противника придумать до первой главы; нужна длина в несколько глав | `story-plan` |
| игрок знает больше (два чата) | минимум два контакта с разным знанием; сцена в двух чатах раз в несколько глав | `story-cast`, `story-continuity` |
| хаб свидетелей | много голосов, которые надо различать; хаб — не в первой главе | `story-cast`, `story-voice` |
| несколько финалов по выбору | ось-переменная через всю историю, финал слышно до последней кнопки | `story-endings`, `story-choices` |
| сезон, реальное время дни | план до первой строки; длина в пределах A-05; каждая глава сдвигает историю | `story-plan`, `story-time` |
| ядро на ожидании | читается и «по клику», где ожидания нет (A-04) | `story-time` |
| новая механика чата | её нет в `docs/capabilities.json` — это запрос к движку, а не к автору | `story-desk` (решение) |
| одна глава, один собеседник | мало — это плюс: проверить формат быстро (`chat-fiction-apps:P-15`) | — |

- **Если** «что трудно» пустое у всех направлений → цена не названа, автор выберет вслепую.
- **Когда не работает:** если автор сам опытный и просит «без разжёвывания» — пиши колонку одной строкой, но пиши.
- **Масштаб:** короткая история — одна строка; сезон — две-три.
- basis: model · опора: `flow-review.md` §A шаг 1 («потребует честных улик → дополнительные узлы на главу»).

## Совет по сочетанию: критерии, а не мнение

«B и D сочетаются» без критерия — мнение модели. Сочетание проверяется по четырём правилам и показывается
автору таблицей «выполнено / нет»:

| правило | вопрос | как проверить |
|---|---|---|
| R-02 (у `story-core`) | есть ли ирония «ты — X, пишет Y, но Z»? | `premise-check.mjs --logline "…"`; иронию по смыслу — модель |
| R-04 | ядро — правило, «обычно…, а здесь…»? | `premise-check.mjs --rule "…"` |
| R-05 | одно допущение, а не два? | сочетание двух ядер часто даёт два чуда — проверь глазами и по числу правил |
| R-06 (у `story-core`) | герой — собеседник, у игрока малое своё желание? | оси «герой» и «роль игрока» |

- **Если** сочетание проваливает R-05 → предложи, какое из двух ядер станет бытовым объяснением другого.
- **Когда не работает:** автор хочет сочетание ради одной детали («нравится имя героини из D») — это не сочетание
  осей, а деталь; перенеси деталь, оси не трогай.
- **Масштаб:** любой.
- basis: source · `flow-review.md` §A шаг 1 («скилл должен прогонять сочетание через R-02, R-04, R-05, R-06»).

## Куда уходит результат

- Раунд целиком — `docs/stories/<id>/directions.md` (формат — `directions-format.md`); его пишет этот скилл.
- Отвергнутые направления с причиной и «когда вернуться» — в банк через `story-desk` (`idea-park.mjs`).
- Шаг `directions` в `STATUS.md` и решение о выборе — через `story-desk`; ядро из выбранного — `story-core`.
- **Когда не работает:** истории ещё нет (нет id) — предложи id и попроси `story-desk` завести папку состояния;
  до этого раунд можно показать в разговоре, но не записать.
- basis: source · `build-plan.md` §7; `story-desk/references/state-format.md`.
