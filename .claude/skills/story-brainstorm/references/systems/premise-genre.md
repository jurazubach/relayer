# Системы: посылка, жанровый тип, законы ремонта

Три системы, из которых направление берёт оси «герой», «противник» и «жанр». Своими словами. В ink их поля не
пишутся (⊘ A-06: шапка — 4 строки): направление живёт в `docs/stories/<id>/directions.md`, ядро — у `story-core`.

## truby-anatomy-of-story:SYS-1 · Посылка и три её проверки

- **Элементы.** Одна фраза про героя, действие и перемену. Три проверки: идея не банальна; есть линия желания от
  начала до конца; есть сильный противник. Начинать с темы, важной самому автору, и искать основное действие —
  главный поступок, который повторяется через всю историю.
- **Вход → выход.** Идея или ситуация → посылка с тремя слотами и основное действие роли игрока одним глаголом.
- **Без шага.** Автор добавляет события, потому что они интересны сами по себе; главы можно переставить, и ничего
  не сломается.
- **Ошибки понимания.** Посылку путают с логлайном для рекламы: логлайн продаёт завязку, посылка задаёт перемену
  и игроку не показывается. Основное действие путают с темой: тема — «правда», действие — «писать под чужим
  именем».
- **Короткая форма.** На пять минут посылка — одна фраза с «но»; основное действие совпадает с единственной
  механикой чата, которую несёт история.
- **В раунде.** Три проверки — к каждому направлению: банально ли (банк и каталог — `ideas-bank.mjs`), есть ли
  линия желания (ось «ставка»), силён ли противник (ось «противник»).

## snyder-save-the-cat:SYS-2 · Десять жанровых типов

- **Элементы.** Десять типов по устройству конфликта, у каждого три обязательные составляющие. Переписке ближе
  три: загадка «почему», невиновный в беде, чудовище в доме; ещё один (путешествие за наградой) — для игр-маршрутов.
- **Вход → выход.** Логлайн → «элемент = конкретная вещь в истории» и ожидания игрока, которые надо закрыть.
- **Без шага.** Ожидание не закрывается: игрок чувствует, что «чего-то не хватает», но не скажет чего. Смесь двух
  типов даёт два набора ожиданий и ни один не закрыт.
- **Ошибка понимания.** Тип путают с антуражем: «детектив в космосе» и «детектив в деревне» — один тип.
- **Короткая форма.** На пяти минутах тип не называют — достаточно вещи, которую игрок боится или ищет.
- **В раунде.** Ось «жанр»: два направления одного типа с разными антуражами — одно значение оси.

## snyder-save-the-cat:SYS-6 · Законы и проверки: ремонт готового текста

- **Элементы.** Семь «законов физики сценария» и шесть проверок для починки готового текста. Названия
  подтверждены, смысл большинства — знание модели. Из подтверждённого: экспозиция во время действия, которое
  держит внимание само, и запрет на долгую подготовку до начала истории.
- **Вход → выход.** Готовый текст → список дефектов, у каждого — известный ремонт.
- **Без шага.** Текст, разложенный по битам, всё равно плоский: голоса одинаковые, злодей слабый, эмоция одна.
- **Ошибка понимания.** Проверки путают с битами и ставят на позиции; это свойства всего текста, их применяют
  после черновика.
- **Короткая форма.** Оставить шесть законов, которые проверяются автоматически или за минуту.
- **В раунде.** На шаге направлений из законов работает один — одно допущение (R-05, `patterns-premise.md`);
  остальные — у ревью (`story-review`) после текста.
