# Система: симулированная панель (наша)

Решение автора 25.10.2026: живых тестов в этом проходе нет; «понятно», «скучно» и «работают ли режимы»
проверяет симуляция — персоны бота, холодные читатели разных профилей, метрики. Система собрана из проверки
понимания (Bromley), бот-персон CoG и случайного среза Маасса; порядок шагов — наш.

| шаг | вход → выход | что будет без шага | команда |
|---|---|---|---|
| 1. Точка | история → узел, где читатель останавливается | читатель видит не тот кусок: «после трёх минут» оказывается серединой главы 2 | `panel.mjs --at opening` / `ch1` / `<узел>` |
| 2. План | точка × профили × режимы → список читателей с персонами; бессмысленные — с причиной | неотвечающий без `#remind` «проверяет» то, чего нет; отвлечённый без паузы | `panel.mjs` (без `--run`) |
| 3. Чтение | план → ответы, ключ, изоляция | — | `panel.mjs --run` (каждый — `story:cold-read --ask`) |
| 4. Изоляция | ответ → ок / нарушена; строки об окружении вырезаны | читатель «знает» финалы из проекта, ответы ничего не стоят | `isolation` в `*.json`, `panel.md` |
| 5. Разметка | ответы → строки формы отзыва с цитатой читателя | сводка из впечатлений модели, а не из слов читателя | модель по заготовкам `*.md` |
| 6. Сводка | отзывы → узел · тип · сколько · сходится с замером | одиночные ответы выдаются за находки | `digest.mjs` |
| 7. Сверка | строка сводки → ink, правило, замер | ложные находки (LOCAL-04) | `story:rule`, `story:lint --only` |

- **Ошибки понимания.** (1) «Восемь читателей сказали одно — значит, восемь человек»: это одна модель, совпадение
  профилей — кандидат, свойство текста подтверждает замер или живой человек. (2) «Дочитал бы» — оценка истории:
  модель доброжелательна, поэтому смотрим на «Слабое место» и совпадения слабых мест у разных профилей. (3) «Второй
  прогон на другой модели» — отменено (A-07): разброс — повтором на Opus и профилями.
- **Короткая форма.** История до `lab.playtest.short_story_min` минут по клику: одна точка `opening`, профили `hurried` и `skeptic`, оба режима — четыре
  читателя. Длинная: `opening`, `ch1`, точка после первой долгой паузы для `distracted`, срезы середины `--slices`.
- **Когда не работает.** Не заменяет живой тест реального времени: читатель не ждёт сутки и не получает
  уведомлений, «тишина 6 ч» для него строка. Поэтому вопрос «открыл бы уведомление сразу?» — только живым (Э6).
