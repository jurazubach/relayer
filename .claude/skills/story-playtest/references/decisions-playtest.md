# Развилки: какой тест, кто читает, что делать с ответом

Каждая запись: если A → делай X; «когда не работает»; масштаб (5 сообщений против 50); `basis`; опора по ID.
Числа — из команд, пороги — ключами `thresholds.json`.

## Симптом автора → что запускать

| симптом словами автора | точка и профили | команда |
|---|---|---|
| «непонятно, кто пишет и зачем», «начало не цепляет» | `opening`: `hurried`, `attentive`, `skeptic`, оба режима | `panel.mjs --at opening` |
| «где игроку станет скучно» | `ch1` все профили + срезы середины | `panel.mjs --at ch1`, `panel.mjs --slices` |
| «работают ли режимы» | любая точка, `--modes realtime,click`; `distracted` после долгой паузы | `panel.mjs --at <узел после паузы>` |
| «что будет, если игрок молчит» | `unresponsive` (нужен `#remind`) | `panel.mjs --profiles unresponsive` |
| «подготовь сборку для тестеров» | — | `playtest-kit.mjs --chapters N` |
| «тестеры ответили, что с этим делать» | — | `digest.mjs`, потом Б-2 ([digest.md](digest.md)) |
| «тестер застрял», «баг у тестера» | — | `transcript.mjs --from-save`, `route-replay.mjs --save` |

### narrative-testing:SYS-5 · narrative-testing:PAT-10 · Симуляция или живые люди

- **Если** живых тестеров нет (этот проход, решение автора) → проверка понимания холодными читателями:
  `panel.mjs` на точках `opening` и `ch1`, пересказ и «почему» — вопросами протокола. **Если** люди есть →
  набор `playtest-kit.mjs` им, а панель — до них (чтобы люди не тратились на то, что ловит модель) и после
  правок (свежий взгляд на начало).
- **Когда не работает.** Паузы реального времени и уведомления модель не проживает: «открыл бы сразу?» — только
  люди. Панель не заменяет человека из среды для «не верю» в профессиональной сцене.
- **Масштаб.** 5 сообщений: одна точка, четыре читателя. 50 и больше: две точки, срезы, `distracted` после
  первой долгой паузы.
- basis: secondary (Bromley — проверка понимания; решение о симуляции — автор) · проверка: `panel.mjs`.

### narrative-testing:P-07 · schell-art-of-game-design:P-17 · Какие профили и кого из людей

- **Если** жалоба на начало → `hurried` (бросит ли), `attentive` (кто есть кто), `skeptic` (почему мне). **Если**
  про паузы и возвращение → `distracted` в режиме `return`. **Если** про молчание игрока → `unresponsive` и
  персоны `silent`, `refuse` у бота. Живые: тестеры разного склада — «обычный игрок» в реальном времени без
  отладки и «ломатель» по клику; смотри на поведение (журнал), а не только на слова анкеты.
- **Когда не работает.** История без `#remind` — `unresponsive` бессмыслен (пропуск с причиной, находка для
  `story-time`); без паузы до точки — `distracted` бессмыслен.
- **Масштаб.** 5: `hurried` + `skeptic`. 50: все пять профилей на каждой точке.
- basis: secondary (Short; Шелл) + our_estimate (профили) · проверка: план `panel.mjs`.

### narrative-testing:P-08 · Сколько волн, когда звать свежих

- **Если** история до `lab.playtest.short_story_min` минут по клику → одна живая волна и один свежий после
  правок. **Иначе** → волны: до `lab.playtest.wave1.max` человек на главы 1–2, новые на всю историю, старые по
  списку изменений. Панель — на каждой версии, раунды не ждут людей.
- **Когда не работает.** Новых людей нет — начало после правки проверяет только панель; это пишется в сводке.
- **Масштаб.** 5: одна волна. 50: две-три волны.
- basis: secondary (Short, CoG; число волн — наше).

### narrative-testing:P-06 · Совпадение у нескольких: чинить или нет

- **Если** одно место и тип у `lab.playtest.repeat_min` живых (в большой волне — доля `lab.playtest.repeat_share`)
  → обязательно: правка или письменная причина в `decisions.md`. **Если** один человек и замер согласен (тот же
  узел, проверка того же симптома) → сигнал, правка по замеру. **Если** один человек против замера → «нужен
  третий» (Б-3, `story-review/conflicts.md`). **Если** только профили симуляции → кандидат: проверить замером у
  владельца, повтор у профилей — не независимые люди.
- **Когда не работает.** «Не верю» от человека из среды — рассмотреть и в одиночку. Жалоба на известное из брифа
  — не считать.
- **Масштаб.** 5 сообщений: любое совпадение двух — правка. 50: таблица сводки, обязательные — наверх.
- basis: secondary (CoG: повторы учитывать, отказ обосновывать) · проверка: `digest.mjs`.

### narrative-testing:P-09 · Ответ без места

- **Если** тестер написал «в середине скучно» без чата и реплики → `digest.mjs` выносит в «без места»;
  переспроси отдельно про скуку и непонимание: «где хотелось закрыть?», «где гадал, кто пишет?». **Если**
  холодный читатель без цитаты → в сводку не идёт (переспросить нельзя), повтори прогон.
- **Когда не работает.** Тестер не помнит — проси журнал: по времени нажатий видно, где он замолчал.
- **Масштаб.** одинаково.
- basis: secondary (Short; PTC).

### narrative-testing:PAT-02 · narrative-testing:PAT-03 · Отдать главы 1–2 или вход в середину

- **Если** проверяем начало и крючок → набор глав 1–N с `beta_stop` (волнами), свежий человек с первой строки.
  **Если** главы 1–2 уже проверены, а нужна глава 3 → вход `test_*` с набранным состоянием, только «ломателю».
- **Когда не работает.** Прыжок в середину для теста впечатления вредит: состояние игрок не набирал сам.
  Состояние `test_*` сверяй с медианой бота (`story:vars`), иначе тестируется недостижимое.
- **Масштаб.** 5: набор целиком. 50: набор + входы по главам.
- basis: secondary (Short, zarf) · проверка: `playtest-kit.mjs` (входы `test_*`, бот `--partial`).

### narrative-testing:P-04 · inkle-ingold:P-15 · Отзыв без журнала выборов

- **Если** баг или «застрял», а журнала нет → сначала попросить журнал («Скачать журнал»); без него — транскрипт
  с маршрутом не восстановить, баг не воспроизвести. **Если** журнал есть → `transcript.mjs --from-save`, затем
  `route-replay.mjs --save`; история ходов, а не конечное состояние.
- **Когда не работает.** `exact: false` (тестер прыгал в отладке) — повтор приблизительный, сверяй по скриншотам.
- **Масштаб.** одинаково.
- basis: secondary (80 Days) · проверка: `route-replay.mjs`.

### maass-fire-in-fiction:P-16 · Когда брать случайные срезы

- **Если** «скучно в середине», а `story-pace` не находит серий и затиший → `panel.mjs --slices`
  (`lab.playtest.slice.count` срезов по `lab.playtest.slice.lines` реплик без контекста, режим `guess`): какой
  вопрос открыт. Срезов без открытого вопроса больше `lab.playtest.slice.empty_max_share` — кандидат «скучно».
- **Когда не работает.** По клику не видно пауз; срез перед паузой проверяй отдельно (C-26).
- **Масштаб.** 5: не нужен. 50: обязателен для середины.
- basis: secondary (Маасс в пересказе) · проверка: `panel.mjs --slices`.

### narrative-testing:PAT-01 · Сохранять ли эталон маршрута

- **Если** глава с развилками переписана или найден баг → эталонный маршрут (`route-replay.mjs --save
  golden-chN`) и второй — «молчун» (`--persona silent`, затем `--save`). **Если** правка одной реплики → не нужен.
- **Когда не работает.** Финал изменился намеренно — пересохрани маршрут и запиши решение, иначе регрессия красная
  навсегда.
- **Масштаб.** 5: не нужен. 50: два эталона на главу.
- basis: secondary (ifMUD) + model (разметка цель / ставка).

### narrative-testing:P-10 · Тестер пишет о стиле фраз

- **Если** замечание о стиле («слишком книжно») → это средний уровень отзыва: в сводку не идёт, передать
  `story-voice` как наблюдение. **Если** нестыковка фактов → нижний уровень, тип «нестыковка». **Если** сцена не
  работает → верхний, один из типов.
- **Когда не работает.** Тестер из среды о профессиональной речи — это «не верю», верхний уровень.
- **Масштаб.** одинаково.
- basis: secondary (форум CoG).

### #attn-check-cold · Где ставить точки холодного теста

- **Если** проверяем начало → точка после трёх минут: `panel.mjs --at opening` (первый новый узел после
  `lab.playtest.panel.opening_incoming` входящих): кто пишет, чего хотят, чем плохо кончится, к какому сроку.
  **Если** конец главы 1 → `--at ch1`: что происходит, чего жду, о чём это одной фразой. Пустой ответ на «что
  дальше» — крючка нет; «не понял, кто это» правится раньше «скучно».
- **Когда не работает.** Узел точки не встретился на маршруте персоны — возьми другой `--seed` или свой `--at`.
  Загадка «кто пишет» задумана — пустой ответ на «кто» не дефект, если ответ на «чего хочет» есть.
- **Масштаб.** 5: одна точка в конце. 50: обе точки и точка после первой долгой паузы.
- basis: secondary (свод `attention-merged.md`) · проверка: `panel.mjs`, `story:cold-read`.

### narrative-testing:P-03 · Сколько вопросов и что писать в брифе

- **Если** у автора есть мучающие вопросы → в бриф до `lab.playtest.brief.questions_max` (скрипт больше не
  примет), каждый — о месте и ощущении, без подсказки ответа. **Если** есть известные баги и недописанное →
  `--known` словами игрока, недописанное закрывает `beta_stop`: тестер не будет искать то, что автор знает.
- **Когда не работает.** Вопрос «заметили, что …?» подсказывает ответ. Вопрос про всю историю («понравилось?»)
  тестер не свяжет с местом.
- **Масштаб.** одинаково: внимание тестера ограничено и на 5 сообщениях.
- basis: secondary (Short, Ryan, форум CoG) · проверка: `playtest-kit.mjs --ask`.

### narrative-testing:GREEN-09 · Брать ли отзыв в сводку

- **Если** у отзыва есть место (узел или начало сообщения), симптом и журнал → в сводку, баг — в маршрут. **Если**
  нет места → «без места», переспросить. **Если** только рецепт («сделай, чтобы…») → симптом выяснить, рецепт —
  в `ideas.md`. **Если** нет журнала, а это баг → сначала журнал.
- **Когда не работает.** Холодный читатель без цитаты — повтор прогона, а не переспрос.
- **Масштаб.** одинаково.
- basis: secondary · проверка: `digest.mjs` (колонки, «без места», «рецепты»).

### narrative-testing:SYS-1 · Какой шаг цикла пропущен

- **Если** отзывы о недописанном → пропущена готовность (нет `beta_stop`). **Если** отзывы в разном формате и
  сводка не собирается → пропущен бриф (форма отзыва). **Если** баг не воспроизводится → нет записи (журнала).
  **Если** спорят о решениях → пропущена сводка симптомов. **Если** правка сломала соседнюю ветку → нет
  регрессии (`route-replay.mjs`). **Если** начало после правки никто не перечитал → нет следующего раунда.
- **Когда не работает.** История на одну сессию без глав — шаги 2–4 сжимаются в одну строку брифа и два вопроса.
- **Масштаб.** 5: короткая форма. 50: все шаги.
- basis: secondary (Short, IFWiki, CoG) · система — [systems/beta-cycle.md](systems/beta-cycle.md).
