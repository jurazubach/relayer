# Поворот и раскрытие как ход меню

Ходы «поворот» и «ложный след» в меню опираются на знания двух соседей, и этот файл темой не владеет
(`owners.md`: повороты замысла — TH-04 у `story-brainstorm/patterns-twists.md`, порядок раскрытий — TH-81 у
`story-mystery/reveals.md`). Здесь — только как превратить поворот в развилку: что он меняет в графе и сколько
стоит. Правила самих поворотов и раскрытий — по ID у владельцев (`npm run -s story:rule <ID>`).

## Поворот — дешёвая развилка

Поворот меняет смысл уже сделанного, а не путь: новая правда пересчитывает прошлые кнопки. Поэтому он почти
бесплатен по тексту и не тратит бюджет, если раскрытие стоит на стволе. Он становится ходом **с выбором**,
когда после него игроку есть что решить заново: прежний союзник оказался противником — кому теперь писать.

| поворот | что меняет в графе | цена | ломается |
|---|---|---|---|
| ложный союзник | развилка «кому верить» после раскрытия; переменная отношения перечитывается | реплики реакции по оси | раскрытие в ветке меньшинства — для большинства поворота нет (R-37) |
| смена противника | меняется адресат угрозы; часть чатов замолкает, открывается новый (`#unlock`) | новый контакт — дорогая ветка (`budget.md`) | новый контакт в последней трети (`#attn-min-ending`) |
| маска | кнопки, сказанные раньше, звучат иначе — колбэк по флагу | одна-две условные реплики | игрок не видел исходной реплики — колбэк пустой |
| драматическая ирония | игрок знает больше героя; развилка «сказать или промолчать» | одна развилка с памятью | герой узнаёт сам без участия игрока — выбор отнят |

`basis: model` — таблица собрана для меню, правила поворотов — у `story-brainstorm`.

## Ложный след — воронка с правдоподобием

Ложный след — это воронка ([decisions-failure.md](decisions-failure.md), `bateman-game-writing:PAT-04`) с
загадкой внутри: игрок проверяет правдоподобную неверную гипотезу и получает потерю и находку. Честность
следа (опровергнут ли он, есть ли улика на стволе) проверяет `story-mystery` (C-54, `clue-map`). Скилл в меню
только помечает: «ложный след — нужна сверка `story-mystery`». `basis: secondary`.

```ink
VAR suspect_keeper = false
-> clue
=== clue ===
на причале следы сапог. у смотрителя такие же #from:zoya
* [Спроси смотрителя прямо]
    ~ suspect_keeper = true
    он обиделся и закрыл дверь. но сказал, что сапоги на складе у всех #from:zoya
* [Сначала проверь склад]
    на складе десять пар. одна мокрая #from:zoya
- -> END
```

## Порядок раскрытий и развилка

- Раскрытие **до** развилки делает выбор осознанным (цена названа); **после** — переосмысляет его. Второй
  вариант сильнее, если игрок помнит кнопку: колбэк называет её словами (`ashwell-standard-patterns:P-04#нюанс`).
- Раскрытие, которое зависит от ветки, — только улика-дубль: главная правда на стволе (R-37, TH-81).
