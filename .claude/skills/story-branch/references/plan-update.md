# После решения: новая версия плана, скелет, D-NN, банк идей

Принятая развилка меняет план: число финалов, главы, контакты, бюджет. Если план после этого никто не
обновит, следующая просьба «и ещё сюда ветку» пройдёт так же, а распределитель финала на скелете никто не
перепроверит (`flow-review.md`, шаг 4). Поэтому решение закрывается пятью шагами. Записывает только
одобренное; в конвейере одобряет королева в пределах `INTENT.md`.

## Шаги

| шаг | что | кто пишет | команда |
|---|---|---|---|
| 1 | новая версия плана `docs/stories/<id>/plans/plan-vN.md` (N — следующий номер; старая не правится) | `story-branch` предлагает текст, пишет после одобрения | — |
| 2 | скелет `plans/skeleton.ink` под новую развилку | `story-plan` (агент `story-architect`); нет его — набросок ink в ответе, применяет `story-fix` | — |
| 3 | прогон скелета | `story-branch` | `npm run -s story:endings -- --story docs/stories/<id>/plans/skeleton.ink`, затем `node ${CLAUDE_SKILL_DIR}/scripts/branch-budget.mjs --story docs/stories/<id>/plans/skeleton.ink` |
| 4 | решение D-NN «ветка» и новая версия плана в `STATUS.md` | `story-desk` (`decision-add.mjs --kind ветка --set-plan plans/plan-vN.md`) | через `story-desk` |
| 5 | отвергнутые варианты меню — в банк идей | `story-desk` (`idea-park.mjs --kind развилка`) | через `story-desk` |

После шага 4 — что устарело (главы, написанные по старому плану): `story-desk`, `stale-check.mjs --if plan`.

## Что меняется в `plan-vN.md`

Первая строка — `core: D-NN` (ядро, на котором стоит план; `story-desk/references/state-format.md`). Затем
раздел «Изменение от plan-v(N-1)» из четырёх строк:

```
изменение: развилка pier_night (гл. 3) — ложный след с капитаном
финалы: было 3, стало 3; fin_alone теперь читает trust
чаты: +keeper с гл. 3 (#unlock); брат молчит гл. 3
бюджет: дорогих 4 из story.branch.budget.max, осталось 1; доля текста ≈ 46 % (оценка до текста)
```

Остальной план — копия прежней версии с правками в главах, которых касается развилка. Числа в строке
«бюджет» после шага 3 заменяются замером скелета.

## Текст D-NN

`decision-add.mjs` у `story-desk` ждёт `--what`, `--why`, `--basis`. Скилл готовит их так:
- **что:** «развилка <узел> (гл. N): <вид> — <одной фразой>; план → plans/plan-vN.md»;
- **почему:** что почувствует игрок и какую боль закрывает («граф почти линейный в середине»);
- **опора:** R-26, R-37 и ID записей reference, на которых стоит ход (`ashwell-standard-patterns:P-03`…);
- **заменяет:** прежнее решение о той же развилке, если было.

## Если шага нет

- Нет папки состояния или `plans/` (история вне цикла) — шаги 1–2 пропускаются, решение и набросок ink
  остаются в ответе, `story-desk` предлагает завести папку.
- Нет скелета — шаг 3 на исходнике `src/stories/<id>/` с пометкой «план без скелета».
- Команда упала — «нет данных: <команда>», запись D-NN без чисел не делается.
