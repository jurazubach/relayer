# Признаки: красные и зелёные, чем поймать, как чинить

Признак → команда, которая его ловит → ход меню. Числа — только из команд; если команда не ловит, признак
помечен «модель». Чужие проверки — у владельцев (C-05, C-10, C-11, C-15, C-19 — `story-choices`; C-25 —
`story-opening`, измерение 2 читает этот скилл; C-43 — `story-endings`).

## Красные

| признак | чем поймать | ход |
|---|---|---|
| «Кнопки ничего не меняют»: в главах почти одни окраски | `branch-budget.mjs`: по главам «с переходом / память / окраска»; `story:lint` C-05, C-10 | память или выбор с мотивом ([patterns-branch.md](patterns-branch.md)) |
| Граф почти линейный: дорогих меньше бюджета | `branch-budget.mjs`: «мало» против `story.branch.budget.min` | один-два дорогих хода в концах глав и в финале ([budget.md](budget.md)) |
| Глава без единой развилки в разные узлы | `npm run -s story:lint -- --story <id> --only C-25` (измерение 2) | развилка-горлышко с осадком |
| Дорогих сверх бюджета | `branch-budget.mjs`: «сверх» против `story.branch.budget.max` | свести или вырезать (`narrative-postmortems:P-06`), новое — только вместо |
| Веер в середине не сходится | `branch-budget.mjs`: «веер в середине», `story.branch.fan.merge_hops` | горлышко, разница в переменные (`emshort-structures:RED-07`) |
| Дорогая ветка у меньшинства | `branch-budget.mjs`: «редкие дорогие», `C-15.rare_branch_share`; `story:lint` C-15 | поднять вход или сократить (R-37) |
| Доля текста выше коридора | `branch-budget.mjs`: «много» против `story.branch.seen_share.max` | выборы почти ничего не меняют — пальцы в финале, эхо |
| Доля текста ниже коридора | `branch-budget.mjs`: «мало» против `story.branch.seen_share.min` | пишешь для меньшинства — свести ветки |
| Плохая ветка кончает историю раньше последней главы | `branch-impact.mjs`: у кнопки `END` вместо финалов соседей | изменённый мир (R-32), закрыть событием (C-43) |
| Отказ сходится с согласием без следа | `story:lint` C-11 (`C-11.refusal_hops`) | отказ с ценой ([patterns-refusal.md](patterns-refusal.md)) |
| Кульминация главы мимо большинства | `branch-impact.mjs --node <узел перед пиком>`: пик не во всех областях | пик — горлышко (`inkle-ingold:RED-10`) |
| Правильная игра даёт меньше текста | `branch-impact.mjs`: «своё» у верной кнопки много меньше | сцена с новой угрозой в короткую ветку (`ashwell-standard-patterns:RED-09`) |
| Тяжёлое решение одной кнопкой | модель | колея или подтверждение (`emshort-structures:RED-12`) |
| Нет шапки `// оси:` | `branch-impact.mjs`: «нет шапки» | оси из `story-core`; без них «что меняет» — по `story:vars` |

## Зелёные

| признак | чем увидеть |
|---|---|
| кнопки развилки уходят в разные чаты и пишут разные переменные (`choiceofgames-design:GREEN-03`) | `branch-impact.mjs`: разные «чаты» и «пишет» |
| плохой исход главы ведёт дальше (`narrative-postmortems:GREEN-05`) | у кнопки провала те же финалы, что у соседей |
| важная проверка — три уровня исхода (`choiceofgames-design:GREEN-07`) | условный блок с двумя порогами одной переменной |
| есть «отступить» с маленькой ценой (`choiceofgames-design:GREEN-08`) | кнопка без проверки с небольшим `-=` рядом с рискованными |
| перед ночной паузой — честная кнопка «ждать» (`serial-hooks:GREEN-10`) | развилка, где ветки различаются длиной ожидания и событием |
| дорогие ветки в бюджете, в концах глав и в финале | `branch-budget.mjs`: «в бюджете», дорогие — в последних главах |
