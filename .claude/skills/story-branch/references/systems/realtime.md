# Система: реальное время и откат (чат-фикшн)

### chat-fiction-apps:SYS-3 · Реальное время с уведомлениями

Система игр-переписок в реальном времени (Lifeline и родня). **Шаги, вход → выход.** 1) Персонаж уходит
(занят, сон, дорога): сцена → пауза с причиной, иначе пауза выглядит как баг. 2) Ожидание в реальном времени:
воображение игрока дорисовывает; работает на первом проходе и раздражает на повторном. 3) Уведомление
возвращает игрока — у нас его нет, возвращает только крючок (`story-pauses`). 4) Откат решения после гибели:
провал → новая попытка; конфликтует с запретом отмены (`chat-fiction-apps:contra-1`). 5) Быстрый режим для
повтора.
**Что берём для ветвления.** Шаг 4 не берём: переписка необратима, плохой исход ведёт дальше (R-32). Шаг 5
решён автором иначе: «по клику» доступен с начала, равноценно реальному времени (A-04), поэтому любая
развилка должна работать в обоих режимах — ветка, цена которой «подождать часы», по клику бесплатна, и цена
должна быть событием мира, а не ожиданием (`failbetter-qbn:PAT-03#нюанс`). Срок паузы персонаж не называет
(A-01). **Ошибки понимания:** уведомление — канал, а не причина вернуться; откат — не единственный способ
снять цену повтора.
