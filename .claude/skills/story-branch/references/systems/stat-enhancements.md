# Система: мелкие структуры с усилителями состояния (Short)

### emshort-structures:SYS-1 · Мелкие структуры с усилителями состояния

**Элементы.** Базовая структура — одна из шести мелких форм (подтверждение, переключение колеи, по очкам,
экспозиция, распределение, финальный веер): она задаёт форму сцены — сколько тактов, куда сходятся ветки.
Усилитель состояния (stat enhancement) — счётчик, который запоминает не выбранный вариант, а манеру: как долго
игрок держался риска, как часто стоял на итоговой стороне. Отложенное чтение — место позже, где усилитель
меняет текст.

**Шаги, вход → выход.** 1) Назвать тип решения (риск, дилемма, ось ценностей, экспозиция, старт, финал).
2) Взять базовую структуру со схемой тактов ([../patterns-pressure.md](../patterns-pressure.md),
[../decisions-failure.md](../decisions-failure.md)). 3) Навесить усилитель — `VAR` с ясным смыслом («сколько
раз настоял»). 4) Назначить чтение — узел в другой сцене и реплику по порогу.
**Если пропустить:** без шага 1 структуру берут по вкусу, и подтверждение риска на равноценной дилемме
превращается в «точно? точно?»; без 3 и 4 мелкая структура — красивая, но забытая сцена.

**Ошибки понимания.** «Подтверждение — это диалог „вы уверены?“» — нет, каждый такт добавляет информацию;
«шляпа — структура всей истории» — это начало для перепроходимых историй; «пещера в финале = много
концовок» — концовки выдают итог накопленных шкал; «шесть приёмов — бери любой» — они парами решают разные
задачи.

**Короткая форма.** 5 минут — одна структура на сцену и один усилитель, который читается в последней строке.
Для меню это самый дешёвый способ сделать «кнопки что-то меняют» без новых веток.
