# Меню «куда свернуть»: как показать варианты автору

Автор не умеет строить сюжеты и выбирает (`INTENT.md`): скилл обязан **предложить варианты и объяснить**.
Меню — 3–5 ходов разного вида ([decisions-branch.md](decisions-branch.md)), у каждого влияние и цена числами
из команд, потом рекомендация. Не меню из пяти формулировок одной кнопки.

## Карточка варианта

```
Вариант 2 · ложный след · «Зоя идёт к капитану с чужой записью»
  где:        узел pier_night (гл. 3), после реплики «запись у меня»
  что меняет: оси — trust ⚑ −1; финалы — те же 3, но fin_alone ближе (читает trust ◆);
              чаты — +keeper (#unlock), брат молчит главу
  цена:       ≈ 12 сообщ. своей области → дорогая; бюджет 4 из 5 → останется 0;
              доля текста 47 % → 45…48 %
  для кого:   драматист (мотив), победитель (проверка)
  ломается:   если запись очевидно поддельная — это ловушка, а не след
  набросок:   2–6 строк ink (теги только ready, текст по docs/style.md)
```

Поля — откуда:

| поле | откуда число | правило |
|---|---|---|
| вид | [decisions-branch.md](decisions-branch.md) | пять видов: развилка, поворот, ложный след, отказ, молчание |
| что меняет: оси | шапка `// оси:` и `npm run -s story:vars -- --story <id>`; ⚑ и ◆ — как в `branch-impact.mjs` | R-26: память важнее узлов |
| что меняет: финалы | `npm run -s story:endings -- --story <id>` до и, для скелета, после | `story-endings` — порог и видимость |
| что меняет: чаты | `branch-impact.mjs`: «чаты», «свои», `#unlock`; состав — `npm run -s story:cast -- --story <id>` | лишний контакт — `story-cast` |
| цена | оценка сообщений своей области → `branch-budget.mjs --add <N>` | [costs.md](costs.md), [budget.md](budget.md) |
| для кого | `choiceofgames-design:P-19` | хотя бы два разных типа игрока в меню |
| ломается | «Когда не работает» из записи reference | без этого поля вариант не показывать |

Числа о том, что ещё не написано, — **оценка** (так и помечать); числа о существующем ink — только из команд.
Упала команда — «нет данных: <команда>».

## Состав меню

- Хотя бы один **дешёвый** ход (память, окраска с разным тоном, мотив) — R-26.
- Хотя бы один ход, который меняет **финалы или состав чатов** — иначе автор не видит, что граф может ветвиться.
- Если бюджет «в бюджете, осталось 0» или «сверх» — дорогой ход только **вместо** названной потраченной ветки.
- Хотя бы один ход, где игрок делает шаг сам (порог, отказ, молчание), если в главе шаг делает персонаж
  (`snyder-save-the-cat:LESSON-11`).
- Без хода, который ведёт в ранний `END` (R-32), и без хода, где «правильная» кнопка очевидна (`choiceofgames-design:SYS-4`).

## После карточек

1. **Рекомендация** одной фразой: какой вариант и почему (что почувствует игрок).
2. **Можно смешать:** какие два варианта совместимы (дешёвый + дорогой), и что это даёт бюджету.
3. **Что будет после решения:** новая версия плана, запись D-NN, отвергнутое — в банк идей ([plan-update.md](plan-update.md)).

## Автор отверг все (Б-4)

Не предлагать снова тех же видов. Спросить, что не так, **по осям**, с вариантами ответа: «слишком дорого /
не тот тон / не тот герой / слишком предсказуемо / не меняет финал». Исключить отвергнутое (и записать его в
банк идей с причиной), дать **два далёких** варианта — другого вида и с другим влиянием (если отвергли
развилки — поворот и отказ; если отвергли дорогое — память и молчание). Два раза подряд «всё не то» —
вопрос не про точку, а про ядро: сказать об этом и предложить `story-core` (через `story-desk`).
