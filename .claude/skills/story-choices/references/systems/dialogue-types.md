# Система: три типа диалоговых систем

Классификация из главы о диалоговых движках в сборнике о написании игр: что запускает реплику и какой ритм
это даёт. В мессенджере все три типа выражаются тегами `ready`.

### bateman-game-writing:SYS-4 · Три типа диалоговых систем

| тип | что запускает реплику | ритм | частая ошибка | у нас |
|---|---|---|---|---|
| событийный | событие в мире | рваный, срочный | слишком частые перебивки приучают игнорировать | сообщение другого контакта посреди разговора |
| тематический | игрок выбирает тему | ровный, свободный | меню-справочник без итога | хаб с исчезающими вопросами, темы в пределах `C-19.spokes_max` |
| дерево | выбор реплики в разговоре | направленный | окраски подряд | `*` со сборками |

- **Вход.** Сцена и её задача. **Выход.** Тип (или смесь) для каждой сцены главы.
- **Если пропустить.** Вся глава — одно дерево, темп однообразный (`bateman-game-writing:GREEN-05`); или
  хаб там, где нужна срочность, и сцена провисает.
- **Чего в классификации нет** (по комментатору): моделей «значимости», которые выбирают реплику по
  состоянию, — в ink ближе всего условные строки `{x: …}`, их у нас хватает; гибридов, где игроку предлагают
  темы внутри дерева, тоже нет.
- **Короткая форма.** Пять минут — дерево и одна перебивка; глава — хотя бы два типа из трёх.
- **Проверка.** Хаб — C-19; событийную перебивку видно как `#from` контакта, которому в главе ещё не
  отвечали (`npm run story:trace -- --story <id> --visible`). Три типа диалоговых систем из главы о движках: решай тип для каждой сцены до текста.
