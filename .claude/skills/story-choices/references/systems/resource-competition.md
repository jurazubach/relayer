# Система: конкуренция за внимание на ходу

Модель из исследования чтения с телефона на ходу: окружение отнимает ресурс внимания, и человек читает
рывками. Скиллу она объясняет, почему кнопка должна быть понятна по трём сообщениям над ней и почему кнопка —
лучшая точка, где игрок может отпустить телефон.

### attention-today:SYS-2 · Конкуренция за ресурс на ходу

Порядок: окружение требует ресурса → ресурс уходит от задачи на экране → внимание к экрану рвётся на рывки →
человек компенсирует. Сначала ресурс снимают со второстепенного (люди замедляли шаг, чтобы дочитать), затем
включают одну из стратегий.

| шаг | вход → выход | для нас |
|---|---|---|
| требование среды | шум, движение, люди → меньше ресурса на экран | игрок читает в транспорте |
| распад взгляда | ресурса мало → короткие рывки, взгляд часто уходит с экрана | одно сообщение — один рывок |
| оценить обстановку заранее | человек прикидывает, сколько спокойного времени до следующей помехи | короткую сцену до кнопки начнут читать; важное — в последней реплике перед кнопкой (`inkle-ingold:P-08`) |
| редкие короткие взгляды | предсказуемая среда проверяется взглядами с промежутками | ровный ритм коротких реплик читается между взглядами, стена текста — нет |
| довести подзадачу до конца | перед результатом человек не отрывается | кнопка — точка, где отпустить не жалко; обрыв посреди серии дороже |

- **Если пропустить.** Проверяешь историю за столом — всё читается; на улице непрерывный взгляд в разы
  короче, а переключений больше.
- **Ошибка понимания.** Короткий рывок — не «длина внимания вообще», а длина непрерывного взгляда в тяжёлой
  обстановке; в спокойной она заметно длиннее (`attention-today:LESSON-01` — о цифрах без замера).
- **Короткая форма.** Единица подачи — сообщение в один рывок; единица завершённости — кусок до кнопки.
- **Проверка.** Кнопка понятна по трём сообщениям над ней (`attention-today:P-01`, `buttons.md`);
  длина сообщения — `story-voice`, длина кнопки — C-13. Короче: это конкуренция за ресурс внимания на ходу, и кнопка — место, где игрок может безопасно отпустить экран.
