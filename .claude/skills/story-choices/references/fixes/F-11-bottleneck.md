# F-11 · Развилка в горлышке

Ремонтный приём `story-choices` для боли «граф почти линейный». Применяет `story-fix` — только одобренное.
Ссылается `story-branch`: куда свернуть сюжет — его решение; здесь — как дать памяти и одной настоящей
развилке появиться в уже написанном коридоре. Глобальные структуры ветвления держит `story-plan`.

### F-11 · Развилка в горлышке

**Когда.** Коридор: почти все узлы проходят все прогоны, выборы в основном меняют реплики. Замеры: C-05
(`C-05.writes`, `C-05.meaningful`), C-10 (`C-10.cosmetic_chapter`), карта `npm run graph` (доля узлов, через
которые идут все прогоны), `node ${CLAUDE_SKILL_DIR}/scripts/choices.mjs --story <id>` (классы кнопок по главам).

**Шаги.**
1. Выпиши оси истории (их держит `story-core`, R-39, R-41) — обычно одна-две: отношение к ключевому
   контакту, риск, правда.
2. Каждую косметическую развилку привяжи к оси: `~ ось += 1` или `-= 1` в ветке — без новых узлов. Убывающую
   ось переверни в растущую (F-14, C-09 `C-09.shrinking_le`).
3. В начале каждой главы со второй поставь отклик на ось: условная реплика, новая кнопка или другой порядок
   сообщений (F-08).
4. В одном-двух горлышках сделай настоящее расхождение узлов по оси — две-три ветки, у каждой своя сцена, — и
   сведи их к следующей главе. Перед развилкой — ставка (R-47); рискованный вариант — в два такта (R-51).
5. Слияние защити: в общем узле после горлышка — условные строки по тому, откуда пришёл игрок (защита
   слияния — F-13 у `story-continuity`).
6. Прогони: `npm run check:story` (нет тупиков, пороги достижимы — C-15 `C-15.threshold_unreached`),
   `npm run story:lint -- --story <id> --only C-01,C-02,C-05,C-10,C-15`, `npm run graph`.

**Готово, когда.** На карте не меньше двух развилок, которые расходятся и сходятся; пороги осей достижимы;
у каждой новой записи есть видимое чтение (C-01, C-03 молчат).

**Что нельзя сломать.** Обязательные сцены остаются на стволе — их проходят все (`sheldon-character-storytelling:LESSON-03`);
не накачивать переменные без чтения (C-01, C-09 `C-09.single_read_share`); не применять к истории из одной-двух
глав — накопить состояние негде, там лучше усилить окраску (F-07) и финал (`story-endings`).

**До** (коридор: обе кнопки сходятся и ничего не помнят):

```ink
# contact: anya, Аня, teal
-> ch1
=== ch1 ===
он опять звонил. брать? #from:anya
* [Бери #to:anya]
    ок #from:anya #delay:30s
* [Не бери #to:anya]
    ок #from:anya #delay:30s
- -> ch2
=== ch2 ===
Глава 2 #sys:anya #chapter
он пришёл к дому #from:anya #delay:3h
-> END
```

**После** (ось риска, отклик в начале главы, расхождение в горлышке):

```ink
# contact: anya, Аня, teal
VAR risk = 0
-> ch1
=== ch1 ===
он опять звонил. брать? #from:anya
* [Бери. Узнаем, что ему надо #to:anya]
    ~ risk += 1
    взяла. он знает мой адрес #from:anya #delay:2m
* [Не бери #to:anya]
    не беру. он пишет смс #from:anya #delay:1m
- -> ch2
=== ch2 ===
Глава 2 #sys:anya #chapter
{risk > 0:зря я взяла трубку. он пришёл к дому #from:anya #delay:3h|он нашёл меня сам. стоит у дома #from:anya #delay:3h}
* {risk > 0} [Выйди и поговори при соседях #to:anya]
    -> talk
* [Не открывай. Зови соседей #to:anya]
    -> hide
=== talk ===
вышла. он отдал письмо и ушёл #from:anya #delay:5m
-> after
=== hide ===
соседи вышли. он ушёл, но оставил письмо в ящике #from:anya #delay:5m
-> after
=== after ===
{talk:он смотрел мне в глаза, когда отдавал #from:anya|я не видела его лица #from:anya} #delay:30s
-> END
```

`skills.md` §6 F-11; проход `/story-deepen` и `ashwell-standard-patterns:PAT-12`.
