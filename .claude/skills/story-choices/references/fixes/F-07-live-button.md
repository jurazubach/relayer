# F-07 · Оживить кнопку

Ремонтный приём `story-choices`. Применяет `story-fix` — только одобренное автором (в конвейере — королевой).
Скилл предлагает правку с вариантами; текст меняется после одобрения.

### F-07 · Оживить кнопку

**Когда.** Пустая группа или кнопка без отклика: C-10 (`C-10.group_bodyless`, `C-10.bodyless_chapter`,
`C-10.cosmetic_streak`), C-11 (а) — молчание без следа, C-13 (`C-13.similar`) — варианты-синонимы.

**Шаги.**
1. Определи роль группы: **ритм** (реакция посреди монолога), **выражение** (тон, имя, отношение) или
   **решение** (поворот с последствием). Роль видна по месту: решение — в конце сцены перед крючком (R-50),
   ритм — внутри длинной серии, выражение — в начале сцены.
2. **Ритм** → своя короткая реплика на каждую кнопку (`meaningful-choice:PAT-08`); если ответ по смыслу
   один — кнопок не нужно, это `#me`.
3. **Выражение** → переменная тона или имени и её чтение позже (`meaningful-choice:PAT-03`,
   `emshort-structures:P-16`); первая реплика всё равно своя на каждую кнопку.
4. **Решение** → дилемма с ценой: ставка «если…, то…» над кнопками (R-47), у каждой кнопки свой исход,
   ответ «да, но» (`mckee-story:PAT-10`); затем в следующей главе одна реплика-напоминание (F-08).
5. Пустое молчание → реакция с паузой или запись в счётчик (`meaningful-choice:PAT-04`).
6. Если ответ одинаков, сначала попробуй оправу без новой ветки: другой отправитель, пауза, чат, `#sys`
   (`procedural-storytelling:P-02`).
7. Перезапусти замер: `npm run story:lint -- --story <id> --only C-10,C-11,C-13` и
   `node ${CLAUDE_SKILL_DIR}/scripts/choices.mjs --story <id>`.

**Готово, когда.** У каждой кнопки группы свой ответ или след; C-10 по главе не выше порогов.

**Что нельзя сломать.** Сборку `-` и переходы после неё (иначе бот найдёт тупик — `npm run check:story`);
длину кнопки (C-13); род игрока в новых репликах (C-14 у `story-voice`); паузу без срока возвращения (A-01).

**До:**

```ink
# contact: sasha, Саша, teal
мне кажется, это был он #from:sasha
* [Понятно #to:sasha]
* [Ясно #to:sasha]
- ладно, потом поговорим #from:sasha #delay:30s
-> END
```

**После** (роль — выражение: отношение к догадке Саши):

```ink
# contact: sasha, Саша, teal
VAR doubted_sasha = false
мне кажется, это был он #from:sasha
* [Ты уверена? #to:sasha]
    ~ doubted_sasha = true
    нет. поэтому и пишу тебе #from:sasha #delay:30s
* [Я тоже так думаю #to:sasha]
    хоть кто-то #from:sasha #delay:20s
- ладно, потом поговорим #from:sasha #delay:30s
{doubted_sasha:я проверила. сомневаться было правильно #from:sasha #delay:2h}
-> END
```
