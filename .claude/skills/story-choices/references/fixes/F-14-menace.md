# F-14 · Угроза вместо тихого провала

Ремонтный приём `story-choices`. Применяет `story-fix` — только одобренное. Ссылается `story-core/axes.md`:
растущие счётчики — его правило R-41; здесь — как превратить тихий штраф в видимую угрозу со сценой.

### F-14 · Угроза вместо тихого провала

**Когда.** Провалы в истории тихие: `-= 1` без сцены, игрок проигрывает, не поняв почему. Замеры: C-08
(`C-08.no_signal` — снижение без сигнала цены, `C-08.grudge` — обида без последствий), C-09
(`C-09.shrinking_le` — убывающая переменная сравнивается с `<=`), C-02 (`C-02.ratio` — счётчик вслепую).

**Шаги.**
1. Найди противника или подозревающего — кто в истории естественно злится или следит (контакт, служба,
   слух). Если такого нет, угрозе неоткуда говорить: сначала вопрос к `story-core`.
2. Заведи растущую переменную угрозы вместо убывающего «доверия» (`failbetter-qbn:P-13`): ошибка игрока →
   угроза растёт. Растущие счётчики не путаются в условиях (R-41).
3. Напиши реплики-уровни: персонаж называет уровень словами, не числом («ещё раз — и я звоню твоему
   начальнику»), чтобы игрок видел потолок (R-116).
4. На пороге — яркая сцена: контакт блокирует, уходит, публикует; после неё история продолжается другим
   путём, а не обрывается (`failbetter-qbn:PAT-08`).
5. Дай способ угрозу уменьшить — иначе она превращается в приговор.
6. Прогони: `npm run story:lint -- --story <id> --only C-02,C-08,C-09,C-15` (порог достижим —
   `C-15.threshold_unreached`), `npm run check:story`.

**Готово, когда.** У угрозы видимый уровень и узел провала; бот доходит до сцены порога хотя бы в части
прогонов; после сцены у игрока есть ход.

**Что нельзя сломать.** Провал не наказывает отсутствие или молчание сильнее, чем осознанный выбор (A-03);
угроза не называет срок во времени игрока (A-01, R-114 у `story-time`); упрёк — за видимый поступок, а не за
невидимую арифметику (`mobile-interactive-stories:RED-11`).

**До** (тихий провал):

```ink
# contact: boss, Начальник, grey
VAR trust = 2
-> day
=== day ===
ключ от склада брали? #from:boss
* [Нет #to:boss]
    ~ trust -= 1
* [Он у меня на час, верну #to:boss]
- {trust <= 1: -> fired}
ок #from:boss #delay:1m
-> END
=== fired ===
вы уволены #from:boss #delay:2h
-> END
```

**После** (растущая угроза с уровнями и сценой на пороге):

```ink
# contact: boss, Начальник, grey
VAR suspicion = 0
-> day
=== day ===
ключ от склада у тебя? #from:boss
* [Нет #to:boss]
    ~ suspicion += 1
    странно. камера говорит другое #from:boss #delay:1m
* [У меня, верну через час #to:boss]
    ладно. жду #from:boss #delay:1m
- {suspicion >= 1:ещё одна такая история — и разговор будет у директора #from:boss #delay:30s}
* [Это была ошибка. Извини #to:boss]
    ~ suspicion -= 1
    принято. последний раз #from:boss #delay:2m
* [Ок #to:boss]
    ~ suspicion += 1
- {suspicion >= 2: -> office}
-> END
=== office ===
директор ждёт тебя в девять. пропуск пока заблокирован #from:boss #delay:20m
-> END
```
