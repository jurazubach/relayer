# F-04 · Нарезать монолог

Ремонтный приём `story-opening`. Применяет `story-fix` — только одобренное автором (в конвейере — королевой);
ссылается на него и `story-pace` (длинная серия в середине). Скилл предлагает правку с вариантами; текст меняется
после одобрения. Перед правкой прочти `docs/style.md` (ST-01…ST-03, ST-30…ST-38).

### F-04 · Нарезать монолог

**Когда.** Серия одного отправителя о прошлом сверх порога в начале: C-35 `C-35.monologue` и `C-35.series_ch1`
(держит `story-pace`), строка C-47 `C-47.backstory` (предыстория блоком, `story-voice`), C-23 `C-23.past` (прошлое в
первых входящих), `opening.mjs` — первая кнопка поздно из-за вступления (C-20). Признак глазами: собеседник
рассказывает, игрок только читает; `edgerton-hooked:RED-03`, `cron-wired-for-story:RED-12`, `snyder-save-the-cat:RED-07`.

**Шаги.**
1. Разметь каждую реплику серии: **нужно для инцидента** (без неё не понять событие), **предыстория** (прошлое,
   которое объясняет, но не нужно для следующей кнопки), **инструкция** (что делать). Заодно — функции реплики
   (`systems/line-functions.md`): реплика без функции вычёркивается.
2. **Нужное для инцидента** оставь в стволе, до первой кнопки или сразу после неё; обязательный факт — на всех
   путях (C-24, `first-minutes.mjs`).
3. **Предысторию** разнеси по двум-трём кнопкам-вопросам с лимитом (`edgerton-hooked:PAT-02` в `backstory.md`):
   кнопка называет дыру словами собеседника, ответ — одно-два сообщения. Кто не спросил — получает факт позже, когда
   он становится уликой (страховка `skolnick-video-game-storytelling:PAT-03`). Длинную предысторию, которую нельзя
   резать, — под тикающим сроком (`snyder-save-the-cat:PAT-08`) или как упрёк в споре (`mckee-story:PAT-03`).
4. **Инструкцию** сожми до пары сообщений; лучше — в ответ на кнопку «Что делать?».
5. Перезапусти замер: `npm run -s story:lint -- --story <id> --only C-20,C-23,C-24,C-35,C-47` и
   `node ${CLAUDE_SKILL_DIR}/scripts/opening.mjs --story <id>`.

**Готово, когда.** Серии без кнопки в начале не длиннее `C-35.series_ch1`; монолога о прошлом дольше `C-47.backstory`
без вопроса игрока нет; обязательный факт на всех путях (C-24 молчит).

**Что нельзя сломать.** Обязательный факт не уходит за необязательную кнопку (`edgerton-hooked:RED-06`); сборку `-` и
переходы (бот найдёт тупик — `npm run check:story`); порог первой кнопки (C-20 не ухудшился); длину кнопки (C-13) и
род игрока (C-14); паузу без срока возвращения (A-01).

**До:**

```ink
# contact: zoya, Зоя, teal
мне нужна помощь со складом #from:zoya
когда-то там работал мой отец #delay:3s
он вёл учёт двадцать лет #delay:3s
потом склад продали, а его уволили #delay:3s
новые хозяева сменили все замки #delay:3s
а вчера мне пришёл ключ по почте #delay:3s
к семи утра там ревизия #delay:3s
* [Что нужно? #to:zoya]
- -> END
```

**После** (в стволе — ключ и ревизия; прошлое — по вопросу, со страховкой):

```ink
# contact: zoya, Зоя, teal
VAR asked = false
мне пришёл ключ от склада. по почте, без записки #from:zoya
к семи утра там ревизия #delay:4s
* [Чей это склад? #to:zoya]
    ~ asked = true
    когда-то там работал мой отец #from:zoya #delay:8s
    его уволили, когда склад продали
* [Что ты хочешь сделать? #to:zoya]
    открыть до ревизии. одна не пойду #from:zoya #delay:8s
- {not asked:
    это склад, где работал отец. потом расскажу #from:zoya #delay:6s
}
-> END
```
