# Признаки: красные и зелёные, чем поймать, как чинить

Таблица для быстрой диагностики. «Чем поймать» — команда, а не взгляд: числа только из неё. Отдельно — ложные
срабатывания, найденные при сборке скилла на трёх историях каталога и мутантах (без имён: примеры обобщены).

## Красные

| признак | чем поймать | правка | где подробно |
|---|---|---|---|
| два контакта пишут похоже | C-44 `C-44.distance`; `voice-stats.mjs` (пары, «ниже порога C-44») | развести два параметра формы, словарь, желание; слепой тест | [voice-sheet.md](voice-sheet.md) |
| реплики против карточки голоса | C-44 `C-44.card_share`; `voice-stats.mjs` строка «карточка» | переписать в голосе или объяснить сюжетом | [voice-sheet.md](voice-sheet.md) |
| у контакта нет карточки голоса | `voice-stats.mjs`: «карточки голоса нет» | карточка в `characters[].voice` (R-75) | [voice-sheet.md](voice-sheet.md) |
| голос не меняется от начала до конца | C-44 `C-44.static_voice`; `voice-stats.mjs --chapters` | одно превращение с триггером (R-82) | [patterns-voice.md](patterns-voice.md) |
| вслепую угадано меньше порога | `blind-sample.mjs --ask` против `style.blind_min` | PAT-01: одна новость двумя голосами | [blind-test.md](blind-test.md) |
| стена текста в пузыре | C-34 (`C-34.line_warning`, `C-34.line_error`, `C-34.long_share`) | 2–3 пузыря, ключевое слово в начало | [line-edit.md](line-edit.md) |
| канцелярит, игровые слова, ярлык финала, капс | `style-diff.mjs` (словари `docs/style.md` §14.5) | по образцу SG того же ST | [author-style.md](author-style.md) |
| эмодзи-гирлянда, многоточия в каждой строке | `style-diff.mjs` (`style.emoji_per_line`, `style.ellipsis_per_queue`) | одно на сообщение / очередь | [line-edit.md](line-edit.md) |
| чувство названо чаще порога | C-47 `C-47.feeling` | действие и деталь вместо слова | [registers.md](registers.md) |

| род игрока в кнопке, легенде, у героя | C-14; «сам / сама», «одна» у игрока — модель | безличные формы, цитата игрока | [player-voice.md](player-voice.md) |
| строка дважды на пути, шаблон в узлах | C-46 | под условием, переписать под момент | [repeats.md](repeats.md) |
| две формы имени, имя не из карточки | C-48 `C-48.forms`, `C-48.unknown` | одна форма до связки; `facts.md` | [names.md](names.md) |
| `#rename` без прозвучавшего имени | C-48 `C-48.rename` | имя в той же строке или рядом | [names.md](names.md) |

## Зелёные

| признак | как увидеть |
|---|---|
| голос узнаётся без имени | слепой тест проходит `style.blind_min`; пары основных контактов дальше `C-44.distance` |
| реплики короткие | медиана ниже `C-34.median`, доля длинных меньше `C-34.long_share` (`style-diff.mjs`) |
| ремарка-интерфейс вместо объяснения | в главе есть «Прочитано» / «печатает…» с паузой и без слов о чувствах |
| доверие делает ответ короче | `voice-stats.mjs --chapters`: реплики и паузы контакта короче к сближению |
| кто шутит — записано | в карточках шутящих «шутит: …», их не больше `style.jokers_max` |

## Ложные срабатывания (сверка обязательна)

Найдены при сборке на трёх историях и мутантах; часть уже исправлена в проверках, часть — дело сверки.

| находка | почему ложная | что делать |
|---|---|---|
| C-48: имя героя в падеже («отдай Ефиму», «спроси Павла») | исправлено: основа без окончания и беглой гласной сверяется с `characters` | — |
| C-14: «„ты была маленькой“ — так говорила мама» | исправлено: цитата в кавычках не считается | — |
| C-46: служебный канал повторяет уведомление | исправлено, если у канала `service: true`; без флага — ложная | добавить `service: true` в карточку канала |
| C-46: одно сообщение игрока ушло двум людям | исправлено: повтор — только тот же чат | — |
| C-46: подпись контакта в каждом письме | подпись — маркер голоса по замыслу | `// намеренно: C-46 подпись` |
| C-46: лог повторяет одну строку отказа | повтор — сама суть лога | `// намеренно: C-46 лог` |
| C-44: незнакомец звучит как известный контакт | это его второй номер или маска | `// намеренно: C-44 маска`, проверить, что подмену видно |
| C-47 «упрёк без основания»: узел, куда ведёт кнопка или условие | исправлено, если все входы — из кнопок или условий; смешанный путь — ложная | прочитать кнопку на каждом пути; верно — `// намеренно: C-47 по выбору` |
| C-47 «упрёк за отсутствие»: «наконец-то» в ответ на кнопку | реакция на решение, а не на отсутствие | прочитать реплику до кнопки; двусмысленно — переписать |
| C-48 (б): порядковое в названии улицы, английское в скрине | законное слово мира | место — в `facts.md`; реальная страна или компания — находка по R-117 |
| `style-diff.mjs`: «кнопк» в реплике о кнопочном телефоне, «данные», «игроки» в мире казино | словари §14.5 шире нужного | сверить по смыслу; просьба о словаре — владельцу `docs/style.md` |
