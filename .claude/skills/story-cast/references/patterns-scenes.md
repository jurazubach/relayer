# Приёмы сцен состава

Продолжение `patterns-cast.md`: приёмы сцен, которые держат правила этого скилла и соседей. Примеры ink компилируются,
теги — только `ready`; имена выдуманы. Перед переносом в историю — `docs/style.md` (ST-30…ST-38).

### Одно событие — две реакции

Опора: `procedural-storytelling:P-08` (`character-card.md`), R-90. После новости — ответы в двух чатах с разной
паузой и разным тоном.

```ink
# contact: arseny, Арсений, indigo
# contact: ulyana, Ульяна, pink
VAR sent = false
-> fork
=== fork ===
скинь фото из машины #from:arseny
* [Отправить фото куртки обоим #to:arseny #label:Переслать фото]
    ~ sent = true
* [Пока не скажу #to:arseny]
- {sent: -> react | -> END}
=== react ===
это же моя куртка #from:ulyana #delay:40s
удали. сейчас же #from:arseny #delay:6m
* [Ульяна, откуда она там? #to:ulyana]
* [Арсений, почему удалить? #to:arseny]
- -> END
```

- **Когда не работает.** Реакции разнесены на часы или одинаковы по тону.
- **Масштаб.** 5 сообщений: две реакции — это вся сцена. 50: одна такая пара на главу, на событие, которое меняет обоих.
- basis: secondary.

### Персонаж ведёт к своей цели, игрок уводит

Опора: `emshort-structures:P-13` (`tiers.md`), R-79. Счётчик уводов: после пары уводов персонаж говорит прямо.

```ink
# contact: gleb, Глеб, amber
VAR drifts = 0
-> push
=== push ===
нам надо поговорить про склад #from:gleb #delay:1m
- (opts)
* {drifts < 2} [Как дома? #to:gleb #label:Увести разговор]
    ~ drifts += 1
    нормально. так вот склад #from:gleb #delay:30s
    -> opts
* {drifts < 2} [Ты видел матч? #to:gleb #label:Увести разговор]
    ~ drifts += 1
    видел. склад, слышишь? #from:gleb #delay:30s
    -> opts
+ [Что со складом? #to:gleb]
    -> straight
=== straight ===
{drifts >= 2: ладно. скажу прямо #from:gleb #delay:20s}
ключ от склада был у тебя в ту ночь #from:gleb #delay:40s
-> END
```

- **Когда не работает.** На всю главу — игрок теряет агентность; союзнику, который хочет рассказать, лучше
  тематический хаб (`story-choices`, `hubs.md`).
- **Масштаб.** 5 сообщений: один увод, и персонаж говорит прямо. 50: приём — на одну сцену главного, не на каждую.
- basis: secondary.

### Гость главы

Опора: `yorke-into-the-woods:P-14` (`arcs.md`). Контакт открывается в главе, торгуется, решает и уходит — линия
закрыта решением, а не вопросом.

```ink
# contact: sonya, Соня, teal
# contact: admin, Админ «Наш двор», grey
VAR admin_deal = false
-> ch6
=== ch6 ===
Глава 6 · Чат двора #sys #chapter
он писал в чат двора. админ всё видит #from:sonya
* [Напишу админу #to:sonya]
- #unlock:admin
Здравствуйте. Я админ «Нашего двора». Вас добавила Соня. #from:admin #delay:1m
Удалённые сообщения у меня есть. Но просто так не отдам.
* [Что вы хотите? #to:admin]
    ~ admin_deal = true
    Чтобы вы не писали в полицию о нашем чате. #from:admin #delay:2m
* [Это для полиции #to:admin]
    Тогда через полицию. #from:admin #delay:40s
- {admin_deal: Договорились. Скриншоты пришлю. Больше не пишите. #from:admin #delay:5m | Всего доброго. #from:admin #delay:10s}
-> END
```

- **Когда не работает.** Глава короче `story.short_min` минут; гость, чья линия осталась вопросом. Гостю C-45 п. 3
  не помеха: `// намеренно: C-45 гость`.
- **Масштаб.** 5 сообщений: гость не нужен — хватает одного собеседника. 50: гость на главу, линия закрыта в ней же.
- basis: secondary.

### Ответ через свидетеля

Опора: C-50 (`tiers.md`), `sheldon-character-storytelling:contra-6`. Адресат действует, а рассказывает свидетель;
на ветке, где адресат молчит, его чат хотя бы показывает «Прочитано» — ответ не ушёл в пустоту.

```ink
# contact: arseny, Арсений, indigo
# contact: vera, Вера, teal
-> deal
=== deal ===
Где флешка? Последний раз спрашиваю. #from:arseny #delay:30s
* [В третьей ячейке #to:arseny #label:Соврать]
    Проверю. #from:arseny #delay:20s
    он открыл третью ячейку #from:vera #delay:1m
    там пусто. он злой
* [В седьмой, в куртке #to:arseny #label:Сказать правду]
    Прочитано #sys:arseny #delay:10s
    он открыл седьмую #from:vera #delay:1m
    нашёл. ушёл
- -> END
```

- **Когда не работает.** Свидетель пишет спустя долгую паузу — связь с ответом игрока теряется.
- **Масштаб.** 5 сообщений: свидетель — одна строка сразу после кнопки. 50: приём на ветку, где адресат действует, а не на каждый ответ.
- basis: our_estimate.
