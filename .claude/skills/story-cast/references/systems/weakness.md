# Слабость: психологическая, моральная и переход одной в другую (Труби)

Система даёт главному NPC дугу без лишних событий: его слабость сама меняет вид.

### truby-anatomy-of-story:SYS-3 · Как одна слабость перерастает в другую

**Элементы.** Психологическая слабость вредит самому герою (страх, зависимость, самообман), моральная —
окружающим (врёт, использует, предаёт). Сильнейшие герои несут обе. Нюанс, которого нет в
`truby-anatomy-of-story:P-03`: психологическая слабость может перерасти в моральную, и этот переход сам по себе
показывает развитие персонажа. Обратный ход — моральная слабость начинает бить по самому герою — наш вывод, в
источниках его нет.

| шаг | вход → выход | без шага |
|---|---|---|
| 1. Психологическая | карточка NPC → чего он боится, в чём себя обманывает | реакции произвольны |
| 2. Моральная | психологическая → кому из `characters` он вредит из-за неё | у истории нет спора о том, как жить |
| 3. Узел перехода | две строки → сцена в стволе, где страх толкает его на поступок против другого | перемена объявлена, но не показана |

- **Где не работает.** У роли игрока психологическую слабость не задать: игроку её не навязать
  (`truby-anatomy-of-story:P-03`). Переход «психологическая → моральная» доступен только NPC.
- **Типичные ошибки понимания.** Слабость в биографии, а не в поступке; моральная слабость без жертвы.
- **Короткая форма.** На карте это три узла в стволе: страх виден, страх толкает на поступок, поступок бьёт по
  другому. Больше ничего не нужно.
- **Как проверить.** Узел перехода в стволе — `npm run story:trace -- --story <id>` (доля прогонов через узел).
- basis: secondary.
