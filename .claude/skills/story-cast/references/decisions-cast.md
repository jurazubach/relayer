# Развилки: симптом → замер → решение

Каждая запись: что сказал автор или что нашла команда → чем померить → что предложить. Решение — всегда варианты
для автора, правку применяет `story-fix` после одобрения. Перед тем как писать реплику, кнопку или пример ink —
`docs/style.md`. Поля: «Когда не работает», «Масштаб», `basis`.

## «Чатов слишком много»

**Замер.** `node ${CLAUDE_SKILL_DIR}/scripts/unlock-plan.mjs --story <id>` (новые по главам, открыто, ждут ответа),
`node ${CLAUDE_SKILL_DIR}/scripts/cast.mjs --story <id>` (уровни), `npm run -s story:lint -- --story <id> --only C-21,C-45,C-50`.

| если | то |
|---|---|
| новых в главе 1 больше `C-21.new_ch1` | у кого в главе 1 нет обмена с игроком — перенести к первой настоящей реплике (`unlock-schedule.md`) |
| среди новых — рассылки и автоответы ядра | пометить `service: true` (`video-three-things:GREEN-03`) — это не собеседники |
| двое уровня «фон» / «эпизодический» с одной функцией | слить в один контакт |
| ждут ответа больше `attn.chats.waiting` | закрыть линию одного: ответ, уход, «не в сети» до следующей развилки |
| много открыто, но ждут мало | перегруза нет — проверь, не путает ли голоса (`story-voice`) |

- **Когда не работает.** Ансамбль — замысел (групповая драма), и автор держит его сознательно: тогда не резать, а
  развести функции и голоса и открывать по одному. Жалоба «много чатов» на одной главе при норме C-21 — часто это
  толпа до первой кнопки (`story-opening`, R-18).
- **Масштаб.** 5 сообщений: один собеседник, вопрос не стоит. 50+: ансамбль к концу главы 1, дальше по
  `C-21.new_other`.
- basis: secondary.

## Игрок путает, кто есть кто

| если | то |
|---|---|
| две одинаковые функции у главных (`cast.mjs`, `dille-ultimate-guide:RED-06`) | развести функции или слить |
| одинаковые позиции по вопросу (`truby-anatomy-of-story:RED-11`) | развести по углам (`patterns-cast.md`) |
| голоса похожи (C-44) | к `story-voice` — это не состав |
| две формы имени одного человека | к `story-voice` (`names.md`) |

- **Когда не работает.** Путаница из-за сюжета (двое намеренно похожи, один выдаёт себя за другого): метка
  `// намеренно:` и улика, по которой их различить.
- **Масштаб.** 5 сообщений: путать некого. 50+: функция и голос у каждого заметного контакта.
- basis: secondary.

## Контакт почти молчит (C-45 п. 1–2)

| если | то |
|---|---|
| служебный по смыслу (банк, заметки, пульт) | `service: true` |
| гость одной главы, линия закрыта решением | законно: `// намеренно: C-45 гость` |
| гость, линия открыта (последняя реплика — вопрос) | дописать решение или перенести (`yorke-into-the-woods:GREEN-06`) |
| нужен сюжету ради одной улики | передать улику живому контакту, этого убрать (`nicklin-writing-for-games:P-17`) |
| нужен как человек | дать функцию и реплики (`character-card.md`) |

- **Когда не работает.** Контакт молчит по сюжету (пропал, погиб): его тишина — событие, показанное интерфейсом
  («не в сети»), и оно читается в других чатах.
- **Масштаб.** 5 сообщений: лишний контакт — сразу резать. 50+: решить по уровню из `story:cast`.
- basis: secondary.

## Персонаж только отвечает (C-45 п. 5, R-79)

**Замер.** Колонка «первым» в `cast.mjs`, `C-45.reactive`.

| если | то |
|---|---|
| у него есть своя цель | заход, который он начинает сам, по своей причине (`sheldon-character-storytelling:P-03`) |
| у него тайная цель | ведёт разговор к ней, игрок уводит, потом он говорит прямо (`patterns-scenes.md`) |
| он проводник и повторяет цель | первым не пишет — подсказка по запросу (`bateman-game-writing:RED-17`) |
| игрок не писал ему всю главу | в начале следующей главы он пишет первым (`nicklin-writing-for-games:LESSON-05`) |

- **Когда не работает.** Погоня: пишет только тот, кто в опасности.
- **Масштаб.** 5 сообщений: первое сообщение — инициатива NPC. 50+: у каждого основного свой заход за главу.
- basis: secondary.

## Ответ ушёл в пустоту (C-50 (а))

| если | то |
|---|---|
| адресат должен ответить | короткая реплика адресата до чужой: «на смене, потом» (`sheldon-character-storytelling:contra-6`) |
| адресат молчит по сюжету | показать молчание в его чате: «Прочитано», «не в сети» |
| адресат действует, рассказывает свидетель сразу | законно: `// намеренно: C-50 ответ через свидетеля` (`patterns-scenes.md`) |
| кнопка — вопрос или обращение по имени, ответил другой | это C-10 «ответил не тот» — к `story-choices` |

- **Когда не работает.** Кнопка закрывает разговор (прощание, «спасибо») — ответа не ждёт, C-50 её не считает.
- **Масштаб.** 5 сообщений: каждый ответ — адресату. 50+: молчание допустимо, если показано.
- basis: secondary.

## Шум перебивает или его много (C-50 (б), (в))

| если | то |
|---|---|
| строка шума между вопросом и кнопкой | перенести на паузу основной линии (`messenger-genre:RED-14`) |
| доля шума выше `C-50.noise_share`, строки несут сюжет (тревоги, рассылка-улика) | это канал-источник: `// намеренно: C-50 канал`, проверь, что голос канала сухой (ST-73) |
| доля выше, строки — фон | резать до дозы, оставить фон из канала ядра (R-88) |
| история до `story.short_min` минут | фон режь первым, оставь не больше одной строки |

- **Когда не работает.** Перебивает контакт, которому можно ответить: это развилка «кому ответить сейчас», не шум.
- **Масштаб.** 5 сообщений: шума нет. 50+: доза по главе.
- basis: secondary · C-50 (в) — наша калибровка на трёх историях (`thresholds.json`).

## Никто не меняется

**Замер.** `node ${CLAUDE_SKILL_DIR}/scripts/arcs.mjs --story <id>`: первая и последняя реплика, `#rename`, «Вы» → «ты»,
голос по C-44.

| если | то |
|---|---|
| нет носителя перемены | назначить одного (`truby-anatomy-of-story:P-04`), записать в «Состав» плана |
| носитель есть, перемены не видно | превращение с триггером (`procedural-storytelling:PAT-04`) |
| перемена есть, но без триггера-выбора | привязать к кнопке игрока не дальше пары сообщений до сдвига (R-82) |
| перемена у всех одновременно | оставить полную дугу одному, у остальных одна смена позиции (`truby-anatomy-of-story:contra-2`) |

- **Когда не работает.** Антагонист и служебные не обязаны меняться; гость одной главы — один поворот.
- **Масштаб.** 5 минут: одно превращение в последней трети. 50+: ступенька главного в каждой главе.
- basis: secondary.

## Новый контакт непонятен (R-78)

**Замер.** Первые реплики новых — `unlock-plan.mjs`.

| если | то |
|---|---|
| первая реплика — справка без связи с игроком | первая фраза — откуда знает игрока, через вещь ядра (`video-three-things:GREEN-05`) |
| желание не видно | вторая-третья реплика — чего хочет от игрока |
| пришёл сразу после долгой паузы (`C-21.unlock_after_pause_lines`) | сначала знакомый голос, потом новый |
| пачка `#unlock` в одной сцене (`C-21.unlock_scene`) | второй — после следующей развилки |

- **Когда не работает.** Незнакомец, чья загадка — крючок: связь не объясняет, но желание видно сразу.
- **Масштаб.** 5 сообщений: одна реплика на голос, желание и связь. 50+: типаж → трещина → слом.
- basis: secondary.

## Сторона, которая ничего не решает

**Замер.** Уровень «сторона» в `story:cast`: с ним много говорят, но финал его переменную не читает.

| если | то |
|---|---|
| он важен игроку (много кнопок) | дать переменную отношения, которую прочтёт финал или распределитель — станет осью (`story-endings`) |
| он нужен как фон для главного | сократить разговоры, оставить функцию |

- **Когда не работает.** История с одним финалом и исходом по состоянию: исход решает последняя глава — проверь,
  читает ли она его переменную.
- **Масштаб.** 5 сообщений: сторон нет. 50+: сторон немного, каждая — кандидат в ось.
- basis: our_estimate.
