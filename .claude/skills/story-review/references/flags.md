# Признаки хорошего и плохого ревью: чем поймать, как чинить

Флаги не про историю, а про само ревью: по ним видно, можно ли отчёту верить. Каждый ловится командой.

## Зелёные

| признак | чем увидеть | почему хорошо |
|---|---|---|
| у каждой выбранной линзы есть ответ | `select-lenses.mjs`, колонка «ответ» — «есть» | нет дыр по темам |
| строки замера сверены: «не сверено» только у подсказок | `merge-findings.mjs`, строка «story:lint …» | в отчёт не попали ложные (LOCAL-04) |
| у каждой находки узел и тип | `report.mjs` — нет строк с «—» вместо узла | находку можно открыть и закрыть |
| раздел «Поломки» есть, даже пустой | `report.mjs` | два прохода разделены (`narrative-testing:P-02`) |
| QA сдал шесть списков, пустые — «проверено, нет» | `qa-six.md` папки прогона | нарративный QA прошёл целиком |
| у холодного читателя изоляция «ок» | `story:cold-read --ask --json`, поле `isolation` | «непонятно» — от того, кто не знает истории |

## Красные

| признак | чем увидеть | как чинить |
|---|---|---|
| в основном списке строка «не сверено» без `--lint-only` | `report.mjs`, теги находки | запустить линзу этой проверки (`select-lenses.mjs --task`) |
| много «не разобрано» у одной линзы | `merge-findings.mjs`, счёт по статусам; приложение отчёта | повторить линзу с фокусом на эти узлы |
| в главе больше P1, чем `skill.review.top_per_chapter` | `report.mjs`, «По главам» | глава не держится: вернуть к плану главы, не чинить по строке |
| «скучно» только от модели в P1 | `report.mjs`: тип «скучно», источник «модель», P1 | понизить до кандидата; подтвердить читателем или человеком |
| находка без числа и без «модель · уверенность» | строка без скобок | вернуть аудитору: формат `finding-format.md` |
| рецепт тестера в поле правки | `human-*.md` и отчёт | рецепт — в `ideas.md`, правка — приём владельца ([conflicts.md](conflicts.md)) |
| отклонённая находка снова в списке без пометки | `merge-findings.mjs`: «скрыто отклонённых» 0 при записях в `decisions.md` | записать отклонение через `story-desk` с узлом и хэшем |
| линза пропущена без причины | `select-lenses.mjs`, колонка «почему» пустая или «нет ни находок, ни признака», а симптом автора про неё | `--focus <линза>` |
| история без шапки и меток, а ревью судит загадку и финал | `select-lenses.mjs`, строка «разметка A-06» | сначала разметка (LOCAL-02), потом `story-mystery` и `story-endings` |
| команда получила отказ в правах, и скилл пошёл в обход | в ответе — `node scripts/lint/lint.mjs` вместо `npm run story:lint` | `allowed-tools`: `Bash(npm run story*)`, не `story:*` (LOCAL-03) |

- **Когда не работает.** Флаги говорят о процессе, а не о качестве истории: зелёное ревью может честно найти
  ноль находок там, где тестеры заскучают — «скучно» до людей только кандидат.
- basis: our_estimate (сведено из LOCAL-02…04 и проверок формата).
