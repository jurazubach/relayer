# scripts/story — команды story:*

Команды для скиллов и автора: считают то, что модель не должна считать на глаз. Все стоят на
`scripts/lib` (разбор ink, компиляция, бот), у всех `--help`, `--json`, `--story <id>`.

| команда | что даёт |
|---|---|
| `story:trace` | прохождение персоной: переписка, маршрут (`--route`), переменные, время в обоих режимах; `--visible`, `--compare silent` |
| `story:vars` | переменные: где пишется → где читается, вид чтения, метки «мёртвая», «невидимая», «только финал», «молчит» (`vars.silent_chapters`) |
| `story:sessions` | расписание без часов игрока: сессии, микросессии, длина против карточки, хвост после последней кнопки |
| `story:cast` | контакты: глава появления, реплики, кнопки к нему, главы, уровень (ось / сторона / источник / фон / эпизодический) |
| `story:endings` | финалы по меткам или графу, доли по персонам, что их решает статически и по прогонам |
| `story:diff <реф> [<реф>]` | метрики `story:lint`, `trace`, `sessions`, `cast`, `endings` до и после между ревизиями git («.» — рабочая копия); `--text` — реплики по узлам до и после |
| `story:rule <ID>` | текст правила, проверки, решения или приёма из свода с порогами `thresholds.json`, владельцем (`owners.md`) и отменами (`superseded.md`) |
| `story:status [--all]` | `docs/stories/<id>/STATUS.md` и `decisions.md`: активная история, шаг, три последних решения; `--all` — таблица |
| `story:cold-read` | видимая переписка до узла для холодного читателя в режимах opening / return / click / guess / voices; `--ask` — сам читатель через `claude -p` с проверкой изоляции, `--profile` — профиль читателя, `--last N` — срез |

Самопроверка — `npm run test:story-cmd` (синтетика в `fixtures/`, состояние историй в `fixtures/stories/`,
три истории каталога и одна ревизия git; `cold-read --ask` не вызывается).

## Устройство

- `core/run.mjs` — `prepare(id)` (загрузка, компиляция, дерево, финалы) и `runOnce(p, { persona, seed, mode, start, set, save, route, partial })`.
- `core/personas.mjs` — персоны как стратегии `bot.play`; «неотвечающий» (`NO_ANSWER`: напоминания `#remind`, потом `#noanswer` или `#silent`; по клику — stall), `noAnswer(choices)` и `reminderSeries(events)` — в `scripts/lib/bot.mjs`. В `--route` «не ответил» — `-1`.
- `core/timeline.mjs` — журнал бота → хронология: чат, кто пишет, `tReal` / `tClick`; время — `scripts/lib/playtime.mjs`, та же формула, что у `story:lint`.
- `core/sessions.mjs`, `core/vars-index.mjs`, `core/graph.mjs` (финальные узлы и распределители по `checks.md`).
- Пороги — только ключи `docs/playbook/thresholds.json` через `scripts/lib/thresholds.mjs` (`threshold`, `thresholdSeconds` — по единице ключа), словари — `scripts/lib/lexicon.mjs` (`dict.*`, те же, что у `story:lint`). Свои — только словари персон в `core/personas.mjs`: это характер бота, а не правило свода.
- `core/visible.mjs` — видимая переписка (`trace --visible`, `cold-read`), обрезка до узла.
- `core/playbook.mjs` — свод по ID: блок правила или проверки, строки таблиц, пороги по ключу, `checks` и `sources`.
- `core/state.mjs` — разбор `STATUS.md` и `decisions.md`, шаги цикла, выбор активной истории.
- `core/revisions.mjs` — история на ревизии git во временной папке: обе версии меряются нынешними командами.
- `core/dialogue.mjs` — реплики узла как переписка без прохождения и построчное сравнение для `diff --text`.
- `core/cold.mjs` — режимы холодного читателя, ключ, протокол и проверка изоляции ответа.

## Состояние истории (`story:status`)

Шаблон — `templates/STATUS.md`. Поля — строки `- ключ: значение` до первого раздела: `шаг` (из списка плана §7),
`активная: да`, `ведёт`, `ядро` (D-NN), `план`, `обновлено`. Раздел со словом «вопрос» в заголовке — открытые
вопросы. Решения — `decisions.md` рядом: заголовок `## D-NN · дата · кто — что`, пункт `- **D-NN** · дата · кто — что`
или строка таблицы с колонками `ID | дата | кто | что`. Активная история — с меткой `активная: да`; без метки —
по ветке `story/<id>`, иначе правленная последней.

## Холодный читатель (`story:cold-read`)

```bash
npm run story:cold-read -- --story <id> --until <узел> --mode <режим> [--profile <профиль>] [--last N] --ask --json
```

Без `--ask` команда печатает только переписку (сводку и маршрут — в stderr, ключ — в `--json`). С `--ask` —
`claude -p --model claude-opus-5-5` из пустого временного каталога: `--tools ""`, `--strict-mcp-config`,
`--setting-sources ""`, `--disable-slash-commands`, без автопамяти и сохранения сессии, роль — системным промптом
(`docs/playbook/claude-code-format.md` §4.1). Это единственный способ получить читателя без контекста: агент
Claude Code получает CLAUDE.md, индекс памяти и git status. Агент `cold-reader` (`.claude/agents/cold-reader.md`)
поэтому только запускает эту команду и возвращает ответ.

- **Протокол один:** `.claude/skills/story-playtest/references/cold-reader.md`. Разделы `## Роль` (системный
  промпт), `## Профиль: <id>`, `## Режим: opening|return|click|guess|voices`, `## Контроль`, `## Формат ответа`;
  что ниже — опора для скилла, читателю не уходит. `--protocol <файл>` — свой протокол с теми же разделами.
- **Режимы:** `opening` — начало; `return` — всё после последней тишины от `story.pause.session_s` приходит пачкой
  после «вы отложили телефон»; `click` — без пауз, скачки времени — «спустя»; `guess` — что придёт дальше (ответ —
  `key.next`); `voices` — имена и чаты заменены буквами (ответ — `key.voices`).
- **`--profile <id>`** — профиль читателя: раздел «Профиль: <id>» протокола дописывается к роли. `hurried` —
  торопливый, `attentive` — внимательный, `skeptic` — скептик, `distracted` — отвлечённый, `unresponsive` —
  неотвечающий. Без `--persona` профиль выбирает и маршрут: `skeptic` → персона `suspicious`, `distracted` →
  `distracted`, `unresponsive` → `unresponsive`, остальные — `random`. Профиля нет в протоколе — код 2.
- **`--last N`** — только последние N видимых строк перед узлом: случайный срез без контекста
  (`maass-fire-in-fiction:P-16`; панель берёт N из `lab.playtest.slice.lines`). Обычно вместе с `--mode guess`.
- **Ответ** — по «Формату ответа»: вопросы режима, блок «Интерес» (держит / ровно / теряю по точкам: после первых
  сообщений, на первой кнопке, перед паузой, после возвращения), «Итог», «Слабое место», контрольные К1–К3.
  Шкалу разбирает `story-playtest/scripts/digest.mjs`: «теряю» с цитатой — кандидат «скучно» в этом месте.
- **Изоляция.** Контрольные вопросы спрашивают служебное имя последнего узла, финалы и виновника, название
  истории. Если в ответе есть имя узла, финала или id истории, которых нет в переписке, или следы проекта
  (`relayer`, `CLAUDE.md`, `src/stories` и т. п.) — изоляция нарушена, код выхода 1. Строки об окружении `claude -p` (почта,
  рабочая папка, пути) из сохраняемого ответа вырезаются после проверки; сколько — `isolation.env`.
- **Коды:** 0 — ответ получен, изоляция цела; 1 — изоляция нарушена; 2 — ошибка запуска (нет узла, профиля,
  `claude` не запустился).
