# Общие правила

- **Свод, а не склейка.** Одинаковые идеи из разных источников объедини в один пункт со ссылками на все источники (`snyder-save-the-cat:P-05, edgerton-hooked:P-01`). Если источники расходятся, выбери решение для нашего формата и коротко объясни выбор.
- **Наш игрок.** Человек с телефоном и коротким вниманием, история идёт в реальном времени. Где правило сложно для него, бери минимальную версию из `attention.md`.
- **Без воды.** Каждый пункт можно вставить в промпт, превратить в проверку или выполнить как шаг. Иначе он не нужен.
- **Честность.** Пороги с пометкой «наша оценка» так и помечай. Новых фактов не добавляй — только то, что есть в разборах.
- **Авторское право.** Цитаты не переносить. Формулировки — свои.
- **Язык.** Русский, по договорённостям `CLAUDE.md`.

В конце выведи 3 строки: сколько пунктов, сколько источников задействовано, что осталось спорным.
