## Закрыто из REVIEW.md
- **«Половина игроков» (P-05):** в репортаже Бейтман приводит доли всех четырёх типов, их основание — неназванное «исследование». Оговорка остаётся, но теперь с цифрами ([L1]).
- **Документация:** рецензия Шорт формат дизайн-документа не описывает. Практика добавлена из Pratchett (фон целиком, биографии для команды) и DeMarle (инструмент учёта ветвлений).
- **Юмор:** подтверждено снова только согласование и поэтапные отзывы ([S1]). PAT-08 дополнен уроком Overlord, но это не текст главы.

## Не нашлось
- Термин «edge of the world»: нет ни в полном репортаже AGDC, ни в рецензиях.
- Методы DeMarle для сцен с произвольным порядком и устройство progress structure у Boon: новых открытых источников нет.
- Постмортем Discworld Noir от самого Бейтмана: его нет, есть только интервью и доклад.
- Материалы Matt Entin и советы главы о юморе по существу. «Семь шагов» Kuehnel на странице подкаста не перечислены.
- Числа: удержание, доли дочитываний, длина сессии — ни для одной игры авторов сборника не опубликованы. Процент вырезанного текста Mirror's Edge встречается только во вторичных источниках, не подтверждён.
- Интервью Dansky на Qwillery (404): тезис о «жире» в диалоге при ревью удалён — страница не открылась.
