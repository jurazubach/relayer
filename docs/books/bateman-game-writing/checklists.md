# Процедуры — Game Writing (ред. Bateman)

Источники [S1]–[S6] — в начале `principles.md`. Ссылки `P-`, `PAT-`, `RED-`, `GREEN-` — на соседние файлы.

## 1. Как придумать и начать историю

- [ ] **Запиши хребет списком из 5–10 событий, которые увидит каждый игрок** (P-01). Результат: столбец «глава → обязательное событие». Если события не формулируются без «если игрок…», хребта ещё нет.
- [ ] **Для каждой главы назови один вопрос и один крючок в конце** (P-11). Результат: строка вида «гл. 2: кто подключался к отладчику? → крючок: токен в окружении».
- [ ] **Отметь 1–2 сюжетные развилки на всю историю и где они сходятся** (P-09). Результат: комментарий `// развилка:` в плане, у каждой — узел-горлышко или финал.
- [ ] **Выпиши словарь мира: термины, имена, правила, которые понадобятся хребту** (P-03). Результат: список, у каждого пункта — глава и реплика, где он объясняется в неизбежном сообщении.
- [ ] **Составь шапку `VAR` с комментариями «где ставится → где читается → какой финал»** (P-08). Результат: ни одной переменной без строки чтения.
- [ ] **Реши, кто шутит и как** (P-15). Результат: строка `// юмор:` в шапке, не больше двух контактов.
- [ ] **Напиши первые 3 сообщения так, чтобы в них были проблема и срок** (P-05, PAT-03). Результат: после третьего сообщения игрок может сказать, чего от него хотят и к какому времени.
- [ ] **Первую кнопку дай по тону или отношению, не на знание мира** (раздел «Начало» в `flags.md`). Результат: оба варианта первой кнопки можно выбрать, ничего не зная о сюжете.
- [ ] **Если история в серии — сверь лист мира** (P-18). Результат: у повторных контактов те же `id`, имя и цвет. Правила мира не нарушены.

## 2. Как написать главу или сцену

- [ ] **Запиши над первым узлом главы: вопрос главы, сюжетная развилка (если есть), `// застрянут:`** (P-09, P-12). Результат: три строки комментария.
- [ ] **Выбери типы диалога для сцен: дерево, хаб, перебивка** (P-16). Результат: в главе хотя бы два типа (GREEN-05).
- [ ] **Отметь сцены, которые можно пройти в любом порядке, и выпиши для каждой «требует → сообщает»** (P-19). Результат: в хаб или в параллельные чаты попали только сцены без взаимных требований, остальные отсылки стоят под условием.
- [ ] **У каждого события главы пометь, что его открывает: выбор, время, контакт, переменная** (P-20). Результат: нигде нет больше двух событий подряд, которые открывает только время.
- [ ] **Сюжетную развилку пиши всеми ветками за один заход** (P-09). Результат: ветки готовы одновременно, факты и тон в них сверены.
- [ ] **Для каждой кнопки реши: выбор или окраска** (P-02). Результат: у выбора есть `~` или уход в узел. У окраски — реакция на тон. Не больше двух окрасок подряд.
- [ ] **У каждой ветки задай, что из неё проходит через горлышко** (PAT-01). Результат: в горлышке есть строка `{переменная: …}` для каждой ветки, которая что-то поставила.
- [ ] **Если есть правдоподобная неверная версия — сделай из неё воронку, одну на главу** (PAT-04, RED-06). Результат: отросток с паузой ≥ 5 мин, ущербом и подсказкой персонажа.
- [ ] **Перед каждой паузой ≥ 5 мин поставь крошку** (PAT-03). Результат: реплика со сроком или ожидаемым действием.
- [ ] **Найди серии больше 6 сообщений без кнопки и разрежь их** (P-10). Результат: в середине главы нет серий длиннее 6.
- [ ] **Необязательные детали положи в побочный чат, `#photo`, `notes`; если они нужны дальше — добавь пересказ** (P-04, PAT-05). Результат: для каждой `saw_*` есть ветка `else` короче, чем оригинал.
- [ ] **Проверь шутки: подготовка и развязка вместе, шутка не похожа на подсказку** (P-13, P-14). Результат: нет RED-07 и RED-08.
- [ ] **Прочти вслух все сшитые реплики во всех вариантах** (P-17). Результат: нет несогласованных родов и двойных пробелов.
- [ ] **Обнови комментарии к `VAR` в шапке** (P-08). Результат: новые переменные записаны с местами чтения.

## 3. Как провести ревью готового сценария

- [ ] **Собери карту `npm run graph` и отметь узлы с долей 100%** (P-01). Результат: хребет непрерывен (GREEN-01), он занимает не меньше 30% узлов.
- [ ] **Пройди словарь терминов хребта: где каждый впервые объяснён** (P-03). Результат: список RED-01 с узлами.
- [ ] **Посчитай окраски по главам** (P-02). Результат: таблица «глава → доля кнопок только с репликой». Главы с долей > 40% помечены.
- [ ] **Проверь переменные: каждая пишется и читается** (RED-04). Результат: список мёртвых переменных.
- [ ] **Найди самые длинные серии без кнопки** (P-10). Результат: топ-5 узлов с длиной серии. Всё выше порога RED-03 — на правку.
- [ ] **Посмотри на финалы: какие переменные их выбирают и где игрок узнаёт о цене каждой** (RED-11, RED-12). Результат: для каждого условия финала — узел, где цена была намечена в тексте.
- [ ] **Проверь паузы ≥ 5 мин на крошки** (GREEN-03). Результат: список пауз без цели.
- [ ] **Проверь переходы между главами** (RED-10). Результат: нет `->` в середину чужой главы.
- [ ] **Прогони хабы во всех порядках и найди серии пауз без выбора** (RED-13, RED-14). Результат: список отсылок вне условия и мест, где история идёт сама.
- [ ] **Прочти шутки отдельным списком** (P-13–P-15). Результат: у каждой шутки автор из строки `// юмор:`, нет RED-07, RED-08.
- [ ] **Сверь `// застрянут:` с картой: на каждом таком месте есть крошка или воронка** (P-12). Результат: ни одно предсказанное место застревания не оставлено без помощи.

## 4. Как тестировать

Бейтман советует проверять идеи на других людях, а не на собственном вкусе ([S3]). Авторы главы о юморе — собирать отзывы поэтапно ([S1]). Отсюда два вида проверки.

**Бот и карта (каждая правка):**
- [ ] `npm run check:story` — нет тупиков и недостижимых узлов. Результат: зелёный прогон.
- [ ] Прогнать автопроверки из раздела 2 в `for-relayer.md`. Результат: список предупреждений с узлами. Каждое — исправлено или помечено «сознательно».
- [ ] На карте сравнить доли прохождений веток одной развилки. Результат: ни одна ветка не набирает меньше 5% прогонов, если только она не задумана как редкая.

**Люди (после каждой главы, а не в конце):**
- [ ] Дать главу человеку, который историю не читал, с `?fresh=1`. Результат: он играет без подсказок автора.
- [ ] Не объяснять ничего во время игры. Записывать, где он остановился, перечитал или спросил. Результат: список мест с временем.
- [ ] После главы задать три вопроса: «что сейчас происходит?», «чего ты ждёшь дальше?», «какой выбор был важным?». Результат: ответы против `// застрянут:` и `// развилка:`.
- [ ] Сравнить. Если человек не может назвать цель — нет крошки (P-05). Если не может назвать важный выбор — развилка не отличается от окраски (P-09). Если пересказывает сюжет неверно — проверить RED-01. Результат: правки с привязкой к узлам.
- [ ] Шутки проверить отдельно до того, как писать следующую главу (P-15): человек отмечает реплики, на которых улыбнулся, и реплики, которые принял за подсказку. Результат: шутки без отметки «смешно» убраны или переписаны. Шутки, принятые за подсказку, уведены из сцены загадки.
