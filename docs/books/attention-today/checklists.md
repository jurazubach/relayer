# Чек-листы — внимание сегодняшнего игрока

Пороги — наша оценка, обоснование в `principles.md`.

## Как начать историю

- [ ] Запиши первую ставку одной строкой, без имён собственных: «у человека пропал брат, и ты последний, кому он писал». → Есть вопрос, понятный без контекста.
- [ ] Выбери одного персонажа, который пишет первым. Остальных пока не вводи. → В шапке может быть 10 контактов, но в первой сцене говорит один.
- [ ] Поставь первую кнопку не позже 5–7-го входящего сообщения и меньше минуты суммарного `#delay`. → Бот подтверждает (проверка A5 в `for-relayer.md`).
- [ ] Посчитай новые имена и места в первой сцене. → Не больше 3; если больше — лишние перенеси в следующие сессии (`PAT-03`).
- [ ] Если игроку нужен список людей, дай кнопку `#to:notes` со списком. → Список хранится в заметках, а не в голове (`PAT-02`).
- [ ] Закончи первую сессию крючком перед первой длинной паузой. → Последняя реплика — вопрос или факт, не «ок, позже».

## Как написать главу или сцену

- [ ] Разбей главу на сессии между длинными паузами. → У каждой 10–40 сообщений и хотя бы одна кнопка (`P-08`).
- [ ] Проверь серии. → Ни одной длиннее 15 входящих без кнопки; длинный монолог разрезан по `PAT-04`.
- [ ] Перепиши первую реплику после каждой паузы от 2h. → В ней есть деталь из крючка (`PAT-01`).
- [ ] Пройди сцену и выпиши новые сущности. → Не больше 3 за сцену и 2 за реплику; у каждого человека одна форма имени (`P-04`).
- [ ] Отметь все реплики с давлением. → Не больше 2 на главу, каждая обеспечена событием (`P-11`).
- [ ] Проверь, где стоят паузы. → Ни одна не стоит посреди перечисления или инструкции (`P-13`).
- [ ] Убери пустые пинги. → Нет цепочек «ещё жду» / «тихо» с часовыми паузами (`PAT-07`).

## Как провести ревью готового сценария

- [ ] Запусти `npm run check:story` (с проверками A1–A11, когда появятся). → Список узлов с превышениями.
- [ ] Для каждой кнопки прочитай только три сообщения над ней. → Понятно, о чём выбор; непонятные отмечены `RED-04`.
- [ ] Выведи пары «крючок / первая реплика после паузы ≥2h». → Вторая подхватывает первую; пустые возвраты отмечены.
- [ ] Выпиши первые реплики после всех пауз ≥ 30m подряд. → Ни одна формула не повторяется больше двух раз (`LESSON-07`, A9).
- [ ] Для каждой паузы ≥ 30m посчитай пачку до кнопки. → Не больше 6 сообщений; длинная хроника стянута в сводку (`PAT-08`, A11).
- [ ] Составь таблицу имён: человек → все формы имени → где каждая появилась впервые. → Нет второй формы без связки (`RED-06`).
- [ ] Найди все `#silent` и все паузы с угрозой. → Если после соседних вариантов история продолжается, то и после молчания есть хотя бы одна кнопка до `END`; тот, кто не зашёл, получает историю не хуже того, кто отказался осознанно (`RED-07`, `LESSON-11`, С-4).
- [ ] Найди длинные серии реакций без факта. → Разрывы больше 5 реплик сокращены (`P-12`).
- [ ] Проверь «упрощения». → Ни одна правка не удалила улику или мотив (`RED-10`).

## Как тестировать

- [ ] Пройди историю с `?fast=1`, но делай перерыв на 2–5 минут на каждой длинной паузе. → После каждого перерыва продолжаешь без прокрутки вверх.
- [ ] Дай тестеру пройти первую главу на телефоне стоя, в дороге или под телевизор, а не за столом. → Отмечены сообщения, которые он перечитал или где переспросил «кто это?»; на улице непрерывный взгляд на экран втрое короче, чем за столом (`LESSON-03`).
- [ ] Вернись в историю после настоящей паузы в 1–3 часа, сделав за это время два других дела. → По первой непрочитанной реплике ясно, о чём речь (`LESSON-04`, `P-06`).
- [ ] После первой главы спроси у тестера, кого он помнит по именам. → Названы все, кто важен для следующей главы; забытые — кандидаты на `PAT-02` или на перенос.
- [ ] Посчитай уведомления за реальное прохождение. → Каждое привело к кнопке или новому факту; пустые записаны в `RED-05`.
- [ ] Попробуй промолчать на каждой кнопке с `#silent`. → Ни одно молчание не закрывает историю сразу.
