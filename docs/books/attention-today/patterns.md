# Приёмы — внимание сегодняшнего игрока

Все примеры на ink проверены компилятором inkjs. Термины «сессия», «серия», «длинная пауза» — как в `principles.md`.

---

### PAT-01. Возврат с якорем (resumption cue, подсказка для возобновления)
- **Когда применять:** после каждой паузы от 2 часов и после ночной паузы. **Когда нет:** после пауз до 10 минут — игрок ещё помнит, повтор раздражает.
- **Схема:** крючок с конкретикой → `#delay:2h+` → первая реплика повторяет одну деталь крючка и добавляет новую → кнопка в первых 3 сообщениях.
- **На ink:**
  ```ink
  # contact: mira, Мира, teal
  VAR asked = false
  мне надо проверить одну вещь #from:mira
  вернусь, когда стемнеет
  * [Только не одна #to:mira]
      ~ asked = true
  * [Жду #to:mira]
  - я у гаража. ключ под ведром, как ты сказал #from:mira #delay:3h
  {asked: и я не одна, с Томом}
  * [Открывай #to:mira]
      открыла. тут пусто #from:mira #delay:20s
  * [Подожди, сначала посмотри вокруг #to:mira]
      машина у ворот. без номеров #from:mira #delay:20s
  - -> END
  ```
- **Цена:** 0–1 лишняя реплика на паузу, деталь вплетается в реплику, которая и так нужна.
- **Ловушки:** якорь в виде пересказа («напомню: вчера ты сказал…») ломает голос. Якорь должен быть действием персонажа «сейчас».
- **Источник:** [Mark] (дорогой возврат к задаче); приём — наш вывод, механизм — знание модели, уверенность: средняя.

### PAT-02. Заметки как внешняя память
- **Когда применять:** персонаж даёт игроку больше двух фактов, которые понадобятся через паузу. **Когда нет:** для фактов, которые нужны в этой же сессии: запись становится лишним кликом.
- **Схема:** факт → кнопка `#to:notes` с `#label` (вторая кнопка — обычный ответ) → следующий факт → … → позже кнопка опирается на записанное.
- **На ink:**
  ```ink
  # contact: ellie, Элли, amber
  # contact: notes, Заметки, green
  VAR saved = 0
  у меня три имени #from:ellie
  Коннор работал в баре ту ночь #delay:5s
  * [Коннор — бар, та ночь #to:notes #label:Записать в заметки]
      ~ saved += 1
  * [Ок #to:ellie]
  - Джесс видела ссору #from:ellie #delay:8s
  * [Джесс — видела ссору #to:notes #label:Записать в заметки]
      ~ saved += 1
  * [Дальше #to:ellie]
  - третью назову завтра #from:ellie
  -> END
  ```
- **Цена:** одна кнопка на факт и одна переменная, если запись потом проверяется.
- **Ловушки:** заметка, которую потом нигде не используют, — пустой клик. Если записанное не открывает ни реплики, ни кнопки, запись не нужна.
- **Источник:** [Cowan10] (внешние опоры снимают нагрузку с рабочей памяти); приём в нашем движке уже используется в `ch1_terms` и `ch6_story`.

### PAT-03. Одно новое лицо за раз (staggered introduction, ступенчатое знакомство)
- **Когда применять:** в начале истории и главы, когда надо ввести несколько людей. **Когда нет:** в сцене, где хаос и есть смысл (паника, групповой чат), но и тогда игрок работает с одним-двумя.
- **Схема:** человек 1 + его ставка → кнопка → человек 2 появляется через действие человека 1 (`#unlock`) → кнопка в новом чате.
- **На ink:**
  ```ink
  # contact: dina, Дина, pink
  # contact: rex, Неизвестный номер, grey
  это Дина. мне дали твой номер #from:dina
  у меня пропал брат #delay:4s
  * [Кто дал номер? #to:dina]
      неважно. важно, что ты ответил #from:dina
  * [Что случилось? #to:dina]
      вчера ушёл и не вернулся #from:dina
  - он писал кому-то ночью #from:dina #delay:6s
  номер без имени. сейчас скину тебе #unlock:rex
  * [Скидывай #to:dina]
  - кто это? #from:rex #delay:2m
  * [Друг Дины #to:rex]
  * [Промолчать #to:rex #silent]
  - -> END
  ```
- **Цена:** вступление растягивается на 1–2 сессии. Компенсация — первая кнопка приходит раньше (`P-07`).
- **Ловушки:** «Неизвестный номер» — тоже сущность. Не открывай два безымянных контакта в одной сцене.
- **Источник:** [Cowan10]; приём — наш вывод.

### PAT-04. Монолог, разрезанный вопросами
- **Когда применять:** развязка, признание, пересказ события, где персонаж должен выдать много фактов. **Когда нет:** короткий ответ до 5 реплик.
- **Схема:** 1–2 факта → кнопка (часто только меняет реплику, ветки сразу сходятся) → 1–2 факта → кнопка → … Длинные паузы — только между блоками, после кнопки.
- **На ink:**
  ```ink
  # contact: judith, Джудит, teal
  VAR asked_why = false
  она всё рассказала #from:judith #delay:40m
  * [Что именно? #to:judith]
  * [Подождите. Вы в порядке? #to:judith]
      нет. но это потом #from:judith
  - она спустилась к Лили на уступ #from:judith #delay:30s
  * [И? #to:judith]
  * [Не надо подробностей #to:judith]
      надо. иначе вы не поверите #from:judith
  - Лили сорвалась. а она ушла с её телефоном #from:judith #delay:20s
  * [Почему никого не позвала? #to:judith]
      ~ asked_why = true
      испугалась. так она говорит #from:judith
  * [Промолчать #to:judith #silent]
  - полицию я вызвала сама #from:judith #delay:1h
  -> END
  ```
- **Цена:** 2–4 кнопки на монолог и по реплике-реакции на каждую. Новых веток нет.
- **Ловушки:** кнопка «Дальше» без смысла — та же пассивность. Каждый вариант должен звучать как реальная реплика игрока с разным тоном.
- **Источник:** [Pielot14], [Mehrotra16] (уведомление без действия мешает); приём — наш вывод.

### PAT-05. Честный дедлайн
- **Когда применять:** нужна срочность. **Когда нет:** если исход не зависит от того, что игрок выбрал, — тогда это ложная угроза (`P-11`).
- **Схема:** событие с временем в мире («в шесть меняют замок») → выбор «иду / не иду / молчу» → мир идёт дальше в любом случае → отказ стоит части улик, но история продолжается.
- **На ink:**
  ```ink
  # contact: tom, Том, cyan
  VAR waited = false
  в шесть они меняют замок #from:tom
  после этого внутрь не попасть
  * [Иду сейчас #to:tom]
      -> go
  * [Не могу. Справишься сам? #to:tom]
      ~ waited = true
      -> alone
  * [Промолчать #to:tom #silent]
      ~ waited = true
      -> alone
  === go ===
  жду у ворот #from:tom #delay:15m
  -> END
  === alone ===
  ладно. пойду один #from:tom #delay:40m
  я внутри. фоткаю всё, что успею #delay:30s
  * [Что нашёл? #to:tom]
  - папку. одну. остальное вывезли #from:tom #delay:2m
  -> END
  ```
- **Цена:** две ветки на 3–6 реплик и одна переменная.
- **Ловушки:** дедлайн в реальном времени игрока («ответь за 10 минут») движок не умеет: кнопка ждёт вечно. Срок всегда сюжетный и решается выбором, а не скоростью.
- **Источник:** [Zagal13] (игра по расписанию как тёмный паттерн, по пересказу); приём — наш вывод.

### PAT-06. Микросессия
- **Когда применять:** короткий заход между длинными паузами, например персонаж «на минутку». **Когда нет:** в кульминации, где нужна длинная сессия.
- **Схема:** вопрос персонажа → кнопка в 1–2 сообщениях → один факт → кнопка с оценкой → крючок или пауза. 4–8 входящих, 2 кнопки, меньше минуты чтения.
- **На ink:**
  ```ink
  # contact: lena, Лена, purple
  VAR mood = 0
  ты прочитал? #from:lena #delay:30s
  * [Да. Это правда она? #to:lena]
      ~ mood += 1
  * [Пока нет #to:lena]
      читай. я подожду #from:lena #delay:2m
  - она. фото с камеры у аптеки #from:lena
  в 02:10 #delay:5s
  * [Время совпадает #to:lena]
      вот и я о том #from:lena
  * [Это ничего не доказывает #to:lena]
      ~ mood -= 1
      одно — нет. два — уже да #from:lena
  - -> END
  ```
- **Цена:** почти бесплатно, это нормальная единица текста.
- **Ловушки:** микросессия без нового факта — «как дела?» ради уведомления. Это `RED-05`.
- **Источник:** [Ferreira14] (короткие заходы в приложение), [Mark]; размер — наша оценка.

### PAT-07. Тишина вместо уведомления
- **Когда применять:** персонажу нечего сказать, но время в сюжете должно пройти. **Когда нет:** если пауза нужна как событие («он не отвечает 14 минут»), это крючок, а не пустота.
- **Схема:** вместо цепочки `#delay:1h` с репликами «ещё жду», «ничего нового» — одна длинная пауза до следующего настоящего события.
- **На ink:** до правки было `пока тихо #delay:1h` / `всё ещё тихо #delay:1h` / `он вышел! #delay:1h`. После — одна пауза до события:
  ```ink
  # contact: tom, Том, cyan
  я на месте. жду, когда он выйдет #from:tom
  * [Не высовывайся #to:tom]
  * [Сфоткай машину #to:tom]
  - он вышел. только что #from:tom #delay:3h
  сел в серую машину. номер заклеен #delay:6s
  * [Езжай за ним #to:tom]
  * [Уходи оттуда #to:tom]
  - -> END
  ```
- **Цена:** отрицательная — текста становится меньше.
- **Ловушки:** «держать игрока на связи» пустыми пингами — это и есть манипуляция вниманием.
- **Источник:** [Pielot14], [Pielot17]; приём — наш вывод.

### PAT-08. Сводка вместо капельницы (digest)
- **Когда применять:** после развязки или большого события нужно показать несколько последствий: кто что сделал, что стало с людьми. **Когда нет:** если каждое последствие — отдельный крючок с выбором; тогда это отдельные сессии с кнопками.
- **Схема:** вместо 4–5 сообщений с часовыми паузами — одна пауза → сводка в 3–6 репликах одним заходом → кнопка-реакция → финальная реплика. Игрок всё равно прочитал бы капельницу одной стеной (непрочитанные копятся, см. `attention.md`), но получил бы 5 уведомлений вместо одного.
- **На ink:**
  ```ink
  # contact: ellie, Элли, amber
  VAR calm = false
  прошла неделя. рассказываю всё сразу #from:ellie #delay:2h
  Оуэн дал показания. сам пришёл #delay:6s
  Джесс уехала к тёте. пишет редко #delay:5s
  дело открыли заново #delay:5s
  * [Ты как? #to:ellie]
      ~ calm = true
      нормально. впервые сплю #from:ellie
  * [А Харт? #to:ellie]
      молчит. но его вызвали #from:ellie
  - спасибо, что ответил тогда на объявление #from:ellie #delay:10s
  -> END
  ```
- **Цена:** отрицательная по уведомлениям, нулевая по тексту: те же факты, другая нарезка.
- **Ловушки:** сводка без кнопки — та же капельница, только короче. Хотя бы одна реакция игрока внутри.
- **Источник:** `LESSON-06` (LinkedIn склеил письма — жалоб вдвое меньше), `LESSON-05`; приём — наш вывод.

## Нюансы к приёмам

| | когда не работает | 5 сообщений против 50 |
|---|---|---|
| PAT-01 | Якорь, который повторяет одно и то же слово после каждой паузы, приедается (`LESSON-07`). Чередуй, что повторяется: место, предмет, вопрос. | В микросессии якорь — одно слово в первой реплике. В длинной главе — первая реплика каждой сессии. |
| PAT-02 | Заметки, которые игрок обязан записать, иначе проиграет, — уже экзамен, а не опора. Запись помогает, но не проверяется как условие финала без второго пути. | На 5 сообщениях не нужен. |
| PAT-03 | Если сюжет держится на том, что игрок не знает, кто пишет, «Неизвестный номер» допустим, но один на сцену. | На 5 — одно лицо. На 50 — новое лицо раз в сессию. |
| PAT-04 | Кнопки-реакции, где все варианты отличаются только пунктуацией, — та же «Дальше» (`inkle-ingold:P-07`). | На 5 не нужен. На 50 — кнопка каждые 8–12 сообщений признания. |
| PAT-05 | Если отказ стоит слишком мало, дедлайн не ощущается. Если слишком много — это уже наказание. Мера: отказ закрывает одну улику, но не путь к финалу. | — |
| PAT-06 | Подряд три микросессии с паузами по часу — капельница (`RED-05`). Склей в одну (`chat-fiction-apps:P-01`). | Микросессия и есть 5–8 сообщений. |
| PAT-07 | Если игрок ждёт ответа на свой вопрос, полная тишина сутки — обрыв нити. Одна реплика-обещание («узнаю к вечеру») перед паузой. | — |
| PAT-08 | Если последствия — главное удовольствие финала, сводку можно разбить на 2 сессии, но не на 5. | — |
