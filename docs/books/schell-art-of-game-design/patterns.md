# Приёмы и структуры

Каждый пример ink самодостаточен и проверен компиляцией inkjs. Ссылки на источники — в `README.md`.

---

### PAT-01. Кривая интереса по данным бота (interest curve, наша адаптация)
- **Когда применять:** ревью готового сценария, сравнение версий главы. **Когда нет:** до первого черновика — там кривую рисуют от руки по плану сцен.
- **Схема:**
  1. Бот проходит историю 300–400 раз, на каждом сообщении пишет: номер, узел, `#delay`, был ли выбор, расходятся ли кнопки, теги раскрытия.
  2. Ось X — номер сообщения внутри главы; паузы `#delay` ≥ 1 ч рисуются разрывом: это граница сеанса (P-05).
  3. Окно — 5 сообщений. Очки окна (наша эвристика, у Шелла её нет):
     `+3` раскрытие (`#photo`, `#rename`, `#unlock`, первое сообщение нового контакта);
     `+2` кнопки ведут в разные узлы; `+1` кнопки только меняют реплику или переменную;
     `+2` сообщение после паузы ≥ 1 ч — вопрос (`?`) или содержит цифру;
     `−1` за каждое сообщение сверх 12 подряд без кнопки;
     `−1` если средняя длина сообщений окна > 100 знаков (стена текста, P-19).
  4. Провал — окно, которое ниже обоих соседних пиков на 3+ очка.
  5. Фрактальная проверка (P-05): в каждом сеансе максимум очков приходится на его последнюю треть; в каждой главе максимум — во второй половине; по главам пики не падают к концу.
  6. Сверяем с формой из книги: вход, крючок, растущие пики с провалами, высший пик в конце, короткий спад.
  ```
  интерес
    ^                    ■ кульминация
    |   ■ крючок   ■    / \
    |  / \    ■   / \  /   \
    | /   \  / \ /   \/     ■ развязка
    |■     ■/   ■
    +-------------------------> сообщения / сеансы
     вход   провалы и растущие пики
  ```
- **На ink:** размечай сцены, чтобы бот подписывал точки графика узлами:
  ```ink
  # contact: ellie, Элли, amber
  -> ch1
  === ch1 ===
  ты же не из девона? #from:ellie #chapter
  * [Нет #to:ellie]
  * [А что? #to:ellie]
  - -> ch1_hook
  === ch1_hook ===
  Скрин: «Lily 💧» в списке серая #from:ellie #photo #delay:20s
  * [Кто это? #to:ellie]
      -> END
  * [Промолчать #to:ellie #silent]
      -> END
  ```
- **Цена:** ~100–150 строк в `check-story.mjs`, текст сценария не меняется.
- **Ловушки:** очки — заменитель интереса, а не интерес. Сцена горя без кнопок может быть пиком при нуле очков; такие места помечай `// peak` и не «чини».
- **Источник:** форма кривой — [notesbylex], [gamedeveloper], знание модели (уверенность: высокая); очки — наше.

### PAT-02. Нитка жемчуга (string of pearls)
- **Когда применять:** истории с главами, где сюжет по сути один, а свобода — внутри главы. Это наш фактический формат. **Когда нет:** история-песочница, где порядок событий решает игрок.
- **Схема:**
  ```
  [глава 1: хаб, 3–6 разговоров] → горлышко → [глава 2: …] → горлышко → …
       свобода внутри             один узел            свобода внутри
  ```
  Внутри «жемчужины» игрок выбирает порядок, тон и с кем говорить; нить — обязательное событие, которое двигает всех дальше.
- **На ink:**
  ```ink
  # contact: ellie, Элли, amber
  # contact: jess, Джесс, pink
  # contact: connor, Коннор, orange
  VAR talked = 0
  -> hub
  === hub ===
  * [Привет, это опрос #to:jess]
      омг да!! #from:jess #delay:1m
      ~ talked += 1
      -> hub
  * [Привет, это опрос #to:connor]
      кто это? #from:connor #delay:3m
      ~ talked += 1
      -> hub
  * {talked >= 1} [Подождать Элли #to:ellie #silent]
      -> pearl_end
  === pearl_end ===
  они знают что это я #from:ellie #delay:8h
  -> END
  ```
- **Цена:** дешевле настоящих ветвей: текст растёт линейно от числа разговоров.
- **Ловушки:** если внутри жемчужины всё сходится сразу и ничего не запоминается, свобода фальшивая — см. RED-09. Горлышко должно быть событием (пост, угроза), а не «прошло время».
- **Источник:** знание модели (Шелл описывает этот способ соединить историю и игру), уверенность: высокая.

### PAT-03. Крючок перед паузой, крючок в уведомлении
- **Когда применять:** перед каждым `#delay` от 30 мин. **Когда нет:** паузы «печатает» внутри разговора (секунды).
- **Схема:** `[пик сеанса] → #delay:Nh → [первое сообщение = новый вопрос] → [подробности]`. Первое сообщение после паузы — это текст уведомления на экране игрока, оно решает, вернётся ли он.
- **На ink:**
  ```ink
  # contact: ellie, Элли, amber
  # contact: unknown, Неизвестный номер, grey
  -> night
  === night ===
  мама пришла. напишу через пару часов #from:ellie
  Элли не в сети #sys:ellie
  Вы не студент. #from:unknown #delay:7h
  Прекратите писать людям о Лилиан.
  * [Кто это? #to:unknown]
      Прочитано #sys:unknown #delay:1m
  * [Заблокировать #to:unknown #silent #label:Заблокировать номер]
      Номер заблокирован #sys:unknown
  - -> END
  ```
- **Цена:** почти ноль: переставить строки так, чтобы событие шло первым, приветствие — вторым.
- **Ловушки:** «Здравствуйте.», «ладно», «ты тут?» после многочасовой паузы — пустое уведомление. Не путать с намеренным холодом: короткое «ок» может быть событием, если до паузы игрок ждал развёрнутого ответа.
- **Источник:** фрактальность кривой — [слайды]; применение к уведомлениям — наше.

### PAT-04. Лестница пиков с передышками
- **Когда применять:** внутри главы на 30+ сообщений. **Когда нет:** короткая глава-кульминация, где передышка снимет напряжение.
- **Схема:** `пик 1 (малое раскрытие) → передышка (быт, юмор) → пик 2 (раскрытие больше) → передышка → пик 3 (меняет положение игрока)`.
- **На ink:**
  ```ink
  # contact: jess, Джесс, pink
  # contact: ellie, Элли, amber
  -> scene
  === scene ===
  лили в ту ночь ругалась с элли #from:jess #delay:30s
  * [Из-за чего? #to:jess]
      не знаю. но громко #from:jess #delay:20s
  * [Промолчать #to:jess #silent]
  - кстати у нас гонка в субботу #from:jess #delay:2m
  придёшь болеть? 🙂
  * [Может быть #to:jess]
  - элли сказала, что ушла домой в полпервого #from:jess #delay:40m
  а я видела её у воды в час
  * [Ты уверена? #to:jess]
      да. я тогда ещё фоткала #from:jess #delay:1m
      -> END
  * [Никому не говори #to:jess]
      -> END
  ```
- **Цена:** передышка — 2–4 сообщения; удлиняет главу на 10–15 %.
- **Ловушки:** передышка без связи с миром (случайная болтовня) — вода. Пусть она добавляет деталь, которая сыграет позже (гонка — алиби).
- **Источник:** [notesbylex], знание модели (чередование напряжения и отдыха), уверенность: высокая.

### PAT-05. Треугольный выбор (triangularity)
- **Когда применять:** ключевые развилки главы. **Когда нет:** бытовые ответы — там риск выглядит надуманным.
- **Схема:** `безопасно, мало пользы` / `рискованно, много пользы` / `молчать`. Текст до кнопок называет цену риска.
- **На ink:**
  ```ink
  # contact: connor, Коннор, orange
  VAR connor_blocked = false
  VAR knows_time = false
  -> ask
  === ask ===
  ну и что тебе надо #from:connor #delay:30s
  я злой когда меня спрашивают про ту ночь
  * [Просто опрос. Пять вопросов #to:connor]
      ну ок. все набухались. всё #from:connor #delay:20s
  * [Во сколько Лили ушла к воде? #to:connor #label:Спросить прямо]
      {RANDOM(0, 1):
          - 0: ~ connor_blocked = true
               Сообщение не доставлено #sys:connor #delay:1m
          - 1: ~ knows_time = true
               в пол первого. с элли #from:connor #delay:1m
      }
  * [Промолчать #to:connor #silent]
  - -> END
  ```
- **Цена:** одна переменная риска на развилку и ветка последствия на 2–5 сообщений.
- **Ловушки:** `RANDOM` в нашем жанре читается как нечестность, если игрок не видел признаков; лучше зависеть от прежних переменных (`connor_trust`). Здесь он ради краткости.
- **Источник:** знание модели (Lens of Triangularity), уверенность: высокая; [notesbylex] (рисковые варианты).

### PAT-06. Сговор персонажа (collusion)
- **Когда применять:** нужно, чтобы игрок скорее всего пошёл в определённую ветку, но мог и не пойти. **Когда нет:** выбор должен быть по-настоящему открытым (финал).
- **Схема:** персонаж желает одного варианта и объясняет почему; кнопка-альтернатива остаётся, но её цена названа.
- **На ink:**
  ```ink
  # contact: ellie, Элли, amber
  # contact: owen, Оуэн Брайт, blue
  -> brief
  === brief ===
  оуэну НЕ пиши #from:ellie
  он организатор. просто не надо
  * [Ок. Начну с остальных #to:ellie]
      спасибо #from:ellie #delay:10s
  * [Привет! Я делаю опрос #to:owen #label:Написать Оуэну, хотя просили не писать]
      Привет! Конечно помогу 🙂 #from:owen #delay:40s
  - -> END
  ```
- **Цена:** одна-две реплики на развилку.
- **Ловушки:** если ветку «против совета» не наградить ничем интересным, игрок выучит, что советы — стены. Запретный путь должен давать информацию.
- **Источник:** знание модели (collusion — персонажи как способ косвенного управления), уверенность: высокая; [Kill Screen] (линейный опыт, в котором игрок думает, что всё решает сам).

### PAT-07. Короткая развязка (resolution)
- **Когда применять:** после финальной кнопки. **Когда нет:** у истории есть продолжение — тогда вместо развязки крючок следующего сезона.
- **Схема:** `решающая кнопка → 1–2 реакции адресата → одно «итоговое» сообщение пачкой → последняя реплика-эмоция → END`. Суммарно ≤ 10 сообщений, ≤ 15 мин `#delay` (`messenger-genre:P-16`).
- **На ink:**
  ```ink
  # contact: judith, Джудит Марш, teal
  # contact: ellie, Элли, amber
  -> door
  === door ===
  Она у двери. #from:judith #delay:40s
  * [Откройте. Вот всё, что у меня есть #to:judith #label:Отдать всю правду]
  - Открываю. #from:judith #delay:3m
  Она рассказала всё. #delay:2m
  Я позвонила в полицию сама. #delay:1m
  Три недели спустя #sys:judith
  Обвинение предъявлено. Дело Денни открыто заново. #from:judith
  джудит прислала мне её последние сообщения #from:ellie #delay:1m
  она не злилась
  -> END
  ```
- **Цена:** экономит текст: эпилоги второстепенных героев сводятся в одно сообщение.
- **Ловушки:** обрубить развязку совсем — игрок не почувствует, что его ход что-то изменил. Одна реплика того, кому было больнее всех, обязательна.
- **Источник:** [gamedeveloper] (быстрый конец после последнего пика); знание модели, уверенность: высокая.

### PAT-08. Приближение дистанции (them → you → me)
- **Когда применять:** план всей истории и каждой главы. **Когда нет:** намеренно отстранённые эпизоды (документ, архив) — но и там их конец должен касаться игрока.
- **Схема:** `событие с чужими → событие с близким игроку персонажем → событие, адресованное самому игроку`.
- **На ink:**
  ```ink
  # contact: ellie, Элли, amber
  # contact: unknown, Неизвестный номер, grey
  -> arc
  === arc ===
  в карьере нашли девушку #from:ellie
  это была моя лучшая подруга #delay:20s
  * [Мне жаль #to:ellie]
  - Это ведь ты задаёшь людям вопросы? #from:unknown #delay:6h #unlock:unknown
  * [Кто это? #to:unknown]
  * [Промолчать #to:unknown #silent]
  - -> END
  ```
- **Цена:** нулевая по объёму; требует продумать, кто знает об игроке.
- **Ловушки:** обращение к игроку без причины («я знаю, где ты живёшь» от случайного NPC) ломает доверие к миру. У персонажа должен быть способ узнать.
- **Источник:** [слайды] (слайд 48, шкала Them / You / Me); схема «от чужих к игроку» в главе — наше применение.

### PAT-09. Удивление формой
- **Когда применять:** раз в главу, в точке, где содержание предсказуемо. **Когда нет:** чаще двух раз в главе — приём превращается в шум.
- **Схема:** поменять канал или служебное состояние вместо реплики: `#sys`-строка, `#rename`, `#unlock` неожиданного контакта, банковский перевод, заметки игрока.
- **На ink:**
  ```ink
  # contact: lily, +44 7700 900521, pink
  # contact: ellie, Элли, amber
  -> twist
  === twist ===
  телефон лили утонул в июне #from:ellie
  его так и не нашли
  я не злюсь #from:lily #delay:3h #unlock:lily
  * [Кто это? #to:lily]
      #rename:lily, Lily 💧
      Прочитано #sys:lily #delay:1m
  * [Элли, мне написали с её номера #to:ellie]
      что #from:ellie #delay:10s
  - -> END
  ```
- **Цена:** одна-две строки; зато требует, чтобы движок умел показать приём (`#photo` пока `partial`).
- **Ловушки:** удивление, которое потом не объяснено, читается как баг движка. В той же или следующей главе нужна разгадка.
- **Источник:** знание модели (Lens of Surprise, poetry of presentation), уверенность: высокая; перенос на теги — наш.

### PAT-10. Видимый счёт перед скрытой проверкой
- **Когда применять:** финал выбирает условие по нескольким переменным. **Когда нет:** финал прямо определяется последней кнопкой.
- **Схема:** `сбор улик по главам → перед решающей кнопкой персонаж перечисляет, что есть и чего нет → кнопка → проверка`. Игрок решает, зная ставки.
- **На ink:**
  ```ink
  # contact: judith, Джудит Марш, teal
  VAR bill_found = true
  VAR ladder_known = false
  -> ledger
  === ledger ===
  Что у Вас есть? #from:judith
  {bill_found:Счёт за июнь — у меня.}
  {ladder_known:Про лестницу я знаю.|Про лестницу мне никто не говорил.} #delay:30s
  * [Этого хватит. Откройте ей #to:judith #label:Отдать всё]
      {bill_found && ladder_known:Хватит. #from:judith|Мало. Но я попробую. #from:judith}
  * [Подождите. Не открывайте #to:judith #silent]
  - -> END
  ```
- **Цена:** 2–4 строки с условиями на каждую ключевую переменную.
- **Ловушки:** перечисление списком читается как интерфейс. Пусть персонаж говорит своим голосом и сомневается.
- **Источник:** наше следствие из линз значимого выбора и обратной связи (знание модели, уверенность: средняя), см. P-18.

### PAT-11. Возврат с напоминанием (второй проход: Lifeline, Bowman, LESSON-01/02/09)
- **Когда применять:** первая реплика после `#delay` ≥ 2 ч и начало каждой главы. **Когда нет:** пауза < 1 ч, игрок не уходил; там напоминание — повтор.
- **Схема:**
  ```
  [крючок сеанса] → #delay ≥ 2h → [ставка + след выбора игрока] → [новый факт] → кнопка (≤ 6 сообщ.)
  ```
  Первая строка — то, что видно в уведомлении: ставка или след прошлой кнопки, а не приветствие.
- **На ink:**
  ```ink
  # contact: ellie, Элли, amber
  VAR told_truth = false
  VAR wrote_owen = false
  -> ch2_end
  === ch2_end ===
  мне пора. но тот номер снова звонил #from:ellie
  * [Кто это? #to:ellie]
  * [Не бери трубку #to:ellie]
  - -> ch3_start
  === ch3_start ===
  {told_truth: ты сказал мне правду. оуэну — нет|ты так и не сказал, кто ты}. {wrote_owen: а он теперь знает твой номер|а он про тебя пока не знает} #from:ellie #delay:8h
  слушание завтра. он хочет встретиться #from:ellie #delay:20s
  * [Пойду с тобой #to:ellie]
      ~ told_truth = true
      -> END
  * [Не ходи #to:ellie]
      -> END
  ```
- **Цена:** одна строка с условием `{var: …|…}` на паузу. Переменные, которые раньше читала только проверка финала, начинают звучать в тексте (P-09, RED-10).
- **Ловушки:** напоминание длиннее одной строки превращается в пересказ. Напоминание без нового факта — то же пустое уведомление (RED-02). Не стыдить игрока за паузу (`attention.md` §5).
- **Источник:** Lifeline — уведомление возвращает только решением (Game Developer, 2015); Bowman — пересказ и напоминания (MobileGamer.biz, 2023); схема и пороги — наши.

## Нюансы к паттернам (второй проход)

| PAT | не работает, когда | 5 сообщений / 50 сообщений |
|---|---|---|
| PAT-01 | сцена держится на чувстве без кнопок — ставь `// peak` | 5: не считать, хватит «+»/«−» глазами / 50: окна по 5 |
| PAT-02 | лучшая сцена лежит в редкой бусине (LESSON-03) | 5: одна бусина / 50: 2–3 бусины на ствол |
| PAT-03 | пауза короче часа: крючок перед ней тратится впустую | 5: последний удар = крючок / 50: на каждую паузу ≥ 1 ч |
| PAT-04 | как P-15 в `principles.md` | там же |
| PAT-05 | цены вариантов не видны — «слепой выбор» (критика Lifeline, IF50) | 5: цена одной фразой / 50: цена + отложенный отклик |
