## Что не нашлось
- Текст книги не открывали. Название третьего фактора (projection) и рисунок волны в канале потока не подтверждены.
- Опубликованных цифр отвала по главам у мобильных историй (Choices, Episode) нет: доклады GDC закрыты, анонсы без данных.
- Слайды Booth о темпе Left 4 Dead (PDF) не прочитались. Утверждение «без передышек игроки выгорали» есть только во вторичной выдаче, в уроке оно помечено.
- Исследование частоты уведомлений и отписок найдено только у вендоров (MoEngage), поэтому в пороги не взято.
- Ни у кого из практиков нет кривой интереса, построенной по данным. Метод PAT-01 по-прежнему наш.
