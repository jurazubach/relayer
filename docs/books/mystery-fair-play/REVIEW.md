## Что осталось под вопросом

- **Revelation list и структурные/фоновые откровения (PAT-07).** Найти первоисточник не удалось. Человеку: найти на thealexandrian.net статью о revelation lists; если разделения там нет, оставить его как наше соглашение и убрать упоминание Alexander из PAT-07.
- **Inverse Three Clue Rule.** Формулировка в README — по памяти модели. Проверить по частям 1–2 серии Node-Based Scenario Design.
- **Пороги** (0,4; 5 минут; 10/15 строк; 1,5×; 30–70%) нигде не обоснованы, кроме здравого смысла. После внедрения проверок в `check-story.mjs` прогнать на трёх историях и откалибровать: если порог срабатывает везде или нигде, он бесполезен.
- **Разметка в комментариях** (`// reveal:`, `// culprit:`, `// warn:`, `// anchor:`, `// risk:`): компилятор ink выбрасывает комментарии, так что скрипт должен читать их из исходника, а не из прогона. Проверки, которые сопоставляют комментарий со строкой во время прогона (RED-08, RED-07), опираются на эвристики. До реализации стоит решить, не заменить ли часть комментариев переменными: их бот видит в `variablesState` без разбора текста.
- **«Чужой голос».** В §4 о нём только вывод из готовых цифр пайплайна; узлы не разобраны. Для скилла `/clue-audit` стоит разобрать финальную проверку этой истории по P-12.

## Лучшее из источника для скиллов

- **P-06 + P-07 + P-08 / PAT-01:** три улики на вывод, в разных чатах, хотя бы одна на общем стволе; бот считает долю прогонов с ≥2 уликами к узлу разгадки. Это ядро проверки «каждая улика для финала достижима».
- **P-05 / PAT-02 / RED-02:** ворота дедукции — пауза, вопрос NPC, 2–3 версии одной длины, у неверной есть опровержение и цена. Главная починка «Слепого пятна» (§4.2) и кандидат для 126 «косметических» кнопок «Чужого голоса».
- **P-12 / RED-07:** скрытая проверка финала честна, только если у каждой её переменной перед кнопкой был намёк на риск. Прямо про наши финалы с невидимыми условиями.
- **PAT-06 / RED-08:** ссылки на улики в разгадке оборачивать в `{clue_x: …}` — «я же это видел» без ссылок на то, чего игрок в своей ветке не видел.
- **PAT-03 / P-09 / RED-05:** ложный след только с явным опровержением, достижимым из его ветки, и с посаженной заранее уликой «за».
- **PAT-07 + for-relayer §2:** разметка `clue_*` и `// reveal: … needs: … at:` — она делает честность загадки машинно проверяемой.
