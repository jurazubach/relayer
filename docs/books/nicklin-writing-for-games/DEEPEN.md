# Второй проход: что добавлено

## Новые файлы
- `lessons.md` — 10 уроков. Mutazione: середины вместо финалов, вырезанная механика. Saltsea: счётчики настроения заменены на Issues, форма приведена в согласие с темой, выбор подписан тоном, хаб-лодка выравнивает внимание. Lifeline: ветки сводятся, 90 000 слов при половине на прохождение, паузы с причиной, быстрый режим после гибели героя. Choices: платный лучший выбор. Nicklin: плохой текст — симптом процесса.
- `attention.md` — минимальные версии P-01…P-19, что резать для нашей аудитории, точки 30 с / 3 мин / глава 1, возвращение после паузы, таблица из 14 порогов нагрузки, тёмные паттерны.

## Углублено
- `principles.md`: устройство четырёх систем (форма → формат → формула; день Mutazione из семи шагов; регистры; голос «слушать → расшифровать → стилизовать → слепой тест»), с входом, выходом, последствием пропуска, ошибками понимания и короткими формами. Таблица нюансов к 14 принципам: когда правило не работает, 5 сообщений против 50.
- `patterns.md`: устройство Critical Response по элементам, три фазы рабочей тетради, нюансы к PAT-01…PAT-08.
- `for-relayer.md` §6: 11 согласий с другими разборами и 8 противоречий, у каждого решение для relayer.
