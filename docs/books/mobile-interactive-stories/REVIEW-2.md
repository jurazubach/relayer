## Лучшее из второго прохода для скиллов

- **LESSON-03 + `attention.md` §2.** Первый акт и первый выбор с последствием — до 5-й минуты реального времени. Бот считает медиану времени до первой развилки или записи в переменную.
- **LESSON-01 + SYS-3.** Считать 2^N комбинаций флагов на входе в финал, при N > 2 сводить к 2–3 состояниям мира. Бот выводит число разных наборов переменных перед финальным узлом.
- **SYS-1, «как неправильно понимают».** Держит крючок, а не ожидание. Пауза ≥ 1h без крючка или сюжетной причины читается как таймер энергии (`LESSON-10`, `RED-03`).
- **SYS-2, «ошибка переноса» + `for-relayer.md` §6, п. 2.** Условием прятать только бонус. Вариант, который спасает от плохого исхода, виден всем.
- **`attention.md` §3.** Таблица возвращения по длине паузы и правило «первая реплика после паузы — событие с деталью из крючка».
- **`attention.md` §5.** Уведомление только от настоящей строки сценария, срок, названный персонажем, выполняется. Готовые правила для генератора.
