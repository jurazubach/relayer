## Что осталось под вопросом

- **Доклад Cass Phillipps (GDC 2016).** Вывод «ветвление не повышает удержание, перепроходят мало» известен только из пересказа dfabulich. На нём стоят P-04 и §5 for-relayer. Человеку стоит посмотреть запись (GDC Vault или YouTube, 2019) и подтвердить или поправить формулировку.
- **Статья Do Own Kim (2023).** Цитата взята из Википедии, сама статья не открывалась. Если цитата нужна в скилле, сверить с оригиналом.
- **Длина главы Choices в 10–20 минут, еженедельный выпуск глав, серии по 2–3 книги, финалы трилогий по очкам.** Это знание модели, уверенность средняя. Проверить по фан-вики или интервью Pixelberry. Если подтверждений не будет, оставить пометку.
- **«Около 400 строк диалога на главу» у Episode.** Это комментарий читателя под JF о собеседовании, а не данные студии. Использовать только как порядок величины.
- **Все пороги** (120 строк на главу, 25 строк без кнопки, 30 с до первой кнопки, 10–60% показов условного варианта, 20% пауз без крючка) — наши стартовые значения, рынок их не даёт. Их стоит откалибровать по трём нашим историям, прежде чем вшивать в `check-story.mjs` как ошибки, а не предупреждения.
- **MG** — совет продуктового лида MAG Interactive для мобильных игр с сюжетом поверх основного цикла, а не для приложений историй. Переносить на нас осторожно.

## Лучшее из источника для скиллов

- **RED-01 + P-07 + разбор `ch10_maya`.** Не отменять нажатую кнопку скрытой проверкой, а прятать вариант условием. Это прямой перенос главной жалобы рынка на нашу механику, и его можно проверить автоматически.
- **P-04 + PAT-04.** Ветвиться экономно, копить последствия в 2–3 состояниях мира на границе глав. Подкреплено и PBR, и пересказом GDC.
- **P-05 + P-06 + RED-04/RED-05.** Своя реакция на каждую кнопку и отзвук переменной позже. Всё считается статически по ink.
- **P-02 + P-09 + RED-03.** Крючок в конце главы, длинная пауза только после крючка. Это самая ходовая проверка для формата с реальным временем.
- **P-12 + PAT-06.** Показывать игроку переменные, которые решат финал, через «Заметки», а не цифрами.
- **P-10 + RED-10.** Лёгкое начало: первая кнопка до 30 с, не больше 2–3 контактов в первой главе.
