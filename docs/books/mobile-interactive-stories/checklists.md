# Процедуры

Сокращения источников — в `README.md`. Каждая процедура опирается на принципы и флаги этой папки.

## Как придумать и начать историю

- [ ] Сформулировать жанровое обещание одной строкой для `tagline`: кто пишет игроку, что случилось, что будет, если не ответить. **Результат:** строка, по которой понятен жанр (детектив, триллер, романтика) до первой реплики: на рынке игрок выбирает жанр сам перед первой книгой (UD).
- [ ] Определить объём сезона: 5–10 глав (`P-01`; у Episode 10–20, JF). **Результат:** список глав с полями `title`, `when`, `about`.
- [ ] Разметить на весь сезон главную линию, точки поворота и крючок в конце каждой главы до того, как писать текст (JF, MG). **Результат:** таблица «глава → крючок → какой вопрос открыт → какой закрыт».
- [ ] Проверить таблицу: ни в одной главе, кроме последней, открытых вопросов не становится 0 (`P-03`).
- [ ] Выбрать 2–3 состояния мира и переменные, из которых они складываются (`P-04`, `PAT-04`). **Результат:** функция `sync_world()` и список переменных.
- [ ] Выбрать 2–4 финала. Для каждого записать, какое действие игрока к нему ведёт и какой персонаж назовёт это вслух (`P-13`).
- [ ] Написать первую минуту: первая кнопка ≤ 30s, 1–2 собеседника, ставка названа до первой развилки (`P-10`). **Результат:** 6–10 строк и первая развилка.

## Как написать главу

- [ ] Начать с паузы и строки, которая называет предмет крючка прошлой главы (`P-15`). **Результат:** первые 2 строки главы отвечают на крючок.
- [ ] Поставить 1–2 развилки с последствием: кнопки в разные узлы или переменная, которую потом прочитают (`P-04`).
- [ ] Остальные выборы — косметические с реакцией (`PAT-02`). У каждого варианта своя строка ответа.
- [ ] Для каждой новой переменной записать, в какой следующей сцене её прочитают (`P-06`). Если не находится — убрать переменную.
- [ ] Добавить не больше 1–2 сцен за доверие (`PAT-03`). Проверить, что основной сюжет понятен и без них.
- [ ] Проверить варианты на каждой развилке: все три «разумных человека», ни один не наказание (`P-07`).
- [ ] Закончить главу крючком (`PAT-05`) и при накопительном финале — итогом в «Заметках» (`PAT-06`).
- [ ] Посчитать: 3–6 кнопок, серия без кнопки ≤ 12 сообщений (25 — ошибка), ≤ 120 строк на главу (`P-01`, `P-11`).

## Как провести ревью готового сценария

- [ ] Прогнать `npm run check:story`. Выписать распределение финалов. **Результат:** нет финала > 50% при 4+ финалах (`RED-06`), нет финала < 2% без явной причины.
- [ ] Открыть `npm run graph`. Посчитать на главу узлы, где кнопки расходятся. **Результат:** 1–4 на главу (`RED-07`, `P-04`).
- [ ] Для каждой финальной проверки (`*_route`) выписать переменные. Для каждой найти место, где она показана игроку в тексте (`RED-05`, `P-12`).
- [ ] Найти все кнопки, под которыми стоит условие с переходом в узел другой кнопки той же развилки (`RED-01`). Для каждой решить: спрятать вариант условием или дать причину отказа репликой.
- [ ] Пройти глазами последние 3 строки каждой главы (`GREEN-01`) и 3 строки перед каждой паузой ≥ 1h (`RED-03`).
- [ ] Проверить первую главу по `P-10` и `RED-10`.
- [ ] Найти повторяющиеся строки в 3+ узлах (`RED-08`) и переписать.
- [ ] Записать итог: список флагов с именами узлов и правкой на каждый.

## Как тестировать

- [ ] `npm run check:story` — тупики, недостижимые узлы, финалы. **Результат:** 0 тупиков, все узлы посещены.
- [ ] Для каждой расходящейся развилки сравнить долю финалов после каждой кнопки (`P-07`). Сейчас бот этого не выводит, считать через лог прохождений или по `for-relayer.md` §2.
- [ ] Для условных вариантов проверить «показана / выбрана»: 10–60% показов (`GREEN-05`).
- [ ] Пройти одну ветку руками с `?fresh=1&fast=1`: играть как человек, который всё время выбирает «осторожный» вариант. **Результат:** финал соответствует осторожному стилю. Если нет — `RED-01`.
- [ ] Пройти вторую ветку, всё время молча (`#silent`). **Результат:** история не застревает, а молчание даёт свой финал или свою реакцию.
- [ ] Прогнать полное время пауз (медиана из отчёта бота) и разделить на число глав. Если средняя пауза между главами > 8h — проверить, что перед каждой стоит крючок.
