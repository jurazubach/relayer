# Приёмы и структуры Failbetter на ink

Источники [F1]–[F12], [S1] — в `principles.md`. У Failbetter в Echo Bazaar около шестидесяти именованных структур ([F1]); здесь только те, что переносятся в переписку. Названия структур — студийные, описания и примеры — наши.

Все примеры ниже скомпилированы inkjs и заканчиваются `-> END`. Сторилет в ink — вариант `* {условие} [...]` в хабе или узел, в который ведёт условный переход.

---

### PAT-01. Хаб сторилетов в главе (storylet hub)
- **Когда применять:** середина главы, где игрок собирает сведения у разных людей и порядок не важен. **Когда нет:** в первой главе до того, как игрок понял ставку; в финале, где нужен один фокус.
- **Схема:**
  ```
  hub ──▶ сторилет A ──▶ hub
      ──▶ сторилет B ──▶ hub
      ──▶ {условие от A} сторилет C ──▶ hub
      ──▶ {clues >= 2} выход ──▶ следующая сцена
  ```
- **На ink:**
  ```ink
  # contact: rae, Рэй, blue
  # contact: dina, Дина, amber
  # contact: notes, Заметки, green
  VAR clues = 0 // что известно про ночь 12-го: 0..3, только растёт
  -> hub
  === hub ===
  { clues < 2:
      Нужно ещё {2 - clues}, чтобы звонить. #sys:notes
  }
  * [Где ты был в 23:40? #to:rae]
      ~ clues += 1
      у брата. спроси дину #from:rae #delay:2m
      -> hub
  * [Дина, он был у тебя? #to:dina]
      ~ clues += 1
      был. до одиннадцати. потом ушёл #from:dina #delay:5m
      -> hub
  * {hub > 1 && clues >= 1} [Рэй, Дина говорит, ты ушёл в одиннадцать #to:rae]
      ~ clues += 1
      ладно. я был у гаража #from:rae #delay:9m
      -> hub
  * {clues >= 2} [Хватит. Звоню #to:notes #label:Закрыть дело]
      -> END
  * -> END
  ```
- **Цена:** каждый сторилет пишется один раз и не дублируется по веткам; текст растёт линейно, а не экспоненциально. Платишь учётом: счётчик, условие выхода, проверка «в любом порядке реплики не противоречат друг другу» — для хаба из N сторилетов это N! порядков, поэтому реплики сторилетов не должны ссылаться друг на друга без условия.
- **Ловушки:** меню из 5+ вариантов или хаб из двух (P-10, P-17); выход без условия, и игрок уходит, ничего не узнав; липкие `+` без изменений состояния.
- **Источник:** [F2] (сторилеты, свободно связанные качествами), [S1] (три улики в любом порядке).

### PAT-02. Цепочка на одном счётчике (questicle / venture)
- **Когда применять:** сюжетная линия с началом, серединой и концом внутри главы или двух, где шаги идут строго по порядку. **Когда нет:** если порядок не важен — это PAT-01.
- **Схема:** `открыть (stage = 1) → шаг (stage = 2) → шаг (stage = 3) → финал при stage >= 3 → награда-флаг`.
- **На ink:**
  ```ink
  # contact: tom, Том, cyan
  VAR boat = 0 // линия про катер: 0 — нет, 1..3 — идёт, 4 — закрыта
  VAR boat_key = false
  -> start
  === start ===
  а ты знала, что у Оуэна был катер? #from:tom #delay:1m
  ~ boat = 1
  -> step
  === step ===
  * {boat == 1} [Где он стоит? #to:tom]
      ~ boat = 2
      у старой пристани #from:tom #delay:3m
      -> step
  * {boat == 2} [Сходишь посмотреть? #to:tom]
      ~ boat = 3
      был. замок новый. а мотор тёплый #from:tom #delay:2h
      -> step
  * {boat == 3} [Кто ещё туда ходит? #to:tom]
      ~ boat = 4
      ~ boat_key = true
      ключ есть у сторожа. и у джесс #from:tom #delay:4m
      -> END
  ```
- **Цена:** одна переменная на линию, одна строка-комментарий. Дешевле любой связки флагов.
- **Ловушки:** стадии, которые поднимают в разных главах разные авторы; пропуск стадии (`boat = 3` сразу из 1).
- **Источник:** [F1] (questicle: квест на одном качестве, в игре переименован в venture), [F4] (порядок — одним качеством).

### PAT-03. Лестница: копить или действовать сейчас (Midnight Staircase)
- **Когда применять:** игрок готовит удар (разоблачение, разговор с полицией) и сам решает, когда хватит. **Когда нет:** если у раннего варианта нет внятного минуса — тогда это не выбор.
- **Схема:** `подготовка +1 (стоит времени) → на каждом уровне: действовать сейчас (слабый исход) | готовиться дальше → на уровне 3 открывается сильный исход`.
- **На ink:**
  ```ink
  # contact: judith, Джудит, teal
  VAR prep = 0 // подготовка к звонку в полицию: 0..3
  -> stairs
  === stairs ===
  * {prep < 3} [Подождите. Я соберу ещё #to:judith]
      ~ prep += 1
      Хорошо. Но время идёт. #from:judith #delay:2h
      { prep == 1:
          Оуэн уже звонил адвокату. #delay:20s
      }
      -> stairs
  * [Звоните сейчас #to:judith]
      { prep >= 3:
          С этим они не отмахнутся. #from:judith #delay:5m
      - else:
          Они записали. Сказали — без доказательств ничего. #from:judith #delay:30m
      }
      -> END
  ```
- **Цена:** 2–4 короткие ветки ожидания; каждое ожидание — настоящие часы, это и есть цена подготовки.
- **Ловушки:** подготовка без риска — игрок всегда копит до максимума. Нужна реплика, что за время ожидания что-то ухудшается.
- **Источник:** [F2] (Midnight Staircase: подготовка поднимает качество, игрок сам решает, когда действовать), [F3] (краткое напоминание). Цена в виде реального времени вместо очков — наш перенос, у студии его нет.

### PAT-04. Стол с закусками: разные исходы по разным качествам (Midnight Buffet)
- **Когда применять:** финал главы или сезона, где сильный исход требует нескольких видов подготовки. **Когда нет:** если игрок не знает, какие качества копить, — это лотерея, а не выбор (P-07).
- **Схема:** `скромный исход: одно качество ≥ 1 | сильный: два качества | лучший: три`. Варианты видны на кнопках.
- **На ink:**
  ```ink
  # contact: judith, Джудит, teal
  VAR proof = 2 // факты: 0..3
  VAR allies = 1 // кто согласен подтвердить: 0..2
  -> buffet
  === buffet ===
  У нас {proof} факта и {allies} свидетель. Что делаем? #from:judith #delay:3m
  * {proof >= 1} [Отправим письмо коронеру #to:judith]
      Отправила. Ответят через месяц. #from:judith #delay:10m
  * {proof >= 2 && allies >= 1} [Идём в полицию вдвоём #to:judith]
      Сержант слушал. Записывал. #from:judith #delay:2h
  * {proof >= 3 && allies >= 2} [Собираем всех у вас. Сегодня #to:judith]
      Все пришли. #from:judith #delay:3h
  - -> END
  ```
- **Цена:** по одному узлу на исход; качества уже есть.
- **Ловушки:** все пороги скрыты, а исход «лучший» видит 1 % игроков — это `fin_puppet` в «Чужом голосе». Лучший исход виден как недоступная цель.
- **Источник:** [F3] (Midnight Buffet).

### PAT-05. Часы: минутная стрелка двигает часовую (Grandfather Clock)
- **Когда применять:** сюжет главы продвигается не по одному выбору, а когда накопится достаточно мелких событий. **Когда нет:** в короткой истории на 25 минут — там каждая глава и так один шаг.
- **Схема:** `мелкие эпизоды +1 к pressure → при pressure >= 2: следующий бит главной линии, pressure = 0`. Главы `#chapter` — часовая стрелка, `pressure` — минутная.
- **На ink:**
  ```ink
  # contact: maya, Мая, red
  VAR pressure = 0 // давление на Маю в этой главе: сбрасывается после бита
  VAR beat = 0 // биты главной линии: 0..2
  -> tick
  === tick ===
  * [Мая, у тебя нет доказательств #to:maya]
      ~ pressure += 1
  * [Мая, ты пугаешь не того #to:maya]
      ~ pressure += 1
  * [Промолчать #to:maya #silent]
  - { pressure >= 2:
      ~ pressure = 0
      ~ beat += 1
      ладно. я покажу тебе запись #from:maya #delay:20m
    }
  { beat >= 1: -> END }
  { tick > 3: -> END }
  -> tick
  ```
- **Цена:** две переменные на главу, много коротких реплик в эпизодах.
- **Ловушки:** игрок не понимает, что двигает главную линию; бесконечная минутная стрелка без выхода по счётчику посещений.
- **Источник:** [F3] (Grandfather Clock).

### PAT-06. Каинова печать: одноразовая линия (Mark of Cain)
- **Когда применять:** предложение, которое можно принять один раз; после этого контакт меняется навсегда. **Когда нет:** для линий, которые должны оставаться открытыми.
- **Схема:** `закончил линию → скрытый флаг → все входы в линию проверяют флаг → линия пропадает, вместо неё одна реплика-отголосок`.
- **На ink:**
  ```ink
  # contact: press, Журналист, grey
  VAR sold_photo = false // продала ли фото прессе; закрывает все предложения press
  -> offer
  === offer ===
  { sold_photo:
      больше не пишите мне #from:press #delay:1m
      -> END
  }
  за фото с причала заплачу. сегодня #from:press #delay:5m
  * [Ладно. Присылаю #to:press]
      ~ sold_photo = true
      получил #from:press #delay:2m
      -> offer
  * [Нет #to:press]
      -> END
  ```
- **Цена:** один флаг и одна реплика-отголосок.
- **Ловушки:** флаг ставится, но вход в линию его не проверяет — предложение приходит второй раз.
- **Источник:** [F1] (Mark of Cain).

### PAT-07. Сделка с ценой и сделка на двоих (Faust, Faust's Tea Party)
- **Когда применять:** игрок просит контакт о помощи. Простая сделка: польза за цену. Социальная: выигрывают или теряют оба, а отказ ничего не меняет. **Когда нет:** если цена нигде не читается.
- **Схема:** `просьба → контакт соглашается (игрок получает факт, контакт теряет безопасность) | отказывается (ничего)`.
- **На ink:**
  ```ink
  # contact: tom, Том, cyan
  VAR tom_risk = 0 // чем Том рискует ради игрока: 0..2
  VAR has_log = false
  -> ask
  === ask ===
  * [Том, скинешь лог чата? Тебя могут уволить #to:tom #label:Попросить лог — Том рискует работой]
      { tom_risk < 2:
          ~ tom_risk += 1
          ~ has_log = true
          скину. но если что — я тебя не знаю #from:tom #delay:15m
      - else:
          нет. я и так засветился #from:tom #delay:3m
      }
  * [Не надо, я сама #to:tom]
  - -> END
  ```
- **Цена:** одна переменная цены на контакт; в будущей главе одна реплика, где цена сработала.
- **Ловушки:** цена без последствия — игрок узнаёт, что риск был фиктивным.
- **Источник:** [F2] (Faust, Faust's Tea Party).

### PAT-08. Угроза с видимым потолком (menace)
- **Когда применять:** у игрока есть противник или подозреватель, а провал не должен обрывать историю. **Когда нет:** если на пороге нет сцены — тогда это просто штраф.
- **Схема:** `ошибка → suspicion +1 → персонаж называет уровень → при 3: яркая сцена, история продолжается другим путём`.
- **На ink:**
  ```ink
  # contact: maya, Мая, red
  VAR suspicion = 0 // насколько Мая подозревает игрока: 0..3
  -> talk
  === talk ===
  + [Элли была дома #to:maya]
      ~ suspicion += 1
  + [Не знаю #to:maya]
  - -> react
  === react ===
  { suspicion:
  - 1: это раз. ещё два вранья — и я перестану тебе писать #from:maya #delay:3m
  - 2: это два #from:maya #delay:3m
  - 3: -> burned
  }
  { talk < 3: -> talk }
  -> END
  === burned ===
  всё. я выкладываю, что знаю. без тебя #from:maya #delay:5m
  Мая удалила чат #sys:maya
  -> END
  ```
- **Цена:** одна переменная, 2–3 реплики-уровня, одна сцена провала.
- **Ловушки:** угроза, которую игрок не видит (`maya_trust >= 3` в `ch10_maya`); угроза, которую нельзя уменьшить ничем.
- **Источник:** [F8] (menaces, драматичный провал), [F4] (показывать длину испытания).

### PAT-09. Колода «иногда» (Sometimes deck)
- **Когда применять:** между битами главы нужен случайный, но уместный эпизод: слух, мем, сообщение от второстепенного контакта. **Когда нет:** для шагов к главной цели — они должны быть доступны всегда ([F6]).
- **Схема:** `пауза → случайный эпизод из пула, отфильтрованный по состоянию → каждый показывается один раз`.
- **На ink:**
  ```ink
  # contact: tom, Том, cyan
  # contact: beth, Бет, purple
  VAR rumor = false
  -> lull
  === lull ===
  { shuffle once:
  - -> tom_meme
  - -> beth_gossip
  - -> END
  }
  === tom_meme ===
  ты видела, что в группе пишут про лодочную? #from:tom #delay:40m
  -> END
  === beth_gossip ===
  говорят, джесс опять плакала в столовой #from:beth #delay:1h
  ~ rumor = true
  -> END
  ```
- **Цена:** пул из 3–6 коротких эпизодов, которые можно не читать.
- **Ловушки:** в пуле эпизод с обязательной информацией — его увидит только часть игроков; бот покажет это как узел с посещаемостью 20–60 % (RED-08).
- **Источник:** [F9] (Sometimes storylets), [F6] (что держать в «always», что в «sometimes»).

### PAT-10. Сначала ситуация, потом выбор
- **Когда применять:** любой выбор, после которого меняется финал или контакт. **Когда нет:** мелкие реплики тона.
- **Схема:** `узел-подводка: 4–8 реплик, цена каждого пути названа → пауза → узел выбора: 2–3 кнопки с #label`.
- **На ink:**
  ```ink
  # contact: jess, Джесс, pink
  # contact: judith, Джудит, teal
  -> setup
  === setup ===
  я у двери #from:jess #delay:5m
  если я скажу сама — меня не посадят. наверное #delay:30s
  если скажешь ты — она тебе поверит #delay:30s
  а если промолчим — всё останется как было #delay:40s
  -> choice
  === choice ===
  * [Скажи сама #to:jess #label:Дать Джесс сказать самой]
  * [Джудит, откройте. Я всё расскажу #to:judith #label:Рассказать самой]
  * [Промолчать #to:jess #silent]
  - -> END
  ```
- **Цена:** один узел-подводка на поворотный выбор.
- **Ловушки:** подводка пересказывает прошлое вместо цены будущего; кнопки дублируют подводку слово в слово.
- **Источник:** [F7].

### PAT-11. Пересказ по запросу (recap storylet)
- **Когда применять:** начало главы после паузы от 6h, сериальная история, линия с тремя и более фактами, которые надо помнить. **Когда нет:** пауза короче часа; история на 25 минут без ночных пауз; пересказ, который выдаёт то, что игрок не узнавал.
- **Схема:** `пауза → новость от персонажа → кнопки: [Напомни] → 2–3 реплики итога, зависящие от состояния → продолжение | [ответ по теме] → продолжение`.
- **На ink:**
  ```ink
  # contact: ellie, Элли, amber
  # contact: notes, Заметки, green
  VAR clues = 2 // прогресс: что известно про ночь 12-го, 0..3
  -> ch5
  === ch5 ===
  День 5 · Утро #sys #chapter #delay:8h
  отпустили. спрашивали про катер #from:ellie #delay:1m
  * [Напомни, на чём мы остановились #to:notes #label:Что мы знаем]
      -> recap
  * [Про какой катер? #to:ellie]
      -> talk
  === recap ===
  Элли увезли на допрос в 23:00. #from:notes #delay:5s
  { clues >= 2: Рэй был у гаража. Дина подтвердила. | Рэй врёт про ночь 12-го. } #delay:5s
  Не хватает одного: кто ещё ходит к катеру. #delay:5s
  -> talk
  === talk ===
  катер оуэна. они знают, что я там была #from:ellie #delay:40s
  -> END
  ```
- **Цена:** узел на 2–4 реплики на главу, одна кнопка. Итог строится из уже существующих переменных, новых не надо.
- **Ловушки:** пересказ без условий не учитывает, что игрок узнал (противоречит его прохождению). Обязательный пересказ злит тех, кто помнит. Пересказ системной плашкой ломает голос: у Failbetter его произносят персонажи ([L2]).
- **Источник:** [L1] (главная жалоба — забыл, что делал), [L2] (сторилет-передышка с пересказом от офицеров). Перенос в чат заметок — наш.

### PAT-12. Ярус с выпуском (tier graduation)
- **Когда применять:** переход между главами, особенно 1 → 2: игрок закончил первые шаги, пора наградить и показать следующий круг. **Когда нет:** внутри главы; если в предыдущей главе нечего отметить.
- **Схема:** `ярус N: всё открыто сразу → завершение нужных шагов → выпуск: #chapter + награда (#unlock, факт) + реплика, отражающая выбор игрока в ярусе + показ цели яруса N+1`.
- **На ink:**
  ```ink
  # contact: tom, Том, cyan
  # contact: judith, Джудит, teal
  VAR tier = 1 // прогресс: ярус расследования 1..2, только растёт
  VAR asked_tom = false // факт: спросила ли Тома про лог. читается: tier_up
  -> ch2_end
  === ch2_end ===
  * [Том, у тебя остался лог? #to:tom]
      ~ asked_tom = true
      остался. скину вечером #from:tom #delay:3m
      -> ch2_end
  * [Пойду спать #to:tom #silent]
      -> tier_up
  === tier_up ===
  ~ tier = 2
  Глава 3 · Город #sys #chapter #delay:6h
  #unlock:judith
  Джудит Хейл, адвокат. Мне дал ваш номер Том. #from:judith #delay:1m
  { asked_tom: Он сказал, вы ищете лог той ночи. Я помогу. | Он сказал, вы задаёте правильные вопросы. } #delay:20s
  Слушание через два дня. До него нам нужно три факта. #delay:30s
  -> END
  ```
- **Цена:** одна переменная-прогресс на историю и одна условная реплика на переход.
- **Ловушки:** выпуск по диапазону навыка, а не по завершению шагов: контент «исчезает» при росте качества ([L3], RED-12). Выпуск без отклика на выбор игрока — просто смена заголовка. Следующий ярус не назван, и игрок не понимает, зачем возвращаться.
- **Источник:** [L3] (ярусы, качество-прогресс, отметка на выпуске, отражение выбора в характере, показ следующего яруса).

### Нюансы к PAT-01…PAT-10: 5 сообщений против 50
- **PAT-01, хаб.** На 5 сообщениях хаба нет. На 50 — один хаб из 3 сторилетов по 4–8 реплик. Порядок свободный, только если каждый сторилет понятен без остальных. Когда хаб не нужен вовсе — P-17.
- **PAT-02, цепочка.** Работает при любой длине. На коротких — порядок узлов вместо `stage`.
- **PAT-03, лестница.** Нужна пауза на каждой ступени. В истории без пауз дольше 10 минут ожидание не стоит ничего, и игрок всегда копит до максимума. Тогда цена ступени — событие, которое ухудшается.
- **PAT-04, стол с закусками.** На телефоне — максимум две переменные в условиях и уровни, названные вслух (`attention.md`, «слишком сложно»).
- **PAT-08, угроза.** В первой главе — только предупреждение (нюанс к P-13).
- **PAT-09, «иногда».** Случайный эпизод не двигает к цели (Система 3 в `principles.md`, LESSON-06).
