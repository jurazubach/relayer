# Приёмы жанра переписки

Все примеры на ink скомпилированы `inkjs/full` без ошибок, теги — из `docs/capabilities.json`. Сокращения источников — в `README.md`.

### PAT-01. Занятой собеседник (в Lifeline — статус «[Taylor is busy]»)
- **Когда применять:** любая пауза длиннее 10–15 минут посреди активной сцены. **Когда нет:** короткие паузы до 5 минут, там молчание без объяснения и есть живой ритм (`P-03`).
- **Схема:** причина ухода → `#sys` «не в сети» → пустая строка с `#delay` → возвращение с новостью → выбор.
- **На ink:**
  ```ink
  # contact: nika, Ника, teal
  -> start
  === start ===
  всё, батарея 4% #from:nika #delay:20s
  заряжусь у охранника и напишу #delay:6s
  не уходи никуда
  Ника не в сети #sys:nika
  #delay:40m
  я тут #from:nika
  охранник ушёл. дверь заперта снаружи #delay:8s
  * [Кто её запер? #to:nika]
      не знаю. я никого не видела #from:nika #delay:30s
  * [Звони 112 #to:nika]
      сеть одна палка. не проходит #from:nika #delay:40s
  - -> END
  ```
- **Цена:** 2–3 строки на паузу. Сложности не добавляет.
- **Ловушки:** одна и та же причина («напишу позже») повторяется из главы в главу. Причина без последствия: обещала «расскажу, что нашла» и не рассказала. Обещание после паузы нужно выполнить.
- **Источник:** WL (статус «busy»), GP (сон). Схема с «не в сети» — наша.

### PAT-02. Крючок на возвращение (cliffhanger перед ночью)
- **Когда применять:** конец главы и любая пауза ≥ 2h. **Когда нет:** после финальной развязки (`P-16`).
- **Схема:**
  ```
  сцена → обещание («завтра расскажу») → не в сети
        → #delay:6h → удар из неожиданного чата (#unlock) → выбор
        → основной собеседник: «тебе тоже пришло?»
  ```
- **На ink:**
  ```ink
  # contact: nika, Ника, teal
  # contact: unknown, Неизвестный номер, grey
  -> night
  === night ===
  ладно. я спать #from:nika #delay:15s
  завтра расскажу, что нашла в архиве
  * [Спокойной ночи #to:nika]
  * [Расскажи сейчас #to:nika]
      нет. сначала проверю #from:nika #delay:20s
  - Ника не в сети #sys:nika
  Вы зря ей помогаете. #from:unknown #delay:6h #unlock:unknown
  * [Кто это? #to:unknown]
      Прочитано #sys:unknown #delay:1m
  * [Промолчать #to:unknown #silent]
  - доброе. мне пришло странное сообщение #from:nika #delay:40m
  тебе тоже? #delay:5s
  -> END
  ```
- **Цена:** одно сообщение и одна развилка на главу.
- **Ловушки:** крючок от одного и того же контакта каждую ночь быстро становится расписанием. Угроза без продолжения в следующей главе учит игрока, что крючки ничего не значат.
- **Источник:** IF50 (напряжение между сессиями). Сама схема — знание модели, уверенность: средняя. Так же устроены `ch1_unknown`, `ch2_hook`, `ch3_hook` в «Чужом голосе».

### PAT-03. Пауза до утра, выровненная флагом
- **Когда применять:** развилка вечером, ветки разной длины, а утро должно наступить в одно и то же сюжетное время. **Когда нет:** короткие паузы внутри сцены.
- **Схема:** ветка ставит флаг → общая точка → `#delay` выбирается условием → общая утренняя реплика.
- **На ink:**
  ```ink
  # contact: nika, Ника, teal
  VAR late = false
  -> evening
  === evening ===
  * [Иди домой, уже поздно #to:nika]
      ~ late = true
      ок. до завтра #from:nika #delay:10s
  * [Ещё один файл и всё #to:nika]
      ладно, ещё один #from:nika #delay:10s
      пусто. всё, я спать #delay:3m
  - Ника не в сети #sys:nika
  // ушла раньше — до утра дольше
  {
  - late:
      #delay:10h
  - else:
      #delay:8h
  }
  доброе #from:nika
  -> END
  ```
- **Цена:** одна переменная и блок условия на каждую ночь.
- **Ловушки:** при пропусках флаг ставится в одной ветке и забывается в другой, утро наступает днём. Проверять в отладке прыжком к узлу.
- **Источник:** GP (паузы по правдоподобному времени, в продолжениях Lifeline). Выравнивание флагом — наш приём. В «Чужом голосе» так сделано в `ch6_ask_ellie` и `ch6_ellie` (флаг `c6_morning`).

### PAT-04. Номер без имени (в Mr. Robot имя скрыто до знакомства)
- **Когда применять:** новый контакт, которого игрок не знает. Сильнее всего работает для антагониста и для свидетеля. **Когда нет:** контакт, которого игрок по сюжету знает давно.
- **Схема:** номер или «Неизвестный» → разговор → имя в реплике → `#rename` сразу после.
- **На ink:**
  ```ink
  # contact: x, +7 900 000-14-02, grey
  VAR knows_name = false
  -> first
  === first ===
  это вы продали велосипед по объявлению? #from:x #delay:30s
  * [Да. А что? #to:x]
  * [Кто это? #to:x]
      ~ knows_name = true
      Рита. он краденый, это мой #from:x #delay:40s
      #rename:x, Рита
  - рама с наклейкой лисы? #from:x #delay:20s
  {not knows_name:
      я Рита, кстати #delay:10s
      #rename:x, Рита
  }
  -> END
  ```
- **Цена:** строка `#rename` и, если имя зависит от ветки, одна переменная.
- **Ловушки:** имя приходит из одной ветки, в другой контакт так и остаётся номером до финала. Нужен запасной `#rename`, как в примере.
- **Источник:** TA-F.

### PAT-05. Улика через чат (перенос сведений между переписками)
- **Когда применять:** у игрока больше одного собеседника, и они знают разное. **Когда нет:** в истории один контакт.
- **Схема:**
  ```
  чат A: факт ──► кнопка #to:B с фактом ──► B реагирует
                                         └─► тост из A: «что ты ему сказал?»
  ```
- **На ink:**
  ```ink
  # contact: nika, Ника, teal
  # contact: oleg, Олег, orange
  -> two_chats
  === two_chats ===
  он сказал, что был дома в 23:00 #from:nika #delay:20s
  но в 23:10 его машина была у склада. мне прислали фото #delay:6s
  * [Олег, где ты был вчера в 23:10? #to:oleg]
      дома. а что? #from:oleg #delay:2m
      ** [Твою машину видели у склада #to:oleg]
          Олег не в сети #sys:oleg
          он мне пишет. что ты ему сказал?? #from:nika #delay:5m
      ** [Ничего, просто спросил #to:oleg]
          ок #from:oleg #delay:30s
  * [Не говори пока никому #to:nika]
      поздно. я уже спросила его #from:nika #delay:30s
  - -> END
  ```
- **Цена:** одна-две реплики реакции на каждый перенос плюс переменная, если потом на это сослаться.
- **Ловушки:** перенос без реакции получателя. Тогда это просто кнопка в другом чате, и игрок не чувствует, что выдал сведения.
- **Источник:** TA-F.

### PAT-06. Задачка из переписки (ответ уже лежит в чате)
- **Когда применять:** выбор с правильным ответом: код, адрес, имя, время. **Когда нет:** моральный выбор, где правильного ответа нет.
- **Схема:** улика (фото, скрин, старое сообщение) → вопрос → кнопка-догадка и кнопка «где посмотреть?» → верный ответ виден только тому, кто понял.
- **На ink:**
  ```ink
  # contact: nika, Ника, teal
  -> clue
  === clue ===
  на сейфе код. 4 цифры #from:nika #delay:20s
  у тёти пароль везде один: год, когда она переехала #delay:8s
  -> guess
  = guess
  * [1987 #to:nika]
      не подходит. осталась одна попытка #from:nika #delay:30s
      -> guess
  * [Где-нибудь записан год переезда? #to:nika]
      на фото в прихожей подпись #from:nika #delay:1m
      «первая зима на новом месте, 1994» #photo
      ** [Попробуй 1994 #to:nika]
          открылось #from:nika #delay:40s
          -> END
  ```
- **Цена:** одно фото или реплика-улика и ветка ошибки.
- **Ловушки:** улика пришла за две главы до вопроса, без напоминания, и игрок её не помнит. Ошибка, которая убивает сюжет без отката, в реальном времени стоит дней (в Lifeline после смерти есть перемотка, в relayer её нет).
- **Источник:** IF50 (вопрос про радиацию в Lifeline), сводки рецензий Replica (пароли из данных телефона, уверенность: низкая). В THE NUMBER так устроен код `4471`.

### PAT-07. Скрытые накопители и финал-сортировщик (как моральный дух, деньги и романтика в Bury Me, My Love)
- **Когда применять:** много выборов, не меняющих узел, и несколько финалов. **Когда нет:** короткая история на 1–2 главы, где счётчик не успеет набраться.
- **Схема:** выбор меняет 2–3 переменные → собеседник отражает состояние словами в следующих главах → финал выбирается проверкой.
- **На ink:**
  ```ink
  # contact: nika, Ника, teal
  # contact: bank, Банк, lime
  VAR nerve = 2
  VAR money = 1
  -> road
  === road ===
  у меня осталось на один билет #from:nika #delay:20s
  * [Бери автобус, дешевле #to:nika]
      ~ money += 1
      ~ nerve -= 1
      ладно. 9 часов трястись #from:nika #delay:30s
  * [Бери поезд, ты вымоталась #to:nika]
      ~ money -= 1
      спасибо. правда #from:nika #delay:30s
  - {nerve <= 1:я уже не понимаю, зачем всё это|ладно. держусь} #from:nika #delay:4h
  -> ending
  === ending ===
  {
  - money <= 0:
      Ника Т. просит вернуть £20 · «прости» #from:bank #delay:1h
  - nerve <= 1:
      я вернулась домой. не пиши пока #from:nika #delay:1h
  - else:
      я доехала. всё было не зря #from:nika #delay:1h
  }
  -> END
  ```
- **Цена:** переменные бесплатны. Реплики-отражения — по одной на каждое пороговое значение в главе.
- **Ловушки:** переменная читается только в последнем узле, и игрок не может понять, почему пришёл к этому финалу (наш случай: 84 кнопки «только меняют переменные»). Тексты финалов в пример с `#delay:1h` попали для наглядности: в живой истории после кульминации паузы короткие (`P-16`).
- **Источник:** GD (три переменные и 19 финалов), KT.

### PAT-08. Шум мира (necessary uselessness, необходимая бесполезность)
- **Когда применять:** длинная история с паузами, телефон должен ощущаться настоящим. **Когда нет:** в сцене, где игрок ждёт ответа на вопрос: шум не должен стоять между вопросом и кнопкой.
- **Схема:** основная линия → пауза → сообщение от шумового контакта → основная линия.
- **На ink:**
  ```ink
  # contact: nika, Ника, teal
  # contact: promo, Пиццерия «Лука», lime
  -> noise
  === noise ===
  я у его подъезда. жду #from:nika #delay:30s
  -50% на вторую пиццу только сегодня 🍕 #from:promo #delay:3m
  вышел. иду за ним #from:nika #delay:2m
  * [Осторожно #to:nika]
  * [Не подходи близко #to:nika]
  - ок #from:nika #delay:20s
  -> END
  ```
- **Цена:** контакт в шапке и 1–3 строки на главу.
- **Ловушки:** шумовой контакт с ранним `#unlock` висит в списке пустым и отвлекает; без `#unlock` чат появится сам с первым сообщением, этого достаточно. Слишком много шума — игрок перестаёт открывать тосты, и важное письмо пропадает.
- **Источник:** TA-F, TA-R.

### PAT-09. Главы как отдельные встречи (пять разговоров за пять лет в Emily is Away)
- **Когда применять:** история про отношения, которые меняются за длинный срок. **Когда нет:** триллер на одну ночь, где разрыв убивает напряжение.
- **Схема:** `#chapter` с меткой времени («Год спустя») → первая реплика сразу показывает, что изменилось → выбор, который ссылается на прошлую главу.
- **На ink:**
  ```ink
  # contact: nika, Ника, teal
  VAR stayed = false
  -> y1
  === y1 ===
  Лето #sys:nika #chapter
  ты правда уезжаешь в сентябре? #from:nika #delay:10s
  * [Да #to:nika]
  * [Ещё не решил #to:nika]
      ~ stayed = true
  - -> y2
  === y2 ===
  Год спустя #sys:nika #chapter #delay:1m
  {stayed:ты так и не уехал. я рада|как там твой новый город?} #from:nika #delay:10s
  -> END
  ```
- **Цена:** по главе на каждый «год». Большой разрыв между главами требует напоминания, что было.
- **Ловушки:** то, что герой «сделал» между главами без игрока, потом становится претензией к игроку (`P-07`).
- **Источник:** ES (пять разговоров за пять лет), PP (упрёки за поступки между главами).

### PAT-10. Лоза (vine, not tree — лоза, а не дерево; Dave Justus)
- **Когда применять:** почти всегда в истории в реальном времени: дерево с полноценными ветками на неделю игры не пишется и не проверяется. **Когда нет:** последняя глава, где расхождение и есть награда (`emshort-structures:P-08`).
- **Схема:**
  ```
  ствол ──► развилка ──► отросток (1–5 реплик, ставит флаг) ──┐
                 └──────────────────────────────────────────────┴──► ствол
                                         … позже: {флаг} меняет реплику или путь
  ```
  Три элемента. **Отросток** уходит в сторону и даёт характер, деталь, предмет. **Возврат** сводит его со стволом в том же узле, чтобы граф не взрывался. **Отложенная отдача** — предмет или персонаж из отростка всплывает позже и перенаправляет игрока (GA). Без третьего элемента лоза превращается в косметику, за которую Emily Short ругала Lifeline 2 (ESL2).
- **На ink:**
  ```ink
  # contact: nika, Ника, teal
  VAR has_key = false
  -> yard
  === yard ===
  я во дворе склада #from:nika #delay:10s
  у будки сторожа что-то блестит
  * [Глянь, что там #to:nika]
      ключ на верёвке. беру? #from:nika #delay:20s
      * * [Бери #to:nika]
          ~ has_key = true
          взяла #from:nika #delay:10s
      * * [Не трогай #to:nika]
          ладно #from:nika #delay:10s
  * [Не отвлекайся, к двери #to:nika]
  - иду к двери #from:nika #delay:15s
  заперто #delay:5s
  {has_key:
      стоп. ключ от будки подошёл #delay:20s
  - else:
      придётся через окно #delay:20s
  }
  -> inside
  === inside ===
  я внутри #from:nika #delay:30s
  -> END
  ```
- **Цена:** одна переменная на отросток и одна условная реплика на отдачу. Дешевле настоящей ветки в разы.
- **Ловушки:** отросток без отдачи (RED-11); отдача через три главы без напоминания, игрок не помнит, откуда ключ; лучшая сцена спрятана в отросток (LESSON-02). Пропуск шага «возврат» даёт то, о чём предупреждал Justus: десятки пассажей без финала (GA).
- **Как применять в коротких формах:** на истории в 5 минут — один отросток и одна отдача в той же сцене, в пределах 10 сообщений.
- **Источник:** GA (Justus и Jokela), ESL2.
