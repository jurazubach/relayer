## Что осталось под вопросом

- **Публичных метрик жанра нет.** Цифры удержания и дочитывания есть только у Hooked, и те со слов основателя, без процента. Все пороги в `attention.md` §4, кроме ссылок на соседние разборы, — наши оценки. Откалибровать их на трёх историях после реализации проверок.
- **LESSON-05, LESSON-06, LESSON-11** — «урок» без переделки: «что поменяли» не найдено, только оценка критика. Оставлены, потому что выводы прямые. Если появится требование «только переделки с итогом», это первые кандидаты на удаление.
- **LESSON-13** держится на спонсорской статье VP. Подтвердить претензии игроков к Sara Is Missing по независимой рецензии.
- **Сам доклад Maurin** (запись GDC) не просмотрен, только аннотация и конспект.
- **Порог 2h напоминания** и «≤ 1 новый контакт за возвращение» — без всякой внешней опоры.

## Лучшее из второго прохода для скиллов

- **PAT-10 + LESSON-01:** лоза с отложенной отдачей. Узаконивает наш почти линейный граф и даёт проверку «отросток без отдачи» (`for-relayer.md` §2).
- **LESSON-06 → правило генератора:** персонаж, который знает мир лучше игрока, не просит совета вслепую и не высмеивает ответ.
- **Система 1, шаг 4 + `attention.md` §5:** время ждёт игрока, упрёк за долгий ответ запрещён. Простое правило, его легко проверить словарём.
- **LESSON-04 / LESSON-10:** повтор без пропуска убивает финалы, прыжок времени без метки ломает ход. Это требования к движку: быстрый повтор и `#sys` на каждом скачке.
- **`attention.md` §5:** список запретов — платный пропуск ожидания, ложный бейдж, вина за уход, скрытый срок истории. Готовый раздел для `docs/PROMPT.md` и README.
- **Система 2 для коротких форм:** брать только роль и оборванное сообщение. Остальное требует дней игры.
