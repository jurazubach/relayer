# Зелёные и красные флаги — Snyder, Save the Cat!

«Входящее» — строка с текстом без `#sys`. «Медианный путь» — прохождение бота с медианным числом строк. Маркеры `// beat:`, `// ±`, `// ТЕМА:`, `// ОСЬ:`, `// A:`, `// B:`, `// АНТАГОНИСТ:` — наша разметка из `PAT-01`–`PAT-04`. Пороги — наш вывод из долей Снайдера (катализатор ~10%, переход ~23%, середина ~50%, всё потеряно ~68%, переход в III ~77%). Коридоры для предупреждений: переход во II 15–30%, середина 40–60%, всё потеряно 60–80%, переход в III 70–90%. Номера `B1`–`B15` — проверки из `for-relayer.md` §2.

## Где игроку станет скучно

Снайдер считает главным местом провисания второй акт. Его критики [SD] добавляют, что как раз второму акту в схеме не хватает битов.

- **Между переходом во II и серединой, если нет обещания завязки.** Главы «расспросов», где каждая сцена устроена одинаково и ничего не стоит: `RED-05`, `RED-06`. Чинить — `P-09`: то же действие с новой ценой.
- **Сразу после середины, если она не сменила вопрос.** Игрок продолжает собирать улики по инерции: `RED-05`.
- **В монологах предыстории:** `RED-07`.
- **Когда угроза стоит на месте:** `RED-11`.
- **Когда тон не меняется две главы подряд:** `RED-13`.
- **Когда все говорят одним голосом:** чаты сливаются в один поток реплик, `RED-16`.
- **Наш вывод для реального времени:** длинная пауза скучна, если перед ней не открыт вопрос. В тёмной ночи пауза работает, потому что перед ней потеря (`PAT-06`). После бытовой реплики та же пауза — повод закрыть приложение.

## Почему начало не цепляет / непонятно

- **Подготовка вместо катализатора:** `RED-02`.
- **Ирония не видна, игрок не понимает, в чём штука:** `RED-01`.
- **Не за кого переживать:** у главного NPC нет «котика» (`RED-03`), цель не первобытная (`P-04`).
- **Игрока везут, а не он входит:** `RED-04` для перехода во II.
- **Жанр не опознаётся:** из трёх элементов типа в первой четверти нет двух (`P-02`). Игрок не знает, чего ждать, и не ждёт ничего.

## Почему выбор не ощущается

- **Дебат без цены:** `RED-08`.
- **Решение приходит без игрока:** `RED-04`.
- **Финал из одной кнопки или из скрытой проверки:** `RED-09`.
- **Переменные, которые никто не читает:** `RED-15`.
- **Снайдер про это прямо не пишет:** он пишет о линейном фильме. Перенос его проверки The Hero Leads на кнопки — наш вывод.
