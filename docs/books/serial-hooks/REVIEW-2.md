## Лучшее из второго прохода для скиллов

- **LESSON-07 + LESSON-08 → P-04, PAT-01.** Обрыв поднимает возбуждение, но сам по себе не держит. Главная ступень крючка — новый факт, а не угроза. Порог «жёстких ≤ 50%» оставить предупреждением.
- **LESSON-09 + PAT-11 + S15 + RED-16.** Рекап после паузы, который упоминает выбор, пишется только условной строкой. Это проверяемо ботом.
- **LESSON-06 + RED-15 + S14.** Одинаковое открытие после разных пауз — это ритуал, его проматывают. Счёт повторов после нормализации.
- **PAT-10 «кнопка ухода» + GREEN-10.** Игрок сам выбирает длинную паузу, а у ветки «сейчас» своя короткая пауза. Самый честный способ объяснить ночное ожидание.
- **`attention.md` §3, таблица «крючок перед паузой по её длине».** Готовая основа для `/pause-audit`.
- **`attention.md` §5 + LESSON-01/05/14.** Граница тёмных паттернов: пауза — время персонажа, а не товар. Каждый «печатает…» ведёт к сообщению.
- **for-relayer §8.** Семь разобранных противоречий с другими источниками, у каждого есть решение для нашего формата.
