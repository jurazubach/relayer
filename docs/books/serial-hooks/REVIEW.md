## Лучшее из источника для скиллов

- **P-01 + RED-01 + S1:** крючок стоит до паузы. Прощание или «Прочитано» перед многочасовой паузой — главная находимая поломка, она уже есть в `ch1_confront`.
- **P-03 + RED-02 + S2:** пауза после события, а не после анонса (Брук: не обрывать на выстреле).
- **P-08 + RED-05 + S7 + PAT-09:** чем длиннее пауза, тем больше сессия после неё. Медиана в 3 строки между паузами от 30m в «Чужом голосе» — самый крупный системный дефект.
- **P-09/P-10 + PAT-03 + S8:** рекап голосом персонажа после паузы от 3h. Опора — метаанализ 2025 года: незаконченное тянет вернуться, но помнится не лучше.
- **P-05 + P-13 + PAT-04 + S3/S10:** длина паузы равна длительности дела персонажа, время возвращения названо в реплике и совпадает с `#delay` (Lifeline, Munpia).
- **P-02 + PAT-02 + S4:** честный выход из обрыва по Эллисон (sequential/augmented), без «показалось».
