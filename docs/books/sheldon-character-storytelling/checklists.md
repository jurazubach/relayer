# Процедуры

## Как придумать и начать историю

- [ ] Составь список контактов и каждому запиши функцию в сюжете одной строкой (`P-04`). Результат: `characters[].role` — функция, а не профессия.
- [ ] Каждому основному контакту выпиши по факту на тело и быт, положение, психику (`P-01`). Результат: в `about` три факта, у каждого запланировано проявление (пауза, регистр, тема-избегание).
- [ ] Выбери каждому 2–3 черты и для каждой назови развилку, где она меняет ответ (`P-02`). Результат: таблица «черта → узел».
- [ ] Задай 3–5 маркеров голоса и сверь пары контактов (`P-05`). Результат: никакие два контакта не совпадают по маркерам больше чем наполовину.
- [ ] Для ключевых персонажей заведи две оси отношения (`P-07`, `PAT-01`). Результат: `VAR x_trust`, `VAR x_respect` (или `x_warm`).
- [ ] Напиши первые три сообщения каждого контакта так, чтобы в них были голос и желание (`P-14`). Результат: в первых трёх строках есть маркер и просьба, условие или вопрос.
- [ ] В первой главе построй модульный хаб из 2–4 чатов (`P-11`, `PAT-03`). Результат: выход по порогу `2 из 3`, а не по обходу всех.

## Как написать главу или сцену

- [ ] Назови цель каждого участника сцены, включая NPC (`P-03`). Результат: у каждого есть, чего он добивается в этой главе.
- [ ] Поставь хотя бы один инициативный заход NPC (`PAT-07`). Результат: блок `#from:`, который не отвечает на последнюю кнопку.
- [ ] Перечисли обещания, прозвучавшие в главе, и пометь их `// promise:` (`P-08`). Результат: у каждого есть запланированный `// payoff:`.
- [ ] Для каждой развилки «только реплика» реши: накапливать тон (`PAT-06`) или оставить косметической. Результат: косметических не больше половины развилок главы.
- [ ] Проверь, что каждая переменная отношения, записанная в главе, читается здесь или в следующей главе (`P-06`). Результат: список «записал → прочитал в узле».
- [ ] Разбей серии входящих длиннее восьми строк вопросом или `#silent` (`P-13`). Результат: максимум восемь строк `#from:` подряд.
- [ ] Ключевой вывод отдай кнопке игрока, а не `#me:` (`P-10`). Результат: строка вывода стоит в `[...]`.
- [ ] Если в сцене игрок расспрашивает одного персонажа, дай вопросам цену (`P-15`, `PAT-08`). Результат: обойти все варианты нельзя или это стоит отношения.

## Как провести ревью готового сценария

- [ ] Посчитай записи и чтения каждой `VAR` (скрипт или `grep`). Результат: список переменных с флагом `RED-01`.
- [ ] Сверь число строк каждого контакта. Результат: список кандидатов `RED-03` (меньше пяти строк).
- [ ] Прочитай подряд только реплики одного контакта, так для каждого. Результат: нет строки, которую можно отдать другому контакту без правки (`RED-05`).
- [ ] Найди все сроки и условия, названные вслух. Результат: у каждого есть payoff в каждом мире (`RED-04`).
- [ ] Выпиши переменные, которые читает маршрутизатор финалов, и главы, где они пишутся. Результат: ни одна не записывается только в последней главе (`RED-07`).
- [ ] Просмотри все `#me:` в двух последних главах. Результат: ни один не делает вывод за игрока (`RED-08`).
- [ ] Найди хабы разговора с одним контактом. Результат: ни один не проходится целиком без последствий (`RED-09`).
- [ ] Сверь `# contact:` и `characters`. Результат: у каждого контакта есть запись с `role`-функцией (`P-04`).
- [ ] Для каждого финала найди хотя бы одну реплику, которая называет конкретный прошлый поступок игрока. Результат: финал объясняет себя через выбор.

## Как тестировать

- [ ] `npm run check:story`: тупиков ноль, все финалы достижимы. Результат: отчёт без ошибок.
- [ ] Посмотри по отчёту бота распределение значений осей отношения перед каждой точкой чтения. Результат: каждая ветка условия выпадает хотя бы в 5% прогонов, иначе порог мёртвый.
- [ ] Пройди историю дважды противоположными стратегиями: «всегда честно» и «всегда молчать». Результат: отличаются хотя бы три реплики каждого основного контакта, кроме финала.
- [ ] `npm run graph`: у хабов (`P-11`) ≥ 3 рёбер в разные чаты. Результат: структура не цепочка.
- [ ] Пройди с `?fast=1` только первые 10 минут: кто хочет чего от игрока? Результат: ответ на этот вопрос формулируется по каждому открытому контакту.
