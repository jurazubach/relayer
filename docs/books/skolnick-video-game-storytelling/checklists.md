# Процедуры — Skolnick, Video Game Storytelling

Ссылки P-/PAT-/RED- ведут в соседние файлы.

## 1. Придумать и начать историю

- [ ] Записать конфликт одной строкой: «кто хочет …, мешает …, срок …». Результат: строка, где есть все три части (P-01).
- [ ] Определить роль игрока: кто он, почему пишут ему, какая у него маска. Результат: строка «я — …, мне пишут, потому что …» (P-14, P-15).
- [ ] Разложить главы по трём актам с пропорцией ~1:2:1. Отметить поворот 1, перелом и поворот 2. Результат: таблица глав с актом и поворотом в каждой (`PAT-01`).
- [ ] Выписать лестницу ставок: что на кону в каждой главе. Результат: ни одна строка не повторяет предыдущую (P-08).
- [ ] Выписать предысторию и для каждого факта решить, когда он нужен игроку. Результат: факт привязан к главе или к кнопке-вопросу (P-04, `PAT-03`).
- [ ] Написать открытие по `PAT-08`: первая кнопка не позже 6-го сообщения, затем 2–4 обмена нормы, пауза и поворот. Результат: бот не выдаёт RED-01 и RED-03.
- [ ] Придумать противника и его мотив одной фразой, в которую он сам верит. Результат: реплика, которую он может написать игроку (P-10).

## 2. Написать главу или сцену

- [ ] Назвать желание и помеху главы в комментарии `// хочет / мешает`. Результат: комментарий над первым узлом главы (P-01).
- [ ] Проверить ставку главы: она выше прошлой. Результат: новая угроза, срок или цена (P-08).
- [ ] Для каждого факта, который игрок должен запомнить, пройти лестницу `PAT-02`. Результат: у ключевых фактов есть кнопка-действие.
- [ ] Каждой входящей реплике дать функцию: сюжет, характер, эмоция, подсказка. Результат: реплики без функции вырезаны (P-13).
- [ ] Серии входящих длиннее 5 разбить кнопкой реакции или сократить. Результат: нет RED-09.
- [ ] Каждый упрёк или благодарность игроку поставить под условие на его выбор. Результат: нет RED-08 (P-14).
- [ ] Закончить главу неразрешённым вопросом и паузой перед следующей. Результат: последняя строка главы — вопрос, угроза или новый контакт.

## 3. Ревью готового сценария

- [ ] Прогнать бот, выписать распределение строк по главам. Результат: доли первой и последней глав в норме (RED-05, RED-06).
- [ ] Найти первый выбор и первую угрозу, посчитать сообщения до них. Результат: RED-01 и RED-03 сняты или осознанно оставлены.
- [ ] Выписать ставку каждой главы одной строкой. Результат: нет двух одинаковых подряд (RED-11).
- [ ] Найти все кнопки отказа и проследить, куда они ведут. Результат: у каждой есть переменная и отголосок позже (RED-04, `PAT-04`).
- [ ] Для каждой переменной, проверяемой в финале, найти, где она выставляется. Результат: каждая выставляется действием игрока, а не в `else` (RED-07, P-11).
- [ ] Для каждого персонажа выписать факты, которые он называет, и откуда он их знает. Результат: нет знаний «из чужого чата» (P-12).
- [ ] Найти точку невозврата. Результат: узел назван, он не в последней главе (P-09).
- [ ] Если глава «не едет», сверить её с мономифом: есть ли порог, испытание, наставник или ложный наставник. Результат: названа недостающая функция (P-09).

## 4. Тестировать

- [ ] `npm run check:story` — выписать кнопки с показом < 4 из 400. Результат: каждая либо удалена, либо условия ослаблены (RED-10).
- [ ] Пройти начало руками с `?fresh=1` без `?fast=1` и засечь время до первой кнопки. Результат: ≤ 60 с (RED-01).
- [ ] Пройти главу, всё время молча (`#silent` везде, где можно). Результат: персонажи реагируют на молчание иначе, чем на ответ, и не благодарят «за ответ» (P-14).
- [ ] Пройти историю с маской и без неё (ложь и правда). Результат: разница видна хотя бы в двух главах (GREEN-06).
- [ ] Отдать первую главу человеку, который не знает сюжета, и спросить после 15-го входящего: «кто ты здесь и чего от тебя хотят?». Результат: ответ совпадает со строкой роли из процедуры 1.
