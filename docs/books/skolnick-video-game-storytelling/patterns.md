# Приёмы и структуры — Skolnick, Video Game Storytelling

Источники [S1]–[S6] перечислены в `principles.md`. Все примеры ink проверены компилятором inkjs; теги — только из `docs/capabilities.json`.

---

### PAT-01. Три акта по главам (three-act structure, plot points, midpoint)
- **Когда применять:** история на 3+ главы, любой длины. **Когда нет:** миниатюра на 3–5 минут — там одна сцена с поворотом.
- **Схема:**
  ```
  Акт 1 (~25%)          Акт 2 (~50%)                   Акт 3 (~25%)
  норма → поворот 1 →  давление → перелом → давление → поворот 2 → развязка
  гл.1                 гл.2        гл.3      гл.4       конец гл.4   гл.5 + финалы
  ```
  Поворот 1 — игрок взялся и уже не может просто выйти. Перелом — меняется понимание цели. Поворот 2 — у игрока есть всё для последнего решения.
- **На ink:**
  ```ink
  # title: Пример · Три акта
  # contact: mira, Мира, teal
  VAR help = 0
  -> ch1
  === ch1 ===
  Глава 1 · Ключи #sys:mira #chapter
  ты дома? я ключи у тебя забыла #from:mira
  * [Дома. Заходи #to:mira]
  * [Через час буду #to:mira]
  - ой #from:mira #delay:40s
  у подъезда стоит мужик. смотрит на мои окна #delay:20s
  -> ch2
  === ch2 ===
  Глава 2 · Подъезд #sys:mira #chapter #delay:2h
  он всё ещё там #from:mira
  * [Позвони 112 #to:mira]
      ~ help += 1
      позвонила. сказали ждать #from:mira #delay:3m
  * [Иди ко мне, открою #to:mira]
      иду #from:mira #delay:1m
  - он пошёл за мной #from:mira #delay:4m
  -> ch3
  === ch3 ===
  Глава 3 · Дверь #sys:mira #chapter #delay:20m
  он стучит. в твою дверь #from:mira
  {help > 0:
      внизу мигалки #delay:2m
  - else:
      я одна. открывать? #delay:2m
  }
  -> END
  ```
- **Цена:** нулевая по тексту, это раскладка. Требует заранее решить, где поворотные точки.
- **Ловушки:** считать акты по числу глав, а не по строкам. Растянуть первую главу, потому что там знакомство со всеми контактами. Ставить перелом в последнюю главу, где он уже не успевает изменить поведение игрока.
- **Источник:** [S3], [S4].

### PAT-02. Лестница «сделай — покажи — расскажи» (do > show > tell)
- **Когда применять:** каждая улика и каждый поворот, который игрок должен запомнить. **Когда нет:** фон и атмосфера: тут хватит одной строки «рассказа».
- **Схема:**
  ```
  Нужно, чтобы игрок узнал X.
  1. Может ли он сам добыть X кнопкой? (спросить, переслать, сохранить) → да: сделай так
  2. Можно ли показать X? (#photo, #sys «Прочитано», молчание) → да: покажи
  3. Иначе пусть персонаж скажет X — коротко и с эмоцией
  ```
- **На ink:**
  ```ink
  # title: Пример · Делай, покажи, расскажи
  # contact: oleg, Олег, orange
  # contact: notes, Заметки, green
  VAR saved = false
  скинь номер машины, которая у тебя под окном #from:oleg
  Фото: серый фургон, номер замазан грязью, видны цифры 4 и 7 #photo #delay:30s
  * [4_7 — серый фургон #to:notes #label:Сохранить в заметки]
      ~ saved = true
  * [Не вижу номера #to:oleg]
  - {saved:
      ты записал? хорошо. сверю #from:oleg #delay:1m
  - else:
      жаль. он уезжает #from:oleg #delay:1m
  }
  -> END
  ```
- **Цена:** одна лишняя кнопка и переменная на улику.
- **Ловушки:** кнопка «Сохранить в заметки», которая ни на что не влияет, — это имитация действия. Сохранённое должно проверяться дальше.
- **Источник:** [S2], [S3].

### PAT-03. Предыстория по запросу (pull exposition)
- **Когда применять:** у истории есть прошлое (старое дело, давняя ссора), которое игроку нужно не сразу. **Когда нет:** без факта первую сцену не понять. Тогда одна строка сразу.
- **Схема:**
  ```
  [дело] ──┬── кнопка «помогу» ─────────────────┐
           └── кнопка «а что случилось?» → 2–3 строки прошлого ─┤
                                                 ↓
                         дальше: реплика, которая использует прошлое, только если спросил
  ```
- **На ink:**
  ```ink
  # title: Пример · Предыстория по запросу
  # contact: vera, Вера, pink
  VAR knows_flood = false
  мне нужен человек, который не из нашего посёлка #from:vera
  поможешь опросить соседей? #delay:10s
  * [Помогу #to:vera]
  * [А что у вас случилось? #to:vera]
      ~ knows_flood = true
      весной дамба #from:vera #delay:40s
      двое не выбрались
      больше не спрашивай #delay:20s
  - вот первый номер #from:vera #delay:15s
  {knows_flood:
      он был на дамбе той ночью #delay:10s
  }
  -> END
  ```
- **Цена:** короткий узел и флаг. Нужна страховка: тот, кто не спросил, должен узнать факт позже.
- **Ловушки:** спрятать по запросу то, без чего непонятна завязка. Забыть страховку, и тогда половина игроков дойдёт до финала, не зная ключевого факта.
- **Источник:** [S3], [S4].

### PAT-04. Отказ с ценой (вместо пустого refusal of the call)
- **Когда применять:** хочешь дать игроку сказать «нет» в завязке. **Когда нет:** отказ ничем не может отозваться позже. Тогда замени его сомнением.
- **Схема:**
  ```
  предложение → «да» ─────────────────────────────┐
              → «нет» → ~refused → давление (деньги, просьба) → «ладно» ─┤
                                                         ↓
                              герой помнит: тон, реплика, условие в финале
  ```
- **На ink:**
  ```ink
  # title: Пример · Отказ с ценой
  # contact: ellie, Элли, amber
  # contact: bank, Банк, lime
  VAR refused = false
  нужен человек на пару вечеров. только переписка #from:ellie
  * [Ок, давай #to:ellie]
  * [Нет, я пас #to:ellie]
      ~ refused = true
      понятно #from:ellie #delay:20s
      Элли перевела вам £12 · «если передумаешь» #from:bank #delay:2m
      ** [Верни деньги себе #to:ellie]
          не могу. больше никто не отвечает #from:ellie #delay:1m
      ** [Ладно. Что делать? #to:ellie]
  - {refused:
      спасибо. правда #from:ellie #delay:10s
  }
  вот номера #from:ellie #delay:15s
  -> END
  ```
- **Цена:** одна переменная и 1–2 реплики-отголоска в поздних главах.
- **Ловушки:** отголосок только в соседней строке. Отказ должен вспомниться хотя бы раз через главу, иначе он фальшивый (`P-06`).
- **Источник:** [S1], [S3]. Сам приём — наше.

### PAT-05. Лестница давления (escalating conflict)
- **Когда применять:** персонаж чего-то требует от игрока, а игрок тянет. **Когда нет:** сцена держится на доверии, а не на давлении.
- **Схема:**
  ```
  требование 1 (вежливо, пауза 3h) → уклон → требование 2 (короче, пауза 1h)
  → уклон → ультиматум со сроком (пауза 20m) → выбор без уклона
  ```
  Паузы сокращаются: время в relayer само работает как растущее давление.
- **На ink:**
  ```ink
  # title: Пример · Лестница давления
  # contact: judith, Джудит, teal
  VAR pressure = 0
  -> step
  === step ===
  ~ pressure += 1
  {pressure:
  - 1: Кто Вы? #from:judith #delay:3h
  - 2: Я спросила второй раз. #from:judith #delay:1h
  - 3: До пятницы. Потом я иду в полицию. #from:judith #delay:20m
  }
  {pressure >= 3: -> deadline}
  * [Позже объясню #to:judith]
      -> step
  * [Меня попросила Элли #to:judith]
      Понятно. #from:judith #delay:1m
      -> END
  === deadline ===
  * [Меня попросила Элли #to:judith]
      Поздно, но спасибо. #from:judith #delay:1m
      -> END
  * [Промолчать #to:judith #silent]
      Номер передан в полицию. #from:judith #delay:2h
      -> END
  ```
- **Цена:** узел-цикл со счётчиком. Текста мало.
- **Ловушки:** ступени одинаковы по силе. Ультиматум без последствий: если срок прошёл и ничего не случилось, следующей угрозе не поверят.
- **Источник:** [S4] (нарастающие конфликты). Сокращение пауз — наше.

### PAT-06. Антагонист объясняет себя сам
- **Когда применять:** в истории есть противник, который может писать игроку. **Когда нет:** угроза безлична (стихия, система). Тогда её голосом служит `#sys`.
- **Схема:** противник формулирует свою цель → показывает, что его логика по-своему разумна → даёт игроку возразить → помнит ответ.
- **На ink:**
  ```ink
  # title: Пример · Логика антагониста
  # contact: owen, Оуэн, blue
  VAR owen_knows = 0
  Доброе утро 🙂 #from:owen #delay:5h
  Давай по-взрослому
  Мне не нужна правда. Мне нужно, чтобы город успокоился #delay:10s
  Город успокоится — Элли оставят в покое #delay:10s
  * [Ты боишься за себя, а не за Элли #to:owen]
      ~ owen_knows += 1
      Я боюсь за всех. Я один тут что-то делаю 🙂 #from:owen #delay:1m
  * [Что ты предлагаешь? #to:owen]
      Файлы мне. Слушание проходит тихо #from:owen #delay:40s
  * [Промолчать #to:owen #silent]
      Молчание — тоже ответ. Я его запомню 🙂 #from:owen #delay:20m
  - -> END
  ```
- **Цена:** 3–5 реплик и одна развилка на каждое появление.
- **Ловушки:** злодей, который угрожает, но не объясняет. Злодей, который объясняет всё сразу: мотив тоже выдаётся порциями (`PAT-03`).
- **Источник:** [S1] (связные мотивы злодея). Схема из четырёх шагов — наша.

### PAT-07. Механика = характер (ludonarrative harmony)
- **Когда применять:** у игрока есть роль или легенда (студент, детектив, чужой голос). **Когда нет:** игрок — нейтральный свидетель без маски.
- **Схема:** выбор маски → каждая ложь копит счётчик → другие персонажи сверяют показания → ложь всплывает, её цена видна действием (удалил из контактов, не ответил).
- **На ink:**
  ```ink
  # title: Пример · Механика равна характеру
  # contact: kai, Кай, cyan
  # contact: tess, Тесс, pink
  VAR lies = 0
  * [Я студент, делаю опрос #to:kai]
      ~ lies += 1
  * [Помогаю подруге погибшей #to:kai]
  - ок. спрашивай #from:kai #delay:1m
  {lies > 0:
      Кай говорит, ты из колледжа. Это правда? #from:tess #delay:2h
  - else:
      Кай говорит, ты дружила с Лили. Это правда? #from:tess #delay:2h
  }
  * {lies > 0} [Да #to:tess]
      ~ lies += 1
      странно. в колледже про тебя не знают #from:tess #delay:30m
  * {lies > 0} [Нет. Опрос — это легенда #to:tess]
      спасибо за честность #from:tess #delay:5m
  * {lies == 0} [Не дружила. Помогаю её подруге #to:tess]
      значит он путает. или врёт #from:tess #delay:5m
  - {lies >= 2:
      Кай удалил вас из контактов #sys:kai
  }
  -> END
  ```
- **Цена:** счётчик и по одной реплике-сверке на главу.
- **Ловушки:** обвинить игрока в том, чего у него не было кнопки сделать. Дать вариант признания, который ничего не стоит и ничего не даёт.
- **Источник:** [S2] (дизайн и сюжет — вместе, а не против); термин ludonarrative harmony есть в книге по отзыву на [S6], уверенность: средняя. Счётчик лжи и сверка показаний — наше.

### PAT-08. Холодное открытие с мини-первым актом (time clock + первый акт)
- **Когда применять:** начало любой истории. **Когда нет:** продолжение сезона, где игрок уже знает героев. Там можно начать с действия без нормы.
- **Схема:** сообщение в середине чужой ситуации → кнопка через 1–3 сообщения → объяснение приходит в ответ на кнопку → 2–4 обмена нормы → пауза → поворот.
- **На ink:**
  ```ink
  # title: Пример · Холодное открытие
  # contact: nina, Нина, red
  VAR who = ""
  ты где?? #from:nina
  он сказал что ты едешь #delay:4s
  * [Кто сказал? #to:nina]
      ~ who = "ask"
  * [Еду. Что случилось? #to:nina]
      ~ who = "play"
  - водитель #from:nina #delay:6s
  номер твой. имя твоё
  {who == "ask":
      подожди. ты кто вообще #delay:10s
  - else:
      так ты едешь или нет #delay:10s
  }
  меня зовут Нина. я в такси уже 40 минут #delay:8s
  -> END
  ```
- **Цена:** нужно переписать открытие так, чтобы сведения шли ответами на вопросы игрока.
- **Ловушки:** холодное открытие, где игрок не понимает, кто он, дольше 3 обменов. Загадка в начале — одна, остальное ясно.
- **Источник:** [S2] (time clock), [S3] (терпение игрока, не выкладывать всё в начале); [S1] (первый акт). Склейка двух советов и пороги — наши.

### PAT-09. Перелом, который меняет цель (midpoint)
- **Когда применять:** второй акт длиннее двух глав. **Когда нет:** короткая история на 1–2 главы.
- **Схема:** игрок добывает то, что искал → оно отвечает на другой вопрос → цель переформулируется кнопкой игрока → появляется новый голос (`#unlock`).
- **На ink:**
  ```ink
  # title: Пример · Перелом в середине
  # contact: ellie, Элли, amber
  # contact: lily, +44 7700 900521, pink
  VAR goal = "find"
  -> mid
  === mid ===
  Глава 5 · Середина #sys:ellie #chapter
  посмотрела запись #from:ellie #delay:30m
  там не лили #delay:15s
  там денни. два года назад #delay:20s
  это не про её смерть. это про его #delay:20s
  * [Значит, ищем, кто был с Денни #to:ellie]
      ~ goal = "denny"
  * [Нам нужна только Лили #to:ellie]
  - {goal == "denny":
      тогда начни с тех, кто был там два года назад #from:ellie #delay:1m
  - else:
      как скажешь. но запись никуда не денется #from:ellie #delay:1m
  }
  я знаю, что ты смотрел запись #from:lily #unlock:lily #delay:3h
  -> END
  ```
- **Цена:** нужно заранее заложить второй вопрос в первом акте, иначе перелом выглядит совпадением.
- **Ловушки:** перелом рассказан, а не сделан: цель меняет герой, а игрок только читает.
- **Источник:** [S3] (midpoint по Сиду Филду в изложении Сколника). Требование «цель меняет кнопка игрока» — наше.

## Нюансы к приёмам (второй проход)

| приём | когда не работает | 5 сообщений | 50 сообщений |
|---|---|---|---|
| PAT-01 три акта | история < 10 мин; сцена-передышка | один поворот вместо трёх актов | три акта на главу или на сезон; перелом — на 45–55% входящих (`snyder-save-the-cat:P-10`) |
| PAT-02 лестница улик | улика — фон, который не проверяется дальше | одна улика кнопкой | 1–2 «делай», остальное «показывай»; каждая «делай»-переменная читается (`emshort-structures:P-15`) |
| PAT-03 предыстория по запросу | без факта не понять завязку | не нужна | один узел-вопрос плюс страховка в следующей главе |
| PAT-04 отказ с ценой | отголоску негде прозвучать | заменить сомнением | `refused` вспоминается через главу; можно отвечать нажимом (`inkle-ingold:P-12`) |
| PAT-05 лестница давления | сцена держится на доверии | две ступени, паузы 1m → 10s | три ступени с сокращающимися паузами; ультиматум обязан сработать |
| PAT-06 антагонист объясняет себя | мистери: мотив — разгадка | одна реплика «потому что» | мотив порциями, хотя бы одна развилка-спор |
| PAT-07 механика = характер | игрок — нейтральный свидетель | одна сверка в конце | сверка на каждую главу; проверить по `LESSON-13`, что ложь не выгоднее правды, если сюжет хвалит правду |
| PAT-08 холодное открытие | продолжение сезона | кнопка на 2-м входящем, нормы нет | кнопка до 5-го, 2–4 обмена нормы после |
| PAT-09 перелом | второй акт ≤ 2 глав | совмещён с единственным поворотом | новая цель кнопкой и новый голос `#unlock` |

**PAT-01 и LESSON-01.** Развилки «кого выбрать» на повороте 2 проверяй на равенство вложений. Перекос до 25/75, как с Дагом и Карли, превращает кульминацию в формальность.

**PAT-05 и тёмные паттерны.** Ультиматум со сроком — только в фикции. Если движок ждёт игрока, «до пятницы» означает пятницу персонажа, а не реальные сутки игрока (`attention.md`, раздел 5).
