## Что осталось под вопросом

- **Catalyst hero** (`PAT-07`, `P-03`): термин у Воглера, скорее всего, есть, но открытым источником не подтверждён. Если доступна легальная копия книги, сверить раздел об архетипе героя. Если нет, оставить «уверенность средняя».
- **Три выхода у стража порога** (`P-08`, `PAT-04`), **захват награды** (`P-11`), **возвращение вопроса из начала** (`P-13`), **круговая и открытая концовки** (`PAT-09`): всё это «знание модели, средняя». На этом стоят только примеры, а не проверки, так что вреда немного. Человеку стоит сверить с книгой.
- **Сайт автора** thewritersjourney.com при разборе не открылся. Перекрёстной проверки из первых рук, кроме интервью [FC], нет.
- **Пороги** (40–60% для испытания, «зов до 3-го входящего», ≥ 3 контакта в коде, разброс дуги ≥ 3) — наши, у Воглера чисел нет. Их нужно откалибровать на трёх историях каталога, когда появятся `V1–V13` в `check-story.mjs`.
- **Разметку** `// stage:`, `// mask:`, `// HERO:`, `// JOURNEY:` компилятор выбрасывает. Скрипту придётся разбирать сырой ink по номерам строк. Это решение для `check-story.mjs`, а не для этой папки.
- **Доли реплик по главам** в разборе посчитаны грубо, по сырому ink с наследованием `#from`. Для точных цифр нужен подсчёт по трассам бота.
