# Приёмы осмысленного выбора

Все примеры ink самодостаточны и компилируются (проверено inkjs). Имена персонажей вымышлены.

### PAT-01. Отложенный отклик (callback, delayed reminder)
- **Когда применять:** кнопка задаёт тон или факт, но ветвиться ради неё дорого. **Когда нет:** если отклик приходит в той же сцене — это просто ответ, а не напоминание.
- **Схема:** выбор → флаг → (1+ глава, сутки игрового времени) → условная реплика, лучше от другого контакта.
- **На ink:**
  ```ink
  # contact: rin, Рин, teal
  # contact: oleg, Олег, amber
  VAR covered_rin = false
  -> day1
  === day1 ===
  День 1 #from:rin #sys:rin #chapter
  олег спросит, где я была. скажешь, что со мной? #from:rin
  * [Скажу #to:rin]
      ~ covered_rin = true
      спасибо. правда #from:rin
  * [Врать не буду #to:rin]
      ок. поняла #from:rin #delay:2m
  - -> day2
  === day2 ===
  День 2 #from:oleg #sys:oleg #chapter #delay:2h
  рин вчера была с тобой? #from:oleg
  {covered_rin:
      она так и сказала. ну ладно #delay:30s
  - else:
      она сказала что одна. странно #delay:30s
  }
  -> END
  ```
- **Цена:** 1 переменная и 2–4 строки на отклик. Ветка не нужна.
- **Ловушки:** отклик, который игрок не связывает с выбором. Повтори в отклике ключевое слово кнопки. Не откликайся на всё подряд: напоминание теряет вес, если его слышишь после каждой кнопки. Отклик называет уже случившийся след («ты сказал, что она была с тобой»), а не обещает будущий («он это запомнит»): обещание без продолжения игрок потом считает обманом (P-09).
- **Источник:** [M] (reminders), [DG].

### PAT-02. Цена в двух чатах (tradeoff через `#to`)
- **Когда применять:** у игрока одна ценная вещь (сведение, фото) и два контакта, которым она нужна. **Когда нет:** если второй контакт об этом так и не узнаёт.
- **Схема:**
  ```
  находка ─┬─ #to:A → A доверяет больше, B узнаёт позже и обижен
           └─ #to:B → наоборот
  ```
- **На ink:**
  ```ink
  # contact: anon, Неизвестный номер, grey
  # contact: mira, Мира, pink
  # contact: dan, Дэн, blue
  VAR mira_trust = 0
  VAR dan_trust = 0
  -> find
  === find ===
  Фото: пропуск с чужой фамилией #from:anon #photo
  покажи одному из них. не обоим #delay:20s
  * [Фото пропуска #to:mira #label:Переслать Мире]
      ~ mira_trust += 1
      ~ dan_trust -= 1
      это его фамилия. дэну не говори #from:mira #delay:5m
      мира что-то знает и молчит. ты в курсе? #from:dan #delay:1h
  * [Фото пропуска #to:dan #label:Переслать Дэну]
      ~ dan_trust += 1
      ~ mira_trust -= 1
      понял. разберусь #from:dan #delay:5m
      это теперь у дэна?? #from:mira #delay:40m
  - -> END
  ```
- **Цена:** 2 переменные, по одной реплике на исход и одна проверка позже.
- **Ловушки:** если обе стороны потом ведут себя одинаково, компромисс фальшивый (`RED-04`).
- **Источник:** [F] (tradeoffs); `#to` — наше.

### PAT-03. Зеркало выражения (expressive choice + mirror)
- **Когда применять:** знакомство, утешение, прощание — места, где сюжету нечего решать. **Когда нет:** в момент решения, где игрок ждёт последствий, а получит только тон.
- **Схема:** 2–3 кнопки разного тона → переменная тона или имени → подстановка `{var}` или условная реплика позже.
- **На ink:**
  ```ink
  # contact: vera, Вера, purple
  VAR nick = "Ли"
  VAR tone = ""
  -> meet
  === meet ===
  как тебя называть? #from:vera
  * [Ли #to:vera]
  * [Ника #to:vera]
      ~ nick = "Ника"
  - а что ты думаешь про всю эту историю? #from:vera #delay:20s
  * [Мне страшно, если честно #to:vera]
      ~ tone = "soft"
  * [Думаю, кто-то врёт #to:vera]
      ~ tone = "hard"
  - -> later
  === later ===
  {nick}, ты тут? #from:vera #delay:3h
  {tone == "soft":
      я тоже боюсь. первый раз кто-то сказал это вслух
  }
  {tone == "hard":
      в точку. врёт
  }
  -> END
  ```
- **Цена:** дёшево, 1–2 переменные.
- **Ловушки:** тон, на который никто не реагирует; кнопки, у которых текст разный, а ответ одинаковый (`RED-01`).
- **Источник:** [F] (personal), знание модели, уверенность средняя.

### PAT-04. Молчание с последствием (`#silent` как ход)
- **Когда применять:** всегда, когда есть `#silent`. **Когда нет:** не добавляй «Промолчать» туда, где у молчания не может быть смысла (ответ на «ты тут?» сразу после своего же сообщения).
- **Схема:** молчание → собеседник решает сам / пишет другому / обижается → своя переменная.
- **На ink:**
  ```ink
  # contact: ira, Ира, amber
  # contact: gleb, Глеб, grey
  VAR ira_alone = false
  -> ask
  === ask ===
  я иду туда одна. скажи что это глупо #from:ira
  * [Это глупо. Подожди меня #to:ira]
      ладно. жду #from:ira #delay:1m
  * [Промолчать #to:ira #silent]
      ~ ira_alone = true
      понятно #from:ira #delay:15m
      Ира не в сети #sys:ira
      ира сказала ты в курсе куда она пошла #from:gleb #delay:2h #unlock:gleb
  - -> END
  ```
- **Цена:** одна переменная и 2–3 строки. Бывает, что молчание открывает чат: дорого, но заметно.
- **Ловушки:** молчание → пауза → тот же вопрос с одной кнопкой (`RED-06`).
- **Источник:** наше применение [M] (awareness, consequences).

### PAT-05. Ветвление с бутылочным горлышком и осадком (branch and bottleneck with residue)
- **Когда применять:** нужна видимая развилка на 1–2 узла, а дальше история сходится. **Когда нет:** если ветки после схождения ничем не различаются, это `RED-03`.
- **Схема:**
  ```
  выбор ─┬─ ветка А (2–6 сообщений, флаг a) ─┐
         └─ ветка Б (2–6 сообщений, флаг b) ─┴─ горлышко → отклик по флагу
  ```
- **На ink:**
  ```ink
  # contact: kai, Кай, cyan
  VAR went_roof = false
  -> night
  === night ===
  на крыше кто-то есть. проверить? #from:kai
  * [Иди посмотри #to:kai]
      ~ went_roof = true
      -> roof
  * [Не ходи. Запрись #to:kai]
      -> door
  === roof ===
  никого. только окурок. ментол #from:kai #delay:4m
  -> morning
  === door ===
  заперся. наверху кто-то ходил до трёх #from:kai #delay:3h
  -> morning
  === morning ===
  утро. я поговорил с соседом #from:kai #delay:5h
  {went_roof:
      он курит ментол. сказал что не поднимался
  - else:
      он сказал что ночью было тихо
  }
  -> END
  ```
- **Цена:** 2 узла и 1 переменная. На карте видна развилка.
- **Ловушки:** осадок только в одной реплике сразу после горлышка. Его стоит повторить ещё раз позже (`PAT-01`).
- **Источник:** термин из теории CYOA (Sam Kabo Ashwell, см. `docs/books/ashwell-standard-patterns/`); связь с последствиями — [SZ] (integrated).

### PAT-06. Счётчик с озвученным порогом
- **Когда применять:** много мелких кнопок кормят одно отношение (`ellie_trust`, `jess_clues`). **Когда нет:** если порог ни на что не влияет.
- **Схема:** `+1/−1` на кнопках → при пересечении порога персонаж прямо говорит о перемене → дальше открывается условная кнопка.
- **На ink:**
  ```ink
  # contact: tai, Тай, lime
  VAR tai_trust = 0
  -> talk
  === talk ===
  ты мне веришь? #from:tai
  * [Да #to:tai]
      ~ tai_trust += 1
  * [Пока нет #to:tai]
  - а если я скажу, что была там? #from:tai #delay:30s
  * [Тогда расскажи всё #to:tai]
      ~ tai_trust += 1
  * [Тогда ты врала полиции #to:tai]
      ~ tai_trust -= 1
  - (gate)
  {tai_trust >= 2:
      ладно. тебе скажу. только тебе #from:tai
  }
  * {tai_trust >= 2} [Что ты видела? #to:tai]
      лодку. без огней #from:tai #delay:1m
  * [Ладно, потом #to:tai]
  - -> END
  ```
- **Цена:** дёшево. Важна только строчка озвучки порога.
- **Ловушки:** счётчик с 14 записями и 2 чтениями (как `jess_clues`) — игрок копит, не зная что. Проговаривай рост хотя бы раз до решающей проверки.
- **Источник:** [M] (awareness, reminders); счётчик и порог — наше применение.

### PAT-07. Сводка перед решающим выбором (evidence recap)
- **Когда применять:** финал или крупная развилка зависит от накопленных флагов. **Когда нет:** если исход не зависит от прошлого.
- **Схема:** персонаж спрашивает «что у тебя есть?» → условные строки перечисляют собранное → выбор.
- **На ink:**
  ```ink
  # contact: june, Джун, red
  VAR has_bill = true
  VAR has_photo = false
  VAR has_voice = true
  -> recap
  === recap ===
  прежде чем решать. что у нас есть? #from:june
  {has_bill:
      распечатка звонков — есть #delay:20s
  }
  {has_photo:
      фото с лестницы — есть #delay:20s
  - else:
      фото с лестницы — нет #delay:20s
  }
  {has_voice:
      голосовое — есть #delay:20s
  }
  этого хватит, если она сама подтвердит #delay:30s
  * [Идём к ней сейчас #to:june]
  * [Сначала найдём фото #to:june]
  - -> END
  ```
- **Цена:** 4–8 строк, переходов не добавляет.
- **Ловушки:** сводка, где перечислено всё, но не сказано, хватит ли этого. Персонаж должен оценить расклад.
- **Источник:** наш вывод из [C] (predictability) и [M] (awareness).

### PAT-08. Ритмическая кнопка (pacing beat)
- **Когда применять:** длинный монолог собеседника из 6+ сообщений, нужна пауза для вовлечения. **Когда нет:** вместо реального решения в конце сцены.
- **Схема:** 2 короткие реакции, у каждой свой ответ; дальше без перехода.
- **На ink:**
  ```ink
  # contact: sol, Сол, orange
  -> beat
  === beat ===
  и тут он достаёт ключ. от НАШЕЙ двери #from:sol
  * [Что?? #to:sol]
      вот и я так сказала #from:sol #delay:20s
  * [Откуда у него ключ #to:sol]
      вот это и есть вопрос #from:sol #delay:20s
  - дальше хуже #from:sol #delay:30s
  -> END
  ```
- **Цена:** по одной строке ответа на кнопку.
- **Ловушки:** обе кнопки без ответа (`RED-01`); одна кнопка «далее» (`RED-05`).
- **Источник:** [C] (когда выбор лишний); знание модели о ритме, уверенность средняя.

### PAT-09. Закрытая дверь (visible permanence)
- **Когда применять:** решение должно ощущаться бесповоротным. **Когда нет:** если контакт нужен сюжету позже — тогда закрой не весь чат, а одну тему.
- **Схема:** выбор → контакт перестаёт отвечать (`#sys`) → позже в этом чате приходят только системные строки или прочтение без ответа.
- **На ink:**
  ```ink
  # contact: nik, Ник, grey
  VAR nik_gone = false
  -> push
  === push ===
  ещё раз спросишь про брата — я пропаду #from:nik
  * [Где был твой брат в ту ночь? #to:nik]
      ~ nik_gone = true
      Ник не в сети #sys:nik #delay:1m
  * [Ладно. Не буду #to:nik]
      спасибо #from:nik #delay:30s
  - -> later
  === later ===
  {nik_gone:
      Прочитано #sys:nik #delay:4h
  - else:
      я подумал. брат был со мной #from:nik #delay:4h
  }
  -> END
  ```
- **Цена:** дёшево, а эффект сильный: молчание контакта видно в списке чатов.
- **Ловушки:** контакт «пропал», а через главу пишет как ни в чём не бывало, без оговорки.
- **Источник:** [M] (permanence, gameplay consequences); перевод на мессенджер — наш.

# Второй проход

### PAT-10. Эпилог со следами (epilogue traces)
- **Когда применять:** финал выбирает скрытая проверка или общий маршрут, а выборов по ходу много. **Когда нет:** если финал и так собран из последнего выбора и его прямых следствий, а история короче 15 минут.
- **Схема:** финальная реплика маршрута → 2–3 условных блока на переменные из разных глав → `END`. Порядок: от самого раннего решения к самому позднему, последнее — то, о котором игрок мог забыть.
- **На ink:**
  ```ink
  # contact: lena, Лена, teal
  # contact: notes, Заметки, green
  VAR told_lena = true
  VAR kept_photo = false
  VAR proof = 1
  -> door
  === door ===
  решай. идём к ним или нет #from:lena
  * [Идём #to:lena]
  * [Промолчать #to:lena #silent]
      я решила сама #from:lena #delay:5m
  - {proof >= 2:
      они поверили #from:lena #delay:1m
  - else:
      нам не поверили #from:lena #delay:1m
  }
  -> traces
  === traces ===
  {told_lena:
      ты тогда написал мне первой. я помню #from:lena #delay:20s
  }
  {kept_photo:
      фото с лестницы так и лежит у тебя #from:notes #delay:20s
  - else:
      фото ты отдал. может, зря #from:lena #delay:20s
  }
  -> END
  ```
- **Цена:** 2–3 условных блока по 1–2 строки на каждый `fin_*`, переходов не добавляет. Блоки можно вынести в общий узел `traces`, как в примере.
- **Ловушки:** перечислить всё подряд — игрок читает список, а не историю; хватит трёх. След без ключевого слова кнопки игрок не узнает (`attention.md`, дальность отклика). Не делай общий узел единственным местом отклика: тогда эпилоги разных финалов звучат одинаково.
- **Источник:** LESSON-07 (Mass Effect 3: эпилоги добавили, когда игроки сочли выборы обесцененными); [M] (reminders). В «Чужом голосе» `fin_herself` и `fin_puppet` содержат по одному условному блоку — кандидаты.

### Нюансы к приёмам

| PAT | когда не работает | пограничный случай | 5 сообщений / 50 сообщений |
|---|---|---|---|
| PAT-01 отклик | ветка, куда попадает мало игроков: отклик дорог и никем не прочитан (LESSON-01) | отклик через сутки реального времени — повторить ключевое слово кнопки | 5: последнее сообщение; 50: следующая глава, третий контакт |
| PAT-02 цена в двух чатах | оба контакта потом ведут себя одинаково (RED-04); один контакт игроку безразличен, и выбор очевиден (LESSON-02) | у обоих контактов была своя сцена симпатии и сомнения до выбора | 5: два контакта уже знакомы; 50: прошлая глава готовит обоих |
| PAT-03 зеркало | тон на месте решения (RED-10) | имя отражено сразу — достаточно и без отложенного отклика | 5: подстановка в следующей реплике; 50: в финале |
| PAT-04 молчание | пауза, заданная игрой, принята за молчание игрока | молчание как единственная честная реакция (Oxenfree, LESSON-08): у него своя строка, даже если сюжет сходится | 5: своя строка; 50: своя переменная и отклик |
| PAT-05 горлышко с осадком | осадок звучит один раз сразу после схождения | два узла по 2 сообщения — почти реплика; осадок важнее длины ветки | 5: одна развилка на всю историю; 50: 3–5 |
| PAT-06 счётчик | порог озвучен, но игрок не знает, что его копил | поведение вместо слов (Life is Strange 2, LESSON-09) — у нас только реплики, озвучка обязательна | 5: не нужен, хватит флага; 50: 1 озвучка на порог |
| PAT-07 сводка | персонаж называет «правильный» финал (`messenger-genre:P-15`) | оценка «хватит ли для этого шага», а не «какой финал» | 5: 2 строки; 50: 3–5 строк, по одной на улику |
| PAT-08 ритм | вместо решения в конце сцены | ритмическая кнопка с переменной тона — уже PAT-03 | 5: 1–2; 50: ≤ 3 подряд |
| PAT-09 закрытая дверь | после потери нет нового хода — игрок бросает (LESSON-06) | закрыть тему, а не контакт | 5: `#sys` не в сети; 50: проверка блока везде, где контакт пишет |
| PAT-10 эпилог | финал из 3 строк: эпилог длиннее самого финала | один общий узел следов на все финалы | 5: одна строка следа; 50: 2–3 блока на финал |
