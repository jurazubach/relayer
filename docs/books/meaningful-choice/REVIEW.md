## Что осталось под вопросом

- **Мейер: situational / personal / persistent.** Filament Games называет их без определений (продолжение статьи не найдено). Толкования в P-05, P-06 и P-08 модельные. Человеку стоит посмотреть фрагмент записи GDC 2012 (по курсу Chemeketa — примерно 37:00–44:37) и сверить.
- **Schell.** Линзы про осмысленный выбор, triangularity и dominant strategy указаны по памяти, без номеров. Проверить по бумажной книге или убрать упоминания.
- **Пороги** (20 % в P-07, 50 % в P-09 и проверке 4, 85 % в P-04, 30 % в проверке 11, пороги проверки 13) — наши эвристики, а не из источников. Откалибровать на трёх историях каталога, когда проверки попадут в `check-story.mjs`.
- **Счётчики RED-07** (`jess_clues` 14/2 и т. д.) посчитаны регулярками. Перепроверить, когда появится проверка на `parseInk`.
- **Определение «пустой кнопки».** `parseInk` считает пустой кнопку без тела, даже если сразу после схождения идёт условная реплика по переменной, заданной раньше. Проверке 1 нужен разбор «тело + ближайший gather», иначе будут ложные срабатывания.
