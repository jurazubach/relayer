# Мутанты

24 копии одной маленькой истории, в каждой — один дефект. По ним меряют, ловят ли `story:lint` и
скиллы то, что должны (`build-plan.md` §10 T-13, §13 Э2: полнота по мутантам).

- `_base/` — основа: «Вешний · Холодная комната», 4 главы, детектив на полярной станции. Чистая:
  `story:lint` не даёт на ней ни ошибок, ни предупреждений, ни подсказок. Разметка по `build-plan.md` §9:
  шапка из 4 строк, `// reveal:`, `// финал:`. Всё вымышлено.
- `m01-…/` … `m24-…/` — мутанты: `story.ink` + `meta.json`. Руками не правятся.
- `key.json` — ключ: `zone` (скилл, который должен найти дефект), `check` (C-NN, которая его меряет),
  `node` (узел), `broken` (что сломано), `lint` (проверки линта, которые ловят мутанта уже сейчас).

Правки мутантов описаны в `scripts/lab/mutants-spec.mjs` парами «найти → заменить» относительно основы.
Поменял основу или спецификацию — пересобери:

```bash
npm run skills:test -- --build        # папки мутантов и key.json
npm run skills:test                   # story:lint: основа чистая, мутанты своей зоны пойманы
npm run skills:test -- --skill story-pauses [--runs 3] [--min] [--control]
npm run test:lab:mutants              # самопроверка: сборка, ключ, разбор ответа скилла
```

## Как считается

**Линт.** Находки мутанта сравниваются с находками основы по проверке, ключу порога и узлу. Мутант пойман,
если появились все проверки из `lint` и его собственная `check`, когда она уже есть в `scripts/lint/checks/`.
Проверки ещё нет — мутант «ждёт» её: он в отчёте, но прогон не роняет. Как только проверку добавят
(вторая волна T-03b), мутант начнёт ждаться автоматически. Порог — `lab.mutants.lint_min_recall`.

**Скилл.** Мутант копируется во временную папку с нейтральным id, ключ и спецификация закрыты от чтения
(`--disallowedTools Read(./docs/lab/mutants/**)`, `Read(./scripts/lab/**)`). `claude -p` вызывает скилл
через `Skill` и в конце выводит находки JSON-блоком. Попадание — находка в узле дефекта (или его stitch)
либо с той же C-NN. Прогоны, где скилл не вызван, — промах; где отказано в правах и находок нет — не
состоялись и в полноту не входят. Порог `--min` — `lab.mutants.skill_min_recall`, прогонов —
`lab.mutants.skill_runs`. `--control` гоняет скилл и на основе: сколько находок он даёт на чистой истории.

## Ключ основы (LOCAL-07, LOCAL-14)

Основа чиста для линта, но не для модели. X-E2 починил три дефекта, которые скиллы находили на основе (`ch3_call` —
кнопкам даны свои ответы, `clue_badge` — убрана мёртвая ветка `not clue_badge`, `ch3_end` — исход сделки под нажатой
кнопкой, а не по счётчику), и завёл `BASE_KEY` в `scripts/lab/mutants-spec.mjs`: что в основе ещё сломано или спорно
(B01…B18 — узлы, слова находки, вид, статус). Находка скилла на основе, которая попадает в ключ, — верная, а не шум.
Сверка — `node docs/lab/runs/X-E2/control.mjs [папка с mutants-*.json]`. `skills:test` и `key.json` от ключа основы
не зависят. Основу правишь — правь и `BASE_KEY`: починенное — `status: 'починен'`, новое — новой строкой.
