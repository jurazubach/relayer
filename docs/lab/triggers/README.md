# Фразы для теста срабатывания скиллов

`npm run lab:triggers` гоняет каждую фразу через `claude -p` из корня репозитория и смотрит, какой скилл
вызвался. Результат — доля по нескольким прогонам: модель недетерминирована, одного прогона мало.
Справка — `npm run lab:triggers -- --help`, как разбирается поток — `docs/playbook/claude-code-format.md` §4.2.

## Файлы

| файл | что внутри |
|---|---|
| `<скилл>.json` | фразы одного скилла: `positive`, `negative`, необязательно `neighbors` |
| `_routing.json` | `{ "фраза": "скилл" \| "none" }` — общая раскладка «симптом → скилл» поверх всех скиллов |
| `_env.json` | какие нечужие скиллы могут стоять в листинге (встроенные Claude Code) |
| `_template.json` | шаблон файла фраз |
| `_example.json` | пример на скилл из плана (`story-pauses`) |

Файлы на `_` скиллами не считаются. Фразы скилла, которого ещё нет в `.claude/skills/`, пропускаются:
файлы можно класть заранее.

## Файл скилла

```json
{
  "skill": "story-pauses",
  "neighbors": ["story-time", "story-pace"],
  "positive": ["Перед паузой глава просто обрывается…"],
  "negative": [
    { "text": "Сколько должна длиться история в реальном времени?", "expect": "story-time" },
    { "text": "Почини падающий e2e-тест", "expect": "none" },
    "фраза, на которую скилл не должен сработать, куда уйдёт — неважно"
  ]
}
```

- `positive` — 8–15 фраз, на которые скилл должен сработать. Словами автора: симптомы и просьбы, а не имя
  скилла. Разной длины и тона: короткие («начало не цепляет»), с контекстом, с опечатками.
- `negative` — 5 и больше соседних фраз: похожих по теме, но принадлежащих другому скиллу. Строка проверяет
  только «не этот скилл»; объект с `expect` — ещё и куда фраза должна уйти.
- `neighbors` — с кем скилл легко спутать. Скиллы из `expect` в негативах попадают в соседи сами.
- Истории в фразах выдуманные: ни героев, ни узлов наших трёх историй.

## Что считается

- **Попадание** — первый вызов `Skill` вне агентов совпал с ожидаемым.
- **Ложное** — скилл сработал на чужой фразе: негатив, позитив соседа, маршрут к другому скиллу или `none`.
- **Обход** — модель прочитала `SKILL.md` через Read или Bash вместо `Skill`. Попаданием не считается.
- `--skill <имя>` берёт фразы скилла, положительные фразы соседей (не перехватывает ли он их) и маршруты
  к ним всем.
- `--min` даёт код выхода 1, если у какого-то скилла доля попаданий ниже порога или ложных больше
  `lab.triggers.max_false_rate`.

Результаты пишутся в `docs/lab/runs/triggers/<дата>.json`.
