- **Выбор легенды игнорируется.** Если сказать «скажу правду: помогаю знакомой», Джесс всё равно отвечает «омг да!! заполню… ваучер на что?» (`ch01.ink:143`, ветки по `cover` нет). Читатель здесь споткнулся: «мой выбор будто не засчитался».
- **Событие приходит поздно.** Смерть и срок приходят на 9-м сообщении, уже после первой кнопки.
- **Сразу за этим — лекция.** Дальше Элли пишет 14 реплик подряд без кнопки.
