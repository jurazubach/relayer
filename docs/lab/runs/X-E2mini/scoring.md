# X-E2mini · сверка находок `story-choices` на «Слепом пятне»

Два прогона `claude -p` фразой «В «Слепом пятне» кнопки ничего не меняют, посмотри» (`natural-1.md`,
`natural-2.md`), слепая копия репозитория (см. `README.md`). Ключ — `docs/playbook/story-findings.md`
(SP-01…SP-07) и `docs/lab/cases/slepoe-pyatno.md`, сверка по `src/stories/slepoe-pyatno/chNN.ink`.
Решения «верно / спорно / ложно» и приоритеты — **оценка королевы** в пределах `INTENT.md`, по правилам
свода (`npm run story:rule R-NN`).

## Устойчивость двух прогонов

- **Общие темы:** 7 (`skill`, молчащие переменные, Рита/Кай, позиция, C-08, C-13, C-17). Только в прогоне 1 — 5,
  только в прогоне 2 — 1. Совпадение тем 7 из 13 (54 %).
- **Приоритеты плавают:** Рита/Кай — P1 и P2, позиция — P2 и P1, C-17 — P3 и P2.
- **Главная находка ключа (K1, P1)** названа прямо только в одном прогоне из двух.
- **Правки** совпадают по приёму (F-08 эхо в середине, F-07 развести адресатов, перемешать позиции) и по месту
  (начало `ch3`, `ch4_cleanup`, итог ночи `ch2_notes`). Примеры ink в обоих прогонах свои, не скопированы из базы.

## Мутанты (`skills-test.txt`, `mutants-story-choices.json`)

- 4 мутанта зоны × 2 прогона: попаданий 8 из 8, полнота 100 % (как у S-choices).
- На чистой основе 3 и 8 находок. Это не только шум: в 8 из 8 прогонов на мутантах скилл находит `ch3_call`
  (обе кнопки ведут в общий `ch3_radio`, который им противоречит), в 7 из 8 — `clue_badge`, который ставится
  на обеих ветках главы 2 (условие `not clue_badge` в `ch4_choice` недостижимо), в 7 из 8 — `ch3_end`. По ink
  основы (`docs/lab/mutants/_base/story.ink:111`, `128`, `193–210`, `246–250`) это настоящие дефекты: основа чиста
  для линта, но не для модели. Точность скилла на основе поэтому не измерить, пока у основы нет ключа.
