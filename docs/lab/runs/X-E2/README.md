# X-E2 · сырые результаты Э2

Э2 после волны диагноза, 2026-10-26: `story-review` на отложенной истории «Чужой голос» (калибровка — THE NUMBER
и «Слепое пятно») и мутанты всех десяти диагностических скиллов. Запись в журнале — `docs/lab/journal.md`,
сверка — [scoring.md](scoring.md).

| файл | что |
|---|---|
| `cal-tn-1`, `cal-tn-2`, `cal-sp-1`, `cg-1` … `cg-9` | прогоны `claude -p` фразой автора: `<прогон>.md` — сжатый транскрипт (шаги главной сессии и агентов, начало результатов, отказы, ответ целиком), `<прогон>.result.json` — итог (ходы, стоимость, отказы, ответ), `<прогон>.review/` — папка прогона ревью из слепой копии: ответы линз `lens-*.md`, холодных читателей `cold-*.md`, `qa-six.md`, `merged.json`, `report.md` (вывод `report.mjs --explain`), `items.txt` (пункты `merged.json` строками) |
| `mutants-<скилл>.json` | `npm run skills:test -- --skill <скилл> --control --runs 3 --jobs 3` по десяти диагностическим скиллам |
| `key-findings.json` | ключ: 28 находок `story-findings.md` с узлами, переменными и словами для поиска кандидатов |
| `judgments.json` | отметки: полнота по прогонам, точность, новые верные находки (оценка в роли автора) |
| `scoring.md` | сверка: полнота, точность, устойчивость, недействительные прогоны, мутанты, пороги |

Инструменты (у каждого `--help`):

| файл | что |

## Как прогоняли

- Слепая копия на каждый прогон (`blind.mjs`), `node_modules` — ссылка, свой `git init` и тег `stories-v1` на слепом
  коммите. Чтение исходного репозитория закрыто правилом `Read(//Users/…/dev/**)`.
- Права (`run.mjs --help`): `Read, Grep, Glob, Skill, Agent`, `Write/Edit(.story-review/**)`, `Bash(npm run story*)`,
  `Bash(npm run -s story*)`, `Bash(node scripts/*)`, `Bash(node .claude/skills/*)` (и абсолютный путь копии),
  `Bash(grep *)`; запрещены `WebFetch`, `WebSearch`, запись в `docs/` и `src/`. `--permission-prompts none`,
  `--max-turns 250`, модель `claude-opus-5-5`.
- Прогоны шли параллельно, каждый в своей копии. Поток `stream-json` целиком (2–2,7 МБ на прогон) в репозиторий не
  положен; `lint.json` из папок прогона удалён — это вывод `story:lint` той же ревизии (`docs/lab/runs/T-15/*.lint.json`).
- Остались в копии: строки калибровки в `thresholds.json` (`history`, `calibrated_on`), где упомянуты узлы и одна
  кнопка «Чужого голоса» (выводы команд, а не находки), и ядро `decisions.md` D-01 со ставкой истории — это знание
  автора о своей истории.
