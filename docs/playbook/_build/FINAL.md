## Что построено

### Скиллы (`.claude/skills/`)

Входы — 8 скиллов, их автор зовёт словами. Модули — 13 (`user-invocable: false`), их зовут входы или главная
сессия по таблице «симптом → скилл» в [`CLAUDE.md`](../../../CLAUDE.md).

| этап | скилл | что делает |
|---|---|---|
| состояние | `story-desk` | где история в цикле, решения D-NN, банк идей, что устарело |
| идея | `story-brainstorm` | 3–5 разных направлений с трейлером на 5 сообщений |
| ядро | `story-core` | ставка, вопрос, оси, роль игрока, противник, время мира; пишет шапку |
| план | `story-plan` | скелет до текста, развилки, паузы, платная граница, число глав — по содержанию |
| куда свернуть | `story-branch` | ходы с влиянием на оси и финалы, бюджет дорогих веток |
| главы | `chapter-write` | глава по плану, стилю, обоим режимам, с напоминаниями |
| ревью | `story-review` | оркестратор: линзы, холодный читатель, QA, отчёт P1–P3 |
| диагноз | `story-opening`, `story-pace`, `story-pauses`, `story-time`, `story-choices`, `story-endings`, `story-cast`, `story-voice`, `story-continuity`, `story-mystery` | десять линз по болям автора |
| тест | `story-playtest` | панель холодных читателей (5 профилей), пакет и анкета для тестеров |
| правка | `story-fix` | применяет только одобренное, дифф до и после, страховка, повтор линзы |
| выпуск | `story-release` | гейт, карточка с двумя временами, затравки без спойлеров, этика, ревизия |
| знания | `story-kb` | ответы по 30 разборам со ссылками, наставник, упражнения |

В каждом скилле есть режим «объясни»: почему так, откуда правило и как сделать самому.

### Агенты (`.claude/agents/`)

| агент | кто зовёт | что делает |
|---|---|---|
| `story-auditor` | `story-review` | одна линза изолированно, только чтение |
| `cold-reader` | playtest, review и др. | запускает чистого читателя (`story:cold-read --ask`), сам историю не читает |
| `story-architect` | plan, core, branch | 2–3 варианта плана со скелетами и сравнением числами, пишет только в `plans/` |
| `chapter-writer` | `chapter-write` | одна глава в фоне, только своя глава |

У каждого агента свой сторож прав (`scripts/hooks/agent-guard.mjs`). Ни один агент не запускает других.

### Движок и интерфейс

- Два режима, «реальное время» и «по клику». Режим выбирают на экране истории, сменить его можно только
  перезапуском.
- Напоминания молчащему игроку `#remind` / `#noanswer`. Персонаж не упрекает игрока и не называет срок.
- Уведомления выключаются внутри игры.
- Журнал выборов выгружается для тестеров.
- Ревизия хранится в сохранении: несовместимое сохранение сбрасывается с предупреждением.
- Бесплатная граница на стыке глав. Покупка пока заглушка.
- Большие карточки:
  - на всю ширину;
  - затравки показаны сообщениями;
  - число героев;
  - два времени, по клику и в реальном времени;
  - без глав.
- Скрытые истории: `hidden: true`, открываются по `?story=` или `?all=1`.

## Решения, которые я приняла за автора

Полный журнал — `runtime/QUEEN-LOG.md` (не в git). Главные решения:

- **Время и режимы.**
  - Метка «спустя N» в режиме «по клику» — от 1 ч.
  - «Не ответил» ведёт в `#silent`, если он есть.
  - В режиме «по клику» напоминаний нет.
  - Напоминания обязательны в каждой развилке, где собеседник ждёт ответа. Движок сам их не ставит: старые
    истории не ломаются.
- **Проверки.**
  - Финал — это метка `// финал:` на пути; общий END после размеченных веток допустим.
  - «Заметки» — служебный контакт, а не персонаж.
  - Игрок («Вы») — не герой.
  - 9 расхождений порогов — оставлены значения, откалиброванные на замере.
- **Порядок работы.**
  - Скиллы создания не ждали волну ремонта: ускорение по просьбе автора.
  - Экономный режим на лимитах: тоже по просьбе автора.
  - Мутантов не плодить ради числа.
- **«Чужой голос».**
  - Состояние трёх историй заведено на шаге «ревью».
  - Ядро v0 восстановлено из текста.
  - Ревизия поднята 2 → 3 после правки, сделанной уже после гейта (тестеры ещё не начинали).
  - Решения Э7 D-03…D-10 приняты в пределах `INTENT.md`.
- **Читатели.** Холодный читатель — только на Opus. Итог читателя — шкала интереса по точкам, а не «да / нет».
- **Правка.** Диагностические скиллы не правят сами, правку применяет только `story-fix`. Одобрение — в
  разговоре.
- **Права.** `story-fix`, `story-core`, `story-plan` и `story-release` получили `Edit` своих путей.

Решения, которые принял сам автор по ходу:
- всё сразу в `master` и деплой;
- только «Чужой голос»;
- скрыть две истории;
- отменить новую историю;
- главы невидимы игроку;
- большие карточки;
- экономный режим и лимит до 100 %.

## Что ждёт автора

- **INBOX пуст.** Ни одна задача не упала окончательно, вопросов «только к автору» не осталось.
- **Живой тест «Чужого голоса»**, пакет лежит в `docs/stories/chuzhoy-golos/playtests/wave-1/`.
  1. Отдать друзьям `chuzhoy-golos-w1.story.json`, бриф нужного режима (`brief-realtime.md` или
     `brief-click.md`) и анкету `survey.md`.
  2. Тестер открывает сайт, нажимает «Загрузить историю» и выбирает режим. После финала выгружает журнал
     выборов из отладки.
  3. Ответы и журналы показать Claude фразой «вот что ответили тестеры». Скилл `story-playtest` сведёт их по
     типам: скучно, непонятно, не верю, нестыковка, баг. Маршрут тестера повторяется командой
     `story:trace --from-save`.
  4. Дальше `story-review` → `story-fix` и, если нужно, план v2 (`story-plan`, `story-branch`).
- **Новая история.** Просто скажи «есть идея — …»: `story-brainstorm` подхватит, а дальше по таблице
  «симптом → скилл».
- **Открытый вопрос:** у THE NUMBER остался флаг «активная: да», хук пишет ⚠. Его можно снять или переключить
  `story-desk` фразой «сделай активной Чужой голос».
- **Хвостовая задача** (по желанию) — по `reports/F-final/checkpoint.md`, «Правки».
