# T-00 · Формат скиллов и агентов Claude Code, чистка окружения — сборка

## Сделано
- `docs/playbook/claude-code-format.md` — проверенные факты о Claude Code 2.1.310, у каждого метка [док] / [эксп]:
  поля скиллов и агентов, ссылки на references/scripts, листинг и бюджет (замер до и после чистки), скрытие
  из листинга, `context: fork`, что получает агент (CLAUDE.md, память, git status), вложенные агенты и скиллы
  из агента, хуки (формат, вход, что видит модель), `claude -p` для холодного читателя и теста срабатывания,
  протоколы 10 экспериментов, итог по предположениям `flow-review.md` §D, раздел «Что это значит для плана».
- `.claude/settings.json` (новый) — отключены 7 плагинов (`enabledPlugins: false`), коннекторы claude.ai
  (`disableClaudeAiConnectors`), через `skillOverrides` скрыты 18 личных/synced скиллов, `claude-api` — `name-only`.
- `docs/playbook/_build/reports/T-00/requests.md` — правки в `flow-review.md`, `build-plan.md`, `CLAUDE.md`, которые задаче менять нельзя.

## Решения
- Отключил все плагины и все коннекторы: ни один не про истории. `brightdata-plugin` перехватывает веб-поиск,
  `engineer:pr-create` требует коммитов без ИИ-подписи, а это противоречит правилам конвейера.
- Сверх плагинов и MCP скрыл через `skillOverrides` личные и synced скиллы, не относящиеся к историям: без этого
  освобождалась только часть листинга. Оставил `skill-budget-audit`, `skill-creator`, встроенные скиллы.
- `claude-api` — `name-only`, а не `off`: его агрессивный триггер на любое упоминание Claude давал бы ложные
  срабатывания в проекте про скиллы Claude Code, но вызов по имени остаётся.
- `skillListingBudgetFraction` не поднимал: после чистки запас около 22 000 знаков. Рекомендация на случай
  тесного бюджета (модули в `name-only`) — в документе, §9.
- Эксперименты механики гонял на `haiku` (поведение Claude Code от модели не зависит), замер листинга — на Opus 5.5
  в этом worktree.
- Для модулей предложил `user-invocable: false` вместо «скрыть и читать по пути»: эксперимент показал, что
  `disable-model-invocation` прямо запрещает обход.

## Проверки
- `test -s docs/playbook/claude-code-format.md` — ок.

- `claude plugin list` / `claude mcp list` в песочнице с тем же файлом: плагины `✘ disabled`, MCP — пусто.
