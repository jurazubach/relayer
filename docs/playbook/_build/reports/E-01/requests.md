# E-01 · Просьбы за пределами разрешённых файлов

1. **`examples/e2e.story.json` (фикстура e2e)** — добавить `"days"` (например, `0.1`) и одну паузу от
   `engine.click.time_jump_label` (`#delay:3h` перед репликой во второй главе). Зачем: сейчас у фикстуры нет
   ни дней, ни скачка от часа, поэтому `e2e/modes.ts` проверяет два числа на карточке на копии фикстуры
   с подставленным `days`, а метку «спустя N» — на синтетической истории внутри теста. С полями в фикстуре
   тесты режимов шли бы целиком на ней, как просит план.
2. **`examples/demo.story.json`** — добавить `"days"`. Зачем: A-05 «на карточке два числа»; образец в
   `scripts/build-prompt.mjs` уже показывает `days`, а пример, который промпт вставляет целиком, — нет.
   У демо сейчас на карточке одно число.
3. **`package.json`, `test:e2e`** — по желанию: `playwright test e2e/smoke.spec.ts` гоняет только smoke,
   поэтому тесты режимов подключены импортом `./modes` из `smoke.spec.ts`. Если `test:e2e` станет
   `playwright test --grep-invert снимки` или перечислит файлы, импорт можно убрать, а `modes.ts`
   переименовать в `modes.spec.ts`.
4. **`scripts/story/core/thresholds.default.json` (T-03b п. 2)** — `click.jump_label` дублирует
   `engine.click.time_jump_label`; движок теперь сверяется с ключом `thresholds.json`, запаска — лишний
   третий источник.
   *Сверка курса:* снято — файла уже нет (удалён в T-03c), движок и `story:*` берут ключ из `thresholds.json`.
