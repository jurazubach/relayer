## Решения

- **Приоритет P2.** История не стоит, кнопка ждёт, но A-03 не исполнено. P1 остаётся за случаем «после напоминаний
  история стоит».
- **Одна находка P2 на главу со списком узлов**, а не строка на каждую развилку. На каталоге список длинный:
  54 / 20 / 98 развилок (the-number / slepoe-pyatno / chuzhoy-golos), в трёх историях нет ни одного `#remind`.
  Скилл начинает с реплик-вопросов и концов глав.
- **Статика плюс бот, а не только бот.** Бот видит только пройденные развилки. Статика видит все, но не видит
  реплику из прошлого узла. Журнал бота добирает только такие случаи.
- **Хаб — по адресату, а не по «разным `#to`».** Первая версия считала хабом любую развилку с кнопками в разные
  чаты и теряла смешанные («ответить ведущему / спросить стажёра»). Сверка с `story:trace` на slepoe-pyatno это
  показала.
- **Мутант не собран.** Основа без напоминаний, так что удалять нечего. Нужна правка основы — просьба п. 8.
