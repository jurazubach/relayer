## Замечания на будущее

- **`lab:triggers --runs 3` для одного скилла не укладывается в 10 минут на вызов** (`--jobs` до 3). Приёмку в
  `claude -p` приходится дробить по `--runs 1`. Варианты: поднять предел `--jobs` или прогонять фразы только
  проверяемого скилла и чужие ложные.
- **Тот же класс бага в `scripts/`:** `process.exit` после большого `console.log`. Стоит пройтись по командам
  `story:*` с `--json`: в трубе вывод обрезается на 64 КБ, в файл — нет. Поэтому прошлые ревью бага не видели.
- **Вывод `lab:triggers` об отказах в правах** склеивает в одну строку огромные команды из прогонов. Такой текст
  нечитаем, его лучше обрезать.

  - `requests.md` п. 1–9;
  - вопрос автору про ≈170 развилок без `#remind`;
