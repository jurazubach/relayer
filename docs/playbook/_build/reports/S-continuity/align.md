# S-continuity — сверка с замыслом

Вердикт: drift-minor

Сверено с `INTENT.md`, `build-plan.md` (§1, §4, §5, строка `story-continuity`), `flow-review.md` §C
(`story-continuity`), `owners.md` (§3–4, TH-74…TH-78), `superseded.md`, отчётами `build.md` и `review.md`,
`git diff build/main...HEAD`, `tasks.json`.

**Замысел.** Скилл отвечает на две боли автора: «где слабые места» (нестыковки знания, слияния, время) и
«чатов много» (сведения между чатами, R-55). Решений против автора нет: персонаж не называет срок паузы
(в `contradictions.md` прямо разведено «время события мира — да, срок возвращения — нет», A-01); упрёк —
только под условием (R-85), упрёк без основания отдан `story-voice` (C-47); к часам игрока не привязан —
`timeline.mjs` сверяет часы мира с паузами сюжета, а не с часами игрока; канон серии — «бонус, а не замок»
со ссылкой на `INTENT.md`, без разметки в ink и без фичи E-06; платных выборов, другой модели и `master` нет.
Текст скилл не правит: черновик `facts.md` и правки идут через одобрение (`story-desk`, `story-fix`).

**План.** Контракт §4 соблюдён: 112 строк ядра, модуль `user-invocable: false`, описание из симптомов,
17 references (≥ 8), 4 скрипта + общий модуль (≥ 2), F-13, C-51, `canon.md`, строка в таблице `CLAUDE.md`.
Отступления от §C записаны в `build.md` («Решения»): четвёртый скрипт `merges.mjs` (иначе F-13 глазами —
запрет `INTENT.md`), формат `facts.md` задан здесь, пороги скриптов в пространстве `C-51.*`. Выход за
`writes` задачи (`C-51.mjs`, `selftest-story-continuity.mjs`, `checks.md`, `thresholds.json`) — починка
собственной проверки C-51 от ложных находок, записана в отчёте и в `history` ключей; это в зоне владельца.

**Единые правила.** Владелец один: среди слитых скиллов (`story-desk`, `-choices`, `-pace`, `-cast`,
`-endings`, `-opening`, `-pauses`) C-51, F-13, R-35, R-55, R-85, R-91 никто не присваивает — только ссылки
на `story-continuity`. ID совпадают со сводом.

**Утечки.** Имён, id и названий трёх историй (из `meta.json`) в скилле и в фразах срабатывания нет; ревью
уже убрало времена мутанта m17. Реальных брендов в тексте нет: латиница — имена API и ink, названия
источников только в `sources.md` (генерируется). Копий книг не видно: пересказ с `basis`.

## Риски для следующих задач

- **S-time (`clock-scan.mjs`).** Часы мира у `timeline.mjs` (реплики «сейчас ЧЧ:ММ» против суммы `#delay`,
  `dict.clock_now`, `C-51.clock_drift_min`) соседствуют с темой `story-time` (R-121, TH-47). Граница: у
  `story-continuity` — согласованность времени мира с самим собой, у `story-time` — время мира против часов
  игрока и режимов. `clock-scan` стоит брать `dict.clock_now`, а не заводить вторую регулярку.
- **Ключи вне своей проверки в `C-51.*`.** `cascade_branches`, `clock_drift_min`, `world_states`,
  `diverging_forks` — не пороги линта C-51, а пороги скриптов и суждения. Пока это записано в `checks.md`;
  если появятся отдельные проверки слияний или времени, ключи надо переименовать с записью в `history`.
- **S-chapter (`facts-anchor.md`), S-release (C-49 г), S-mystery.** Формат `docs/stories/<id>/facts.md`
  задан здесь (`references/facts-format.md`: «Хронология», «Реестр», «Ложь»); C-49 читает только `ЧЧ:ММ`,
  C-51 — «Реестр». Следующие задачи должны ссылаться на этот файл, а не заводить свой формат.
- **A-auditor / S-review.** Скрипты зовутся `node ${CLAUDE_SKILL_DIR}/scripts/<x>.mjs --story <id>`;
  теперь работает и позиционный id. Находки модели — поле проверки «—», P3 по умолчанию.
- **C-51 без мутанта** (`requests.md` п. 1): полнота линта по C-51 не меряется, RED-строки на L2.
