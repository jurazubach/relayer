## Решения

- **Четыре скрипта вместо трёх из §C.** `merges.mjs` добавлен под F-13: в §C защита слияния без скрипта, а
  алгоритм F-13 («множества кому писал / что слышал с бота») без него делался бы глазами (запрет `INTENT.md`).
- **Формат `facts.md` задаю здесь** (`facts-format.md`): три таблицы «Хронология», «Реестр», «Ложь». C-49 уже
  читал из файла только `ЧЧ:ММ` — формат с ним совместим. Скилл файл не пишет: черновик идёт в отчёт, заводит
  `story-desk` после одобрения.
- **Время во входящей не считается фактом для C-51 (а).** Источники (`inkle-ingold:P-05`, `RED-05`) говорят о
  кнопке; на трёх историях все находки времени во входящих были ложными. Опору входящей на событие ловят
  слова реестра. Записано в `contradictions.md` и в `history` ключа.
- **Пороги скриптов — в пространстве `C-51.*`.** Отдельной проверки у слияний и часов мира нет, а ключ обязан
  быть `C-NN.*` или из областей схемы; C-51 — единственная проверка скилла, тема та же (знание на пути).
  В checks.md они помечены «для скриптов, вне линта».
- **«Знает лишнее» — только время и слова реестра, без имён:** люди мира знают друг друга без игрока, иначе
  шум на каждой реплике.
- **Канон серии** — описание в `canon.md`, хранить в `docs/series/<series>/canon.md`, без разметки в ink
  (A-06), без замков между историями (`INTENT.md`).
- **Чужие ID** (уроки других владельцев) — в `lessons.md` карточками со ссылкой на владельца, без якоря в
  заголовке; якоря attention — чужие, взяты дословно, в заголовках без `#attn-`.
