## Замечания на будущее

- `Progress.locked` — снимок из сохранения; при открытии продолжения движок его пересохраняет, но если открытие появится вне игры
  (покупка с главного экрана), карточке нужно будет пересчитывать границу, а не верить флагу.
- `jump` к `chN` выставляет счётчик глав по имени узла: истории, где узлы глав названы иначе, границу из отладки посчитают от текущего счётчика.
- Бот `check:story` и `story:trace` границу не видят — для `story-release` пригодится режим «только бесплатные главы» (длина бесплатной части, крючок на границе).
- Тексты плашки — черновик до решения о монетизации (build-plan §12): проверить с автором вместе с `story-release/references/ethics.md`.
