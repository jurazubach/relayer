## Решения

- **Таблица «симптом → скилл» — 21 строка, а не 15–20.** Скиллов 21, у каждого свой маршрут, а правило раздела —
  «строка на скилл». Слить две строки — значит оставить скилл без маршрута. Строки не менял: их фразы промерены
  в W5, правка текста таблицы без перемера рискует срабатыванием.
- **`lab:triggers -- --runs 3` не гонял.** Задача в конце прямо велит не гонять (полный прогон — F-final), W5 п. 2
  оставляет F-docs только `--skill` скиллов, чьи описания он меняет; описаний я не менял. Прогнал `--dry-run` —
  план собирается. Риск записан в `requests.md` п. 4.
- **`kb:clean -- --verify` после `story:coverage`.** В свежем клоне `docs/books/_clean/` нет, и `--verify` падает
  («сначала npm run kb:clean»); `story:coverage` её собирает. Проверено: убрал `_clean`, `--verify` ✗, после
  `story:coverage -- --summary` ✓.
- **Пометки в `build-plan.md`** — `[x]` и курсивом «Сделано → файлы» в конце пункта, текст плана не переписывал:
  план остаётся историей решений. Э4/Э6 зачёркнуты, а не удалены.
- **README коротко для людей**: таблица «говоришь → что происходит» на 10 строк вместо полной на 21; полная — в
  `CLAUDE.md` по ссылке. Короткая проверка перед коммитом в README — для тех, кто не трогает скиллы и базу.
- **REVIEW.md, рекап после паузы** — ступени `attn.recap.*` (R-70 теперь ссылается на них, а не на «от 6 ч»);
  хаб — `attn.hub.addressees` и `C-12.four`.
