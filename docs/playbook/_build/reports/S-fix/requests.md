# S-fix · просьбы за пределами разрешённых путей

1. **Мутант для `attention-today:RED-10`** — `scripts/lab/mutants-spec.mjs`, `docs/lab/mutants/`.
   Что: мутант основы, где правка «для краткости» вырезала реплику с уликой из узла с `// reveal:` (или
   строку со словом из `facts.md`). Зачем: RED на L3 засчитывается только с мутантом; сейчас RED-10 у
   `story-fix` на L2, а `fix-guard.mjs` этот дефект уже ловит («улики ⚠»), так что мутант станет его
   регрессионным тестом.

2. **Формат вариантов в отчётах линз** — `story-review/references/finding-format.md` и шаг «Правка» у
   диагностических скиллов (`story-choices` … `story-mystery`). Что: одной строкой закрепить, как линза
   записывает варианты под находкой: строка «Вариант А — что делает», под ней блоки ```ink с подписями «До:» и
   «После:». Зачем: `story-fix/scripts/pick.mjs` берёт варианты дословно (решение после W2) и разбирает именно
   этот вид; сейчас линзы пишут варианты как придётся, и часть отчётов `pick.mjs` увидит «без вариантов».

3. **`fixes/F-15-missing-beat.md` у `story-plan`** — когда скилл будет собран. `story-fix/references/fixes-index.md`
   уже ссылается на путь `.claude/skills/story-plan/references/fixes/F-15-missing-beat.md`; до сборки приём берётся
   строкой `npm run story:rule F-15`. Самопроверка `selftest-story-fix.mjs` пропускает ссылки на несобранные скиллы.

4. **`story-desk`: вид решения для «намеренно»** — `story-desk/scripts/decision-add.mjs`. Что: `--kind намеренно`
   (с обязательными `--node` и `--finding`, как у «отклонено»). Зачем: `story-fix` требует решение D-NN перед
   меткой `// намеренно: C-NN`; сейчас его пишут как `--kind автор --basis C-NN`, и связь «метка ↔ решение» по
   узлу не проверяется.
