# S-fix · Скилл story-fix — сборка

## Сделано

**`.claude/skills/story-fix/SKILL.md`** — пользовательский вход (не модуль), `metadata.version: 1`, `allowed-tools`
по контракту. Алгоритм из 9 шагов: состояние → пункты (`pick.mjs`, одобрение по одному) → вариант дословно или
приём владельца → правка (`docs/style.md` в этом шаге) → страховка (`fix-guard.mjs`) → до и после (`text-diff.mjs`,
`diff-report.mjs`) → повтор линзы на изменённых узлах → отчёт → состояние через `story-desk`. Режим `--compress`
через `compress-plan.mjs` и `compress.md`. Формат результата — строка находки с итогом «→ применено / отклонено /
отложено / намеренно (D-NN) / устарело».

**references/** (15 файлов):
- `fixes-index.md` (TH-87) — F-01…F-15 → файл владельца, перезамер, чего приём боится; F-15 помечен «не собран».
- `safety.md` (TH-84) — шесть вещей, которые правка сохраняет (улики, мотивы, переменные, переходы, разметка, оба
  режима); блоки `attention-today:RED-10` и `narrative-testing:P-16`.
- `approval.md`, `diff-for-author.md` (TH-86) — одобрение по пункту, королева в конвейере, «намеренно» только с
  D-NN; три слоя отчёта для автора.
- `compress.md`, `compress-sources.md` (TH-85) — порядок сжатия, `#attn-cut` целиком (наши пределы ключами),
  по блоку «минимальная версия и что резать» на каждый из 30 разборов.
- `decisions-fix.md`, `patterns-fix.md` (5 примеров ink, компилируются), `flags.md`, `lessons.md`, `attention.md`
  (карта якорей других владельцев), `explain.md`, `contradictions.md`, `systems/fix-loop.md`, `sources.md`
  (сгенерирован `--sources --write`).

**scripts/** (6, у всех `--help`, вывод для человека и `--json`):
- `fix-core.mjs` — запуск `story:*` с `--json`, история на двух ревизиях, `compareTrees` (страховка) и разбор
  отчёта линзы (`parseReport`, `locateBefore`) — чистые функции под самопроверку.
- `fix-guard.mjs` — сборка, удалённые узлы, записи и видимые чтения переменных, `// финал:`, `// reveal:`, убранные
  реплики в узлах раскрытия и со словами `facts.md`, новые `// намеренно:`, маршруты (`route-replay.mjs` у
  `story-playtest` и `--routes`). Код 1 при «✗».
- `text-diff.mjs` — обёртка `story:diff --text`: «было / стало» по узлам, `--nodes`, `--md`, сигнал «правка вышла за
  одобренные узлы».
- `diff-report.mjs` — обёртка `story:diff --json`: ушло / появилось у правленых узлов / появилось в чужих местах,
  сдвинувшиеся метрики (персоны свёрнуты), строка для `STATUS.md`. Код 1, если ошибок стало больше.
- `pick.mjs` — находки и варианты А/Б/В из отчёта линзы дословно, `--take 2:Б`, сверка «до» с файлами («устарело»).
- `compress-plan.mjs` — сейчас → цель → во сколько ужать; контакты, переменные, финалы против ключей короткой формы;
  паузы, которые рвут историю на сессии.

## Решения

- **Своих проверок и приёмов нет** (`owners.md` §1, §4): `story-fix` держит указатель, а не копии F-NN —
  иначе разойдётся с владельцами. Перезамер по приёму — колонкой в указателе.
- **`story:diff` уже умеет `--text` и lint до/после**, поэтому `text-diff.mjs` и `diff-report.mjs` — тонкие обёртки
  над ним (числа совпадают по построению: проверено на временной правке `the-number` и `slepoe-pyatno`, «появились:
  C-23 · ch1» и счёт подсказок 84 → 85 — одинаково у скрипта и команды). Добавлено то, чего нет в команде: подача
  «было / стало», разделение регрессии «рядом» и «в чужом месте», свёртка шума по персонам.
- **Варианты дословно (после W2):** `pick.mjs` не пересочиняет, а достаёт ink «до» / «после» и проверяет, что «до»
  ещё стоит в файлах; если нет — «устарело», повтор линзы. Отчёт `story-review` вариантов не содержит (аудиторы
  пишут только приём) — тогда варианты строятся по F-NN владельца.
- **Маршруты:** хранилище маршрутов уже есть у `story-playtest` (`route-replay.mjs`, TH-94), `fix-guard.mjs` гоняет
  его всегда, а `--routes` — лёгкий вариант для бага бота без сохранения.
- **`compress.md` разбит на два файла одной темы** (метод + `#attn-cut` и блоки по разборам), чтобы уложиться в
  `skill.reference.max_lines`. Числа из `#attn-cut`, у которых есть ключи, заменены ключами (`attn.hub.addressees`,
  `attn.state.axes`, `attn.mystery.suspects`, `story.short_min`); названия чужих систем («15 битов») оставлены
  — это не наши пороги.
- **Пункт «намеренно»:** метка только после решения D-NN; тупик C-52, недостижимое C-15 и разметка C-53 меткой не
  гасятся (развилка в `decisions-fix.md`).
- **Одобрение «всё»** допустимо после показа списка с выбранным вариантом каждого пункта (`contradictions.md`).
