## Замечания на будущее

- В `compress-sources.md` пороги из книг записаны словами («не больше двух параллельных чатов», «минута-две»,
  «не больше трёх тем»). `skill-check` ловит только цифры, поэтому такие числа проходят мимо правила «только
  ключами». Где ключ есть (`attn.chats.waiting.ch1`, `attn.hub.addressees`), лучше ставить ключ. Это касается и
  других скиллов с блоками `attention§1`.
- Блоки `attention§1` пересказывают в основном раздел «Слишком сложно — резать», а таблицу «минимальная версия»
  почти не используют, хотя каждый блок начинается словами «Минимальная версия принципов». Для `--compress`
  этого хватает, но заголовок обещает больше, чем в блоке.
- `compress-plan.mjs` печатает пределы именами ключей («цель короче attn.state.axes.short_min»), без значения.
  Автору было бы понятнее видеть значение рядом с ключом.
- Предел контактов короткой формы в `compress-plan.mjs` взят из `attn.chats.waiting.ch1` — это ключ про первую
  главу. Нужен отдельный ключ короткой формы (решение для `thresholds.json`).
- Просьбы исполнителя (`requests.md`) обоснованы, особенно 2 (формат вариантов у линз): без него `pick.mjs`
  часто увидит «без вариантов».
- В двух прогонах `lab:triggers` фраза из `_routing.json` «Ок, исправь второй и четвёртый пункт» уходит в
  `none`: без контекста отчёта модель не знает, о каком ревью речь. Это ожидаемо, но фразу стоит дополнить
  словом «ревью».
