# E-02 · просьбы за пределами разрешённого

## 1. `scripts/lab/mutants-spec.mjs`: m10 и m11 на настоящий синтаксис, `lint` — C-32

Задача просит снять `lint_auto: false` с m10 и m11 и записать им `lint: C-32`, но `scripts/lab/**` в список
разрешённого не входит. Обе правки проверены на копии основы (`docs/lab/mutants/_base`, `story:lint --only C-32`).

**m11-reminder-dead-end.** Сейчас мутант изображает напоминания комментариями-заглушками: `#silent` уводит
в узел `ch3_wait`, а тот кончается `-> DONE`. Его ловит C-11, а не C-32. С настоящим синтаксисом:

```js
lint: ['C-32'],
// lint_auto и lint_why — убрать
edits: [
  [
    '{trust_lev >= 2: может, он правда хочет как лучше?|я ему не верю}\n* [Соглашайся для вида]',
    '{trust_lev >= 2: может, он правда хочет как лучше?|я ему не верю}\n- (deal)\n* [Соглашайся для вида]',
  ],
  [
    '* [Скажи ему про следы]\n    ~ bold += 1\n    -> ch3_end\n',
    '* [Скажи ему про следы]\n    ~ bold += 1\n    -> ch3_end\n* [#remind:20m] алё, ты тут? мне нужно да или нет\n    -> deal\n* [#remind:20m] он ждёт у двери. ответь\n    -> deal\n',
  ],
],
```

Проверено: `ошибка · C-32 · ch3_after · после напоминаний история стоит — нет ни #noanswer, ни #silent`.
Описание `broken` подходит как есть.

**m10-absence-reproach.** Правка не меняется. C-32 п. 7 ловит мутанта ключом `C-32.no_answer_reproach`:
«упрёк за отсутствие на пути «неотвечающего» (ch3): «ты где пропала? сколько можно…» — игрок не нажимал
#silent». Предлагаю `lint: ['C-47', 'C-32']`. Комментарий «C-32 п. 7… ждёт напоминаний E-02 и этого мутанта
не ловит» устарел, его нужно убрать. `check` оставить C-47: упрёк меряет его строка.

После правки — `npm run skills:test -- --build`, затем `npm run skills:test -- --lint-only`.

## 2. `scripts/lint/selftest-wave2.mjs`: тест «напоминания — deferred:E-02» устарел

Тест `C-32: «сплю» → «доброе утро» через два часа; напоминания — deferred:E-02` проверяет, что
`story.reminders.max` пропускается как `deferred:E-02`. С E-02 deferred снят. Пока этот файл не поправлен,
`scripts/lint/selftest.mjs` не регистрирует устаревший тест (множество `REPLACED`) и ставит вместо него свой
с тем же «сплю → утро» и проверкой, что C-32 ничего не пропускает. Нужно удалить тест из wave2, а затем фильтр
`REPLACED` в `selftest.mjs`.

## 3. `scripts/lint/static.mjs` (и C-19): напоминание и `#noanswer` — не кнопки

Статический разбор `buildButtons` считает кнопкой любой вариант ink. У вариантов `#remind` и скрытых `#noanswer`
в дереве теперь есть `choice.role` (`scripts/lib/ink.mjs`, `choiceRoleOf`): `'remind' | 'noanswer' | 'button'`.
На мутанте m11 с настоящим синтаксисом C-19 видит петлю напоминания как хаб и даёт ложные подсказки:
«хаб ch3_after: «» даёт 1 строку и возвращает обратно», «выход доступен сразу и без условия».
Просьба: в `buildButtons` пропускать варианты с `role !== 'button'` как кнопки, но обходить их `items`
(переходы и записи переменных там настоящие). Индекс переменных (`buildVarIndex`) трогать не нужно:
записи в ветке `#noanswer` должны считаться.

## 4. `scripts/story-graph.mjs`: напоминания на карте

Карта рисует `* [#remind:40m] …` и `* [#noanswer]` как кнопки с пустым текстом. Лучше показывать их
пунктиром: «молчит 40 мин → напоминание», «не ответил». Роль варианта — `choice.role` из `parseInk`.

## 5. `scripts/check-story.mjs`: прогон «неотвечающего»

Бот check:story не молчит у кнопок, поэтому тупик «после напоминаний история стоит» он не видит. Сейчас его
ловят C-32 п. 6 и `story:trace --compare silent`. Можно добавить в check:story отдельный прогон
`strategies.unresponsive()` (`scripts/lib/bot.mjs`) и считать событие `stall` с `reason: 'no-target'` тупиком.
