# T-14 · E2e на фикстуре вместо текстов the-number — сборка

## Сделано

- `examples/e2e.story.json` — новая служебная фикстура «Фикстура · Пустой причал» (id `e2e-fixture`):
  две главы, два контакта (`mira`, `keeper`), развилка с `#unlock` и `#silent`, второй выбор, финал.
  Тексты вымышленные, короткие первые реплики (нужны тесту ширины экрана).
- `e2e/fixture.ts` — общий помощник: путь к фикстуре, её JSON (ожидаемые тексты читаются из файла),
  `uploadFixture` / `fixtureOnHome` (загрузка через «Загрузить историю»), `FIXTURE_GAME`
  (`?story=e2e-fixture&screen=game` после загрузки), опорные точки сценария `PLOT`,
  `BUILTIN` — любая встроенная история из `src/stories/`, тексты берутся из её файла.
- `e2e/smoke.spec.ts` — все проверки переведены на фикстуру: карточка (квадрат, метка «свой файл»),
  описание (герои и главы из JSON), запуск, чат с сообщениями, назад с прогрессом, начать заново,
  перезагрузка (в игру и в тот же чат), загрузка, ошибка файла, удаление (и не возвращается после
  перезагрузки), «сбросить прогресс» под кнопкой, центрирование, ширина экрана, вытеснение копии.
  Добавлены: выбор двигает сюжет и открывает новый контакт; загрузка с id встроенной истории
  отклоняется; пример для авторов `demo.story.json` по-прежнему загружается.
- `e2e/shots.spec.ts` — снимки идут на фикстуре; вторая загруженная история — `demo.story.json`.
- `playwright.config.ts` — веб-серверу явно `--host 127.0.0.1`: на macOS Vite слушал только `::1`,
  и Playwright ждал `127.0.0.1` до таймаута.
- `CLAUDE.md`, `README.md` — точечно: строка про фикстуру в структуре, «e2e опираются на фикстуру».

## Решения

- **Отдельная фикстура, а не `demo.story.json`.** Демо — шаблон для авторов и пример в промпте
  (`scripts/build-prompt.mjs` его читает); его будут править. Тесты на нём снова привязали бы
  проверки к живому тексту. Демо проверяется одним тестом: что загружается и играется.
- **Загрузка через интерфейс, без нового флага.** Флаг в `flags.ts` сам ничего не загрузит: логику
  пришлось бы класть в `library.ts`/`useLibrary.ts`, они вне разрешённого. Загрузка кнопкой проверяет
  настоящий путь игрока и занимает доли секунды. После неё работает `?story=e2e-fixture`, потому что
  загруженные истории лежат в `relay:uploads`. Таблица флагов в `CLAUDE.md` не менялась.
- **Ожидаемые тексты читаются из JSON фикстуры**, а не вписаны в тесты: правка описания не ломает
  тесты. Строки из `ink` (развилка, ответ, открываемый контакт) собраны в `PLOT` в одном месте.
- **Вытеснению нужна встроенная история** — берётся первая из `src/stories/` по имени файла, её
  `title` читается из файла. Если каталог опустеет, два зависящих теста пропускаются (`test.skip`),
  а не падают.

## Открыто

- `flags.ts` и README в примерах адреса по-прежнему пишут `?story=the-number`. Это пример, а не
  зависимость тестов; когда истории каталога сменятся, пример стоит обновить вместе с ними.
- Правка хоста в `playwright.config.ts` касается всех, кто гоняет e2e: если у кого-то
  `reuseExistingServer` подхватывал свой dev-сервер на `localhost:4173`, теперь сервер должен слушать
  `127.0.0.1` (как и раньше требовал `baseURL`).
