## Риски для следующих задач

1. **T-02 (формат папками) тихо отключит два теста.** `BUILTIN` в `e2e/fixture.ts` читает
   `src/stories/*.json`. Когда T-02 разложит истории в `src/stories/<id>/story.ink + meta.json`, плоских
   `.json` не останется. Тогда `BUILTIN` станет `undefined`, тесты «вытеснение копии» и «загрузка с id
   встроенной отклоняется» уйдут в `test.skip`, а прогон останется зелёным. T-02 может писать в `e2e/**`,
   так что это его зона. Но в его спецификации про это ни слова.
2. **Фикстура и новые поля формата.** T-02 вводит `revision`, `minutes`/`days` и `free_chapters`,
   E-04 и E-05 их используют. Фикстура — однофайловый `.json` для загрузки, то есть результат
   `story:pack`. Если пакер начнёт требовать новые поля, фикстуру нужно обновить в той же задаче.
   Ожидаемые тексты тесты читают из файла, так что сами тесты при этом не сломаются.
3. **`--host 127.0.0.1` в `playwright.config.ts`.** Это касается всех следующих задач с e2e
   (E-01…E-05): если кто-то держит свой dev-сервер на `localhost:4173` через `reuseExistingServer`,
   этот сервер должен слушать IPv4.
4. **Примеры адресов `?story=the-number`** в `flags.ts`, README и таблице `CLAUDE.md` останутся после
   переписывания каталога. Если X-E7 сменит id историй, примеры перестанут работать. В зависимости
   тестов это не превращается.
