# T-15 · Э1: базовый снимок трёх историй — сборка

## Сделано
- `docs/lab/baseline.md`: таблица метрик по трём историям (время в обоих режимах, паузы, хвост, сессии,
  lint по уровням, финалы и их доли, контакты по уровням, переменные по меткам, развилки без `#silent`,
  отвлечённый). Плюс главное в семи пунктах и сверка 28 находок `story-findings.md` с командами:
  ловится 11, частично 11, не ловится 6; по каждой — какая проверка ловит и чего не хватает.
- `docs/lab/journal.md`: журнал заведён, первая запись — Э1 от 2026-10-25.
- `docs/lab/runs/T-15/`: сырые выводы всех шести команд (текст и `--json`), `trace` для всех персон в обоих
  режимах и `--compare silent`, пачки отвлечённого, `story:diff stories-v1 .`, время команд, `metrics.json`
  и `collect.mjs`, который собирает из них сводку. Команды — в `README.md` папки.
- `requests.md`: шесть просьб за пределами разрешённого (уроки LOCAL, `dict.refusal`, C-14, C-35,
  `sessions` для отвлечённого, `endings` по `ending`).

## Решения
- **Снимок — на `HEAD`, а не на теге `stories-v1`.** Команды сегодня читают папки, а под тегом лежат `.json`.
  Сначала проверил `story:diff stories-v1 .` по трём историям: trace, cast и endings без изменений, разница
  только в поле `days` и находке C-31 про него. Значит, снимок по содержанию равен `stories-v1`, а
  сравнивать дальше удобнее с `2b1b509`.
- **Трассы — только текстом.** `trace --json` по всем персонам весит 6–20 МБ на историю. Метрики берутся из
  `sessions`, `endings` и `lint --json`. Из JSON отвлечённого (50 прогонов) оставил только `batches`,
  нужные для метрики §13. Папка весит 5,3 МБ.
- **«Отвлечённый» досчитан отдельно.** Ни одна команда не выводит его метрику сводкой, поэтому медиану, p90
  и максимум строк при возвращении считает `collect.mjs` из `batches`. Просьба про `sessions` — в `requests.md`.
- **Статусы сверки:** «ловится» — команда указывает на то же место и ту же причину; «частично» — симптом или
  часть пунктов; «не ловится» — ни одна команда на место не указывает. Бэклоги P3 оценивал целиком: ◐, если
  ловится хотя бы одна строка.
- **Паузы «Чужого голоса» не чинил.** Задача — снимок, а находку C-31 записал с разбором: откуда берутся 176 ч
  и почему одних ночных пауз мало.
- **Скиллы не запускал.** В Э1 их ещё нет в цикле, доля «модель / человек» = 0, это точка отсчёта.
