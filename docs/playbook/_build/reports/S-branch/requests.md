# S-branch · просьбы за пределами разрешённых путей

1. **`docs/playbook/rules.md`, R-37** — в тексте правила число «30–60 %». Заменить на ключи
   `story.branch.seen_share.min` / `story.branch.seen_share.max` (заведены этой задачей, `basis` и источники —
   в `thresholds.json`). Зачем: «числа только в `thresholds.json`»; `story:rule R-37` покажет пороги по ключу.
   То же для R-26 («1–2 развилки в разные узлы на главу») — если нужен ключ, его стоит завести у владельца
   C-25 (`story-opening`), а не у `story-branch`.

2. **`story-plan` (когда будет собран)** — в `plan-check.mjs` / `plan-compare.mjs` звать
   `.claude/skills/story-branch/scripts/branch-budget.mjs --story <skeleton.ink> --json` вместо своего счёта
   дорогих веток: метрика «число дорогих веток против бюджета 3–5» из `flow-review.md` §B, шаг 3, уже
   считается здесь (ключи `story.branch.budget.*`). Иначе два определения «дорогой ветки» разойдутся.

3. **`docs/lab/triggers/story-mystery.json`** — негатив «Придумай неожиданный поворот: кто-то из друзей героя
   окажется не тем, кем кажется» ждёт `story-brainstorm`, которого ещё нет; сейчас его забирает `story-branch`
   (3/3). Когда `story-brainstorm` слит, перемерить; если `story-branch` продолжит забирать — сузить
   описание `story-branch` («поворот в точке истории», а не «поворот замысла»).

4. **`docs/lab/triggers/story-cast.json`** — позитив «Хочу, чтобы неизвестный номер потом стал человеком с
   именем и перешёл на сторону игрока» уходит в `story-branch` (3/3). По смыслу фраза на стыке (дуга
   персонажа = куда свернуть его линии). Просьба к `story-cast` или итогу волны: решить, чья фраза, и
   уточнить формулировку в одном из двух файлов.

5. **Конвейер (`_build`)** — проверка `npm run lab:triggers -- --skill story-branch --runs 3 --min build`
   гоняет 101 фразу × 3 = 303 запуска и идёт ≈ 18 минут при `--jobs 3`, дольше предела одного вызова
   (10 минут). Я прогнал её частями (`--file` по каждому файлу группы и маршрутам, отчёт — `build.md`).
   Если конвейер запускает её одним вызовом — нужен таймаут больше 10 минут.
