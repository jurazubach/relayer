## Решения

- **Ключи.** `C-NN.<имя>` для порога одной проверки; общий предел — `story.* / engine.*` с полем `checks`. Проверка
  может выдавать находку по общему ключу (C-31 → `story.length.max_h`): ID проверки в находке свой, ключ — общий.
- **Уровень берётся из порога.** Код проверки не выбирает уровень, его задаёт `level` ключа. Поднять C-01 из
  ошибки в подсказку — правка одной строки в `thresholds.json` (это проверяет тест).
- **C-01 — ошибка.** `checks.md` предлагал предупреждение, пока истории не исправлены. Флаг `--strict` решает ту же
  задачу: без него текущие истории не роняют общую приёмку, а гейт выпуска (`story-release`, «lint без ошибок»)
  видит мёртвую переменную как ошибку.
- **«Больше трети» в C-11** записано как 0,3334: ровно треть (3 из 9 у THE NUMBER) не срабатывает, как в прогоне
  `checks.md`.
- **Финалы без меток (C-40).** Если меток нет, финалы — финальные узлы, в которые ведёт распределитель, плюс узлы с
  `-> END`, кроме общего эпилога после них. Иначе в «Слепом пятне» все `end_*` слились бы в `debrief`. С метками —
  последняя пройденная `// финал:`; несколько меток в одном узле различаются по первой реплике после метки.
- **Узел последней строки перед END** бот пишет неверно (просьба 1). `journal.mjs` поправляет его по тексту строки:
  без этого C-40 не видел финалов вида `* [x] -> fin`.
- **Подавление.** Метка над узлом гасит находки этого узла и его stitch'ей; метка до первого узла — находки без узла
  (на всю историю). Подавленное видно в `--json` с причиной.
- **«Неизвестная метка» C-53** — только `// слово:` со строчной буквы и прежние метки без двоеточия (`// сезон`).
  Авторские заметки «Главы:», «Кто есть кто:» в начале файлов меткой не считаются, иначе каждая история шумит.
  Неизвестный ID в `намеренно` проверяется по заголовкам `checks.md`, а не по числу в коде.
- **`--partial`** требует узел `beta_stop` и пропускает C-01, C-03, C-06, C-40, а в C-31 — длину и карточку: в части
  глав чтения и финалы ещё впереди. **`--plan`** запускает только проверки структуры (`plan: true`): C-01, C-03,
  C-06, C-10, C-11, C-12, C-21, C-40, C-53. Скелет ищется в `docs/stories/<id>/skeleton.ink` или `plans/skeleton.ink`.
- **`--changed`** берёт изменённые и новые файлы `src/stories` из `git status`; изменений нет — выход 0 с сообщением.
- **Время игрока** повторяет `engine.ts` точно, включая детерминированный зазор от хэша текста; константы — в
  `engine.typing`, тест ловит расхождение с движком.
- **Места.** Одно место на всех прогонах — одно срабатывание; решение «на месте нет крючка / приветствие» — по
  большинству путей через это место. Медианы — как в `check:story`.
- **Ключи конвейера** (наша оценка): `min_share` 0,8 — 4 из 5 прогонов; `max_false` 0,2 — один ложный вызов из пяти;
  `fidelity.min_share` 0,9 — 18 из 20 строк выборки.
