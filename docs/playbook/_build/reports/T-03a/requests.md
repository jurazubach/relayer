# T-03a · Просьбы за пределами разрешённых файлов

1. **`scripts/lib/bot.mjs`, `play()`: узел последней строки перед `-> END`.** После конца истории у inkjs нет
   ни `previousPointer`, ни `currentPathString`, и строка получает узел предыдущей строки: в
   `* [север] -> north` / `=== north === холодно -> END` бот пишет «холодно» в узел развилки. Из-за этого
   финал по узлу не находился. Сейчас `scripts/lint/journal.mjs` поправляет узел по тексту строки
   (`textKnots` в `static.mjs`), но строки с подстановкой `{…}` так не узнать. Зачем: правильный узел нужен
   всем потребителям журнала (`story:trace`, `story:endings`, T-04a). Как: запоминать путь до `Continue()`
   или брать узел из `VisitCountAtPathString` после конца.
2. **`docs/capabilities.json` и `docs/PROMPT.md` — разметка C-53** (шапка из 4 строк, `// reveal:`,
   `// намеренно: C-NN причина`, `// финал: <имя>`). `checks.md` C-53 поручает это T-03 и T-06, но файл не в
   списке T-03a. Поведение чата разметка не меняет, это раздел о формате сценария; `build-prompt.mjs`
   сверяет только теги, так что `ready` для комментариев ничего не уронит.
3. **`CLAUDE.md`, «Команды»:** добавить `npm run story:lint` (флаги `--strict`, `--changed --quick`,
   `--partial`, `--plan`) и `npm run test:lint`; в «Проверку перед коммитом» — `npm run test:lint`. В
   «Устройстве» — строку `scripts/lint/` и `docs/playbook/thresholds.json`.
4. **`docs/playbook/checks.md`:**
   - «Словари — общие для всех проверок, хранить в одном месте скрипта» → «в `thresholds.json`, ключи `dict.*`»;
   - «Уровни: ошибка — `check:story` завершается с кодом 1» → «`story:lint --strict` завершается с кодом 1»;
   - C-01 «до правки историй включать как предупреждение» → уровень ошибки оставлен, код выхода держит `--strict`
     (см. `build.md`, «Решения»);
   - C-38 «словарь угрозы заводит T-03» → `dict.threat`;
   - числа порогов в тексте проверок — заменить ключами `thresholds.json` (правило «числа только в
     thresholds.json»). Это большая правка свода, лучше отдельной задачей после T-03b, когда ключи будут у всех 54 проверок.
5. **`docs/playbook/rules.md` R-122:** «ключ `thresholds.json`, его заводит T-03» → `engine.click.time_jump_label`
   (1 ч). То же для R-67 / R-110 / R-120 / R-121: числа пределов → `story.length.target_h`, `story.length.max_h`,
   `story.pause.max_h`, `story.tail.max_delay_min`, `story.reminders.max`, `story.sleep_morning.min_h`.
6. **Вопрос (королеве / автору): контакт «Заметки» в «Слепом пятне».** C-21 не считает контакты без `#from`, а
   в `slepoe-pyatno` заметки пишутся `#from:notes`, поэтому попадают в «новые контакты главы 2» (5 вместо 4 из
   прогона `checks.md`). Варианты: служебная роль в `characters` `meta.json` (T-02, вместе с голосом R-75) и
   исключение по ней — или считать заметки контактом. Сейчас проверка следует букве правила.
