# T-08 · просьбы за пределами разрешённого

## 1. T-03 (`thresholds.json`): перенести пороги внимания

- **Что.** Завести в `docs/playbook/thresholds.json` 64 ключа из таблицы `docs/playbook/attention-merged.md` §6 (`#attn-load`):
  значение из колонки «решение», единица, опора (`ист.` → `source`, `оц.` → `our_estimate`), источники — из колонки «источники».
  Имена ключей — кандидаты. Если T-03 выберет другую схему имён, нужна таблица соответствия, чтобы T-08 мог заменить числа ключами.
- **Где.** `docs/playbook/thresholds.json` (T-03), затем `docs/playbook/attention-merged.md` §6: числа заменить ключами (повторная правка T-08
  или задача сверки).
- **Зачем.** Правило «числа живут только в `thresholds.json`». Пока файла нет, числа стоят в своде с пометкой опоры (как разрешено
  инструкцией к задаче), а таблица §6 служит готовым входом для T-03.
- **Особо.** `pause.max`, `story.realtime`, `tail.after_last_button`, `reading.per_day` — решения автора (A-05, `build-plan.md` §3).
  Их опора — «решение автора», а не `our_estimate`.

## 2. T-09 (`story:coverage`): единицы `алиас:attention§N`

- **Что.** Считать 150 единиц `алиас:attention§1…§5` покрытыми этим сводом (каждая упомянута хотя бы в одной строке; проверено скриптом,
  см. `build.md`). Пункты из §9 (`#attn-superseded`) получают статус `superseded:A-NN`.
- **Зачем.** Чтобы нарезка по скиллам не считала их непокрытыми.

## 3. T-10 (`owners.md`): владельцы якорей

- **Что.** Принять таблицу §10 (`#attn-slicing`) как черновик владельцев разделов `attention-merged.md`.
