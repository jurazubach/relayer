# A-cold · просьбы за пределами разрешённых путей

## 1. Подпись в переписке холодного читателя дублирует имя

- **Что.** `scripts/story/core/cold.mjs`, `compose`: строка печатается как `<имя>: <текст>`. Если реплика в ink
  сама начинается с имени отправителя (служебные рассылки: «Оператор: SIM-карта активирована…»), читатель видит
  «Оператор: Оператор: …». Не добавлять подпись, если текст уже начинается с `<имя>:`, или вырезать её из текста.
- **Зачем.** Скептик на прогоне A-cold отметил это как «не верю» («имя отправителя повторено дважды») — это
  шум транскрипта, а не текста истории (в чате игры подписи над пузырём нет), и он съедает внимание читателя.

## 2. Хук агента cold-reader — отдельным скриптом

- **Что.** `scripts/hooks/cold-reader-bash.mjs` (тот же разбор, что сейчас в `hooks:` агента одной строкой
  `node -e`) и ссылка на него из `.claude/agents/cold-reader.md`; самопроверка — в `npm run test:hooks`.
- **Зачем.** Claude Code в сообщении об отказе печатает агенту всю команду хука — сейчас это ~300 знаков JS
  (`claude-code-format.md` §2.5: вывод хука засоряет контекст агента). Короткий путь к скрипту и тест в
  `test:hooks` вместо ручной проверки. Мои пути — только файл агента, поэтому сейчас хук встроенный.
