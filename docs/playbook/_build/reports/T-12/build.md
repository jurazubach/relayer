# T-12 · Тест срабатывания скиллов lab:triggers — сборка

## Сделано
- `scripts/lab/triggers.mjs` — CLI `npm run lab:triggers`: план прогона, сверка окружения, запуски
  `claude -p` пулом (по умолчанию 2, максимум 3), таблица / `--json`, запись в `docs/lab/runs/triggers/<дата>.json`
  (второй прогон за день — `<дата>-2.json`), код выхода по `--min`.
- `scripts/lab/triggers-lib.mjs` — чистые функции: разбор stream-json, файлы фраз, план с соседями,
  подсчёт долей, проверка окружения, пороги из `thresholds.json` с временными значениями.
- `scripts/lab/triggers.test.mjs` — 13 тестов без запуска claude (`npm run test:lab:triggers`).
- `docs/lab/triggers/`: `README.md` (формат и что считается), `_template.json`, `_example.json`
  (пример на будущий `story-pauses`, 6 позитивов, 5 негативов с адресами), `_routing.json`
  (27 фраз на 20 скиллов плана и 4 `none`), `_env.json` (нечужие встроенные скиллы листинга).
- `package.json` — скрипты `lab:triggers`, `test:lab:triggers`.

## Решения
- **Срабатывание** — первый `tool_use` `Skill` в событии без `parent_tool_use_id` (§4.2). Как только он
  найден, процесс гасится: дальше скилл начал бы работу, а она не нужна и стоит денег.
- **Обход** — Read с путём `…/skills/<имя>/SKILL.md` или Bash с `SKILL.md` в команде до вызова `Skill`;
  отдельная колонка, в попадания не идёт. Имя скилла из пути, иначе `?`.
- **Сверка окружения** — отдельный запуск, который гасится на событии `init` (≈2 с, к модели не обращается).
  Чужие = `init.skills` минус проектные (`.claude/skills/*/SKILL.md`) минус `_env.json`; плюс предупреждения
  о пропавших проектных скиллах, плагинах не `@builtin` и MCP. `--strict-env` отменяет прогон, `--check-env` — только сверка.
- **Безопасность прогона** — из корня репозитория модель может что-то сделать. Поэтому `--permission-prompts none`,
  `--disallowedTools` на запись, Artifact, расписания и рассылки (в пробном прогоне модель потянулась к Artifact),
  `--max-turns 3`, таймаут; `git status` до и после — предупреждение, если изменился.
- **Ожидания** трёх видов: `скилл`, `none`, `!скилл` (строка-негатив: «не этот, куда угодно ещё»).
  Негатив-объект `{text, expect}` проверяет ещё и адресата, и адресат сам попадает в соседи.
- **Ложные** считаются по фразе: скилл сработал на прогоне фразы, которая к нему не ведёт (негатив, позитив
  соседа, маршрут к другому, `none`). Доля — от всех чужих прогонов.
- **`--skill X`**: фразы X, позитивы соседей в обе стороны (`neighbors` у X и у тех, кто назвал X) и маршруты
  к группе. Негативы соседей не берём — они про соседа, а не про X.
- **Пустой набор**: фразы скиллов, которых нет в `.claude/skills`, пропускаются; `none`-маршруты без единого
  проектного скилла тоже (тавтология). Поэтому файлы фраз и `_routing.json` можно класть заранее, а сейчас
  прогон проходит без единого запуска. `--file` прогоняет любой файл явно (для примера и встроенных скиллов).
- **`--min`** без числа берёт `lab.triggers.min_hit_rate`; без `--min` код выхода 0 при любых долях —
  пороги показываются, но не роняют. Порог ложных для `--min` — `lab.triggers.max_false_rate` или `--max-false`.
- **Числа**: `thresholds.json` ещё нет — три ключа `lab.triggers.*` с временными значениями в `DEFAULTS`
  (пометка в коде, предупреждение в выводе, просьба в `requests.md`). Параллельность, `--max-turns`, таймаут —
  технические параметры запуска, не пороги: флагами с дефолтом в коде.

## Проверки
- `npm run lab:triggers -- --help` — ✓.
- `npm run lab:triggers` и `-- --dry-run` на пустом наборе — ✓, 0 запусков, код 0; 31 фраза пропущена.
- `npm run lab:triggers -- --check-env` — ✓ «окружение чистое: 24 скилла, проектных 0».
- `npm run test:lab:triggers` — 13/13.
- Живой прогон `--file` на встроенном `dataviz` (3 фразы × 2) — разбор работает: «палитра для heatmap» → `dataviz` 2/2,
  «дашборд» → модель шла в Artifact без `Skill` (честный промах), арифметика → `none`.
- Сквозной прогон на временном проектном скилле `lamp-probe` с `--skill --min` и `--json` — 100 %, ложных 0,
  окружение без предупреждений, код 0. Скилл и фразы удалены, `git status` чистый, кроме своих файлов.

## Открыто
- `thresholds.json` нет — ключи `lab.triggers.*` пока временные (просьба 1). Значения 0.8 / 0.1 — оценка, не калибровка.
- Цена прогона занижена: оборванные на `Skill` запуски не присылают `result` со стоимостью.
- Запрет Artifact и других внешних инструментов слегка меняет окружение относительно живой сессии автора.
  Для скиллов историй это не должно влиять, но если какой-то скилл должен конкурировать с Artifact — автору:
  стоит ли сделать флаг, снимающий запрет?
- `_routing.json` заполнен по плану §5 до появления скиллов: сборщики скиллов могут уточнить фразы.
- В плане §10 и `CLAUDE.md` формат и команда не описаны (просьбы 2, 3).
