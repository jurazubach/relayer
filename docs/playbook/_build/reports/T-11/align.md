## Риски для следующих задач

- **W0** не гоняет `npm run test:hooks` в приёмке — хук можно сломать правкой `check:story` или `story:lint`
  (формат `--json`), и никто не заметит до живой сессии.
- **Формат `--json` у `check:story` и `story:lint` стал контрактом**: `stories[0].errors/endings/runs/nodes.unvisited/problems`
  и `stories[].findings[].{level,check,node,chapter,message,threshold}`. Задачи, которые трогают эти команды
  (новые проверки волн, T-13 мутанты), должны его сохранять.
- **`chapter-writer` / `S-chapter`.** Спека говорит «проверки после главы — полный хук»: это `node scripts/hooks/full.mjs <id>`
  (код 1 — ошибки). Для неполной истории (`beta_stop`) хук не включает `story:lint --partial` — агенту глав будут
  сыпаться находки о ненаписанных главах. Нужна строка в `MODE_BY_AGENT` (режим `partial`), когда появится агент.
- **Шум первой правки.** Прежние ошибки истории приходят как «новые» при первой правке в каждой сессии
  (у истории с пятью C-01 — пять строк). Для Э2–Э3 на текущих историях это будет повторяться.
- Хук печатает «пометь `// намеренно: C-NN причина`» — это формат A-06/`story:lint`; если T-05 или линт поменяют
  форму метки, строку нужно править в `post-edit.mjs`.
- Состояние сессий в `$TMPDIR/relayer-hooks/` не чистится.
