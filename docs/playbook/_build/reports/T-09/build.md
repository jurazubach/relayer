## Решения

- **Кластеры — «первая заявка», без слияния.** Объединение по общим ID (union-find) по «Источникам» и согласиям
  склеивает 692 строки в один кластер: согласия цепляются друг за друга. Поэтому строка входит в первую группу,
  которая её назвала, в порядке: правило `rules.md` с «Источниками» → пункт согласий `for-relayer.md` →
  принцип, на который ссылается флаг, приём или урок («почему хорошо (P-01)»). К чужому кластеру группа
  пристраивается только своей первой ссылкой (головой). Получилось 685 кластеров — в ожидаемых §C 500–700.
  ID кластера — `K-<голова>` (`K-R-29`, `K-mckee-story:P-07`): он не плывёт при пересборке. Одиночки в файл
  не пишутся — строка сама себе кластер. Нюансы, системы, противоречия и разделы attention в кластеры не
  входят: их нельзя закрыть ссылкой на родителя (§C «Защита», п. 4).
- **Владелец — только из `owners.md`** (просьба T-10, п. 4). R/C/F/якоря — по ID. Строка базы — по TH-NN своей
  «опоры»; нет — по большинству «опоры» соседей по кластеру (ничья — меньший TH, как у пересечений §5); нюанс —
  по теме своего P; раздел attention — по якорю `attention-merged.md`, который цитирует его чаще; иначе — по
  ссылкам в тексте строки; противоречие без ссылок — в общий индекс `story-kb` (TH-106). Откуда взят владелец,
  видно в колонке `owner_via`. Остальное — «без владельца» (`--unowned`, `reports/T-09/unowned.md`).
- **Блок, который считается покрытием.** Заголовок markdown в файле скилла-владельца (кроме `sources.md`) с ID
  строки: `алиас:P-NN` (алиас полный или короткий, как в `owners.md`), `алиас:P-NN#нюанс` (или «нюанс» в
  заголовке), `R-NN`, `C-NN`, `F-NN`, `#attn-…`. Тело — до заголовка того же уровня. L2 требует:
  длина не меньше `skill.coverage.block_min_chars`; не меньше `skill.coverage.key_terms_min` из
  `skill.coverage.key_terms` ключевых терминов (самые редкие по базе основы заголовка и «Сути», морфология —
  по началу слова); у P и PAT — «не работает» / «исключение»; если строка стоит в `sources` ключа
  `thresholds.json` — сам ключ. Пример ink в блоке обязан компилироваться (`scripts/lib/compile.mjs`), иначе
  блок не засчитывается. Не прошёл — L1 с причиной в колонке `why`.
- **L3**: блок L2 плюс проверка `story:lint` (C-NN блока есть в `scripts/lint/checks/`, или ID строки стоит
  в коде проверки), блок в `decisions-*.md`, компилирующийся пример ink или мутант в `docs/lab/mutants/`.
  RED — только мутант. Строки владельца `story:lint` (C-52, C-53, `#attn-load` и разделы §4 attention): L3 —
  проверка есть, L2 — строка в «опоре» ключа `thresholds.json`.
- **Кластер покрыт лучшим блоком**, но строка получает его уровень, только если её ID есть в `sources.md`
  владельца (§C: «в reference перечисляются все ID кластера в `sources.md`»). `--min` проверяет кластеры:
  уровень кластера — лучший уровень его строк в работе (`used`).
- **Причины `rejected` — коды**, чтобы их можно было проверить: `not-our-format`, `duplicate:<кластер>`,
  `contradicts:D-NN`, `obsolete:E-NN`, `needs-engine` (пять причин §C). `deferred:E-NN` сверяется с
  `build-plan.md` §11, `merged-into` — с существующей строкой (её уровень и считается).
- **Отменённое** — из `superseded.md` «База»: «в силе» = «—» → `superseded:A-NN`, иначе `used` с пометкой
  «частично» (берётся часть «в силе»). Раздел attention отменённым целиком не бывает. Нюанс наследует отмену P.
- **Ручной слой разделён:** `coverage.json` — статусы, `basis`, `verified_by`, `fidelity` (пишет `--record`
  с проверкой); `clusters.json` — вычисленные кластеры и `manual` (`move`, `th`, `title`). Матрица целиком в
  файл не пишется: уровни меняются с каждым reference, их считает команда (`--json`).
- **Верность**: `--fidelity-sample <скилл> [N]` берёт сначала строки с блоком; N по умолчанию —
  `lab.fidelity.sample`; `--seed` повторяет выборку. Ревьюер пишет итог `--record <ID> fidelity=ok|bad`, сводка
  показывает долю и отмечает ✗ ниже `lab.fidelity.min_share`.
- **`--owners-check`** — постоянная команда вместо `node -e` из `owners.md` §8, с тем же результатом; входит
  в `test:coverage`. Список скиллов берётся из `owners.md` §1, а не из кода.
- **`--affected`** принимает строку (короткий алиас тоже), R/C/F, TH-NN, кластер, алиас разбора или путь
  файла; правка разбора задевает и правила, у которых он в «Источниках». Код выхода 1 — ничего не нашлось.
- Сводка выходит с кодом 1, только если ошибся ручной слой (`coverage.json`) или проверка §8. Отставший
  `clusters.json` — предупреждение в сводке и падение `test:coverage`.
