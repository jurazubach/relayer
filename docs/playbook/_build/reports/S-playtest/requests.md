# S-playtest · просьбы за пределами разрешённых путей

## 1. Заменить заглушку протокола холодного читателя протоколом скилла

- **Что.** `scripts/story/selftest.mjs`, тест «cold-read: режимы return и voices; протокол; проверка изоляции»:
  читать протокол из `.claude/skills/story-playtest/references/cold-reader.md`, а не из
  `scripts/story/cold-reader-protocol.md`; добавить проверку профилей (`readProfiles` экспортирует
  `scripts/story/cold-read.mjs`). После этого удалить `scripts/story/cold-reader-protocol.md`.
- **Зачем.** Задача просит заменить заглушку протоколом `story-playtest` (TH-88). `story:cold-read --ask` уже
  берёт протокол скилла по умолчанию (заглушка — запасной путь, если скилла нет в проекте), но самопроверка
  команд читает заглушку, поэтому удалить её сейчас — уронить `test:story-cmd`. В заглушке пока исправлен К3
  (без «что у тебя в контексте») — она не расходится с протоколом скилла по контрольным вопросам.

## 2. README команд story:*

- **Что.** `scripts/story/README.md`, раздел «Холодный читатель (`story:cold-read`)» и строка таблицы: протокол —
  `story-playtest/references/cold-reader.md`; новые флаги `--profile` (hurried, attentive, skeptic, distracted,
  unresponsive) и `--last N` (срез без контекста); строки ответа об окружении (почта, рабочая папка, пути)
  вырезаются из сохраняемого ответа, счёт — `isolation.env`.
- **Зачем.** README описывает заглушку и не знает о профилях.

## 3. Мутанты для красных флагов зоны story-playtest (L3)

- **Что.** `docs/lab/mutants/`: зона `story-playtest` и мутанты на флаги, которые ловит панель, а не `story:lint`:
  `narrative-testing:RED-22` (пересказ после главы 1 не называет цель), `RED-23` (первый контакт не говорит, кто
  он игроку), `attention-today:RED-04` (кнопка непонятна по трём строкам над ней). Ключ — ответы холодного
  читателя (`panel.mjs`), а не находка C-NN; `skills:test` для этого нужен режим «читатель», которого нет.
- **Зачем.** `story:coverage` признаёт RED на L3 только с мутантом; остальные RED скилла (RED-14, RED-15,
  RED-18, RED-19, RED-07, RED-28, RED-20) — про отзывы тестеров или уже у `story:lint` (C-16, C-24), мутант
  на них не имеет смысла. Сейчас все они на L2.
