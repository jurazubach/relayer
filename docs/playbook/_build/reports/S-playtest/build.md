## Решения

- **Ключи `lab.playtest.*`, а не `playtest.*`:** валидатор `thresholds.json` пускает только области из списка;
  `lab` — эксперименты и тесты, поле `checks` не нужно (своих проверок у скилла нет).
- **Протокол в скилле, заглушка остаётся запасной:** самопроверка `test:story-cmd` читает заглушку, а она вне
  моих путей — удаление через просьбу. `cold-read.mjs` берёт протокол скилла, если скилл есть.
- **Против доброжелательного читателя (находка W0):** профили + обязательное «Слабое место» в каждом ответе +
  у `hurried` фраза «бросаешь большинство историй». Прогон подтвердил: «Итог» у всех 18 читателей (панели 9 + 8 и одиночный скептик) — «дочитал бы»,
  но слабые места названы и совпадают у разных профилей (на «THE NUMBER» двое независимо — одна автоматическая
  рассылка); это и есть материал для сводки, а «дочитал бы» — не оценка.
- **Совпадение профилей — «кандидат», не обязательная строка:** профили — одна модель, а не независимые люди
  (P-06 про независимые повторы). В обязательный список — только живые люди; симуляция с замером — кандидат
  с подтверждением.
- **Пропуск бессмысленных точек с причиной:** `unresponsive` без `#remind` = случайная персона (в трёх историях
  `#remind` нет — это находка для `story-time`, C-32); `distracted` в `return` без паузы до точки — не к чему
  возвращаться. Панель печатает пропуск, а не гоняет пустой прогон.
- **Набор для тестера с id `<id>-wN`:** встроенная история вытесняет загруженную копию с тем же id, и прогресс
  смешался бы. Сообщение `beta_stop` — системная строка по ST-70 (без «ты» и «!»).
- **Блоки «чужих» ID не пишу:** P-15, P-16, P-05 у других владельцев — ссылкой в тексте, не заголовком.
- **Строки уроков — в `lessons.md`, а не в целевых файлах `owners.md`:** `story:coverage` считает блок в любом
  reference владельца; темы держат правила, уроки — карточками с классом доказательства.
- **«Неотвечающий» только в реальном времени:** по клику напоминаний нет (A-04), персона стоит.
