# S-kb · Просьбы за пределами разрешённых файлов

1. **Конвейер (`docs/playbook/_build/`), проверка «готово» S-kb** — `npm run lab:triggers -- --skill story-kb
   --runs 3 --min build` даёт 345 запусков `claude` (у `story-kb` семь соседей, каждый со своими фразами):
   ≈13–15 минут при `--jobs 3`, больше при `lab.triggers.jobs`. Зачем: в одном вызове с пределом 10 минут
   она не проходит. Просьба: запускать с большим сторожем или по частям `--file`; результаты частей — в
   `docs/lab/runs/S-kb/`.
2. **`docs/lab/triggers/_routing.json`** — добавить маршрут общего вопроса ремесла к скиллу темы, например
   «Сколько кнопок ставить в развилке и какой длины их писать?» → `story-choices`, «Какой длины должно быть
   сообщение в чате?» → `story-voice`. Зачем: граница «вопрос к базе» ↔ «вопрос по теме» держится только
   описанием `story-kb`; маршрут закрепит её для всех скиллов.
3. **Проверка перед коммитом (`CLAUDE.md`, общий файл)** — по желанию добавить
   `node .claude/skills/story-kb/scripts/kb-index.mjs --check` и `kb-contradictions.mjs --check`: генерируемые
   индексы устаревают при смене владельцев в `owners.md`. Сам не добавил: строка общая, её правят все задачи.
