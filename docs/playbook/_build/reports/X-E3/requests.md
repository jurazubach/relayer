## Сделано вне списка «можно менять» — по правилу эксперимента

Правило «Как делать эксперимент» требует, чтобы новый `LOCAL-NN` получил владельца (`manual.th`). Без этого
`story:coverage -- --summary` падает («без владельца»). Сделано точечно, как в X-E2:

| файл | что |
|---|---|
| `docs/playbook/clusters.json` | `manual.th`: LOCAL-17 → TH-60 (`story-endings`), LOCAL-18 → TH-46 (`story-time`), LOCAL-19 и LOCAL-20 → TH-84, LOCAL-21 → TH-86 (`story-fix`) |

Откатывать — только вместе с `local-lessons.md` LOCAL-17…21 и блоками `### LOCAL-NN` в lessons владельцев.
