## Решения

- **Свежее ревью, а не прогоны Э2.** Скиллы менялись после Э2, и ремонту нужен отчёт той же ревизии. Один прогон в
  слепой копии той же фразой, что в Э2.
- **Какие пункты.** Из 81 пункта взяты 14 по темам задачи: 3 (срок за кнопкой), 7 + 50 (контакты главы 1),
  43 + 46 + 76 + 22 (эпилоги и развязка пилота), 42 + 70 + 44 + 45 + 51 (видимость порогов финала), 18 + 2 (мёртвые
  переменные), 54 (напоминания). Род игрока (пп. 5, 6) — P1, но вне тем задачи: отложен с записью в `STATUS.md`.
  Разметку A-06 (`// финал:`, пп. 37, 69) не взяла: задача про ремонт текста — это ошибка выбора, см. «Открыто».
- **Одобрение двумя сообщениями.** `story-fix` сначала показывает варианты (`--resume` той же сессии), королева
  одобряет по пунктам — как с автором. К п. 3 добавлена поправка «и строка о смерти»: холодный читатель «до» не знал,
  что случилось.
- **Три прогона правки вместо одного.** v1 вскрыл два дефекта, которые видит только отложенный замер, и пять отказов в
  правах; скиллы поправлены и проверены v2 на чистой копии; v3 — контроль отказов после полного абзаца. Итог в ветке —
  v2: он прошёл полный цикл «правка → повтор линзы → новая находка → одобрение → правка».
- **Признак перекрытия без порога.** Чисел вне `thresholds.json` нельзя, а порог по одному прогону не откалибровать:
  признак сравнивает модальный финал по кнопкам при значении флага и без него, только для переменных, которые
  распределитель читает сам (производные давали ложные). Проверен: v1 и v2 — только настоящий флаг, три истории
  каталога, основа и 27 мутантов — 0.
- **C-32 в `ch1_unknown`** — «намеренно» (D-02): «не ответил» не совершает поступок «Заблокировать» за игрока (A-03).
  Правильнее чинить проверку — просьба.
- **Холодные читатели** — три точки, по одной на тему ремонта (начало, неотвечающий, развязка), тем же маршрутом
  до и после; для v1 — те же три.
