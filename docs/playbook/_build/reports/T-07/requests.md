# T-07 · просьбы за пределами разрешённого

1. **`CLAUDE.md`, раздел «Команды» и схема «Устройство».** Добавить строки:
   - `npm run kb:clean` — очищенная копия базы `docs/books/_clean/` (без строк про наши истории), вырезанное — в `docs/lab/cases/`; `--verify` проверяет копию;
   - в схему: `scripts/kb/` — инструменты базы знаний; `docs/lab/cases/<история>.md` — кейсы наших историй для экспериментов (собираются `kb:clean`, руками не править).

   Зачем: сборщики (T-09, T-10 и дальше) должны знать, что читают `_clean`, а не `docs/books/`. Иначе скиллы снова наберутся примеров из трёх историй.

2. **Свод `docs/playbook/` (T-05/T-10).** В базе остались советы, которые учат опираться на наши истории без названия: «дать модели 1–2 образцовые сцены из наших историй» (`procedural-storytelling`: `principles.md` и `checklists.md`), «замеры по нашим историям» в `attention.md` семи разборов. Упоминаний по словарю там нет, поэтому `kb:clean` их не трогает. Сборщику свода стоит заменить их на «образцовые сцены из придуманного эталона», как велит INTENT («примеры внутри скиллов придуманные»).
