# T-10b · Просьбы за пределами разрешённых файлов

1. **`scripts/kb/kb-clusters.mjs`, `assignOwners`** — нюанс берёт тему родителя, только если у родителя своя
   «опора» или кластер (`direct(r.parent)`, `clusterTh`). Родитель с владельцем по ссылкам (`via: refs`) нюансу
   его не передаёт: так 9 из 29 нюансов остались без владельца при владельце у P/PAT. T-10b обошла это,
   дописав родителей в «опору» явно. Просьба: нюанс без своей опоры — владелец родителя, как бы тот его ни
   получил (порядок в цикле: сначала строки базы, потом нюансы). Зачем: следующий нюанс с родителем «по
   ссылкам» снова уронит `--summary`.
2. **`scripts/kb/kb-clusters.mjs`, голосование кластера** — владелец «по кластеру» местами ошибается по теме:
   `narrative-testing:P-02` («работает по замыслу» против «замысел хорош») был у `story-pauses`,
   `narrative-testing:P-04` и `LESSON-01` (транскрипт и журнал выборов) — у `story-fix`, тесты бота
   `narrative-testing:P-11`, `P-12`, `LESSON-03`, `LESSON-04` — у `story-endings`. Первые три T-10b закрепила
   явно (TH-28, TH-91), остальное не трогала: задача — строки без владельца. Просьба к ревьюеру T-16 / F-final:
   пройти `npm run story:coverage -- --skill <скилл>` по строкам с `owner_via: cluster` и `refs` своего скилла
   и дописать чужие в «опору» верного TH-NN.
