1. **`docs/playbook/README.md`** — добавить строку о `superseded.md`: «реестр отменённого решениями автора:
   ID → решение (дата) → чем заменено». Зачем: файл — один из источников правды (`build-plan.md` §1), а
   README перечисляет файлы свода.
2. **`docs/playbook/REVIEW.md`, таблица согласования порогов, строка «причина паузы»** — значение «от 15 мин,
   время — от 3 ч» устарело: время возвращения больше не называется (`rules.md` R-63, `superseded.md` A-01).
   Строку «реальное время истории … 48 ч» дополнить «потолок около 3 дней» (R-67, A-05).
3. **`docs/playbook/skills.md` D-01** — пометить в заголовке «заменено `build-plan.md` §9, см.
   `superseded.md` A-06», чтобы сборщики не взяли десятиполевую шапку. Там же S-06 (`pause-audit`): проверки
   «время возвращения названо» и «ночь игрока» отменены (A-01, A-02).
4. **T-02 (формат истории)** — в `characters` файла `meta.json` нужны служебные поля, которые не показываются
   игроку на экране истории: голос (`rules.md` R-75) и смена функции по главам (R-76). Сейчас `role` и `about`
   видны на `StoryScreen`, и «виновная с главы 8» там была бы спойлером. Плюс поле `days` рядом с `minutes`
   (R-11, C-31) — оно уже есть в плане T-02.
5. **T-03 (`story:lint`, `thresholds.json`)** — завести ключи для чисел, которые T-05 записал словами по
   решениям автора и базе, а не ключами (файла ещё нет):
   - длина истории: цель 48 ч, потолок 72 ч (R-67, C-31);
   - пауза — не больше 24 ч; после последней кнопки — 15 мин (R-67, R-110, C-42);
   - напоминания — не больше 2 (R-120, C-32 п. 6);
   - порог метки «спустя N» в режиме «по клику» (R-122) — числа нет ни в плане, ни у автора;
   - сон → утро не меньше 5 ч (R-67, R-121, C-32 п. 5);
   - расхождение карточки с замером — в полтора раза (C-31, наша оценка).

   Там же: словари «срок возвращения», «упрёк за отсутствие», «прожитое ожидание», «время игрока» из
   «Общих данных» `checks.md`; словарь угрозы для передышек C-38; валидатор разметки по таблице C-53.
6. **T-04 (`story:trace`)** — персона «неотвечающий» должна уметь сравниваться с персоной, которая в той же
   развилке жмёт `#silent` (C-32 п. 7).
7. **E-02 (движок)** — синтаксис напоминаний и ветки «не ответил» в `docs/capabilities.json`. Свод исходит из

   `#silent`, если он есть. Если движок решит иначе — поправить R-120 и C-32.
