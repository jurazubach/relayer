## Решения

- **Дубли — статусами, а не блоками.** Сначала закрыл 37 повторов `merged-into` (пять уроков «не продавай лучший
  вариант», четыре разбора одного эпизода с выравниванием знакомства, восемь записей спора «откликаться на
  каждую переменную / на немногое» и т. п.); у целевого блока в теле названы влитые ID и их оттенки. Остальное —
  блоки по кластерам. Итог: 444 строки, 246 кластеров, used — 282 L3 и 125 L2, ниже L2 — ноль.
- **Блоки там, где читают, а не строго по `target`.** RED/GREEN — в `flags*.md`, уроки — в `lessons*.md`, приёмы
  с ink — в `patterns-*.md`; длинные темы разрезаны, чтобы каждый файл был не длиннее `skill.reference.max_lines`.
- **`sources.md` переверстан.** Генератор даёт 558 строк (строка на ID), skill-check роняет больше 350.
  Генерирую `--sources --write`, затем `sources-compact.mjs` склеивает ID по кластерам TH (состав не меняется;
  нюансы — отдельными строками, иначе `headingIds` считает нюансом всю строку). Просьба о `--compact` —
  `requests.md`.
- **Описание без «граф почти линейный».** В `_routing.json` эта фраза у `story-branch`; у нас лечение коридора —
  F-11, а в описании «ветки сходятся и всё забывают».
- **Калибровка мутантов (план: «на этом скилле калибруются»).** `skills:test --skill story-choices --control`:
  4 мутанта × 2 прогона, полнота 8/8, все попадания — по узлу дефекта и своей C-NN; на чистой основе по 10
  находок (6 подсказок линта + суждения модели, в т. ч. C-10 в `ch3_call`/`ch3_end` каждый раз).
  `lab.mutants.skill_min_recall` оставлен 0.8 (на 8 прогонах — не больше одного промаха), записан
  `calibrated_on` и история. Строгость `matchFinding`: совпадения «только по C-NN» мало — шумовая C-10 засчитала
  бы m14 без находки в узле; предлагаю «узел дефекта или находка без узла» (в `scripts/lab`, вне моих путей —
  `requests.md`).
- **C-17 не трогал.** На трёх историях много срабатываний на выборе действия, где одна кнопка — другому адресату
  («решай ты» начальнику). Отличить такое от дилеммы по графу нельзя без смысла; добавил в `people-choice.md`,
  как модели гасить это с причиной, а порог оставил.
- **Ключ вместо «3 сообщений»** в `attention.md`: нарезка «без пересказа», но «числа — ключами»; ключа не было,
  завёл `attn.echo.reply_msgs` (level null, `checks: C-04`), просьба поправить сводный файл — `requests.md`.

  7 отрицательных фраз с `expect` пропущены; перехват соседних тем проверится после их сборки.
