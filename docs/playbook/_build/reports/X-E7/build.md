## Решения

- **Время мира — в ядро, а не паузы правкой.** Ревью сказало, что в гл. 5, 7, 9 ночь держит сроки сюжета. Новое ядро
  D-04: среда вечер → рассвет воскресенья, слушание в пятницу в 10, ночь ≈ `story.sleep_morning.min_h`, её
  объявляет персонаж; заголовки глав — день недели и время суток вместо «День N» (панель путала их с днями игрока).
- **Ядро и план записаны так, чтобы главы не устарели:** главы переписаны после D-04 и D-05, `stale-check` п. 3
  глав не показывает (устарели только отчёты ревью до переписи — это верно).
- **Перепись по главам параллельно**, по копии на главу и только свой файл: в десять раз быстрее подряд, сведение
  дешёвое (LOCAL-25). Главы 1, 2, 7, 9, 10 — `chapter-write` начисто, 3–6, 8 — `story-fix` (как советовало ревью).
- **Напоминания — у вопроса, а не у каждой реплики** (план §5, LOCAL-23): 69 развилок «ждёт» по `guilt-scan` — без
  вопроса, с `#noanswer`; неотвечающий нигде не стоит, его время +11 %, упрёков 0. Задача говорит «в каждой
  развилке, где собеседник ждёт ответа», — «ждёт ответа» прочитано как вопрос или просьба решить.
- **Финалы — шесть**, `fin_puppet` — оттенок `fin_scapegoat`; исход решает кнопка у двери, пост Маи — обстоятельство;
  молчание у Маи — пост без имени (своя цена, не месть); путь молчащего — `fin_silence` (R-103).
- **Состав гл. 1 — Элли, Джесс, Коннор**; Неизвестный номер — первая строка после ночи в гл. 2 (ночь внутри гл. 2,
  стык 1→2 — 45 мин: C-32 п. 4); Оуэн и Бет пишут сами в гл. 3; запрет «оуэну НЕ пиши» — без кнопки.
- **Легенда без рода:** «учебный опрос для университета» или «помогаю знакомой», ответы по легенде у всех.
  Внутреннее значение `cover = "student"` оставлено (игрок его не видит).
- **Ревизия 2, платной границы нет до живого теста, C-16 у двери — намеренно** (D-07…D-09, решения королевы на
  вопросы гейта); `minutes` — 40 по замеру гейта (D-10).
- **Пропущено осознанно:** `story-review --plan` по скелету (D-06: план построен прямо по ревью целиком).
- **Состояние THE NUMBER не тронуто:** `story-desk` дважды предлагал снять с неё «активная: да» — в репозиторий не
  перенесено (решение автора 28.10); `story-status --check` поэтому ✗ «две активные» (просьба).
- **Потоки `stream-json` в репозиторий не положены** (≈ 50 МБ): вычищены из коммитов ветки, оставлены `result.json`
  и сжатые транскрипты.
