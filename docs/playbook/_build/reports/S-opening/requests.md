# S-opening · просьбы за пределами разрешённых путей

1. **Мутанты на красные флаги начала без мутанта** — `scripts/lab/mutants-spec.mjs`, `docs/lab/mutants/` (задача T-13
   или следующая волна мутантов). Шесть строк зоны `story-opening` с ботом или моделью в «как обнаружить» стоят на
   L2, а не на L3, только потому, что RED засчитывается на L3 лишь с мутантом: `video-three-things:RED-11`
   (первый ответ игрока перекрыт), `video-three-things:RED-05` / `RED-07` (сильная вещь только в карточке, кнопки
   мимо ядра), `mckee-story:RED-06` (кнопка «вернуться» ведёт туда же, что и рискованная), `snyder-save-the-cat:RED-07`
   (монолог без таймера), `nicklin-writing-for-games:RED-15` (нет формата). Предложение: два мутанта — «монолог о
   прошлом до первой кнопки» (ловит C-35 и C-47 `C-47.backstory`, скилл чинит F-04) и «первый ответ перекрыт» (ловит
   только скилл: «отмахивается» в ветке первого выбора). Первый закроет и `edgerton-hooked:RED-03`, и F-04 на L3.

2. **`docs/playbook/coverage.json`** — общий файл, правился только командой
   `npm run story:coverage -- --record … by=S-opening` (12 строк `merged-into`: дубли R-13, R-18, C-23, R-12). Если
   королева предпочитает, чтобы статусы ставил ревьюер, — откатить эти 12 записей и закрыть строки блоками.

3. **`docs/playbook/checks.md` C-23, раздел «Как считать»** — текст не правил (вне путей, правил только строку
   «Ключи»). Детектор инцидента в коде расширен: срок мира, угроза (`dict.threat`), `#unlock`, фото **или прямой вопрос
   игроку, кроме приветствия** — иначе на двух историях из трёх инцидент «только на 15-м входящем» при событии во
   втором-третьем. Запись — в истории ключа `attn.opening.incident.msg`. Просьба: дописать в описание C-23 строку
   о вопросе-инциденте, а в C-22 — о `C-22.rare_chapters`, телефоне одной сущностью и `C-22.everyday`.

4. **`docs/playbook/checks.md` C-24, «Как считать»** — добавить второе измерение `C-24.by_msg` (номер входящего, где
   ставка впервые звучит; R-17 «не позже 10-го входящего») и упоминание перебора маршрутов `first-minutes.mjs`
   (`C-24.routes_max`). Ключи уже в строке «Ключи» и в `thresholds.json`.

5. **`CLAUDE.md`, таблица «симптом → скилл»** (если её заводит другая задача): строка «начало не цепляет, непонятно,
   кто пишет, первая кнопка поздно, ставка не на всех путях → `story-opening`».
