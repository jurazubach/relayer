# A-architect · просьбы за пределами разрешённых путей

1. **Сторожа агента — в файлы `scripts/hooks/architect-write.mjs` и `architect-bash.mjs`** (сейчас — два
   однострочных `node -e` в `hooks:` frontmatter `.claude/agents/story-architect.md`).
   Зачем: при отказе Claude Code показывает агенту весь текст команды хука (≈ 900 знаков) — шум в контексте
   (`claude-code-format.md` §2.5); в прогоне 3 так вышло на трёх `grep`. Плюс случаи в `npm run test:hooks`
   (31 случай из `build.md`, раздел «Проверки»). Та же просьба есть у A-auditor и A-cold: общий модуль сторожа
   с белым списком на агента.

2. **`story-plan/SKILL.md`, шаг 4: вызов агента.** Где: `.claude/skills/story-plan/SKILL.md` (и `story-core` шаг 8,
   `story-branch/references/plan-update.md` шаг 2). Что: «варианты в фоне — агент `story-architect`, задание: история,
   ядро D-NN, вариантов, бесплатных глав, рамка, повод»; после возврата — сверить `core:` с `STATUS.md`, показать
   таблицу автору, после выбора скопировать скелет в `plans/skeleton.ink` и запарковать остальные через `idea-park.mjs`
   строками из раздела «в ideas.md» ответа агента. Зачем: сейчас ни один скилл не говорит, как и с чем звать агента;
   контракт задания живёт только в файле агента.

3. **`skeleton-format.md`: строка `статус:` в `plan-vN.md`.** Агент пишет третьей строкой
   `статус: на выбор · story-architect · <дата>`; после выбора `story-plan`/`story-desk` меняют её на
   `выбран` / `отвергнут: <причина>`. Зачем: формат знает только «отвергнутые — с пометкой», а где и как — нет.

4. **Разрешения для фоновых агентов в недоверенной папке.** Хуки агента и разрешения проекта работают только в
   принятой папке: в копии репозитория (scratchpad) все `node .claude/skills/…` получили «requires approval» даже
   с `permissionDecision: allow` в хуке. Записать в `claude-code-format.md` §2.5 как [эксп]: тест агентов —
   только из принятого каталога (корень или worktree репозитория).

5. **Шапка `// оси:` от `core-snapshot.mjs --header` не проходит C-53.** Прогон 3: `core-snapshot.mjs` печатает
   `// оси: miron_trust (доверие Мирона, счётчик), proof (…)`, а `story:lint` C-53 разбирает слово из скобок как
   имя переменной («счётчик — нет такой VAR»). Где: `.claude/skills/story-core/scripts/core-snapshot.mjs` (печатать
   только имена) или разбор `// оси:` в `scripts/lint/checks/C-53.mjs` (игнорировать скобки). Зачем: каждый скелет
   из записанного ядра получает ложное предупреждение.

6. **Одно определение «дорогой развилки».** Прогон 3: `plan-check`/`plan-compare` (`skill.plan.branches`) насчитали
   3 дорогих развилки, `branch-budget.mjs` на тех же скелетах — 1 («мало»): строка-сцена скелета короче
   `story.branch.expensive.msgs`. Это риск из `S-plan/align.md` и `S-branch/align.md`, на живом скелете он
   подтвердился. Где: `story-plan/scripts/plan-check.mjs` и `story-branch/scripts/branch-core.mjs`. Зачем: архитектор
   отдаёт автору два разных числа об одном и том же; на скелете `branch-budget` ещё и систематически занижает.
