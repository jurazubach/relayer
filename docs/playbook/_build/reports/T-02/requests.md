# T-02 · Просьбы за пределами разрешённых файлов

1. **`src/ui/StoryTile.tsx:15`, `src/ui/StoryScreen.tsx:34`** — передать дни в подпись:
   `sizeLabel(story.chapters?.length, story.minutes, story.days)`. Зачем: замысел требует на карточке два
   числа, минуты по клику и дни в реальном времени. `sizeLabel` в `src/engine/library.ts` уже принимает
   третий аргумент («5 глав · ~25 мин · ~7 дней», меньше суток показывается часами), а `ui` не в моём списке.
2. **`scripts/build-prompt.mjs`, раздел «Что ты отдаёшь»** — в образце `.json` поправить комментарий
   `"minutes"` на «сколько минут по клику, без ожиданий». Добавить `"revision": 1` и `"days"`, а в персонажа
   `voice` и `arc` с пометкой «служебное, игрок не видит» (R-75, R-76). Зачем: генератор должен писать
   новые поля. Пример `examples/demo.story.json`, который промпт вставляет целиком, я уже дополнил.
3. **`docs/playbook/story-findings.md`, `docs/playbook/REVIEW.md`** — там написано «номера строк — по полю
   `ink` из `src/stories/*.json`». Этих файлов больше нет. Те же номера даёт склейка:
   `npm run story:pack -- --flat --out <папка>` собирает `ink` байт в байт как прежний. Ещё можно
   перевести ссылки на `chNN.ink:строка`. Зачем: иначе находки ведут на несуществующий файл.
4. **T-03 (`story:lint`)** — подключить `layoutProblems(story)` из `scripts/lib/story.mjs`. Он ловит узел
   в главном файле, текст до первого узла в главе, `INCLUDE` не из главного файла и неподключённый `.ink`.
   Сейчас это проверяет только `story:pack -- --check`.
5. **T-11 (хуки)** — матчер на `src/stories/**` теперь видит правки `.ink` и `meta.json`. Быстрый режим
   на правку главы может гонять `check:story -- <id>` по папке и `story:pack -- --check <id>`.
