# Как делать задачу с кодом

- Перед правкой прочитай код, который меняешь, и его тесты.
- Перевод скрипта на общую библиотеку не меняет поведение: сравни вывод до и после на трёх историях.
- Новые команды — npm-скриптом в `package.json`, с `--help` и `--json`.
- Изменения в `src/` проверяй сборкой (`npm run build`) и e2e (`HEADLESS=1 npm run test:e2e`).
- Если меняешь формат истории или поведение чата, обнови README, `CLAUDE.md` и `docs/capabilities.json` в том же коммите.
- Для своей части добавь самопроверку (`npm run test:lib` или аналог), которую прогонит конвейер.
