# Что проверить

1. **Замысел.** Отвечает ли результат хотя бы одной боли автора? Нет ли решений против решений автора:
   - персонаж называет срок паузы;
   - упрёк за отсутствие;
   - привязка к часам игрока;
   - платные выборы;
   - замки между историями;
   - другая модель вместо Opus;
   - пуш в `master`.
2. **План.** Задача сделана в рамках своего раздела. Нет расползания: чужая зона, лишние фичи, подмена контракта. Нет тихих отступлений от плана без записи в отчёте.
3. **Единые правила:**
   - числа только в `thresholds.json`;
   - один владелец темы: нет дублей с уже слитыми скиллами (посмотри `.claude/skills/*` в этой ветке);
   - имена и ID совпадают со сводом.
4. **Утечки.**
   - Нет строк про наши три истории внутри скиллов, кроме разрешённых мест (`docs/lab/`).
   - Нет копий текста книг.
   - Нет реальных брендов.
5. **Совместимость.** Не ломает ли результат задачи, которые идут следом (`docs/playbook/_build/tasks.json`): имена команд, форматы файлов, пути.
