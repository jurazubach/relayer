# Как делать задачу с документом

- Документ — рабочий инструмент: каждое положение можно применить, проверить или вставить в промпт. Без воды.
- Опирайся на свод (`docs/playbook/*`) и базу (`docs/books/*`), ссылайся на ID. Решения автора — из `INTENT.md` и `superseded.md`.
- Числа — только ключами `thresholds.json` (если файл уже есть) или с пометкой «наша оценка» и источником.
- Если документ заменяет часть другого, отметь это в обоих местах.
