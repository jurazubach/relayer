# Как собирать агента

Контракт — `docs/playbook/build-plan.md` §6. Формат агентов Claude Code — `docs/playbook/claude-code-format.md`.

Файл: `.claude/agents/<имя>.md`.

## Frontmatter

- `name`;
- `description` — «Вызывается скиллами …», без пользовательских фраз: автор зовёт скиллы, а не агентов;
- `model: opus`;
- `tools` — минимум для роли, **без `Agent`/`Task`**: вложенный запуск агентов работает, запрет сам не действует (`claude-code-format.md` §2.3, §9);
- пишущий агент — `permissionMode: acceptEdits`; ограничение путей записи — хуком `PreToolUse` по `tool_input.file_path` и `agent_type` (в `hooks:` агента или в `.claude/settings.json`), а не надеждой на `tools`;
- `skills:` — если `claude-code-format.md` подтверждает предзагрузку.

## Тело

- роль в 2–3 строках;
- таблица «ситуация → скилл → какие references читать» с путями к существующим файлам `.claude/skills/*`;
- порядок работы;
- формат выхода: находки в общем формате или файл по контракту;
- запреты:
  - не вызывать других агентов;
  - не спрашивать автора: агент возвращает результат один раз;
  - не писать за пределами своих путей;
  - числа брать только из команд.

## Проверка

Прогони агента на одной истории через `claude -p` с промптом, как его вызвал бы скилл. Результат положи в отчёт. Для `cold-reader` проверь изоляцию: он не должен знать имя виновника или последний узел.
