# Правила

- **Не запускай команды в фоне** (`run_in_background`, `&`, Monitor): в режиме `claude -p` процесс молча ждёт фоновые задачи после ответа, и сторож конвейера убивает его через 25 минут без вывода. Долгие команды (`lab:triggers`, `skills:test`, e2e) — в переднем плане с большим `timeout` (до 10 минут на вызов; длиннее — дроби прогон, например `--skill` по одному).
- **Код и тексты** — на русском, по договорённостям `CLAUDE.md`. Комментарии в коде только там, где объясняют «почему».
- **Без новых зависимостей.** Инструменты пиши на Node без пакетов, используй то, что уже есть (`inkjs`). Скрипты в `scripts/` — ESM `.mjs`, у каждого `--help`.
- **Поведение чата меняешь** — правь `docs/capabilities.json` в том же коммите и проверь `npm run prompt -- --quiet`.
- **Git.** Работай только в своей ветке задачи: не переключай ветки, не пушь (в `master` сливает и пушит конвейер), не делай rebase общих веток. Коммить свою работу в текущую ветку: осмысленное сообщение по-русски, последней строкой `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **`docs/books/*` и `{{pipeline}}/*` не меняй**: это источник знаний и сам конвейер.
- **Числа и пороги** живут только в `docs/playbook/thresholds.json`. В остальных местах — ключ.
- **Истории полностью вымышлены.** Примеры внутри скиллов придумывай сам, не бери из трёх наших историй.
- **Не копируй текст книг.** Пересказывай своими словами. Цитата — не длиннее 15 слов.
- **Неизвестный факт о Claude Code** проверь в документации (WebSearch/WebFetch) или в `docs/playbook/claude-code-format.md`, если он уже есть.
- **Не вызывай скиллы через Skill tool и не запускай субагентов.** Работай сам.
