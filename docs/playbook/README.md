# Свод базы знаний

Здесь собрано то, что 30 разборов из `docs/books/` дают для relayer: правила для генератора,
спецификация автопроверок, находки по трём историям и план скиллов. Разборы — это сырьё
(принципы `P-NN`, паттерны `PAT-NN`, флаги `RED-NN` по каждому источнику). Свод сливает одинаковые
идеи, решает споры между источниками под нашего игрока и ссылается обратно: `алиас:P-NN` — пункт
в `docs/books/<алиас>/`, `алиас:§N` — раздел `for-relayer.md` этого разбора.

Собран скриптом `docs/books/_pipeline/synthesize.mjs` по шаблону `synthesize.md`. Ревью свода —
`REVIEW.md`.

## Части

| файл | что внутри | как пользоваться |
|---|---|---|
| `rules.md` | 119 правил `R-NN` в 9 разделах, сверху — короткая версия из 20 строк | Короткую версию вставлять в промпт генератора как есть. Полные правила — при ревью и правке промпта. Строки «Спор:» в промпт не идут. |
| `superseded.md` | реестр отменённого решениями автора: ID → решение (дата) → чем заменено | Выше базы и свода: сборщики и проверки не берут отменённое как действующее. |
| `checks.md` | 54 проверки `C-NN`: данные, формула, порог, текст, уровень, сложность; первая волна из 15 | Спецификация для `scripts/check-story.mjs` и `scripts/story-graph.mjs`. Внизу — прогон первой волны по трём историям. |
| `story-findings.md` | Находки `CG-NN`, `SP-NN`, `TN-NN` по трём историям, сверху топ-10 правок | Брать правки сверху вниз. Каждая находка указывает узлы ink и правку. В конце — что не подтвердилось. |
| `skills.md` | Шапка `D-01`, команды `K-NN`, скиллы `S-NN`, ремонтные приёмы `F-NN` | План реализации: волны и зависимости — в начале файла. |

Пороги в `rules.md`, `checks.md` и `skills.md` согласованы: правило и проверка об одном и том же
используют одно число. Меняешь порог — меняй во всех трёх файлах.

Разметка комментариями в ink (`// ядро:`, `// герой:`, `// reveal:`, `// крючок:` и другие) одна
на весь свод. Схема — `skills.md` D-01, метки проверок — `checks.md` C-53.

## Правила правки свода

- Новый пункт ссылается на существующий `алиас:P-NN` или `RED-NN`. Проверка ссылок — скрипт
  из `REVIEW.md`, раздел «Как проверяли».
- Цитаты из книг не переносить, формулировки свои. Всё в историях вымышлено (`CLAUDE.md`).
- `R-NN` — правила, `C-NN` — проверки, `F-NN` — ремонтные приёмы. Номера не переиспользовать.
