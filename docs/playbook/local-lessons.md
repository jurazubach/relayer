# Наши уроки (`LOCAL-NN`)

Что мы узнали на своих историях, мутантах и прогонах скиллов. Это не база (`docs/books/`) и не свод
(`rules.md`): урок держится на нашем замере и записан в журнале `docs/lab/journal.md`. Формат: **было →
поменяли → результат**. Если правка ещё не сделана, в «поменяли» стоит, что предложено и кому, а в «результат» —
чем это проверено и что осталось открытым. Класс доказательства — как в `lessons.md` скиллов: A — наш эксперимент
или замер, B — постмортем с цифрами, C — мнение. Числа — только ключами `thresholds.json` или ссылкой на прогон.

Скилл, которому урок нужен, ссылается на него по ID (`LOCAL-NN`) из своего `lessons.md`, а не переписывает.

## LOCAL-03 · `Bash(npm run story:*)` не пропускает ни одной команды `story:*`

- **Было:** скиллы (`allowed-tools`), `scripts/lab/skills-test.mjs` (`ALLOW`) и шаблон скилла писали
  `Bash(npm run story:*)`. Хвост `:*` равен « *» с пробелом, поэтому `npm run story:lint` под правило не подходит.
  В `claude -p` каждый прогон `story-choices` получал два отказа и запускал `node scripts/lint/lint.mjs` в обход,
  без `--json` из своего шага 2.
- **Поменяли (предложено королеве):** `Bash(npm run story*)` и `Bash(npm run -s story*)` в `allowed-tools` скиллов,
  в `ALLOW` у `skills-test.mjs`, в шаблоне `prompts/type-skill.md` и в `claude-code-format.md` §9.
- **Результат:** проверено в `claude -p`: старое правило даёт отказ, новое — ok, в том числе с `2>&1 | head`
  и в `allowed-tools` самого скилла без внешнего `--allowedTools` (`docs/lab/runs/X-E2mini/permissions.md`).
  Класс A. Журнал: 2026-10-25 · X-E2mini. Сделано: правило поправлено везде (W1), `skills:test` и `lab:triggers` считают
  прогон с отказом на Bash/Skill недействительным, `--control` хранит находки основы (T-17); `skill-check` роняет `story:*`.
