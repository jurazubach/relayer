# Наши уроки (`LOCAL-NN`)

Что мы узнали на своих историях, мутантах и прогонах скиллов. Это не база (`docs/books/`) и не свод
(`rules.md`): урок держится на нашем замере и записан в журнале `docs/lab/journal.md`. Формат: **было →
поменяли → результат**. Если правка ещё не сделана, в «поменяли» стоит, что предложено и кому, а в «результат» —
чем это проверено и что осталось открытым. Класс доказательства — как в `lessons.md` скиллов: A — наш эксперимент
или замер, B — постмортем с цифрами, C — мнение. Числа — только ключами `thresholds.json` или ссылкой на прогон.

Скилл, которому урок нужен, ссылается на него по ID (`LOCAL-NN`) из своего `lessons.md`, а не переписывает.

## LOCAL-01 · Длину «Чужого голоса» держат паузы внутри глав, а не только ночные

- **Было:** считали, что история длиннее потолка `story.length.max_h` из-за ночных пауз, и чинить надо их.
- **Поменяли:** ничего. Э1 разложил длину по видам пауз (`story:sessions`, персона `random`).
- **Результат:** даже если убрать все ночные паузы, история остаётся выше потолка. Почти половину длины дают
  средние паузы внутри глав, от 1 до 6 ч; чаще всего — по 1–3 ч (`docs/lab/baseline.md`, «Главное», п. 1).
  Ремонт длины (`story-time`, `story-fix --compress`) начинается с них. Класс A. Журнал: 2026-10-25 · Э1 · T-15.

## LOCAL-03 · `Bash(npm run story:*)` не пропускает ни одной команды `story:*`

- **Было:** скиллы (`allowed-tools`), `scripts/lab/skills-test.mjs` (`ALLOW`) и шаблон скилла писали
  `Bash(npm run story:*)`. Хвост `:*` равен « *» с пробелом, поэтому `npm run story:lint` под правило не подходит.
  В `claude -p` каждый прогон `story-choices` получал два отказа и запускал `node scripts/lint/lint.mjs` в обход,
  без `--json` из своего шага 2.
- **Поменяли (предложено королеве):** `Bash(npm run story*)` и `Bash(npm run -s story*)` в `allowed-tools` скиллов,
  в `ALLOW` у `skills-test.mjs`, в шаблоне `prompts/type-skill.md` и в `claude-code-format.md` §9.
- **Результат:** проверено в `claude -p`: старое правило даёт отказ, новое — ok, в том числе с `2>&1 | head`
  и в `allowed-tools` самого скилла без внешнего `--allowedTools` (`docs/lab/runs/X-E2mini/permissions.md`).
  Класс A. Журнал: 2026-10-25 · X-E2mini.

## LOCAL-04 · Модель повторяет ложные срабатывания замера, не сверив их с ink

- **Было:** в шаге 7 `story-choices` суждение модели работает «там, где замер молчит», а находки замера идут
  в отчёт как есть.
- **Поменяли (предложено королеве):** перед отчётом каждая находка замера сверяется с узлом ink и с текстом
  правила (`npm run story:rule R-NN`). Не подтвердилась — `// намеренно: C-NN` или «ложное: <почему>».
- **Результат:** на «Слепом пятне» все ложные находки — из этого источника: C-17 (выбор адресата действия
  принят за дилемму R-49), C-19 (хаб порядка без раннего выхода), C-04 по `rotate_full` (отклик есть в
  `ch3_ghost_locked`). Один прогон из двух сам заметил C-04. Все находки с пометкой «модель» верны. Класс A,
  два прогона. Журнал: 2026-10-25 · X-E2mini.

## LOCAL-05 · Скрытый штраф теряется в списке молчащих переменных

- **Было:** echo-map и C-03/C-04 дают список «переменная пишется → читается только в финале». Скилл перечисляет
  его подряд.
- **Поменяли (предложено королеве):** отдельный шаг для каждой переменной из условия финала: какие кнопки её пишут
  и есть ли у них сигнал цены до нажатия (C-03 × C-08, R-47). Естественная кнопка («кто это?»), которая скрыто
  двигает к плохому финалу, — отдельная находка P1.
- **Результат:** SP-02 (P1) прямо назван в одном прогоне из двух, во втором — только как имя в списке.
  Класс A, два прогона. Журнал: 2026-10-25 · X-E2mini.

## LOCAL-06 · «Кнопка одному, отвечает другой» видит только модель

- **Было:** C-10 проверяет, есть ли у кнопки свой ответ. Кто отвечает, он не смотрит.
- **Поменяли (предложено королеве):** подпроверка C-10. Если кнопка `#to:A` сразу уходит в узел, где первая
  реплика `#from:B` (B ≠ A), а от A ответа нет, — «ответил не тот». Мутант на неё — в набор зоны `story-choices`.
- **Результат:** в «Слепом пятне» (`ch3`: «Рита, сначала алерт…» → отвечает Кай) находку нашли оба прогона,
  среди 28 находок свода её нет. Класс A. Журнал: 2026-10-25 · X-E2mini.

  выборка для команд — мутанты и новая история (Э4). Класс A. Журнал: 2026-10-25 · X-E2mini.
